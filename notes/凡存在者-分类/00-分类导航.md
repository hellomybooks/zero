# 《凡存在者，必有其界》—分类资料导航

这是对共享会话原内容的二次整理入口。原始资料按原会话版本拆分，分析资料按创作用途拆分。

## 0｜当前 Canon 入口

先读：[CANON / 唯一真源 v1.0](./07-CANON-唯一真源-v1.0.md)

这份文件已经吸收原始对话的核对结果，优先处理以下关键修正：

- v1—v7 是不同维度的设计文档，不能用 v7 覆盖全部前文。
- Zero 与 Alpha 相关，但不能写成 Zero = Alpha。
- “第一观察者”是故意的错误称呼，真实词是 Observed / 被观察者。
- Mat、OpenCV、Layer、Channel 都是 Representation，不是世界本体。
- 终极母题是“描述不等于世界本身”，而不只是“谁定义计算规则”。

## 三、推荐阅读顺序

1. 先读本导航。
2. 读 v5，确认人物不能被写成职业模块。
3. 读 v6，确认 252 章的情绪和关系如何移动。
4. 读 v7，确认第一卷具体每一章要发生什么。
5. 写正文前查 04、05、06。
6. 需要核对原话时，再回到：[完整共享会话转录](../凡存在者-共享会话-完整转录.md)。
