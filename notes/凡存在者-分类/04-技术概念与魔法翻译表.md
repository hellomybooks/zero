# 技术概念与魔法翻译表

## 使用规则

这里的英文术语不是咒语。它们是任在理解当地规律后，为古代魔法语言建立的个人翻译。

每个概念必须：

1. 先以真实魔法现象出现。
2. 通过危险、谜题、战斗或社会规则体现。
3. 任在事后用熟悉的技术词给它命名。
4. 具备观察条件、失效条件和代价。
5. 推动人物或世界观，而不只是展示能力。

最高层限制：

> OpenCV、Mat、Layer、Channel 和“图像”都是 Representation，不是世界本体。

不能把结局写成“宇宙就是一张 Mat”。

## 第一层：任的能力线

| 概念 | 故事化能力 | 初期限制 | 人物意义 |
|---|---|---|---|
| Edge / Canny | 看见物体留下的边缘；白界视觉 | 只看见变化和交界，噪声过多时会过载；不能直接看见完整物体 | 任从逃命者变成观察者 |
| Contour | 将目标边界闭合，定义形状 | 目标边缘必须足够连续；火焰、烟雾和无界物会让闭合失败 | 任开始“定义问题” |
| Bounding Region | 圈定目标可能所在的范围 | 只能限制区域，不能证明区域内只有目标 | 任学习先改变问题规模 |
| ROI | 只观察一个有限世界区域 | 选错区域会漏掉真正危险；注意力被人为限制 | 任学习承认自己不必同时处理一切 |
| Mask | 预先定义 Inside / Outside，再强制比较 | 由任决定的区域可能伤害被排除者；定义本身带有权力 | 任从观察走向干预 |
| Layer | 把叠加结构拆开 | 拆解会暴露隐私、破坏关系和不可逆状态 | 对应任的工具化倾向 |
| Non-destructive Transform | 允许对象变化而不摧毁原有状态 | 不能恢复一个不存在的“原图”；不同对象可能需要不同策略 | 任最终学会允许变化 |

## 第二层：其他五人的视觉概念

| 人物 | 概念 | 故事表现 | 最终转化 |
|---|---|---|---|
| 零 | Alpha / Visibility / Existence Recognition | 覆盖、透明、内外区域；没有正常影子，只有外沿轮廓 | Alpha 是功能，不是零的完整身份；零最终自主定义自己 |
| 露米 | Channel / Color / Spectral Separation | 看见别人看不见的色差、频段和通道 | 不再问自己属于哪一类，而是选择如何使用标签 |
| 赛恩 | Geometry / Hough / Line / Circle / Perspective | 追求完美直线、精度和无误差术式 | Ground Truth 是他的哲学诱惑，不是魔法能力；最终接受噪声和偏差不是错误 |
| 伊莉亚 | Morphology / Erode / Dilate / Opening / Closing | 腐蚀、膨胀、净化、修复和重新连接；治疗只是表现 | 不再默认所有裂缝都应该修复，先判断什么应当保持开放 |
| 诺克 | Optical Flow / Tracking / Prediction | 看见运动方向、速度、轨迹和群体流 | 关闭预测，承认选择不能被概率代替 |

## 第一卷关键呈现顺序

1. 看不见的魔兽留下现实痕迹。
2. 白线只出现一瞬。
3. Edge 让任看见世界的边缘。
4. Contour 让复杂对象闭合。
5. Bounding 让火兽被限定在一小块区域。
6. Closing 让修复成为人格问题。
7. Foreground / Background 解释“敌人没有边”的真正原因。
8. Mask 让任先定义边界，再使对象显现。
9. Inside / Outside 让无界兽获得可攻击的身份。

## 必须避免

- 任说出函数名，魔法就自动成功。
- 一次能力成功后永久稳定。
- 术语解释取代了场景。
- 只写“很像 OpenCV”，却没有人物代价。
- 把当地术师写成无知的背景板；他们应当精通经验和结果，只是不知道底层原理。
