# 伏笔、反转与谜题登记表

## A. 任的身份线：Copy

### 第一卷只埋不证

- 没有穿越过程。
- 身体比记忆中更干净。
- 旧伤痕消失。
- 手机背面划痕位置改变。
- 没有 Source / 源痕。
- 检测器出现 SOURCE ERROR。
- “映入者”这个词暗示投影、观测或被写入。
- 水中倒影慢一帧。
- 地球任尚未出现。

### 第五卷集中回收

- Source = NULL。
- 任确认自己是 Copy。
- 地球任出现。
- 任的情绪不能只写成“我是谁”，还要写成“谁有资格被称为原本”。
- 任曾短暂希望地球任死掉，随后为此羞耻。

## B. 零的身份线：Zero / Alpha

### 第一卷只埋异常

- 没有正常影子。
- 只有最外沿轮廓。
- 光线穿过身体时表现异常。
- 不喜欢检测、档案和分类术。
- 第一卷不直接出现 Alpha 这个词。
- 价值焦虑来自“如果我没用，任还要不要我”。

### 后期回收

- Zero 与 Alpha / Visibility / Existence Recognition 高度相关，但不能写成 Zero = Alpha。
- Alpha 是零在世界系统中的功能之一，不是零的完整身份；这是专门留给技术读者的“猜中机制、猜错意义”反转。
- 零第一反应应是愤怒：找到分类不等于找到自我。
- 终局不是确认“我究竟是什么”，而是“不再需要这个答案”。
- 第 248 章，零第一次不等待任许可，自己选择改变。

## C. 世界本体线

- 古代文明早已掌握某种视觉/结构规律。
- 学院地下档案出现像函数调用的结构。
- 残碑露出 “...Mat...View...”。
- 遗迹出现 “THE WORLD IS NOT WHAT IS SEEN”。
- 残缺文字 OBSERVE_ 会让人物和读者误称其为 Observer / 第一观察者。
- 完整文字恢复后应为 OBSERVED / 被观察者；“第一观察者”只是故事中的错误称呼。
- 真正的问题变成“那么是谁观察了它？”。
- Mat / View 应导向 World View，而不是 cv::Mat world。
- OpenCV、Mat、Layer、Channel 和图像都是 Representation，不是世界本体。
- 第一卷让读者相信世界是程序或视觉计算世界。
- 后续必须证明这只是模型，不是完整世界。
- 最终问题升级为：如果我们只能通过某种 Representation 观察世界，所谓真实究竟是什么？是否存在唯一 Original？

## D. Ground Truth 线

- 赛恩相信存在可追求的完美结构。
- 第六卷揭示 Ground Truth 更接近 Annotation，而不是绝对真值。
- 露米较快接受，赛恩拒绝。
- 冲突不应写成赛恩看不懂证据，而是他追问：“知道没有真值之后，人要怎么办？”

## F. 第一卷的合理错误答案

读者在第 36 章应该暂时相信：

> 这是一个底层类似视觉计算的世界，古代文明已经把它写成了某种魔法程序。

这个答案必须：

- 足够漂亮。
- 足够合理。
- 足够能解释现象。
- 但不能是终极答案。

## G. 四个最高级认知爆点

1. 任没有穿越，而是跨世界观测后由有限信息重建出的 Editable Copy。
2. Original 未必存在唯一版本；Ground Truth 可能只是 Annotation。
3. Observer 实际上是 Observed；未知观察层仍在世界上方。
4. OpenCV、Mat、Layer、Channel 乃至图像都只是 Representation。
