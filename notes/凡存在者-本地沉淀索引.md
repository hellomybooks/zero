## 0. Canon 校准与当前状态

- 正式主角：任 / Ren；沈砚属于孤立草稿，非 Canon。
- 第一卷正式标题：《白色边缘 / White Edges》。
- OpenCV、Mat、Layer、Channel 和图像都是 Representation，不是世界本体。
- Zero 与 Alpha 相关，但不能写成 Zero = Alpha。
- Observer 是故事中期的错误称呼，真实词是 Observed / 被观察者。
- 第一卷仍要让读者相信“世界底层类似视觉计算”，但这是漂亮、合理、最终会被推翻的错误答案。
- 终极母题升级为：我们对世界的描述，不等于世界本身。

## 1. 故事核心

现代软件工程师进入真正存在魔法的异世界。

当地人能够使用火焰、结界、治疗、定位、空间等力量，却只会依赖古老术式和经验，并不了解力量的底层规律。主角把自己熟悉的计算机视觉思维带入这个世界，逐渐发现：

- 魔法不是念 API 名称。
- OpenCV 术语只是主角为古代魔法语言建立的翻译层。
- 每个“能力”都必须先作为真实魔法现象、战斗、社会制度或危险出现。
- 主角真正的优势不是 OpenCV，而是把混乱拆成可观察、可验证、可重组的问题。
- 技术能力解决外部问题，也暴露主角的内部问题，并且最终必须被角色自己推翻或超越。

全书核心问题：

> 如果世界可以被计算，那么是谁定义了计算规则？

第一卷的读者认知应经历：

> 什么鬼？ → 好酷。 → 原来魔法有规则。 → 主角好像真的能破解魔法。 → 等一下……这个世界为什么会出现他认识的东西？

## 2. 六人核心人物

| 人物 | 核心能力/视觉概念 | 内在问题 | 最终成长 |
|---|---|---|---|
| 任 REN | Edge、Contour、ROI、Mask、Layer、Non-destructive Transform；擅长分解问题 | 把人和关系工具化；害怕自己并不特别；后期发现自己可能是 Copy | 仍然分析和拆解，但先询问对方需要解决方案还是需要被倾听；不再强迫一切拥有统一答案 |
| 零 ZERO | 与 Alpha、Visibility、Existence Recognition 高度相关；负责执行、覆盖、建立内外区域；没有正常影子，只有外围轮廓 | 不知道自己是什么；害怕“没用”后被抛弃；厌恶检测、档案和分类 | Alpha 不是零的完整身份；零不再需要一个物种或源头定义，从“任需要我所以改变”走向“我自己选择改变” |
| 露米 LUMI | Channel、Color、Spectral Separation；能拆分颜色和魔法频段 | 被“异常”定义的童年；害怕真正被看见；一直追问自己属于哪个 Channel | 从“我属于什么”走到“为什么必须属于某一类”；仍珍惜身份，但把标签当成可选择的工具 |
| 赛恩 SAIN | Geometry、Hough、Line、Circle、Perspective；后期与 Ground Truth 冲突 | 把优秀和被爱绑定；无法容忍误差；嫉妒任的快速理解 | Ground Truth 是哲学诱惑而非魔法能力；接受世界没有完美结构，允许偏差和噪声存在 |
| 伊莉亚 ELIA | Morphology、Erode、Dilate、Opening、Closing；治疗只是表现 | 通过让所有人需要自己来避免被抛弃；无法容忍裂缝和离开 | 不再默认别人需要被修复；先判断什么应当修、什么应当保持开放 |
| 诺克 NOX | Optical Flow、Motion Estimation、Tracking、Trajectory Prediction | 因害怕做错而躲在概率后面；把选择伪装成预测 | 模型失效时不再强行计算；承认选择不能被数据代替，最终可以只因为“太阳好看”而决定方向 |

### 六人设计总原则

六人不能只是“主角、女主、宿敌、奶妈、侦察、宠物”。他们首先是六个彼此无法完全理解的人。

每个人的能力都必须同时：

1. 解决外部问题。
2. 暴露内部问题。
3. 最终被这个人自己推翻一次。

全书 21 个篇章，每 12 章至少要同时改变：

- 世界认知。
- 至少一个人物。
- 至少一段关系。
- 至少一个旧伏笔的意义。

人物不应在每一章平均出现。252 章总体情绪权重建议：任 100%、零 95%、露米 75%、赛恩 70%、伊莉亚 60%、诺克 55%；每个 12 章篇章只让 1—2 人真正成为情绪中心。

## 5. 技术概念如何转成故事能力

| 概念 | 故事中的第一层含义 | 人物/主题方向 |
|---|---|---|
| Edge / Canny | 发现对象留下的边缘；看见问题而非完整答案 | 任从猎物变成观察者 |
| Contour | 把复杂目标的边界闭合，定义它是什么 | 任开始定义问题 |
| Bounding Region / boundingRect | 先圈出目标属于哪一块区域 | “哪里是火”比“如何灭火”更关键 |
| ROI | 限制问题的观察区域 | 不让整个世界同时成为问题 |
| Mask | 预先规定 Inside/Outside，再强制区分对象 | 任从观察走向干预 |
| Foreground / Background | 不是没有边，而是前景和背景未分开 | 物体是否独立存在的哲学问题 |
| Closing | 让破损区域重新连接，治疗与修复 | 伊莉亚必须学会不是所有裂缝都该补 |
| Channel / Color | 拆解不同颜色、频段和感知通道 | 露米拒绝由单一标签定义自己 |
| 几何/误差 | 结构、精度、完美形状 | 赛恩学习噪声和偏差不是错误 |
| Optical Flow / Tracking | 观察运动方向、速度、轨迹和群体流 | 诺克学习选择不是预测 |
| Alpha | 定义覆盖、透明、内外和存在区域 | 零从被归类走向自主定义 |
| Layer | 拆开叠加关系和隐藏结构 | 任最容易把伙伴当成可拆解模块 |
| Non-destructive Transform | 允许结构变化而不摧毁原状态 | 全书后期的 Non-destructive World 原则 |

重要约束：

- 术语应先以魔法现象、谜题、战斗或社会规则出现，随后才被任翻译成自己熟悉的词。
- 不使用“念 Canny 就释放 Canny”这种方式。
- 任主动进入白界失败的情节必须保留，用来证明理解规律比记住名称重要。
- 第一卷最强的“爽点”不是 API 彩蛋，而是改变问题的问法：从“怎么灭火”变成“哪里是火”。

## 6. 关键隐藏伏笔

### 任的身份

当前设计不直接证明他是 Copy，而是逐步制造异常：

- 没有穿越过程。
- 身体比记忆中更“干净”。
- 小时候的伤痕消失。
- 手机背面的划痕位置改变。
- 没有 Source / 源痕。
- 检测结果出现 SOURCE ERROR。
- “映入者”暗示被观测或投影进来。
- 水中倒影慢一帧。
- 第五卷确认任是 Copy；地球任出现后，身份问题彻底转为“谁有权被称为原本”。

### 零的身份

- 没有正常影子。
- 只有外围轮廓。
- 检测和光线表现异常。
- 与 Alpha 有关，但第一卷不直接出现 Alpha 这个词。
- 零最害怕的不是弱，而是被“没用”或某个分类替代。
- 它的最终成长不是获得正确物种答案，而是不再需要答案。

### 世界底层

- 古代文明似乎早已发现了类似视觉处理的规律。
- 地下遗迹包含像函数调用的符号。
- 残碑出现 Mat / View 片段。
- 第一卷结束时读者应相信世界就是程序或视觉计算世界。
- 这只是第一层真相，后续必须推翻“世界只是程序”的解释。
- 最终问题不是“API 谁写的”，而是“谁定义了可计算的对象、边界、真值和规则”。

## 7. 关键关系曲线

- 任 × 零：陌生 → 互相依赖 → 伙伴 → 任把零当研究对象 → 零害怕被抛弃 → 决裂 → 分离 → 重新建立信任 → 不属于彼此但选择彼此。
- 任 × 露米：互相好奇 → 感知与系统互补 → 任的保护变成剥夺选择 → 关系进入成熟的边界与投射问题。
- 任 × 赛恩：互相佩服 → 双向嫉妒 → 几何与分解的理念冲突 → 对“真值”和制度的分歧。
- 零 × 伊莉亚：从治疗与被救开始形成特殊信任；两人都面对“有用”与“被需要”的问题。
- 露米 × 赛恩：异常感知与完美结构之间的长期摩擦，最终触及“标签”和“真值”。
- 六人团队：不能靠一次演讲永久团结；第五卷后半团队必须真正解散，第六卷开始分别带着自己的答案回来。

## 8. 全书最终原则：Non-destructive World

第七卷最终不在三个单一方案中选择：

- Flatten：把世界压平。
- No Boundary：取消边界。
- Restore Original：恢复所谓原图或原始状态。

任的成长是说：

> “这三个问题本来就不是同一个问题。”

最终世界允许不同区域、不同生命、不同历史采用不同策略，而不是强行给一切套用同一个最优解。

## 9. 正文写作护栏

- 保持神秘、奇幻、探索感；技术概念藏在世界现象内部。
- 每个新概念必须伴随具体事件、谜题、危险或关系变化。
- 主角不能一开始无敌；能力必须有噪声、失效、观察条件和代价。
- 少量现代幽默可以来自任的工程师习惯，但避免互联网梗泛滥。
- “首先……”可以作为任的生活化固定笑点，但不能让他变成说明书。
- 任不是冷酷寡言型主角，他其实爱解释；问题在于他经常解释系统，却没有先理解人的情绪。
- 六人不能被简化成能力模块；能力只是他们理解世界的方式。
- 不要过早解释 Copy、Alpha、古代文明和世界本体。
- 第一卷结尾要留下一个合理但错误的答案，同时让读者迫切想知道它为什么会错。
- 正文应优先写场景、动作、感官、对话和后果；设定说明只能嵌入冲突。
