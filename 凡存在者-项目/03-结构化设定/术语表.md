# 术语表

## Canon 术语

| 术语 | 当前正式含义 |
|---|---|
| 任 / Ren | 正式主角 |
| 维亚 / Veyra | 故事世界 |
| 视术 / Sightcraft | 当地魔法体系 |
| Representation | 观察者接触世界的一种表示/接口 |
| Editable Copy | 任的真实身份方向 |
| Original | 角色和读者追寻的“原图”概念，未必存在唯一版本 |
| Ground Truth | 赛恩的哲学诱惑；后期可能只是 Annotation |
| Annotation | 对世界的标注或解释，不自动等于真值 |
| World View | 对世界的视图，不等于世界本体 |
| Boundary Form / 定界态 | 零在第一卷末的重要形态 |
| Non-destructive World | 最终原则，不是简单第四种统一方案 |

## 故意的错误称呼

| 错误称呼 | 后来修正 |
|---|---|
| Zero = Alpha | Alpha 是零的功能之一，不是零的完整身份 |
| 第一观察者 / Observer | 真实文字是 Observed / 被观察者 |
| 世界是一张 Mat | Mat 是表示/视图，不是世界本体 |
| Ground Truth 已经被证明 | Ground Truth 可能只是 Annotation |
| 沈砚 | 非 Canon 草稿；正式主角是任 / Ren |

## 任的翻译层

这些词是任对古代视术规律的命名，不是当地人的原生 API：

Edge、Canny、Contour、ROI、Mask、Layer、Morphology、Hough、Optical Flow、Threshold、Channel、Perspective、Representation。
