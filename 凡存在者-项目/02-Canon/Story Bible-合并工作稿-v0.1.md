## 1. 一句话定位

一名现代软件工程师在维亚醒来。他把计算机视觉知识当作理解视术的翻译工具，逐渐从“看见世界”走向“质疑所有观察方式”，最终发现描述、分类和边界都不能代替存在本身。

## 2. 主题阶梯

1. 如果世界可以被计算，谁定义计算规则？
2. 如果世界可以被观察和重建，谁见过原图？
3. 如果我们只能通过 Representation 观察，Ground Truth 是什么？
4. 我们对世界的描述，不等于世界本身。

最终表达：

> All things may have an edge. But no thing is only its edge.

## 3. 世界与视术

### 世界

- 名称：维亚 / Veyra。
- 当地魔法：视术 / Sightcraft。
- 当地人擅长结果和经验，不知道底层规律。
- 任使用 OpenCV 等现代概念翻译规律，但 OpenCV 不是世界源码。

### 视术写作规则

- 先出现现象，再由任命名。
- 每个术式有观察条件、输入、输出、失效条件和代价。
- 观察不等于控制；定义边界会带来排除和权力。
- 当地术师的经验必须真实有效，不能写成等待主角解释的背景板。
- 术式失效是世界规则的一部分，不是作者临时削弱主角。

## 4. 六人

### 任 / Ren

- 身份：现代软件工程师；后期方向是 Editable Copy。
- 能力弧：Edge → Contour → ROI → Mask → Layer / Decomposition → Non-destructive Transformation。
- 人格问题：拆解能力强，但容易把人和关系工具化。
- 最终：仍然分析，但不再把分析结果当作对象本身。
- 最终命题：理解 ≠ 拥有。

### 零 / Zero

- 任的核心伙伴。
- 异常：没有正常影子，只有边缘式形态。
- 功能方向：Alpha / Visibility / Existence Recognition。
- 禁区：不能写成 Zero = Alpha。
- 人格问题：害怕没用、被分类、被抛弃。
- 最终：不再需要别人告诉它是什么。
- 最终命题：看不见 ≠ 不存在。

### 露米 / Lumi

- 能力：Channel / Color / Spectral Separation。
- 经历：童年举报能看见异常通道的母亲，并曾因母亲被带走而短暂轻松。
- 人格问题：标签、羞耻、身份和被看见的恐惧。
- 最终：不再让 Channel 决定她是谁。
- 最终命题：标签 ≠ 身份。

### 赛恩 / Sain

- 能力：Geometry / Hough / Line / Circle / Perspective。
- 人格问题：把完美和被爱绑定。
- Ground Truth：思想诱惑和政治立场，不是单一魔法能力。
- 最终：接受误差和噪声。
- 最终命题：误差 ≠ 错误。

### 伊莉亚 / Elia

- 能力：Morphology / Erode / Dilate / Opening / Closing。
- 人格问题：通过让别人需要自己来避免被抛弃。
- 最终：判断哪些裂缝应该修，哪些裂缝应该保留。
- 最终命题：裂缝 ≠ 失败。

### 诺克 / Nox

- 能力：Optical Flow / Motion / Tracking / Prediction。
- 人格问题：躲在概率之后，逃避选择责任。
- 最终：即使不确定，也承认“这是我选的”。
- 最终命题：不确定 ≠ 无法选择。

## 7. 高级反转

- SSS-1：任没有穿越，而是跨世界观测后重建出的 Copy。
- SSS-2：Original 未必存在唯一版本。
- SSS-3：Observer 是错误称呼，真实是 Observed / 被观察者。
- SSS-4：OpenCV、Mat、Layer、Channel 和图像都是 Representation。

## 8. 终局

三个极端方案：

- Restore Original：相信唯一正确原图。
- Flatten：把所有 Layer 压成单一状态。
- No Boundary：消灭所有边界和分类。

最终方案：

> Non-destructive World

它不是第四种统一世界，而是一套允许改变、组合、拆解、保留历史信息并容纳不同局部策略的原则。

## 9. 写作生产规则

- 结构化设定不能直接替代正文。
- 正文不能悄悄改变 Canon。
- 新概念先写事件，再写术语。
- 读者必须能在没有编程经验的情况下理解魔法结果。
- 任不能靠知道函数名获胜。
- 每章至少改变一个危险、关系、规则或伏笔。
- 第一卷必须给出一个漂亮但错误的世界模型。
- 所有未确认内容标记为“工作假设”。
