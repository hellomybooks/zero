# 02｜Canon 层

Canon 是正式设定的唯一真源。它控制世界规则、人物根性、长期真相、开放谜团和已经确认的连续性事实。

## 变更规则

- 新设定先对照唯一真源。
- 与 Canon 冲突时，先登记冲突和影响范围，再决定是否进入 Canon Change。
- 正文、章节卡和原始资料都不能静默替代 Canon。
- `CANON-*.md` 的正式入口必须保持唯一；验证器会检查这一点。
