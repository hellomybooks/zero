# 正文写作执行清单

## 每章必查

- [ ] 本章有一个具体事件、危险、谜题或关系冲突。
- [ ] 新概念首先以可感知的魔法现象出现。
- [ ] 任没有因为知道术语就自动成功。
- [ ] 能力有观察条件、限制、失效或代价。
- [ ] 本章至少推动一项：人物关系、世界认知、伏笔意义、社会规则。
- [ ] 章末有行动钩子、信息钩子、身份钩子、视觉钩子、情绪钩子或哲学钩子之一。
- [ ] 技术解释没有占据主要篇幅。
- [ ] 当地人的经验和魔法传统仍然有价值。
- [ ] 场景保留奇幻感，不被现代互联网梗打断。

## 主角任的专用检查

- [ ] 他是否先观察，再命名？
- [ ] 他是否把复杂问题拆开了？
- [ ] 他是否把某个人错误地拆成了几个模块？
- [ ] 他是否把“解决问题”误当成“理解对方”？
- [ ] 他是否有一次无法技术化的情绪或选择？
- [ ] 他是否正在从控制变化，走向允许变化？

## 零的专用检查

- [ ] 零是否有独立选择，而不是只负责卖萌或执行？
- [ ] 它是否害怕被分类、被检测或被判断为没用？
- [ ] 它与任的关系是否避免主人/宠物模式？
- [ ] 它的玩笑是否在遮掩真实恐惧？
- [ ] 它的进化是否来自自己的选择？
