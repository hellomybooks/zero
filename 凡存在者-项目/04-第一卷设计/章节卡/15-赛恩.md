# 第 15 章场景卡：《赛恩》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 15
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；赛恩的内心不直接揭示，只通过礼貌、动作和术式结果观察
- 承接：第14章测试后，高值新生停步看封存纸板并向任礼貌点头；任公开记录为 0 / 零级，Undefined 仍被长老封存。第15章正式揭示高值新生姓名为赛恩。
- 核心功能：正式引入赛恩；让任第一次直观看到与自己完全不同的、稳定而精确的几何视术；让赛恩以礼貌和认真观察制造压力，不以羞辱制造冲突；让任真心佩服赛恩，同时第一次感到自己可能被“精准、等级和比较”衡量；为第16章露米登场和后续赛恩的嫉妒萌芽建立关系底色。

## 本章必须完成的事

1. 赛恩正式自我介绍或被教师点名；他礼貌、克制，不以贵族口吻羞辱任，不在本章展开家庭、父亲来信或完整世家背景。
2. 课堂/练习场先出现真实的几何魔法现象：教师给出不规则石台、偏斜标杆和缺口圆环，学生需要用固定支点、线材、金属环或几何刻痕建立稳定结构。赛恩用精确几何术完成全场效果。
3. 赛恩的术式必须具有规则和限制：至少需要明确支点、稳定平面、足够光线或可验证的角度；支点移动、地面震动、目标不在同一平面或信息不完整时，几何术会偏移、断裂或无法闭合。赛恩强大在精度与控制，不是无限能量。
4. 赛恩的第一次正式演示要形成“全场碾压”的视觉结果，但不是无代价破坏：他让散乱的石片、金属线和光圈归入完美直线/圆弧结构，完成教师要求，其他新生的尝试明显失败。
5. 任必须先真心佩服，再产生不舒服。佩服来自他看见精度、稳定和可复现；不舒服来自赛恩的礼貌比较、任无法重现白界、自己刚被归为零级，以及“完美结构”似乎比人更容易获得信任。
6. 任不能用白界或 Canny 解释/破解赛恩术式；他只能观察支点、线段、角度和误差，并提出一个关于“如果支点本身不可靠”的具体问题。赛恩给出礼貌而有限的回答，不解决更深层问题。
7. 赛恩与任产生第一次真正的对话：赛恩不把任看成笑话，询问他对边缘、界视或测试异常的观察；任不透露世界本质，只回答自己看到的是变化留下的边，不是对象本身。
8. 章末不让赛恩出现嫉妒或反派宣言；只留下两个平行信号：赛恩对任产生研究兴趣，任在离开练习场时仍记着那条没有误差的线，并发现自己不愿承认那条线让他感到压力。第16章进入露米和颜色/通道问题。

## 本章不能做的事

- 不能把赛恩写成傲慢贵族模板，不能让他当众羞辱任、命令任或用家世压人。
- 不能把“完美几何术”写成无条件自动成功；必须展示支点、平面、角度、光线或稳定条件。
- 不能让任因为懂数学或计算机就立刻破解赛恩；任只能看出结构化方法，不能复制结果。
- 不能在本章引入 Hough、Ground Truth、Contour、Bounding Region 等正式技术术语；几何概念先作为魔法现象出现。
- 不能解释赛恩的家庭创伤、父亲评价、政治立场或 Ground Truth 哲学；这些留给后续章节。
- 不能让赛恩已经嫉妒任；本章是“兴奋和认真观察”的起点，嫉妒以后从比较与评价中生长。
- 不能让任的零级测试结果被赛恩解释为无能；赛恩只能承认测试输出和观察能力是两件未必相同的事。

## 几何练习规则（作者侧）

- 练习场中央有一块略微倾斜的黑石台，台上插着三根高度不同的短标杆，标杆之间挂着松弛金属线。
- 学生要让金属线围出一个稳定圆弧，并让另一条线从指定支点穿过石台上的两个刻痕；支点一动，线就会偏移。
- 普通新生通过反复调节线材和位置勉强完成，结果带有明显误差；赛恩先确认三根标杆和石台平面，再用少量术力让线材自行归位。
- 赛恩的完美结果依赖观测到的支点和当下平面；教师故意让一枚标杆轻微下沉，赛恩的圆弧出现一处细小颤动，他必须立即修正。不要写成绝对无误的神迹。
- 任看见赛恩不是“画出一个圆”，而是先让一组分散关系稳定下来，再让圆弧显形；任的佩服与不适都来自这里。

## 场景推进

### 场景一：名字与礼貌

- 第14章测试后，学院把新生按基础课程重新分组。负责几何练习的教师点名一名高值新生：“赛恩。”
- 赛恩向教师行礼，再向任点头。他不提 0，不提 Undefined，也不提任的村庄经历，只说自己希望看看任在现场如何判断边界。
- 任感到这份礼貌比嘲笑更难处理：嘲笑只需要反驳，认真观察却像一面擦得很干净的镜子。
- 赛恩在队伍里站得不靠前也不靠后；其他学生自然给他留出位置，但他没有要求。学院的比较秩序通过他人的动作出现，不通过赛恩自夸出现。

### 场景二：不规则石台

- 几何教师把新生带入一处半开放练习场。黑石台略微倾斜，三根短标杆高低不同，松弛金属线在风里晃动。石台四角各有一块白石安全标记。
- 教师要求每个人完成两个结构：让一条金属线经过石台上的两个刻痕；让另一条线围出不碰到第三根标杆的稳定圆弧。
- 第一名学生把线拉得太紧，圆弧从中间断开；第二名学生忽略石台倾角，线在另一侧抬高；第三名学生用力过大，标杆被拽歪，安全线发出短鸣。
- 任没有进入练习区。他站在外侧，看见所有人都在试图直接修正线，却很少有人先确认三根标杆的相对位置。
- 教师要求下一组重新摆放标杆。赛恩没有马上动线，而是蹲下看石台上的水痕、支点和刻痕，先确认平面正在向哪边倾。

### 场景三：赛恩的精确术式

- 赛恩向教师确认：“支点以现在的位置为准？”教师回答“以现在为准”。这句话锁定术式的观察条件，也让赛恩没有擅自改变场地。
- 他用三枚细小金属钉固定标杆，不是把钉子打得更深，而是让三枚钉子与石台刻痕形成一组可重复的参照。金属线在他没有直接触碰的情况下开始收紧。
- 第一条线从一个支点穿过两个刻痕，光沿线亮起；第二条线绕过第三根标杆，弧线在黑石台上闭合。线与弧同时完成，误差小到肉眼几乎看不出。
- 练习场出现一阵低呼。刚才失败的学生看着自己的歪线，教师没有批评他们，只让他们站远一点观察赛恩如何先处理支点。
- 赛恩的术式不是爆炸或巨大光柱，却让整个不规则石台像突然承认了一套秩序：松线停止晃动，石片边缘彼此对齐，圆弧与两条直线在同一平面上稳定下来。
- 任真正被震住。他想起自己在村庄里只能从一闪而过的边缘里寻找运动；赛恩却让边缘本身服从精确关系。

### 场景四：完美出现裂缝

- 几何教师故意用脚尖碰了一下最低的标杆，让它下沉不到一根指节。赛恩的圆弧立刻出现细微颤动，闭合处亮度变薄。
- 赛恩没有维持表面完美。他先让圆弧松开，再重新固定支点；这一瞬间让任看见几何术不是无代价的绝对控制。
- 赛恩修正成功，但教师指出：“你修的是当前平面，不是刚才那一个。”赛恩点头接受，没有把偏移归咎于术具或学生。
- 任注意到赛恩的精度依赖他对支点、平面和当前条件的承认；这与任对“白界可否重开”的执拗不同。任第一次既羡慕这种稳定，又怀疑它是不是也会把变化排除在外。

### 场景五：任的问题

- 赛恩主动走到任旁边，问任在村庄里是不是通过边缘判断移动对象。任回答“只看见变化留下的边，不知道里面是什么”。
- 赛恩没有立刻纠正。他问：“如果边缘本身来自错误的支点呢？”
- 任看向黑石台上刚刚修正的圆弧，回答：“那就算得再准，也只是把错误固定得更漂亮。”
- 这句话让周围两名新生听见，却没有引起争吵。赛恩认真想了一会儿，说：“所以支点要先被证明。”
- 任问：“谁来证明？”赛恩没有给出完整答案，只说：“通常是更早的线。”这句话保留他的几何信念与未来 Ground Truth 诱惑，但本章不解释。
- 任意识到赛恩不是在试探他是不是零级，而是在确认他如何提出问题；这让任感到被尊重，也感到自己正在被放在一张更精细的比较表上。

### 场景六：两种稳定

- 教师让任和赛恩各自站在石台两侧。任被要求描述刚才圆弧最先发生变化的位置，赛恩被要求在不移动标杆的前提下恢复稳定。
- 任指出圆弧靠近最低标杆的位置先变薄；赛恩根据这句话调整金属线。任的观察和赛恩的几何术第一次形成协作，但任没有因此复制赛恩的能力。
- 圆弧重新稳定。教师承认任提供了有用的异常位置判断，却没有因此修改任的零级记录；能力价值和等级记录在本章第一次被明确分开。
- 赛恩向任道谢，语气平常，不带施舍。任却因为这个道谢更不舒服：对方的精确已经足够强，不需要借礼貌来证明优越。

### 场景七：章末关系钩子

- 练习结束后，学生们收回金属线和标杆。其他人开始讨论赛恩的读数和术式，赛恩却独自检查三枚固定钉是否松动。
- 任仍站在石台旁，盯着圆弧最后留下的浅光。它已经消失，只剩石面上三处支点和一条几乎看不出的划痕。
- 赛恩问任：“你的白界也有支点吗？”
- 任回答：“我不知道。它从来不听我的。”
- 赛恩没有笑。他只是把一枚固定钉收进布袋，说：“那很值得研究。”
- 任本来应该因为这句话高兴，却先感到肩膀发紧。他不想再成为一张被别人解读的图，也不想否认有人终于认真看他。
- 赛恩把其中一枚固定钉递给任：“你刚才指出最先变薄的位置。”任接过那枚普通金属钉，没有把它当作礼物，只把它握在掌心。
- 章末停在任回到外院侧廊：零在暗处看着他手里的金属钉，赛恩的圆弧已经消失，但任仍然记得它没有误差的样子。第16章《第四种颜色》从“看见同一阵法的不同颜色”开始，不提前引入露米。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 公开零级、私下 Undefined，刚经历被数值化 | 真心佩服赛恩的精度，同时开始抗拒被比较；发现自己的观察也能参与正式术式 |
| 赛恩 | 高值新生，礼貌观察任 | 正式进入主线；对任产生研究兴趣，不是嫉妒或敌意；展示精确几何术与条件限制 |
| 零 | 在外院侧廊保持独立观察 | 不解释赛恩的术式或任的反应，只通过观察金属钉和暗处保留自己的判断 |
| 学院同学 | 以读数比较新生 | 把赛恩视为精度标准，把任视为异常零级；比较秩序变得更具体 |

## 读者此时应该误判什么

- 赛恩的礼貌只是更高级的傲慢，他之后必然成为羞辱任的对手。
- 几何术的完美结果说明赛恩已经掌握了世界的真实结构。
- 任只要理解几何原理，就能复制赛恩的术式。
- 任与赛恩的差异只是数值高低，任的边缘观察不具备正式价值。
- 零观察金属钉是在嫉妒赛恩或替任不满。

## 本章新增或推进的世界规则

- 几何视术需要可确认的支点、平面、刻痕和当前观察条件；支点移动或平面改变时，完美结构会先出现细微裂缝。
- 精确术式可以让分散结构稳定成直线和圆弧，但精确不等于理解对象本身，也不等于永远不变。
- 任的局部变化判断可以辅助传统几何视术，却不能替代几何术式本身；等级记录与实际观察价值可以分离。
- 学院比较不只通过数字，也通过“谁的结构更稳定、谁值得被研究”形成；礼貌不等于没有压力。

## 技术概念与魔法翻译

- 先出现的现象：不规则石台、松弛金属线和偏移支点被赛恩整理成稳定直线与圆弧；任通过先确认支点和变化位置参与修正。
- 任的私人理解：赛恩不是凭空创造几何，而是在一组观察条件下让关系收束；本章不命名 Hough、Line、Circle 或 Ground Truth。
- 对应方向：为后续 Geometry / Hough / Line / Circle / Perspective 线建立人物与魔法基础；技术概念仍藏在练习、失败和比较中。
- 失败或代价：赛恩的圆弧会因标杆下沉而颤动；任不能复制稳定几何；两人都开始被学院和彼此的观察框定。

## 连续性与伏笔登记

- 延续 `REN-04`：任被 0 / Undefined 数值化后，面对新的精度比较。
- 延续 `ACAD-02`、`SOC-03`：学院测试和课堂结果都可能把表现压缩成等级或标准。
- 延续 `S-01`：0 / Undefined 不在本章解释，赛恩只观察任的异常而不接触封存真相。
- 延续 `REL-02`、`Z-07`：零不作为任的等级或关系附属物，也不因赛恩出现而宠物化反应。
- 新增候选 `GEO-01`：赛恩的几何术依赖支点、平面和当前条件；完美结构会因支点改变而裂开。
- 新增候选 `SAIN-01`：赛恩对任产生研究兴趣；本章不进入嫉妒，后续从比较与评价中生长。
