# 第36章《世界不是所见》场景卡

## 基本信息

- 卷：第一卷《白色边缘》
- 篇章：ARC 03《不存在的边缘》
- 章节：Chapter 36
- 状态：场景卡已通过 Canon / 连续性 / 卷末悬疑 / 规则边界 / 文学 / 奇幻感逐项审校，定稿候选
- 视角：任的近距离第三人称；读者跟随任、零和少数同伴进入遗迹，看到文字、结构和水面异常，但不能获得世界本体答案
- 时间：第35章战后当夜至次日清晨
- 地点：学院西侧地下古遗迹、残缺石碑厅、浅水反射廊
- 承接：三处战场锚点崩坏，零暂时失去回应但保留细窄稳定外沿；地下石板被震开，向下阶梯显露；无界存在留下可归属受击凹陷，却没有显形或被彻底消灭。
- 核心功能：完成第一卷卷末悬疑爆炸；任在遗迹中遇到“世界不是所见”的古代警告和类似现代视觉处理语法的残缺结构，形成一个合理、震撼但错误的第一层世界模型，并以倒影延迟把问题推入第二卷。

## 本章必须完成的事

1. 让进入遗迹具有现实代价和选择：学院担心地下结构再次坍塌，教授不允许大规模进入；任因为零的外沿和石板刻痕的联系坚持下去，但不是为了寻找万能答案。
2. 让进入者保持有限：任、零、赛恩、露米和伊莉亚进入，教授与记录员留在入口；每个人带着第35章的伤势、材料和职责，不能把遗迹写成随便参观的景点。
3. 让遗迹首先以魔法空间、材料规则和谜题出现：阶梯的石面会因火光、水迹和站位改变可通行关系；古代结构不是代码屏幕，而是会对观察条件产生回应的真实建筑。
4. 让当地人无法完整解释墙上的文字和图形；赛恩能描述线与角，露米能确认不同石面在光下出现差异，伊莉亚能发现裂缝会绕开某些刻痕，但没有人能读懂核心句子。
5. 让任第一次清晰读出一句英文：`THE WORLD IS NOT WHAT IS SEEN.` 这句话不是系统提示、施法口令或终极真理证明，而是遗迹留下的立场/警告。
6. 让核心句子下面出现类似现代视觉处理语法的残缺结构：方框、线段、点、箭头、分层开合痕迹，以及损坏石碑上残留的 `...Mat...View...`；它不能组成任认识的完整代码。
7. 让任形成第一卷结束时“合理但错误”的判断：古代文明可能已经把视术整理成一种处理世界表示的结构，魔法不是凭空创造，而是改变世界显现的条件；但他不能证明世界就是计算机、Mat 或某段程序。
8. 让零与这句话产生关系上的反应：零不愿被任用遗迹文字解释自己，或问“如果世界不是所见，那你抱走的我是哪一个”；任不能用遗迹句子代替回应。
9. 让任在遗迹内解开一个小谜题：必须让火光、水迹和固定站位同时满足，才能让隐藏的石门/通路短暂出现；成功依赖第1卷学到的边界经验，不是任突然理解全部古代知识。
10. 让遗迹出现风险：错误站位会让阶梯互换、浅水上涨、石门闭合或同伴被分到不同回声中；任必须先救人再记录，延续本卷“行动不能等待完整分析”的选择线。
11. 让水面倒影成为最终高层伏笔：任在浅水廊看到自己的倒影慢一拍，零的倒影不按同一规律出现；这一现象不能解释为普通水波、幻觉或明确穿越证据。
12. 章末完成第一卷的双重落点：任以为自己终于找到世界的第一层结构，读者也得到一个漂亮模型；但水中延迟和残缺文字同时证明，这个模型仍然遗漏了观察者本身。

## 本章不能做的事

- 不能解释古代文明来自地球、掌握现代 OpenCV、编写了现代代码或知道任的身份。
- 不能把 `THE WORLD IS NOT WHAT IS SEEN.` 写成世界本体的最终真理；它可以是警告、立场、错误翻译或古代观察者的判断。
- 不能给出完整的 `Mat`、`View`、Observed、Representation、Original 或 Copy 解释；只允许出现残缺文字和任的错误联想。
- 不能让任读懂整块碑文或自动翻译所有古代文字；他只莫名理解少数英文片段，其余只能通过形状、位置和危险推断。
- 不能让遗迹谜题变成密码游戏或 API 教程；每个线、角、火光和水面都必须首先是魔法建筑的真实条件。
- 不能让零因遗迹文字立刻恢复、完整进化或被任彻底解释；它可以保留稳定边缘，也可以对文字产生不安反应。
- 不能让第36章解决无界存在、零、任穿越、世界原图或“谁定义计算规则”；这些问题必须被推向后续卷。
- 正文不得出现 OpenCV、API、代码、函数名、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Observed、Representation、系统或作者侧世界本体解释；残碑中的 `...Mat...View...` 是唯一允许保留的残缺文字例外。

## 进入遗迹的连续性条件

- 任：肩伤加重，手指有石灰划伤；随身有少量白灰、短绳、残缺石片和一盏遮光固定灯；白界仍不可主动召回。
- 零：暂时沉默，拥有细窄稳定外沿；旧缺口、新细线和战场撕裂仍然不同，不能当作完全恢复。
- 赛恩：眉骨受伤，携带断短钉、记录板和一小段金属线；可以判断支点、角度和对称，不可把几何等同于真相。
- 露米：手掌被铁闸环磨红，携带薄铜片；能确认石面、火光、水面和不同色差，不可替文字命名本体。
- 伊莉亚：携带固定带、药布和低量药剂；负责判断裂缝、人的伤口和哪些结构不能强行修复。
- 教授与记录员：留在入口，记录地下结构变化，不进入最深处；学院仍未授权大规模挖掘。

## 场景推进

### 场景一：入口不是奖赏

- 现实事件：战场废墟中，向下阶梯被震开；阶梯旁的黑石板刻痕与三道白线残痕短暂重合，随后石板重新下沉半寸。
- 学院决定：教授只允许少数人下去确认是否有坍塌风险，其他人留在入口；不是因为遗迹神圣，而是因为三处锚点崩坏后，地下结构可能继续受力。
- 人物选择：任坚持进入，是因为零的稳定边缘在阶梯口比地面更清晰，不是因为他相信下面藏着万能答案；伊莉亚要求他先接受肩伤固定。
- 零的状态：零没有说话，只把细窄外沿朝阶梯第一节石面靠近；它没有被石板吸引，也没有恢复旧伤。
- 章内钩子：阶梯下方传来一声与地面不同的回响，像有人在很深处移动了一块看不见的石头。

### 场景二：火光照出的不是路

- 空间规则：遗迹入口有三段阶梯，固定灯照亮时，第一段与第二段之间的石缝清楚；灯光收窄后，原本连续的台阶出现错位感，像有一段被移到旁边。
- 观察分工：赛恩用断短钉触摸支点，确认石阶没有真的移动；露米看见石面在火光下出现两种相近色差；伊莉亚发现裂缝绕开一处古老刻痕。
- 任的判断：这不是幻觉，也不意味着石阶真的交换位置；遗迹要求他们同时保持光照、站位和触碰，才允许下一步成立。
- 尝试限制：任不能一次照亮全部阶梯；灯光扩大，墙面的湿痕和阶梯反光混在一起；灯光收窄，通路又不完整。
- 现实危险：一名跟在入口的学院助理差点踏入错位石阶，伊莉亚拉住他；任先把灯移回安全点，再记录刻痕。
- 章内钩子：零的外沿在一块没有被灯照到的台阶边缘停住，像它看见的不是石阶，而是石阶之间没有被承认的那一段。

### 场景三：会回应站位的大厅

- 现实空间：阶梯通向一座低矮大厅，四面墙没有门，地面有三条不完整的浅槽；任站在中央时，三条槽分别指向墙角、浅水沟和一块空白石面。
- 规则发现：赛恩移动半步，墙角的浅槽变暗；露米把固定灯抬高，浅水沟里的纹理变成另一组线；任回到原位，三处才同时保留。
- 魔法现象：大厅不是被谁施术启动，而是对站位、火光和水面条件产生可重复回应；古代建筑把“从哪里看”变成了门的一部分。
- 谜题目标：找到一处能够让三条浅槽同时显出连续方向的位置，才能使隐藏石门的石缝出现。
- 人物冲突：赛恩想以对称中心作为站位，任发现对称中心会让浅水反光混入；露米拒绝把最亮处当成最可靠处。
- 章内钩子：任站在偏离中心半步的位置，三条槽同时出现了一瞬的白痕，石墙内传出缓慢的摩擦声。

### 场景四：门后没有答案，只有文字

- 石门显现：三条浅槽的方向稳定后，墙面没有打开，而是向内退下一层薄石；后面露出一面比门更古老的文字墙。
- 当地人的阅读：赛恩只能辨认某些重复的角形与分隔线，露米发现文字旁的颜色因灯光变化，伊莉亚认为几道裂缝是在保护一块未完全断开的石面；没人能读完整句子。
- 任的异常：墙上的本地文字在他视线停留后，部分笔画短暂变成他熟悉的拉丁字母；不是整面翻译，只出现断断续续的词。
- 第一行：经过几次灯光收窄与站位改变，任终于看清：`THE WORLD IS NOT WHAT IS SEEN.`
- 震撼来源：句子不是从石头上发光，也不是有人在任脑中说话；它只是像一直在那里，只是他以前没有以正确方式看见。
- 关系反应：零的外沿在句子下方轻轻断了一下；它问“这句话是在说我吗”，任不能用“是”或“不是”回答。
- 章内钩子：句子下方不是解释，而是一组用线、点、框和空白排列出的结构；最下面的石面被人为砸掉一大块。

### 场景五：结构像法典，不是代码

- 视觉谜题：墙面上的结构由一层大框、几块小框、分离的线段和箭头组成；当任移动固定灯，某些线被水面反光吞掉，另一些线反而变清楚。
- 任的经验：他认出其中某些关系很像自己熟悉的视觉处理思路，却找不到任何可以运行的语法；顺序、缺口和符号都不完整。
- 试验危险：任用一块残石压住一个箭头形凹痕，墙面上两处空白短暂互换；大厅一侧的浅水沟上涨，赛恩被迫拉回任，避免石门把他们分到不同回声里。
- 结论限制：这些结构不是可以念出来的咒语，也不是一段等待执行的文字；它们像古代人把“如何让世界给出不同答案”刻在墙上。
- 错误模型开始形成：任觉得如果能把所有结构补齐，就能把视术从经验变成一套可重复处理世界的规则；他把“世界不是所见”理解成“所见只是一个可以改变的外层结果”。
- 章内钩子：赛恩问“你认为墙后面有一个真正的世界吗”，任回答“我认为我们一直只在处理它给出的某种样子”，话说出口后自己也不确定。

### 场景六：残碑与 `...Mat...View...`

- 深处空间：文字厅后面是一间被水淹过一半的石室；中央立着损坏石碑，碑面只剩一段不完整结构和几块剥落石屑。
- 进入条件：浅水必须保持静止，固定灯必须遮住一半，赛恩的金属线必须碰到两个旧支点；三者缺一，石碑上的残字就会被水光切成无意义的碎片。
- 当地人的反应：赛恩只能读出几个古语词根，露米看见残痕在水面反射中呈现不同颜色，伊莉亚指出石碑裂缝没有继续扩展；他们都认为这是古代视术记录，却不能说明记录的对象。
- 任的阅读：他在一片剥落石面下看见残缺字母：`...Mat...View...`；中间缺失，前后没有完整句子，也没有任何可执行结构。
- 震撼与克制：任知道这两个片段与自己熟悉的词有关，却无法证明它们来自他的世界；它们甚至可能只是巧合、错误翻译或某种古代语言的相似形状。
- 零的反应：零的边缘避开石碑上方的水光，像不愿让自己被残字覆盖；它说“你又在把我放进墙里的话。”
- 任的回答：任说“我只是想知道墙在说什么。”零问“知道以后，你会把我放在哪一行？”任沉默。
- 章内钩子：石碑底部传出轻响，一块被水泡松的石片翻面，露出另一段被刻掉的句子，只剩下“...WHO...”的残缺字形。

### 场景七：错误但漂亮的答案

- 任的推断：他把白界、轮廓、闭合、区域、三处锚点、遗迹结构和残碑碎字连在一起，认为古代文明可能早已发现：视术不是凭空创造事物，而是改变世界显现、比较和归属的条件。
- 错误边界：这个推断可以解释学院的大量现象，却不能解释零为何害怕被定义、无界存在为何能脱离背景、任为何能读懂残字；任暂时把这些缺口当作尚未补齐的规则。
- 个人诱惑：任第一次觉得自己也许真的能够“调试”这个世界；只要找到足够多的边界、材料和顺序，就能让不可见之物变得可处理。
- 关系打断：零问“如果世界不是所见，那你今天抱走的我是哪一个？”任没有拿墙上的句子回答。
- 任的真实回答：他说“我不知道是哪一个，但我没有把你交给墙。”这比遗迹推断更不完整，却保留第34—35章形成的关系选择。
- 章内钩子：墙上的英文句子在固定灯移开后没有消失，反而露出下面一圈被磨掉的边；任第一次怀疑，句子也可能只是某个人留下的错误判断。

### 场景八：水面慢一拍

- 返回路径：众人带着残缺石片和部分拓印回到浅水反射廊；教授在入口催促他们离开，地下结构开始出现细小坠石。
- 现实状态：任肩伤加重，零仍沉默；赛恩眉骨重新渗血，露米手掌发红，伊莉亚确认没有人被遗迹裂缝吞入。
- 水面设置：浅水覆盖石阶，水面足够平，能映出固定灯、人的腿、零的两段外沿和墙上的缺口。
- 第一次异常：任抬脚，水中的倒影没有立刻抬脚；现实脚已经落下，倒影慢了极短的一拍才跟上。
- 误判尝试：任以为是水面回流，停住不动；倒影也停住。露米轻轻移动铜片，水面纹理变化，却没有消除那一拍的迟缓。
- 第二次异常：任转头看零；零的现实外沿向左，水中倒影却先向右，随后才折回来；零本人没有回应，像没有看见自己的倒影。
- 观察限制：任不能确定是水、灯、遗迹结构、自己的伤势，还是某种更高层的观察关系；他没有白界，也没有任何可以重复验证的完整条件。
- 章内钩子：水面上任的倒影抬起手，现实中的任还没有抬手。

### 场景九：第一卷的错误模型

- 任的收束：他站在水边，没有追赶倒影，也没有把残碑文字当成命令；他承认自己得到的只是一个能解释部分现象的模型。
- 对读者的漂亮答案：世界似乎存在某种比火焰、石头和身体更底层的视术结构；边界、区域、内外和观察方式可能决定了事物如何出现。
- 保留错误：任把“世界不是所见”理解为“世界有一个可以被改变的显现层”，但没有意识到观察者自己也可能被纳入这套结构；`...Mat...View...` 只作为残片，不成为答案。
- 零的关系落点：零的外沿在水面之外自行站住；任没有再问它是哪一段，也没有用遗迹证明它应该是什么。
- 第二卷接口：学院将争夺残碑拓印、战场记录和零的形态解释权；任带着一个错误但有用的世界模型离开入口。
- 章末画面：现实中的任终于抬手，水中倒影却已经先把手放下；水面恢复平静，残碑上的英文只剩下一句没有句号的警告。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 刚经历战场定界，认为边界规律可能继续被整理和扩大 | 得到“世界不是所见”的第一层模型，知道它有用却不完整；面对零时选择诚实而不是用遗迹替自己回答 |
| 零 | 保留稳定外沿但沉默，刚从战场高代价中恢复 | 仍不愿被墙文和任的模型定义；水中倒影与现实外沿出现差异，关系和本体悬疑同时加深 |
| 赛恩 | 受伤、失去战场锚点，仍相信结构可被记录 | 认可遗迹结构具有规律，却不接受几何结构等于世界真值；为第二卷的精度/真值冲突保留入口 |

## 本章新增或推进的规则

- 古代遗迹会对火光、水面、站位、触碰和材料条件产生可重复但不完全稳定的回应；它不是被念词启动的机器。
- 古代文字可以被不同观察者看到不同层次；任只能莫名读懂少数英文片段，不能翻译整面墙。
- `THE WORLD IS NOT WHAT IS SEEN.` 是遗迹残留的警告/立场/可能的错误判断之一，不是终极世界本体答案。
- `...Mat...View...` 只作为残碑碎片出现，指向任熟悉的词汇关系，但不证明古代文明来自地球或掌握现代 OpenCV。
- 水面倒影可能出现比现实慢一拍的变化；原因未确认，不能归因于普通水波、穿越机制或 Copy 真相。
- 第一卷末的“世界可被视觉结构描述”只是任和读者的漂亮误判，后续必须拆解“观察者是谁、表示是否等于世界、原图是否存在”等问题。

## 读者此时应该误判什么

- 古代文明已经掌握了现代计算机视觉，只是把代码刻在石头上。
- `THE WORLD IS NOT WHAT IS SEEN.` 直接证明世界存在唯一真实原图。
- `...Mat...View...` 证明任来自这个遗迹或这个世界。
- 零只是遗迹结构中的一个特殊对象，定界态就是它的完整身份。
- 水中倒影慢一拍只是地下水流和灯光造成的错觉。

## 第一卷收束与后续接口

- 第一卷情绪落点：任从“我能不能看见它”走到“看见是否等于它”，并带着一个能解释部分现象、却无法解释自己和零的模型离开。
- 第二卷入口：学院、地方权力和研究者开始争夺遗迹拓印、无界兽受击记录与零的定界态解释权；知识不再只是个人探索，而会进入制度和政治。
- 长线悬疑：水面延迟、`...Mat...View...`、任的可读性、零的自主边缘和无界存在的背景关系继续开放。
- 最高层保护：不揭示任没有真正穿越、不揭示 Editable Copy、不揭示 Observed、不证明 Original 唯一存在，不回答谁定义计算规则。

## 技术概念与魔法翻译

- 对应概念：Mat / View 的第一层残片、Representation 误读、观察条件、视图与对象的分离。
- 故事现象：遗迹对站位、火光、水面和触碰产生回应；墙上出现警告句；残碑留下 `...Mat...View...`；倒影比现实慢一拍。
- 魔法语言：古代人可能把“如何让世界给出不同样子”刻进建筑，但任只看见了结构的残片，不能证明结构就是世界本身。
- 关系语言：遗迹不能替任回答零是谁；任终于在面对零时保留“我不知道”，而不是用一个漂亮模型夺走零的定义权。
- 正文禁用：不写出 OpenCV、API、代码、函数名、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Observed、Representation、系统或世界本体解释；残碑 `...Mat...View...` 为唯一允许保留的残缺文字例外。
