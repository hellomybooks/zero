# 第 4 章场景卡：《刚来的》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 01《白界》
- 章节：Chapter 04
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称
- 承接：第 3 章末，任在零经过的低坡上看见废弃猎人小屋的塌门；零已经转入旁边的窄土路
- 核心功能：让任第一次获得短暂遮蔽和真正的对话机会，同时埋下“刚来的”这一句的双义伏笔，把“也许能回去”的希望引入故事。

## 本章必须完成的事

1. 任根据自己的判断绕回小屋侧面的塌门，不是被零带进屋。
2. 任检查小屋，确认它废弃已久，但仍有可暂时休息的地方；遮蔽不等于安全。
3. 任逼问零这里是什么地方、零知道多少、有没有离开的办法。
4. 零只提供局部信息：这里被称为“维亚”，它知道得不多，也不能解释任如何来到这里。
5. 零问出：“你刚刚才来？”任误以为这意味着零见过其他从外面来的人。
6. 这句话的真实重要性只作为双义伏笔保留：零问的是“你是什么时候出现的”，不是“你从哪里来的”。
7. 零尝试处理第 3 章偷来的能量棒：包装打不开，最后直接连包装咬下；这是它第一次在任面前吃地球包装食品。
8. 夜里任醒来，发现零坐在小屋门口；任问“你不睡？”，零回答“我怕你跑了。”

## 本章不能做的事

- 不能确认存在其他穿越者或“穿越者群体”。
- 不能让零解释任来自哪里、为什么来到维亚、白线是什么。
- 不能让零成为地图、百科全书或可靠向导。
- 不能解释“刚来的”真正指向，也不能让零明确说“出现”与“来自”不同。
- 不能出现 Alpha、Copy、Observed、Mat、Edge、Canny、OpenCV 等后期或技术术语。
- 不能让小屋变成绝对安全区；夜间仍要有风声、远处震动或屋外的未知动静。
- 不能把零的“怕你跑了”写成撒娇；它应带有控制、恐惧和不愿失去的复杂性。

## 场景推进

### 场景一：任自己进入小屋

- 地点：猎人小屋侧面的塌门，窄土路从后墙绕到门前。
- 欲望：获得遮蔽物、可能的水源和一个能检查伤势的地方。
- 阻力：门框腐朽，屋内有霉味和旧兽皮的气味；屋顶漏风，角落有不知名的小动物留下的痕迹。
- 变化：任确认小屋虽然废弃，却能让他暂时不暴露在空地上；他把进入小屋当作自己的选择，不把功劳归给零。
- 感官锚点：潮湿木板、熄灭很久的灰、墙上褪色的刻痕、从屋顶漏下的一条灰光。

任进入后先把门虚掩，不彻底关闭；他要保留逃生路线，也要听见屋外动静。

小屋里有一只倒扣的陶罐，可能装过水，但通往那里的地板已经腐朽。任移动挡路的木架时，木架在地面上撞出一声闷响，门缝外的灰尘随之向内滑了一寸。他放弃立刻取水，选择先保留遮蔽；小屋因此成为一个带代价的临时选择，而不是静态背景。

### 场景二：逼问与双义问题

- 地点：小屋内的旧火塘旁。
- 欲望：建立一个最小的世界模型，知道自己身在何处，以及零是否见过和自己类似的人。
- 阻力：零只回答它愿意回答的部分，且常常把地点、时间和来源混在一起；它没有义务替任整理语言。
- 变化：任第一次听见“维亚”这个地名，却没有获得方向、地图或返回方法；他开始把零当作唯一可询问对象，又立即发现零并不可靠。

建议对话逻辑：

- 任：“这里是什么地方？”
- 零：“维亚。”
- 任：“维亚是什么？”
- 零：“这里。”
- 任追问：“有没有别人像我这样来过？”
- 零看着他：“你刚刚才来？”

任把这句话理解为：零可能见过其他“刚来的人”。零没有确认，也没有纠正；它只继续追问任是什么时候出现的。任对“有没有离开的办法”的追问，只得到零的“不知道”，或指向屋外某处的“那里没有”，不产生返回路线。

对话必须通过动作打断：屋外石缝方向传来一次闷响，任停下；零对屋门外的黑暗比对任的问题更在意。

### 场景三：包装打不开

- 地点：火塘旁的一块平石。
- 欲望：任想夺回第 3 章被偷走的那块能量棒，零想取出其中的食物。
- 阻力：包装已经被泥水和挤压弄皱，且任之前曾沿裂口撕开；零无法沿着已有裂口继续撕开，任的手指也仍然受伤。
- 变化：零试了几次，最后直接咬穿剩余包装；任第一次看到它粗暴处理地球物品的方式，不用主题总结替代动作。
- 视觉限制：不要把零的咬动作写成可爱动物表演；重点是它粗暴、有效、没有耐心。

任可以短暂解释“包装不是食物”，零回答“你把能吃的东西藏在不能吃的东西里”，把陌生感还给任。

### 场景四：夜里的门口

- 地点：小屋内部到门口的暗处。
- 欲望：任想在不安中睡着，并决定第二天是寻找水源、离开森林，还是继续跟着零。
- 阻力：伤口发热，屋外偶尔有远处的震动；任不确定门外的黑暗是否仍有追杀者。
- 变化：任半夜醒来，发现零坐在门口，轮廓挡住了门外一小片灰光。它不是在守护任，更像是在看守出口，也看守任。
- 关键对白：
  - 任：“你不睡？”
  - 零：“我怕你跑了。”

这句话同时推进两条线：任第一次感到自己可能被某个存在需要；零第一次暴露出对任离开的恐惧。不要立即把它解释成友情或依赖。

任原本计划天亮后独自离开，去找水和道路。听见这句话后，他没有把门彻底关上，也没有立刻离开；他决定至少留到天亮，先观察零和屋外的东西。这是暂时的生存选择，不是信任宣言。

## 人物情绪变化

- 开始：任把小屋视为临时工具，不愿承认自己需要零。
- 中段：听见“维亚”和“刚刚才来”后，任第一次产生“也许能回去”的希望，但这个希望建立在误解上。
- 结束：任发现零在门口看守，开始意识到自己并非只是被零顺手遇见；他仍不信任零，却无法把零当作普通野兽。

## 读者此时应该误判什么

- 零见过许多来自其他世界的人。
- 维亚存在一套成熟的“外来者”经验或接待规则。
- 零知道返回原来世界的方法，只是不愿意说。
- “我怕你跑了”只是嘴硬的陪伴或宠物式依赖。

本章不揭穿这些误判，只让它们变得足够合理，供后续推翻。

## 本章新增或推进的世界规则

- 世界有一个被称为“维亚”的地名，但地名不等于地图和解释。
- 零对时间与来处的理解可能不同于任，暂不确认这是普遍语言规则。
- 零对任的判断依赖它自己的感知，不能直接翻译为人类分类。
- 废弃建筑说明这里曾有人建造或活动，但不能证明存在稳定文明。

## 技术概念翻译

- 先出现的现象：零把“什么时候出现”与任理解的“从哪里来”错开。
- 任的理解：同一句话可能对应不同的观察角度；他暂时只把它当作语言歧义和零的怪脾气。
- 对应概念：观察结果依赖表示方式；本章不命名，不进入角色解释。
- 限制：任无法通过追问获得唯一答案，零也无法提供全局上下文。
- 失败或代价：任因为错误理解“刚来的”而产生回家的希望；希望会成为后续更深伤口。

## 连续性与伏笔登记

- 延续第 3 章：任从小屋侧门自行进入；零只是经过窄土路，不是向导。
- 延续第 3 章：能量棒仍是同一块，零本章才真正咬穿包装并进食。
- 延续第 1—3 章：手机仍只有屏幕冷光功能；任的伤势和工牌仍在。
- V-01：零的“刚来的”双义问句，回收时不得改写成普通口误。
- Z-02：零怕任离开，先以门口看守和“我怕你跑了”表现，不直接讲心理背景。
- 地点锚点：废弃猎人小屋在第 5 章前继续作为临时避难点，不自动升级为安全基地。

## Canon 检查

- [x] “刚来的”保持双义，不确认其他穿越者。
- [x] 零不是向导、系统、救援者或宠物。
- [x] 第 3 章的能量棒在本章才完成第一次进食，包装裂口连续。
- [x] 夜间小屋仍有危险背景，不能写成彻底安全区。
