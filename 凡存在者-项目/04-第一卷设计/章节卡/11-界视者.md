# 第 11 章场景卡：《界视者》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 01《白界》
- 章节：Chapter 11
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称
- 承接：第10章末，视术师把任短暂进入白界的现象命名为“界视”；赫恩听见并记入纸片，村民开始低声转述；封牌车因东侧岩层塌落暂时无法立即进城
- 核心功能：把“界视”从一个视术师的现场判断转化为村庄的社会分类；让任第一次获得特殊待遇并尝到被看见的快感，同时让零第一次明确感受到“任被重新接纳、自己仍被排斥”；章末以村内出现数十处互不相连的异常痕迹，把社会缓冲推入群体危机，为第12章《凡存在者》蓄压

## 本章必须完成的事

1. 交代封牌车暂时不能立即离开：东侧岩层塌落堵住旧路，视术师需要等边境道路恢复；“随车入城”仍然有效，但不是任已经脱离村庄。
2. 赫恩把“界视”写入村落记录，并向村民转述视术师的判断；村民的态度变化来自权威分类和现实利益，不是突然集体善良。
3. 之前不让任进村的人开始主动邀请他进入居民区、接受食物或询问白界；同一批人前后态度变化必须具体可见。
4. 任第一次感受到“被特殊对待”的快感：他嘴上说没什么，心里却享受别人询问“你是怎么做到的”；同时他担心自己会被带走、检查、定义，不能把特殊待遇写成单纯爽文奖励。
5. 任尝试解释或复现白界，但无法主动重开；“界视者”是社会称呼，不是任的新技能，也不能由任喊出或模仿视术手势触发。
6. 零在本章第一次明确表现不高兴，但不能宠物化：它不是只因为任不看它而撒娇，而是发现村民愿意接受被分类的任，却仍把它留在灯影外；它要作出自己的行动或拒绝。
7. 章末在村内出现可能属于群体的多处异常痕迹：不是一处，而是几十处；只给脚步、灯影异常、边界受压或湿泥下陷，不展示完整本体，不提前进入第12章的正面防守高潮。

本章因果链：

> “界视”被抄入村落副本 → 门为任打开 → 任被要求证明这项标签的价值 → 任因享受关注而短暂留在门内 → 零主动追向另一处异常 → 危险证明安全边界早已失效。

## 本章不能做的事

- 不能让村民因为一个词立刻完全信任任；态度变化要带着好奇、利益、畏惧和试探。
- 不能让“界视者”成为已确认的贵族身份、学院录取或正式等级；这些组织和制度尚未展开。
- 不能让任主动重开白界，不能让白界变成随时可用的透视能力；他最多回忆、尝试失败，或在压力下出现极短残痕。
- 不能让零的情绪变成宠物吃醋；零必须有自己的判断、距离和行动选择。
- 不能让村民接纳任就顺带接纳零；任的特殊待遇必须和零的排斥并置。
- 不能在本章完整解释“界视”的来源、白界的底层机制、任的 Copy、零的 Alpha 或 Observed 身份。
- 不能让数十只隐形魔兽在本章被击退；本章只负责让读者意识到村子已经被包围或渗入。

## 场景推进

### 场景一：车还不能走

- 天亮前后，封牌车沿东侧旧路试行；第10章塌落的岩层向下延伸，碎石同时堵住魔物回村的窄道和进城道路，车轮打滑后退回外栅。
- 视术师不为任讲解“界视”，只把纸片交给赫恩，允许他抄一份村落副本，并要求在道路恢复前暂时按记录管理任；石盘仍在封存匣内。
- 赫恩确认纸片上的两种分类：“无源，待复验”与“界视”；同一个人同时拥有排斥性记录和稀有能力标签。
- 任听见“界视者”这个词第一次被村民说出来，意识到它已经不只是昨夜那个人对他的判断。

任的第一个情绪不是纯粹高兴：

> 他们终于开始问“你看见了什么”，而不是只问“你从哪里出生”。

但他也知道，问得越多，纸片上的字就可能越多。

### 场景二：门第一次为任打开

- 赫恩站在居民区外侧，主动对任说“进来坐一会儿”；这个位置正是第8章拒绝任和零进入的门。
- 曾经把孩子拉回门后的妇人端出一小碗热水，先看任，再看灯影外的零；她愿意让任进门，但要求零留在外面。
- 村民围着任问：白界是什么、他是否能看见魔物、界视是否能看穿墙；问题带着敬畏，也带着把任当作工具的试探。
- 任没有给出完整答案，只能说“有时候会看见线”“刚才只是一下”；他第一次享受别人等待自己回答的安静。

这不是村民突然变好，而是分类改变了他们计算风险的方式：一个被认为有用的人，值得暂时靠近。

### 场景三：任尝试复现

- 赫恩带任走到昨夜被魔物撞过的木栅和灯影边，问他能否再次看见白色边缘；不做学院式测试，只是村民对昨夜现象的粗糙模仿。
- 任尝试让自己回忆昨夜的摩擦声、伤口热度和光球收缩，甚至下意识做出视术师的手势；世界没有失色，石片只是石片。
- 他向村民承认自己不能随时做到；有人失望，有人反而更兴奋，认为界视者的能力必须在危险时才出现。
- 任意识到：昨夜那几息既可能是天赋，也可能只是身体快要承受不住；他第一次害怕这个新名字会比“无源”更牢。

### 场景四：零拒绝被安排的位置

- 任接受了热水，却没有立刻喝；他把碗放到外灯边，递给零。
- 妇人阻止他把零带进来，说“界视者可以进，那个东西不行”；她的语气比第8章温和，却没有改变边界。
- 零没有碰那碗水，也没有靠近门。它先看任，再看门内的人，随后朝粮仓后方另一处灯影异常的方向主动离开外灯，进入村民看不清的位置。
- 任看见它离开，仍然因为门内的人开始询问他昨晚看见的“白线”而留下回答了三个问题；他第一次具体地选择了被关注，而不是立刻跟随零。

任可以短暂留下回答问题，但不能把这写成他已经选择村庄。场景结束时，他应当看见：门为他打开了，零仍被留在门外。

### 场景五：特殊待遇的代价

- 村民请任指出昨夜魔物可能经过的地方，想用他作为“界视者”保护村落；任发现他们把一个不可控的现象直接变成了职责。
- 赫恩出面阻止过度询问，只允许任描述自己真正看见的东西；他提醒任：“名字不是保证。”
- 视术师在车旁听见任无法复现，仍然不撤销“界视”记录，也不承诺任一定能随车获得保护；这项记录只意味着他会被复验，不意味着他已被谁收养或录取。
- 任第一次产生隐约的自负：如果他能看见别人看不见的东西，或许他在这个世界有一个位置；同时，他害怕这个位置只是另一种笼子。

### 场景六：村内出现不属于村民的痕迹

- 午前，外灯已经重新稳定，居民区的门半开；任在门内看见地面上出现一串没有人踩出的湿脚印。
- 第一串脚印从外栅方向来，第二串从粮仓后方出现，第三串停在村民身后不到几步处；没有人听见脚步。任仍处于普通视觉中，只能看见湿泥被踩陷，却看不见踩它的东西。
- 村门刻痕没有完整变红，只在不同位置依次发白；灯影里偶尔闪过一截错位的木栅影子，任无法确认那是反光、灯火受压，还是某种生物留下的痕迹。他没有再次进入白界。
- 任想提醒村民，却发现自己被围在门内，零在外灯之外；村民此刻愿意听他说话，但他们仍不愿意听零发出的任何声音。

### 场景七：几十个影子

- 任站在门槛处，开始数灯影边缘的轻微变化。
- 一个、三个、七个……很快变成几十处互不相连的异常痕迹；村外、屋后、粮仓旁和居民区深处都有湿泥下陷、灯影错位或木梁轻响，但任不能把每一处都确认成同一种东西。
- 赫恩问“有多少？”任不能给出精确数字，只说：“不是一只。”
- 任抬头，看见村中每一盏灯都像被什么从外侧轻轻碰了一下；零在粮仓后方突然停住，朝与任不同的方向看去，那里传来一声没有脚步的木板轻响。
- 章末不写全面战斗，只落下：村子里面也出现了看不见的东西，而且数量远多于昨夜。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 无源外乡人，留在村外 | 被称为界视者，获得有限邀请，也开始担心被定义 |
| 零 | 被排斥在灯影外，与任共同承受 | 发现任被接纳而自己仍被排斥，主动追向粮仓后方另一处异常 |
| 赫恩 | 负责限制任与零的村民 | 试图保护任免受过度利用，但仍不能公开接纳零 |
| 村民 | 害怕任的未知身份 | 因界视标签对任产生敬畏和利益性亲近，对零的排斥保留 |
| 视术师 | 行政处理者与现场施术者 | 保留“界视”记录，等待道路恢复；不成为任的导师 |

## 读者此时应该误判什么

- “界视者”是一个可靠、稀有而且能随时看见隐形魔兽的天赋等级。
- 村民态度改变说明他们已经接受任和零。
- 只要任进入村庄，零也会顺理成章被允许进入。
- 视术师已经看懂任的白界，只是还没有告诉他。
- 村内的多个痕迹是昨夜同一只魔物留下的残影，而不是新的群体威胁。

## 本章新增或推进的世界规则

- 一个本地分类词可以改变社会对人的待遇，但不改变被分类者的真实状态。
- “界视者”首先是行政与社会标签，能力本身仍不稳定，标签不能替任完成视术。
- 村民可以同时对同一个人产生敬畏和利用欲，对另一个异常对象保留排斥；社会态度不是一致阵营。
- 本村现有的外灯和局部边界在本次事件中未能阻止多处异常痕迹进入；第12章的群体袭击不再只是村外追杀的重复。

## 技术概念与魔法翻译

- 先出现的现象：同一人被不同标签处理；一项不可复现的视觉现象被制度化命名；多个不可见对象同时留下局部边缘和痕迹。
- 任的理解：分类会改变行动权限，但标签不等于对象本身；能看见边缘不等于能控制边缘。
- 对应方向：Representation / 观察接口与群体对象问题继续推进；本章不命名 API，不将“界视”解释成技术术语。
- 失败或代价：任尝试复现失败；特殊待遇伴随被检查、被利用和被带走的风险；零与任的共同位置被社会重新拆开。

## 连续性与伏笔登记

- 延续 `VIEW-02`：视术师命名“界视”，赫恩和村民将其转为社会称呼；不解释来源。
- 延续 `CITY-01`：封牌车和“随车入城”仍在，城市压力没有因村民态度变好而消失。
- 延续 `REL-03`：村民愿意保护或利用边界内的任，却仍将零留在边界外。
- 新增 `SOC-02`：界视标签能让任获得有限邀请，但这种接纳是风险计算和利益驱动，不等于平等。
- 新增 `Z-07`：零因任被重新分类而拒绝成为任的附属物，并主动追向另一处异常；不把情绪写成宠物化嫉妒。
- 新增 `M-02`：单体追杀升级为村内多点异常痕迹，可能对应一群不可见对象；第12章回收，不在本章确认数量和本体。

## Canon 检查

- [x] 村民态度改变通过记录、权威和利益呈现，不是集体突然洗白。
- [x] 任获得特殊待遇，但没有获得稳定白界能力。
- [x] 任尝试复现失败，且“界视者”是标签而非答案。
- [x] 零有自主拒绝或离开动作，不被写成宠物或单纯吃醋者。
- [x] 视术师不解释 Copy、Observed、Alpha、白界来源或世界本体。
- [x] 隐形魔兽群体只留下痕迹和数量压力，不在本章完成战斗。
- [x] 任只确认“不是一只”和多处异常，不在本章精确锁定每一个对象。
- [x] 章末明确把第12章《凡存在者》的村庄群体防守推上台面。
