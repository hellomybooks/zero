# 第16章场景卡：《第四种颜色》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 16
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；露米的过去和内心不直接解释，只通过她对颜色的描述、嘴硬和短暂的认真注视表现
- 承接：第15章结束后，任把赛恩递来的固定钉收在袖口；零仍在外院侧廊的阴影里；学院下一堂课进入颜色与阵法辨识。赛恩已正式登场，但本章不推进他的嫉妒或家庭线。
- 核心功能：正式引入露米；让读者第一次看见“同一阵法并不必然产生同一种视觉经验”；让颜色差异先成为真实魔法现象和课堂危险，再成为任对“单一输出不等于完整对象”的第一次具体理解；建立露米对任的谨慎兴趣。

## 本章必须完成的事

1. 露米正式登场，敏锐、嘴硬、反应快，不写成单纯傲娇或恶意少女；她不解释母亲、童年、教会或“怪物的女儿”历史。
2. 课堂先展示一个所有人都能看见的三色阵法：三盏不同颜色的术灯经过薄片与水面叠合后，在黑石盘上形成稳定的蓝色圆环。教师要求学生描述颜色和位置，学生和赛恩都回答“蓝”。
3. 露米回答“不是”，并指出蓝色下方有一种更细、更窄、无法归入课堂颜色名的色差。她暂时把它称为“第四种颜色”，并明确这不是一个新色名，只是她找不到更合适的词；同学嘲笑，教师要求她说明具体位置。
4. 颜色异常必须带来具体谜题或危险：教师让一名学生沿蓝色圆环移动铜片，普通视野看不出问题；露米指出下方偏左的色差正在先移动，学生若继续推进会碰到未显形的错位边。教师迟疑后调整术灯，某一层光失去重合，热光沿同一条错位边逸出，铜片被弹开并烧焦学生袖口，证明她描述的是可验证的变化。
5. 露米的能力必须有限：她能分辨叠加色层、指出色差位置和相对运动，却不能直接说出颜色来源、阵法原理或对象本体；光源角度、薄片位置、距离和水面波动会改变她看到的色差。
6. 任不替露米宣布她“看得更对”，只问：“能不能说说你看到的位置？”露米第一次认真看任，因他没有先问“你是不是看错了”而产生微弱兴趣；两人的第一次连接来自可验证的描述方式。
7. 赛恩保持礼貌和精确：他承认自己看到的是稳定蓝色，不羞辱露米；他可以问“如果只有你看见，如何确认”，但不把露米当成骗子或敌人。任、赛恩、露米形成三种不同的观察位置，不立刻组成小队。
8. 章末留下社会分类和关系钩子：教师在学院现象记录板的记录栏写下“色差异常 / 待复验”，不把露米正式认证为更高等级；露米对任说出自己的名字或反问任为何只问位置，随后认真看他一眼。她意识到任也有一种无法被课堂颜色描述的经验，但本章不确认两者来源相同。

## 本章不能做的事

- 不能在正文中出现 Channel、RGB、HSV、Spectral Separation、OpenCV 或 API 名称；这些只保留在作者侧技术映射中。
- 不能把“第四种颜色”写成任或露米的万能透视；露米只看到叠加层之间的差异，不能凭颜色直接锁定目标、来源或本体。
- 不能让全班突然都看见露米所说的第四种颜色；验证应通过阵法失稳、热光擦过安全线、薄片位置改变等物理后果完成，保留她的视觉孤独。
- 不能把露米写成无理由羞辱同学的刺头；她的攻击性应是被嘲笑后快速自保，且要在任提出可验证问题后短暂收住。
- 不能提前解释露米的母亲、教会带走、童年举报或她对“被看见”的恐惧；本章只让“被看见异常”产生轻微防御反应。
- 不能让赛恩在本章嫉妒任或露米；他只坚持共同可观测结果，同时对异常保持克制的研究兴趣。
- 不能把任的白界、露米的色差和零的可见性直接合并；只允许读者感到它们都在挑战单一观察结果。
- 不能提前进入第17章“首先”生活笑点，也不能引入 Contour、Bounding Region、Hough 或 Ground Truth。

## 颜色阵法规则（作者侧）

- 课堂使用三盏术灯、三片不同透光率的薄片、一个浅水盘和黑石盘。三种光经过叠合后，普通观察者看到的是稳定蓝色圆环；蓝色是有效的合成结果，不是所有人都看错。
- 阵法的圆环由三层光共同维持。任一术灯角度、薄片位置、盘中水面或观察距离改变，叠合区域会出现短暂色差、亮度断层或热光偏移。
- 露米能把普通人合并为一个蓝色的部分分开，看到藏在蓝色下方的窄色带；她看到的色带不稳定，不能脱离阵法条件持续出现，也不保证能说明是哪一盏灯造成。
- 本章验证露米的方法不是让全班共享她的视觉，而是让教师调整薄片后，原本看似安全的蓝色圆环发生错位，热光擦过安全线，证明色差对应了阵法的真实层次。
- 露米只能说出相对位置、先后变化和色带宽窄；她不能给出完整地图，也不能阻止阵法本身继续变化。任的问题让她把“我看见了”翻译成他人可以操作的描述。

## 场景推进

### 场景一：同一阵法

- 第15章后的下一堂基础辨色课在半封闭教室进行。教室中央有浅水盘，盘下嵌黑石板，三盏术灯分别从高处、侧面和低处照入，薄片悬在灯与水面之间。
- 教师先让学生只描述颜色，不允许使用“像什么”或“可能是某种术式”的解释。三层光在水面上叠成蓝色圆环，所有学生都回答“蓝”。赛恩的答案最稳定，任也看见蓝。
- 教师让学生记住蓝色圆环的边缘和缺口位置，准备下一步用铜片验证阵法是否稳定。任把赛恩的固定钉藏在袖口，不让它碰到桌面。

### 场景二：露米说不是

- 靠窗最后一排有一名一直没有举手的女生。她的视线没有停在圆环整体，而是盯着蓝色下方一块很窄的区域，像在等某种颜色从水里浮出来。
- 教师问：“颜色？”
- 学生们齐声回答“蓝”。女生说：“不是。”
- 教师让她重复。她说：“蓝上面是蓝，下面还有一种。”停顿后补充：“我暂时叫它第四种颜色。不是新色名，只是我找不到更合适的说法。它不是白，也不是紫，只在圆环下方偏左的位置，像一根被压扁的线。”
- 同学开始笑，有人说她连颜色都不会认，有人说三盏灯只有三种颜色，只有她在给空气添名字。露米看了那人一眼：“你们连三种都没看全，问我做什么？”说完便把脸转向窗外，不再解释。
- 教师让她报姓名。她说：“露米。”教师在点名册上确认这个名字，没有立即把她赶出课堂，但要求她不要干扰阵法判断。

### 场景三：蓝色下方的细带

- 教师让一名学生拿铜片沿蓝色圆环内缘移动，把圆环的稳定范围标出来。普通视野里，铜片每次都在蓝光中经过，没有碰到任何看得见的缺口。
- 露米突然说：“停。”
- 学生没有停，铜片继续向左下方移动。露米盯着那一小块区域，声音变快：“不是那里。再往里半指。它先动了。”
- 同学又笑，赛恩却低头看铜片和水面，没有马上评价她。任发现蓝色圆环没有变化，但水面上的一圈细纹比刚才多了一道，位置恰好在露米所说的方向。
- 教师把第三盏低灯往左移，想让普通人看清她说的缺口。色差先向内缩了一下，低灯移开后，原本重合的其中一层光失去覆盖，热光沿那条错位边逸出，突然向安全线外擦出一线。铜片被弹开，学生的袖口出现一小块焦黑。
- 白石安全标记亮起，教师立即收束术灯。没有人受重伤，但全班的笑声被切断；露米说的不是凭空的颜色。

### 场景四：验证而非证明

- 教师没有承认露米“正确”，只要求她重新说明刚才的变化：色带在什么位置、先向哪里动、是在灯移动前还是之后出现。
- 露米的描述并不完整。她说色带在蓝色圆环下方偏左，靠近第二片薄片投下的影子；灯往左移时，它先向内缩，再从圆环边缘下方穿出。她无法说出那是什么颜色，只能说“像一块不愿意和蓝色待在一起的薄玻璃”。
- 任第一次意识到，露米并不是看见了另一个完整世界，而是把别人合并成一个结果的部分拆开；她看到的也受水面波动、薄片位置和观察距离影响。
- 教师让另一名学生把浅水盘的水面压平，再让露米站到侧面。色带变窄，位置向后退；露米立刻说“现在看不清了”。限制被保留下来，她不是无条件全知。
- 教师在学院现象记录板的记录栏写下“色差异常 / 待复验”，没有给露米额外等级，也没有把她称作新的认证类别。

### 场景五：任问位置

- 休息时，几名新生围着露米追问她是不是看见了鬼火。露米先用玩笑挡回去，有人继续追问，她便看着那块焦黑的铜片说：“它比你们的答案诚实。”随后独自擦拭铜片，不再给他们留下可供取笑的解释。
- 任没有问“你是不是看错了”，也没有问她到底是什么。他站在水盘旁，看着已经恢复蓝色的圆环，问：“能不能说说你看到的位置？”
- 露米抬头，第一次认真看任。她似乎准备反问他为什么相信自己，最后却只说：“你只问位置？”
- 任回答：“位置能先试。”
- 这句话让露米短暂安静。她指出任刚才站的位置如果向前两步，就会挡住低灯的一部分；任退开后，圆环下方的细纹变得更清楚。
- 露米报出自己的名字：“露米。”任也告诉她自己叫任。她看见他胸前的“零级”木牌，却没有立刻询问数字，只把目光移回他的袖口，问那里面是否藏着一枚刚从别人的术式里留下的钉子。
- 任没有解释赛恩，只说：“它提醒我支点会变。”露米看着他，像在判断这句话是不是另一种颜色。

### 场景六：三种答案

- 教师要求全班再次描述阵法。绝大多数人仍然回答“蓝”；赛恩补充“蓝色圆环的内缘稳定，左下方有短暂亮度变化”，他没有说自己看见第四种颜色。
- 露米说：“那不是亮度。”
- 赛恩礼貌地问：“如果只有你能分辨，其他人如何确认？”
- 露米立刻绷紧，像被逼回了刚才同学的笑声里：“你们不需要确认。你们只需要别踩进去。”
- 任插入一句：“先让她说完位置。”这不是替露米证明，而是把争论重新放回可操作的描述上。露米给出位置，赛恩根据她的方向调整铜片，教师让低灯回到原角度，蓝色圆环恢复稳定。
- 三个人的答案并不相同：任看见的是水面变化留下的细纹，赛恩看见的是可重复的边和稳定范围，露米看见的是蓝色中被合并的窄色带。课堂没有宣布谁拥有完整真相。

### 场景七：被看见的代价

- 下课钟响，学生离开教室。有人仍在背后模仿露米说“第四种颜色”，有人把她的名字和“看空气”连在一起。
- 露米没有哭，也没有追上去。她把被烧黑的铜片塞回教师的器具盒，像是在拒绝留下自己的证据。
- 任从门口回望，发现露米仍盯着蓝色圆环消失后的黑石盘。她的眼睛在确认某种别人无法确认的残留。
- 露米忽然看向任，问：“你是不是也有别人看不见的东西？”
- 任想起白界、零和木牌，回答：“我不知道。”
- 露米没有笑。她只说：“那你至少比他们诚实一点。”
- 她转身离开，走到门外时又停了一瞬。任看见她回头认真看了自己一眼，不像在看零级，也不像在看一个传闻，而是在看一个尚未被颜色归类的人。
- 章末停在黑石盘上最后一丝蓝光收拢的瞬间。水面轻轻颤了一下，露米的视线却仍停在蓝光下方某个任无法辨认的位置。任没有看见她所说的颜色，只看见露米离开的方向。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 刚因赛恩的精度感到压力，仍把观察理解为寻找变化的边 | 第一次承认不同的人可能从同一阵法得到不同但都可操作的视觉经验；主动用“位置”与露米建立沟通 |
| 露米 | 被同学视为说错颜色的异常学生，习惯用尖刻保护自己 | 被记录为“色差异常 / 待复验”；对任产生谨慎兴趣，但仍害怕被定义为某种异常 |
| 赛恩 | 把稳定、可复现的蓝色视为课堂共同基准 | 承认露米的描述可能有用，但尚未接受“个人视觉即证据”；与任、露米形成观察方法差异 |
| 零 | 留在外院侧廊，不进入课堂 | 本章不直接介入；任对露米的回答会让他重新想到零不能被单一标签归档 |

## 读者此时应该误判什么

- 露米只是看错颜色、为了引人注意而说“第四种”。
- 露米看到的第四种颜色就是更高等级的视觉能力，学院迟早会把她认证成优等生。
- 任、赛恩、露米之间的差异只是三种不同的魔法天赋，互相可以直接替代。
- 只要让所有人共享同一颜色，阵法就拥有了唯一正确的现实。
- 任能理解露米，是因为他已经完全理解零和自己的白界。

## 本章新增或推进的世界规则

- 颜色是叠加后的观察结果，不保证包含所有参与叠加的层次；三种光可形成稳定蓝色，但蓝色下方仍可能存在无法被大多数人分辨的色差。
- 视觉差异依赖光源角度、薄片位置、水面状态和观察距离；露米的能力能分离部分色差，但不提供无限距离、来源识别或对象本体知识。
- 学院可以把异常视觉记录成“色差异常 / 待复验”，但不会立即将其转成等级或能力认证；行政记录与实际观察再次出现分离。
- 同一魔法现象可以同时拥有共同可见的合成结果、几何稳定边和少数人可见的色差层；本章不裁定哪一种是唯一真实。

## 技术概念与魔法翻译

- 先出现的现象：三盏术灯和薄片在浅水盘上合成蓝色圆环；露米看到蓝色下方一条窄色带，并用它预警错位热光。
- 任的私人理解：别人把不同来源合并成一种颜色，露米能把被合并的差异拆出；这不是“看得更真实”，而是看见了另一种表示层分解。
- 对应方向：Channel / Color / Spectral Separation 从社会性课堂异常进入；后续可扩展到 RGB、HSV、频段与身份标签，但本章不命名 API。
- 失败或代价：露米无法解释色带来源，也无法让他人直接共享她的视觉；她因此被嘲笑并被行政记录为异常，任只能帮助她把视觉翻译成位置和变化。

## 连续性与伏笔登记

- 延续 `REN-04`：任已被公开记为零级，却能参与颜色阵法的观察讨论；等级与实际观察价值继续分离。
- 延续 `GEO-01`、`SAIN-01`：赛恩的稳定几何视线与露米的色差视线并置；赛恩保持求知，不提前进入嫉妒。
- 延续 `ACAD-02`、`SOC-03`：学院把异常写进现象记录板的记录栏，但不立即赋予正式等级；制度仍把复杂经验压缩成字段。
- 本章落地 `COLOR-01`：三色叠合后的蓝色是有效合成结果，但不是完整视觉层；色差随条件改变，不能直接等同本体。
- 本章落地 `LUMI-01`：露米因“第四种颜色”被嘲笑并记录为异常；任用“位置”而非“你看错了”与她建立第一次信任。
