# 第22章场景卡：《哪里是火》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 22
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；战斗仍在公开练习场内延续，读者只知道任如何承受火势、观察场地并改变问题
- 承接：第21章末，教师已用白石封术、浅水盘和湿布隔离观众侧一段油槽，但火兽腹下另一段连续媒介仍燃烧；任知道白痕不稳定，却还没有办法处理火兽整体。
- 核心功能：完成第一卷最重要的问题转换——任不再问“怎样熄灭火”或“哪条边是真的”，而是先决定“哪里属于火”；让第18章已有的 Contour 经验在动态火兽上失败后，转为更粗的空间范围观察；首次在任的白界中形成透明包围区，为第23章不断收缩与越级胜利提供基础，但本章不完成收缩。

## 本章必须完成的事

1. 战斗从第21章的失控边缘继续。火兽没有被教师完全熄灭，火势仍沿未封住的连续媒介向场心蔓延；公开练习场的安全线与水汽只能暂时隔离，不能替任解决问题。
2. 任先尝试沿用第18章对连续边缘的闭合经验，结果再次失败：火焰、烟、热浪和油光的边缘无法在同一时刻稳定接合。失败要通过白线断裂、透明痕迹熄灭或场地后果呈现，不写成理论解释。
3. 对手继续保持强大而克制的控火：她尝试把火兽收回油槽，但火势已沿连续媒介扩展；她不主动伤任，却也不能凭经验独自收回整个火兽。
4. 任明确说出或在极短对白中完成问题转换：他不需要先熄灭火，而要先决定哪里属于火。具体措辞可以接近导演卡名场面，但必须由危险逼出，不像作者宣言。
5. 任放弃追逐每一条变化中的白痕，改观察火焰在场地上留下的共同后果：持续发热的石面、油槽的连续亮带、灰烬落点、蒸汽反复被推开的区域和火兽最外侧曾经触及的几处位置。
6. 任先后记住这些外侧位置，白界中的透明范围标记短暂汇成一个粗大的包围区。包围区不是任召出的实体，也不是火兽真实身体；它不证明里面只有火兽、不要求火焰外沿稳定闭合，只把巨大火兽当前可能占据的范围显示出来。
7. 透明包围区形成时必须有代价：范围很大，包含空白石面、烟和部分安全空间；任的肩伤加剧、白界时间接近极限，脚下和出口仍然危险。任不能同时精准分辨内部细节。
8. 章节结尾让任在白界中看见巨大火兽被透明区域显示在四边以内；其他人只看见火势、蒸汽和任的动作变化。教师与对手只知道火势没有熄灭，任知道这个范围仍然粗大而危险。第23章从“包围区太大”开始，进入区域不断收缩。

## 本章不能做的事

- 不能让任直接复现第18章的闭合轮廓并把火兽完整圈成稳定实体；第18章的经验必须先失败，再转向更粗的空间范围。
- 不能把透明包围区写成证明“里面只有火兽”的结界；它只能给出可能范围，不能确认内部对象身份或完整形状。
- 不能让任凭一句“哪里是火”立刻获胜；包围区很大、很粗、很不稳定，第23章才收缩并完成主要能力爽点。
- 不能提前引入 Mask、ROI、minAreaRect、Hough、Ground Truth、Inside / Outside 或世界本体解释；Bounding Region 只作为任事后写下的私人翻译标签，不是咒语。
- 不能让教师、露米、赛恩或对手替任提出完整答案。教师负责安全，露米只能指出色热层的局部差异，赛恩只能看见范围的几何变化，对手继续维持火势。
- 不能把对手写成突然失控的反派；火兽变大来自连续媒介被引燃和战斗条件改变，不来自她主动伤人。
- 不能让零进入公开练习场；零仍在外院侧廊的非照明侧，不成为答案或救援。

## 火兽与包围区规则（作者侧）

- 火兽仍依附火种、油槽和连续媒介；教师的封术已经隔离观众侧一段，但腹下另一段媒介继续提供火势，火兽因此无法立即消失。
- 火兽的外焰、内焰、烟、热浪和反光继续产生多层边缘。第18章的 Contour 可以处理短时连续的局部边，但不能让整只动态火兽形成稳定闭合轮廓。
- 任可以记录火兽在地面和空气中造成的持续影响，从最外侧的若干位置判断一个粗略范围。这个范围允许包含空白、烟、热影响和暂时没有火焰的石面。
- 透明包围区的边界由任从现有火种、油槽、灰烬、蒸汽、白石和残余白界中先后记住的四个极值位置汇成，形状接近普通轴对齐范围标记，但不需要在正文中使用 API 或几何函数名。四边是任视觉中的观察结果，不是新召出的实体边界或锚点；它显示的是“可能属于火的范围”，不是火兽本体。
- 包围区形成后，只有任能在白界中看到框内外的范围差异；火焰、热浪和烟仍可能越过这四条透明边。实际隔离仍由教师主动施放的封术、湿布和浅水盘完成；框内不应因此变成安全区。
- 包围区过大是核心代价：它显示火兽可能出现的范围，也显示大量空白；任只能先取得“有界”，不能取得“精确”。

## 场景推进

### 场景一：封不住的火

- 章节开头承接第21章末，教师的封术仍维持在观众侧白石线，助手推着浅水盘后退，湿布压住一段油槽，另一道连续媒介在火兽腹下燃烧。
- 火兽的拟兽形状已经比上一章更大，但每次抬头、转身和落下都由不同火舌短暂聚成；烟和热浪将形状推向白石线之外。
- 对手试图收回火势。她先压低手腕，火兽一侧确实缩回，另一侧却沿连续媒介向场心展开。她对任说“我只能让它回到还有油的地方”，不解释火兽本体。
- 教师没有再给任新的尝试，只守在白石线旁维持已经开始的安全干预，并明确只要现实中的火焰、热浪或油槽逼近观众侧，就会主动封术。任肩侧的焦黑处被水汽打湿，灼痛重新出现。

### 场景二：再次闭合失败

- 任的白界并非应声而回。只有高压、照明范围缩小、残余白石边界和呼吸逼近极限叠在一起时，白色才短暂返上来；任不能主动召回、稳定或延长它。他看到几条断裂白痕，试图按第18章的经验让它们首尾相接。
- 第一段白痕沿兽首出现，第二段却在烟柱里升高；第三段贴着地面向油槽退回。任试图在自己的判断中把它们接成一圈，白痕却不响应他的意志，透明痕迹在火光中发出细响，随后从中间断开。
- 断裂造成一小片热浪反冲，任的肩伤再次疼痛；教师用湿布压住靠近他的油槽，对手立刻将火舌收回，不让反冲变成直接攻击。
- 任没有得到完整轮廓。他只确认：如果继续追逐每条白痕，自己会被火势拖着走。

### 场景三：问题改向

- 火兽的前肢一瞬间越过任原先判断的边缘，白石线外的灰被热浪卷起；任没有去找下一条白痕，而是低头看石面上持续发红的一片区域。
- 他把几个局部现象放在一起：火焰曾经抵达的最远处、灰烬落下的最外侧、油槽亮带仍然连续的位置、蒸汽被反复推开的空处。
- 任把过去留下的热痕外缘误当成当前火势的边界，向自以为较安全的空隙靠近；火兽另一侧沿油槽绕过，热浪从他背后压来，逼得他再次退向白石线。湿布及时压住一段油槽，任却发现那片石面只是留下了过去的热，并不能告诉他火下一刻会从哪里来。
- 露米从场边指出一处“颜色退了，热还在”的石面；她只提供一个局部差异，不替任画范围。
- 赛恩看见任不再跟着火兽的形状跑，而是沿场地几个方向移动视线。他的木记板停在半空，没有急着落笔。
- 任退到白石线旁，火兽的咆哮压住了他的呼吸。他本来还想去找下一条外沿，脚下的石面却再次发红。
- 他把手掌按在白石上：“我不需要先熄灭火——”热浪撞来，半句话断在喉咙里。
- 任没有抬头追火兽的头。他咬住灼痛，补完：“我只需要先决定——哪里是火。”这句话先是让自己活下来的选择，之后才有了别的重量。

### 场景四：迟到的热

- 任没有继续寻找火兽的完整外沿。白界中，一小点亮处先出现，随后消失；火焰退去后，那里仍留着迟到的热。更远处的灰烬停留处、被热浪推开的水汽边、白石发红的尽头，也各自留下同样迟到的热感。
- 这些异常从来不在同一时刻稳定存在。任只能在白界即将消退前，用手指、残余白线和火势留下的既有石面痕迹把它们先后记住；每记住一处，肩侧伤口就更疼，视野中的白色也更薄。
- 对手发现任不再追火兽的头和爪，改变油槽的火势方向，试图让火焰从那些异常之间绕出去。任没有拦每一条火舌，只盯住曾经留下迟到热感的最远位置。
- 一道火舌擦过其中一处，教师看见现实中的危险，主动把湿布压向油槽；白石封术随之加深。没有任何线自动替他拦住火焰。

### 场景五：透明包围区

- 那些位置之间没有立刻出现方框。先是一片火焰突然失去向外延伸的白痕，烟却向内折了一下；接着灰烬在没有风的地方滚回油槽，浅水盘的水面朝同一个方向倾斜。任只能在白界里看见这些变化彼此靠近。
- 其余迟到的热感也先后亮起。直到这时，任才意识到，自己在不同的时刻记住了四个位置；残余白线从它们之间掠过，像在空中寻找一条不肯出现的路。
- 火兽的火舌从左侧越过那道尚未成形的亮边。它没有撞上墙，也没有被任何透明东西推回；教师看见火势逼近观众，立即把浅水盘推近白石线，湿布压住油槽，水汽替实际封术争取了一瞬。
- 任的视野里，四个先后出现的位置终于被同一层淡白连接起来。四条边不是实体，只是白界中一块粗略范围的显示；它们离火兽很远，之间包含大片空白石面、烟和油槽。
- 任的白界已经消耗到几乎只剩四条边仍能被他看见。他和火兽被显示在同一片范围的两端，脚下仍然灼热，出口仍被烟遮住。

### 场景六：章末

- 透明范围完整显现，巨大火兽在任的白界中被显示在四条边以内。它仍然咆哮，火焰仍然燃烧；烟和热甚至越过其中一条淡边，教师只能继续用封术、湿布和浅水盘处理现实中的火势。
- 场边忽然安静下来。观众看见的是水汽突然沿着白石线升高、任站在场心不动、火兽的外焰在某些地方失去去路又从别处冒出；没有人看见任眼中的透明范围。
- 对手的手腕停在半空。她试着把火拉回油槽，火焰却沿另一段媒介向外拱；她没有再把最尖的火舌推向任，只是盯着火势迟疑了一瞬。
- 赛恩先看见任的站位、油槽亮带、灰烬停留处、蒸汽边和白石发红尽头之间出现了某种对应，才在木记板上画下一个粗大的四边形；露米只看见其中一处颜色退了，热却没有退。
- 透明范围先在任的白界中剧烈颤动，没有真正缩小。颤动尚未止息，白色迅速退薄，只剩一层贴着四边的残白；任只来得及记住：这个范围太大，里面有火，也有许多不是火的东西。
- 章节停在残白尚未完全消失、透明范围依旧没有缩小的瞬间。第23章从这个过大的范围开始第一次收缩，进入“一平方米”的越级胜利。

## 读者此时应该误判什么

- 任已经真正看清了火兽的完整形状。
- 透明包围区就是结界，框内因此安全。
- 包围区边界贴着火兽本体，里面不会有空白或烟。
- 对手即将因为范围被框住而失去所有控制。
- 任只要继续把框缩小，就能稳定掌握新的能力。

## 本章新增或推进的世界规则

- 当对象的边缘无法稳定闭合时，可以先对其可能占据的粗略范围进行限制；范围不等于对象本体。
- 粗略包围区可以包含大量空白、烟、热影响和非目标空间；它的有效性与精确性不是同一件事。
- 包围区不能限制框外扩散，也不能立刻熄灭框内火焰；它只让任暂时看见一个可能范围，不能自动分辨范围内所有变化。
- 任的问题转换可以改变视术的可行性：先定义“哪里属于火”，比先问“如何熄灭火”更接近当前战斗的生存条件。

## 技术概念与魔法翻译

- 先出现的现象：动态火兽、Contour 闭合失败、四个外侧位置、透明四边包围区、框外火势仍可能越界、框内仍有空白。
- 故事内翻译：任事后可能在木记板边写下 `Bounding Region`，它不是施法词，只是对透明包围区的私人命名。
- 对应方向：正式落地 `CV-04 / boundingRect` 的第一层故事化表现；第23章继续收缩范围，但本章不引入旋转矩形、精确最小面积或 Mask。
- 失败或代价：包围区很大、包含非火区域；任肩伤加剧、白界退去、框内仍危险；他获得的是“暂时有界”，不是完整识别。

## 连续性与伏笔登记

- 延续 `FIRE-01`：火兽仍依附油槽和连续媒介；动态火焰的多层边缘继续造成观察困难。
- 延续 `CONTOUR-01`、`REN-06`：第18章闭合经验在动态火兽上失败后，任转向决定一个更粗的范围，定义责任随之扩大。
- 推进 `CV-04`：首次形成透明包围区，包围的是可能范围而非对象本体；第23章继续收缩。
- 延续 `COLOR-01`、`LUMI-01`：露米的颜色退去与热仍在帮助区分表示层差异，但不提供完整答案。
- 延续 `GEO-01`、`SAIN-01`：赛恩记录四点与四边形，保持几何观察与求知，不替任掌控战斗。
