# 第25章《伊莉亚》场景卡

## 基本信息

- 卷：第一卷《白色边缘》
- 篇章：ARC 03《不存在的边缘》
- 章节：Chapter 25
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；读者只知道任看到、听到、触到并能暂时判断的东西
- 时间：第24章从地下档案馆返回后的同一日下午至傍晚
- 地点：学院外院侧廊、侧廊尽头的退役低灯练习角、临时医务室
- 承接：零在第24章没有进入地下档案馆，仍留在外院侧廊非照明侧；任带着石板上那组未解结构、学院格言与零之间暂时分离的不安回到地面。石板仍封存在地下档案馆，任肩伤仍在，白界不能被他随意召出。
- 核心功能：把第24章的历史悬疑重新落回身体与关系。零为了证明自己没有被留下、仍然有用而进行受限训练并受伤；伊莉亚第一次正式登场，以有条件的“重新连接破损区域”完成治疗；任第一次发现自己的观察不能替别人完成修复，也不能替零回答“有没有用”。

## 本章必须完成的事

1. 任等人从地下档案馆返回后，零已经离开外院侧廊，主动前往侧廊尽头的退役低灯练习角。任从这一空缺中意识到：零没有等他，也没有把自己放进“被留下的人”位置里等待解释。
2. 练习角必须有明确现实规则：固定灯照明范围、石墙暗边、三段旧安全线和一枚仍会反弹越界者的训练石环。它不是中央训练场，零可以沿既有非照明侧接近，但未经正式许可，不得把这次训练写成学院接纳零为学生。
3. 零的训练动机不是升级或表演，而是证明自己仍能在有限阴影里完成一件事。它尝试沿暗边连续通过三段标记，在不踏入固定灯直线的情况下取回一枚铜环；前两次成功，第三次为了追赶移动的铜环而越过旧安全线。
4. 训练石环的反弹规则必须先以真实现象出现：触碰安全线的东西会被推回暗边。对普通物体是推回，对零却造成外沿局部断裂；危险来自规则与零的身体差异，不是随机摔倒。
5. 零第一次在学院训练规则下产生、并需要外部治疗的新破损：第12章留下的肩侧旧缺口仍在，训练石环的反弹力在旧缺口旁撕开一段新的外沿断口；两端仍在，中间缺失，黑色内部向新缺口塌陷，行动和说话变得不稳定。不要把旧缺口写成已经治好，也不要揭示零的真实身份。
6. 任在急迫中尝试召回熟悉的白色视觉，希望确认伤口范围；白界没有为这次求助稳定出现。他只能看见明暗变化、零轮廓变薄和断口反复错位，无法准确判断哪里属于“伤口”。这只是本章的局部无力，不是任的全部能力在本章崩溃；第27—28章才进入无边敌人与知识优势全面归零。
7. 伊莉亚以治疗者身份正式登场。她从临时医务室带来热水、干净布、细夹、药粉和固定带，先让伤处保持稳定、清除残留石粉，再施放治疗术；她不以强光覆盖伤口，不把治疗写成一照即愈。
8. 伊莉亚的治疗必须表现出明确限制：她只能处理一个局部、稳定、仍有两侧可相互连接的破损；不能凭空创造已经消失的部分；若残留石粉未清除，贸然闭合会把异物留在里面；若零移动，刚接上的两侧会重新分开。
9. 治疗现象是断口两端在她的手指、固定带和低声咒语作用下缓慢靠近，缺口逐渐变窄，边缘重新咬合，但最后仍留下一条暗色细线和轻微不对称。读者先看到“修复是重新连接”，不听到形态学或 API 解释。
10. 零在治疗后问：“没有用的东西你也救？”伊莉亚不直接回答价值问题，只在固定断口时说：“你能不能别动？”这句温柔而强硬的话同时表现她的可靠与控制倾向。
11. 任本能想替零回答“你不是没用”，但停住；他意识到替零定义价值仍是在替零说话。任不因此完成哲学觉醒，只留下一个不舒服的停顿与新的关系边界。
12. 章末让伊莉亚在处理完零后注意到医务室一件“还能用但已经裂开”的物品，未经请求便开始修补。她的善意真实有效，却已经显出无法容忍破损存在的习惯，为第26章《修好》接入生活线。

## 本章不能做的事

- 不能让零自由穿过明亮训练场；所有移动都沿外院侧廊、石墙暗边和受限低灯区域完成。
- 不能把零写成任的宠物、战斗工具或等待任召回的附属物；它主动离开、主动训练、受伤后仍保留拒绝和选择。
- 不能把本章新伤写成零第一次出现任何破损；第12章的肩侧旧缺口必须继续存在，本章只新增旧缺口旁一段需要治疗的断口。
- 不能把训练事故写成零突然获得攻击能力；本章只呈现受限移动、越界反弹与身体破损。
- 不能让任用白界、旧世界知识或新概念准确定位并修复零的断口；白界只能短暂不回应，任不能总结根因。
- 不能宣告任的能力在本章全面失效；“没有轮廓”的敌人与 Edge / Contour / Bounding 全部失败留给第27—28章。
- 不能让伊莉亚凭空生成组织、填补完全消失的部分或把零恢复成无伤状态；治疗必须留下细线、轻微不对称或动作限制。
- 不能把伊莉亚写成恶意控制者或无条件圣人。她真诚想救、确实能救，但不先询问零是否愿意被调整，且比零更在意断口是否整齐、是否稳定。
- 不能提前解释伊莉亚的父母、童年、被抛弃经历或她未来的控制事件；人格问题只能从她的动作和语气中露出一角。
- 不能在正文出现 `Morphology`、`Erode`、`Dilate`、`Opening`、`Closing`、`Mask`、`Foreground`、`Background`、`Inside / Outside`、`Alpha`、`Mat / View`、`Observer / Observed`、`Ground Truth`、`OpenCV` 或 API 教程式表达。
- 不能治疗任的肩伤作为伊莉亚登场奖励；任仍需自行换药或承受伤势。

## 场景推进

### 场景一：侧廊空出来的位置

- 现实事件：任、教授、档案管理员、赛恩和露米从地下档案馆返回地面。教授带走石板记录，档案管理员重新检查窄门封条；赛恩急着补写拓本差异，露米停在固定灯下看自己手指上的冷色残影。任回到外院侧廊时，发现原本非照明侧的墙根只剩一碗已经凉掉的水和一小段被踩断的灰线。
- 危险 / 谜题：零不在侧廊。墙根灰尘里没有普通脚印，只有一段被暗影压窄的痕迹通向侧廊尽头；任无法确认零是主动离开、被什么引走，还是在回避他。
- 情绪变化：任先产生被零拒绝的刺痛，随后想起第24章自己把零留在历史发现之外，意识到零可能正在用行动回答“没有我也可以”。
- 章内钩子：侧廊尽头的退役低灯练习角传来一声铜环撞石的轻响。

### 场景二：暗边训练

- 现实事件：练习角由三段旧安全线、固定低灯和一枚嵌在石槽里的训练石环组成。训练石环会把越过安全线的普通物体推回暗边；零沿墙根的暗边移动，尝试在不进入固定灯直线的情况下取回一枚被铜丝牵引、不断向亮处滑去的铜环。
- 规则限制：零只能在光线收窄后经过下一段暗边；固定灯一旦抬高，零的外沿就变薄；训练石环不是攻击法术，不辨认对象，只对越过线的部分产生反弹。
- 事件节奏：零前两次成功，第三次为了赶上铜环越过旧安全线。石环先把铜环弹回，随后反弹力擦过零肩侧的旧缺口旁；旧缺口本身没有消失或闭合，反而在旁边新撕出一段短裂。零的外沿像一块薄布从中间被再次扯开。
- 情绪变化：零先用玩笑说“这次算我快了一点”，但它的声音在断口处出现空响；任的玩笑没有接上，冲过去时第一次真正害怕零会从那道断口继续散掉。
- 章内钩子：断口两侧都还在，却无法自行碰到一起；黑暗从缺口里向内塌陷。

### 场景三：白线没有回答

- 现实事件：任按住自己的肩伤，试图唤回那种曾经把世界拆成黑暗与白线的视觉。他等到耳鸣、眩晕和眼前短暂发白，却没有得到稳定的边缘世界。
- 危险 / 谜题：普通视线只能看到零外沿变薄、断口位置随呼吸似的起伏和石环留下的灰屑；任不能判断断口到底从哪里开始，也不能确认那段缺失是否属于零的“身体”。
- 规则限制：白界不是任可随时调用的检查工具；本章不解释它为何不回应，也不把一次失败总结成全面失效。任只能让周围人压住训练石环、调低固定灯，并用自己的声音让零停在暗边。
- 情绪变化：任第一次感到自己熟悉的观察方法并没有把他送到更接近答案的位置。他想说“我看得见”，最终只说：“别再往亮处动。”
- 章内钩子：有人从医务室方向跑来，先喊的不是任，而是：“伊莉亚，带水和固定带！”

### 场景四：伊莉亚接管伤处

- 现实事件：伊莉亚从侧门赶到，带着热水、干净布、细夹、药粉和一卷窄固定带。她先看零的断口，再看训练石环，不问零是什么，只要求任把灯影压低、让旁人退开，并让零保持原来的姿势。
- 危险 / 谜题：新断口边缘粘着细灰与石粉，旁边还连着第12章遗留的旧缺口；如果立刻让新断口合拢，残屑会被封进里面，之后每次活动都会把裂缝撑开。零的外沿还在轻微错位，伊莉亚必须先分清哪两段属于这次新伤，不能把旧缺口当成可以凭空补回的部分。
- 人物动作：她用湿布和细夹一点点清除灰屑，用固定带托住断口附近的暗色边缘；她的手很稳，语气却不容讨价还价。零试图缩回阴影时，她按住固定带：“别躲，躲了就接不上。”
- 伊莉亚的第一印象：温柔、可靠、动作熟练，同时天然地把现场变成她能调整的形状。她不是冷漠地控制零，而是相信“不动、对齐、接好”比询问更重要。
- 章内钩子：她的两根手指分别压在断口两侧，低声咒语只响了三个音；缺口没有被光填满，反而开始向中间收窄。

### 场景五：让断开的两边重新相遇

- 现实事件：伊莉亚先让残屑沉入药粉，再让断口两边保持相邻。她用手指、固定带和短咒维持位置，治疗术只在两侧仍然存在且彼此对应时产生回应。
- 魔法现象：断口两边缓慢向彼此靠近，黑色内部停止向外塌陷；每当零因疼痛或不安轻微移动，刚合拢的地方便重新渗出暗色，伊莉亚不得不退回一步重新清理、重新对齐。
- 明确限制：她不能凭空补回消失的部分，也不处理旧缺口已经缺失的那一块；她只接住本次新撕开的两侧。最后新伤留下暗色细线和轻微不对称。她说的不是“已经好了”，而是“先接住了，别把它再扯开”。
- 任的观察：任没有白线可以依赖，只能从伊莉亚的手指压力、零的声音和断口收窄的速度判断发生了什么。他第一次看见“修复”不是抹除损伤，而是让原本相邻的部分重新连接。
- 人物情绪：零从抵抗到暂时安静；伊莉亚在断口逐渐整齐时几乎松了一口气，但看见那条不对称细线后又下意识伸手想调整。
- 章内钩子：零低头看着肩侧仍未完全消失的细线，问：“没有用的东西你也救？”

### 场景六：别动

- 现实事件：伊莉亚没有直接回答零关于“有没有用”的问题，只继续压住固定带：“你能不能别动？”她解释移动会让刚接上的两边再次分开，不解释为什么值得救。
- 情绪冲突：任本能想替零说“它不是没有用”，话到嘴边停住；第13章零拒绝任替它回答的记忆回到他面前。他第一次发现，给零贴上“有用”标签与贴上“没用”标签一样，都是替它决定形状。
- 零的反应：零被治疗后的感激与被摆布的不适同时存在。它没有完全服从，只在伊莉亚松手后试着移动半寸；细线立刻变暗，零自己停下，不是因为被驯服，而是因为它看见后果。
- 任与伊莉亚的关系：任想感谢她，又察觉她把零的身体当成必须按正确方式闭合的东西；他暂时不提出质疑，因为断口确实需要她的判断。
- 章内钩子：伊莉亚把固定带重新绕紧，轻声说：“今天不需要证明什么。”这句话没有回答“有没有用”，却刺中了零真正想证明的事。

### 场景七：还能用的裂缝

- 现实事件：临时医务室安静下来。伊莉亚给零留下动作限制和换带时间，拒绝承诺伤势会马上恢复；任的肩伤仍由自己重新压好。离开前，伊莉亚发现药架旁一只还能盛水、但边缘已经裂开的陶碗。
- 魔法规则的余波：陶碗缺了一小块，伊莉亚不能凭空补回，只能把还在的两片裂口对齐，以细金属线和药泥固定；碗能继续使用，但承重和冷热变化仍有限。她把这件事当成必须处理，而不是可有可无的小事。
- 人物变化：任对她产生真实欣赏，也记住她在没有人请求时仍然伸手；零在门边看着她，仍没有把自己交给她，却没有立刻离开。
- 伊莉亚的控制伏笔：有人说“还能用，明天再换一个就好”，伊莉亚已经拿起陶碗，回答得很轻：“先别让裂口继续走。”她把照顾说得像常识，没有意识到自己正在替别人决定什么必须被修好。
- 章末钩子：固定带下的断口仍留着一道暗线。任看见伊莉亚抬手时，陶碗的裂缝和零肩侧的细线在同一盏低灯下短暂重叠；他第一次不确定，闭合究竟是在保护一个东西，还是在替它规定应该保持什么形状。

## 本章新增或推进的规则

- 退役低灯练习角仍保留训练石环；它只对越过安全线的部分产生反弹，不理解对象身份。
- 零的外沿可以被边界压力再次局部撕开；第12章旧缺口与本章新断口并存，两端仍存在的新伤表现为断口、错位和内部塌陷，而非普通血肉创口。
- 伊莉亚的治疗需要清洁、稳定、相邻且仍存在的破损两侧；她不能凭空补回缺失部分，治疗后会留下细线、不对称或动作限制。
- 治疗魔法的第一种故事表现是“让断开的部分重新连接”，不是光照、抹除或自动复原。
- 任的白界不能在本章作为随叫随到的伤口定位工具；这一局部失败不等于第27—28章的全面能力失效。
- `E-01` 获得第一次正文推进：修复可以有效救治，也可以在“对齐、稳定、别动”的温柔要求中带来控制。

## 读者此时应该误判什么

- 零受伤只是一次训练事故，和第24章被留在外面没有关系。
- 伊莉亚只是传统意义上的温柔治疗者，不会把“照顾”变成对他人形状的调整。
- 只要两侧存在，伊莉亚就能把任何裂缝接好。
- 任的白界只是暂时疲劳，下一次必然会准确显示零的伤口。
- 零接受治疗后会因为被救而完全服从伊莉亚或任。

## 后续接口

- 第26章《修好》：伊莉亚开始修复学院里的杯子、扣环、器具和生活物品；“没关系，我来”从可靠变成让所有人依赖她的习惯。
- 第27章《没有轮廓》：任进入白界却发现袭击者就在眼前，没有可锁定的边缘；这是新的敌人现象，不是第25章局部失败的简单重复。
- 第28章《失效》：任反复尝试 Edge、Contour、Bounding 仍失败，知识优势全面归零。
- 第29章《没用》：零把第25章的价值问题继续变成夸张玩笑和夜间追问。
- 第33章《零的边界》：伊莉亚面对无法确认实体区域的零伤势，前后两次治疗形成反差；第25章必须留下“仍存在的两侧可连接”这一条件。

## 技术概念与魔法翻译

- 对应概念：Closing 的第一次自然呈现。
- 故事现象：清除裂口中的残屑后，让仍相邻的两侧重新靠拢、连接，形成暂时可用但不等于恢复原状的区域。
- 魔法语言：伊莉亚的短咒、手指压力、固定带和对“别动”的要求共同构成治疗条件；咒语不能绕过缺失材料、错误对齐和对象不稳定。
- 任的认知位置：他能把现象与自己熟悉的“修复”经验类比，却不能命名、运行、复制或用它替代伊莉亚的判断。
- 禁止泄露：正文不出现 `Closing`、形态学、API、函数名或任何现代计算机视觉解释。

## Canon 检查

- [x] 零没有进入明亮训练场或获得正式学生身份，训练地点和许可边界清楚。
- [x] 零主动训练、受伤并保留选择，不被写成任的宠物或工具。
- [x] 任的白界只在本章局部不回应，不提前完成第27—28章全面失效。
- [x] 伊莉亚先以现实处理稳定伤处，再以有条件的治疗术重新连接，不凭空补全。
- [x] “没有用的东西你也救？”与“你能不能别动？”出现，但伊莉亚不直接回答价值问题。
- [x] 伊莉亚的温柔控制只通过动作、限制和对裂缝的执着显现，不提前解释创伤。
- [x] `E-01` 推进，但不出现 `Morphology`、`Closing`、`Mask`、`Alpha`、`Mat / View`、`Observer / Observed`、`Ground Truth`、`OpenCV` 等高层概念。
- [x] 章末为第26章生活修复线、第27—29章失效与价值焦虑线留下明确接口。
