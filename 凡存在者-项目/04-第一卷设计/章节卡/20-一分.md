# 第20章场景卡：《一分》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 20
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；以任观察赛恩为主，必要时贴近赛恩收到家信后的动作，但不进入全知家庭解释
- 承接：第19章当晚，赛恩因“当前不可区分”的问题重新翻书；第20章翌日进入正式几何训练与家信余波。当晚另行安排一次边界附近的训练，许可只覆盖任与赛恩在学院内侧活动，零仍位于学院外侧非照明区域，不依赖第17章的一晚许可。
- 核心功能：把赛恩的“求知兴奋”推进到“精度压力”；第一次展示他的顶级视术家族与父亲来信，但明确家庭没有虐待，问题在于爱与优秀长期绑定；用一分成绩 / 一度偏差建立赛恩追求完美的情绪根；让零以轻微推歪尺子的动作进入赛恩视野，不把零宠物化或写成嫉妒答案。

## 本章必须完成的事

1. 课堂或个人训练场给赛恩一组高难度几何练习：当前平面、支点、刻痕、金属线和短时稳定条件全部明确；赛恩几乎完美完成，取得全班最高的近乎满分成绩。
2. 成绩必须具有具体物质载体：木板上出现分数或刻痕，教师指出最后一个术式只偏了一度；“一分”既是成绩差距，也是几何偏差的情绪化重量，不把它写成单纯数字梗。
3. 任从旁观察赛恩：赛恩不是靠蛮力，而是先确认平面、支点、线的松紧和当前条件；他的高精度来自多年训练与稳定方法，不是无代价天赋。
4. 赛恩收到父亲的家信。信中不夸奖近乎满分，只问：“为什么最后一个术式偏了一度？”信封里同时夹着父亲惯常寄来的护腕药膏或细布，说明父亲确实关心他的身体；父亲没有侮辱或惩罚，爱与“你还可以更好”绑定的压力通过简短措辞和赛恩的身体反应表现。
5. 任不替赛恩解释父亲，也不强行安慰；他只观察赛恩如何把信折好、重新收起，意识到“被认可”与“被要求更好”在赛恩身上从未分开。
6. 当晚新的边界训练安排延伸到既有外院侧廊非照明侧。赛恩把尺放在边界附近重新校准；零先确认赛恩的视线落在尺上，再自主从阴影侧触碰尺的一端，使尺偏开一小格。
7. 赛恩沉默十秒，视线在尺、刻痕和阴影之间往返，没有立刻发火，也没有把零当作宠物或工具；十秒后他把尺摆正，零随即退回更深的阴影，不等待夸奖或解释。任不替零解释动机。
8. 章末留下赛恩追求完美的第一道裂缝：尺已经摆正，但地面、灯影或白线仍留下无法被完全消除的微小偏差；下一章进入火兽，对任的 Edge 在火焰中不稳定。

## 本章不能做的事

- 不能让赛恩在本章嫉妒任、羞辱任或转为反派；他仍处于兴奋、求知和自我要求阶段。
- 不能把赛恩父亲写成虐待者；父亲确实爱他，只是爱的表达长期等同于“还能更好”。
- 不能把“近乎满分”写成任轻易超越赛恩；任可以看见方法和偏差，不能直接复制赛恩十五年的训练。
- 不能把一度偏差写成世界本体错误；它属于当前训练条件与目标刻度之间的可测误差。
- 不能让零进入学院内部、使用攻击或自动侦察能力；零只在既有外院侧廊非照明侧，以一个轻微物理动作推歪尺。
- 不能把零推歪尺写成宠物恶作剧、嫉妒或对赛恩的哲学回答；动机保持未知，零保持主体性。
- 不能提前引入 Hough、Bounding Region、Mask、Ground Truth、火兽或光流术语；下一章才进入火焰目标与 Edge 不稳定。
- 不能让赛恩通过反复训练在本章完全修正一度偏差；本章的功能是建立压力，不是解决压力。

## 几何训练规则（作者侧）

- 训练场为外院一间半开放几何室，中央黑石台略有倾斜；三枚白色固定钉稳定当前平面。赛恩另有一枚普通金属钉作为个人标记，它不是任袖口里的那枚，也不参与支点、平面稳定或术式条件。
- 练习要求赛恩让金属线依次经过四个刻痕，再绕过一个会轻微下沉的标杆；线需维持十息，偏离刻痕达到一度即扣最后一分。
- 赛恩前三次完整尝试分别为稳定、近乎稳定、最终完成；最后一段白线只偏一度，教师给出近乎满分而不是完美分数，并把偏差刻在成绩木板上。
- 任看到赛恩先测当前平面，再调支点和线松紧；他能看见“最后一度”如何产生，却不能凭一次观察掌握赛恩的全部训练。
- 父亲家信由学院传信员交来，信封有几何家族的简洁印记，里面夹着惯常寄来的护腕药膏或细布；正文只呈现一行问题和赛恩的反应，不展开家族名称与政治资源。
- 夜间边界训练使用新的、单独的训练安排，不延续第17章的一晚许可：零仍在既有外院侧廊非照明侧，赛恩的尺伸到边界附近，零从阴影中只触碰尺的一端；赛恩不跨入非照明侧，零不进入学院内部。

## 场景推进

### 场景一：近乎完美

- 训练课从第19章的“当前不可区分”余波转入几何成绩。教师在木板上写出四个刻痕和十息维持要求，学生按顺序练习。
- 先上场的一名学生的线在第二个刻痕处抬起；另一名学生用力压住支点，导致平面另一侧的白光溅开。
- 赛恩先不碰线。他确认黑石台倾斜、三枚白钉的压点、标杆下沉的方向和当前风从哪一侧进来，再开始施术。
- 任观察赛恩的方法：赛恩不是把线拉到目标上，而是先让条件允许线稳定出现。

### 场景二：一度

- 赛恩在第三轮完整尝试中，先让第一段直线稳定，再让第二段绕过标杆，最后一段白弧在最后一个刻痕处只偏开一度。
- 赛恩立即察觉，试图在白线熄灭前微调；教师切断术式，防止他用额外力量改变已经记录的结果。
- 成绩木板落下近乎满分的刻痕。教师只说最后一道术式偏了一度，并把那一度刻在分数旁边。
- 赛恩没有争辩，也没有看任；他先看自己的支点，再看木板上那一小段偏差。
- 任第一次明白，对赛恩来说“几乎完美”不是安慰，而是一件仍然需要解释的失败。

### 场景三：家信

- 训练结束后，传信员把一封薄信交给赛恩。信封没有华丽装饰，只有简洁的几何印记，里面还夹着一小包父亲惯常寄来的护腕药膏。
- 赛恩拆信，里面只有一句：“为什么最后一个术式偏了一度？”没有夸奖分数，也没有责骂。
- 任看到赛恩的手指在纸边停住，随后把信折成原来的大小；他没有撕毁，也没有立即回信。
- 赛恩说父亲不是在责怪他，语气平静，却没有解释为什么一句平静的问题会让他重新检查整套支点。
- 任不把自己的“首先”搬出来；他只问赛恩要不要先收起信。赛恩回答“不用”，把信放在木记板下面，继续看训练记录。

### 场景四：边界的尺

- 夜间，任在外院侧廊内侧整理记录，赛恩得到许可使用靠近边界的一块窄石地继续校准。
- 赛恩把一把细长金属尺放在固定灯与非照明侧的交界附近，尺的一端伸到阴影能触及的位置；他用它确认黑石台训练中的一度偏差如何被灯影放大或缩小。
- 零的轮廓从非照明侧靠近。它没有进灯，也没有穿过边界；它先停住，确认赛恩的视线落在尺上，才从阴影里自主碰了一下尺的末端。
- 尺偏开一小格，金属边与地面刻痕不再平行。
- 赛恩看见了，却没有立刻纠正。他沉默十秒，视线在尺、刻痕和阴影之间往返；十秒后，他把尺摆正，零退回更深的阴影，没有等待夸奖或解释。
- 任没有替零解释，也没有替赛恩道歉；他只感到这一次偏差与课堂上的一度不同，它没有来自术式，也没有来自平面。
- 十秒后，赛恩把尺重新摆正。动作很轻，像把一句没有说出口的话压回原处。

### 场景五：章末

- 尺已经摆正，赛恩却没有立即继续读数。固定灯的亮边仍在轻微颤动，尺下的细灰线留下了一道无法完全重合的旧痕。
- 零退回阴影，动机不明；任没有把它归类为嫉妒、恶作剧或测试。
- 赛恩重新拿起木板，写下训练结果：99，以及旁边的一道一度偏差。
- 他没有把那一度擦掉，也没有把它改成零。
- 章末停在任看见的两种偏差：课堂上属于赛恩的偏差，边界处不属于任何人的偏差。下一章进入火兽与火焰中不稳定的 Edge，不提前解释差异来源。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 对赛恩的研究兴奋已有基本理解 | 看见赛恩的完美追求与家庭压力；不再把偏差只当技术问题 |
| 赛恩 | 因任的问题兴奋，仍相信精度能继续推进 | 近乎满分仍被父亲的一度追问牵动；面对零的尺偏差后仍选择摆正，不进入嫉妒 |
| 露米 | 保持独立训练与观察 | 本章不承担主线解释，关系暂不新增重大变化 |
| 零 | 在外院非照明侧保持边界 | 以轻微物理动作影响赛恩的尺；动机未知、主体性保留，不进入学院内部 |

## 读者此时应该误判什么

- 赛恩的父亲不爱他，或家族会直接惩罚他。
- 赛恩只要再训练一次就能把一度偏差完全消除。
- 零推歪尺是嫉妒、恶作剧或对赛恩的挑衅宣言。
- 任已经能够复制赛恩的几何精度。
- 尺的偏差与课堂的一度属于同一种原因。

## 本章新增或推进的世界规则

- 几何术的精度依赖当前平面、固定支点、标杆状态、灯位和记录刻度；近乎完美仍可能留下可测偏差。
- 学院成绩可以把极小偏差写入公开木板，家庭记录可以进一步追问偏差；“高分”不自动消除压力。
- 零可以在不进入照明边界的情况下对边界附近的实物施加极小的物理影响；这不是攻击、侦察或自动能力。
- 赛恩的完美追求不是单纯傲慢，而是长期被“你还可以更好”的爱塑形；本章只展示入口，不解释全部家庭关系。

## 技术概念与魔法翻译

- 先出现的现象：多支点几何练习、最后一度偏差、成绩木板、家信追问和边界处尺子的轻微偏移。
- 赛恩的经验方向：精确结构能减少误差，却不能保证条件、记录和对象永远一致；本章不命名 Ground Truth。
- 对应方向：推进 `GEO-01`、`SAIN-01` 的精度与完美压力；不新增 OpenCV / API 概念。
- 失败或代价：赛恩没有得到完美分数，父亲的爱以一度问题出现；他摆正尺，却不能让地面旧痕消失。

## 连续性与伏笔登记

- 延续 `GEO-01`：赛恩以当前平面和支点取得高精度，但精度不是世界本体。
- 延续 `SAIN-01`：赛恩仍先求知、训练和解释，不进入嫉妒；父亲关系首次具体露面。
- 延续 `G-01`：客观结构的诱惑从课堂问题进入赛恩的自我价值与家庭记录，但不命名 Ground Truth。
- 延续 `REL-04`：零的活动仍受既有外院侧廊边界限制，不把第17章的一晚许可误写成长期通行。
- 延续 `Z-02`、`Z-07`：零保持自主动作与动机未知，不被赛恩或任占有、驯化或解释。
