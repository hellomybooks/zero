# 第 14 章场景卡：《零级》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 14
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；测试装置的读数必须通过任能看到、听到和被告知的现象呈现
- 承接：第13章末，所有新生进入等级测试场；任尚未触碰石盘，装置先在石盘边缘亮起一道所有人可见的白色刻线；白界没有重开。任因带零同行，被登记为共同看护责任对象，普通住宿暂缓。
- 核心功能：完成任第一次制度化等级测试；让“零级”作为社会标签先落到任身上；通过先出现有效的 0、随后出现无法解释的 Undefined，建立二者不是同一状态的长期伏笔；让测试长老第一次出现表情变化；让任意识到一个输出可以影响他人如何对待自己，却不一定说明自己是什么。

## 本章必须完成的事

1. 先让其他新生获得稳定、可比较的测试结果，例如 23、57、108；数值表现为装置输出，不解释完整测量公式。
2. 同批有一名礼貌、克制、读数异常高的学生引起注意，但本章不正式展开其姓名、家庭和性格；第15章再正式写赛恩。不要把他写成公开羞辱任的人。
3. 任触碰石盘后，装置先输出清晰的 `0`；测试记录员或旁观新生将其口头归为“零级”，人群出现笑声或轻蔑。0 在本章先被当作最低等级或无效表现，不能被解释为终极身份。
4. 装置在 0 之后出现正式词 `Undefined`；这个结果不能被任主动触发，必须是装置自身从稳定输出转入异常状态。
5. 测试长老在看见 `Undefined` 时第一次明显改变表情，但不能解释测试原理、任的 Copy 身份、Zero 的 Alpha 关系或世界本体。他只需要让现场停止、封存记录或要求重测。
6. 任必须同时经历羞耻、愤怒、技术性好奇和自我保护：他不接受“0 说明你就是零”这种简单等同，却也不能立即向全场证明自己。名字相同的“零”和他的等级不能被写成同一身份。
7. 零必须对测试作出独立反应：它不因任得到 0 就安慰或卖萌，也不因 `Undefined` 就给出解释。它可以退到更暗处、观察记录槽、拒绝靠近装置或在任被嘲笑时选择不看人群，但行为要保留不可解释性。
8. 章末推进第15章《赛恩》：公开木牌写“0 / 零级”，`Undefined` 由长老保存在独立封存记录中；任看见那名高值新生停步看一眼封存纸板，再礼貌地点头离开，正式人物戏份留到第15章。

## 本章不能做的事

- 不能把 `0` 解释成世界系统里的空值、Copy、Alpha 或任的真实本体；它只是当前装置给出的一个输出。
- 不能把 `Undefined` 解释成装置坏了就结束；它必须让学院产生制度性不安，但本章不揭示原因。
- 不能让所有同学都因为任 0 而恶意霸凌；保留笑声、轻蔑、好奇和少数人的沉默差异，避免校园扁平化。
- 不能让任使用白界、代码或现代术语反向破解测试；他只能观察两个输出的先后和旁人的反应。
- 不能正式展开赛恩；高值新生的礼貌和观察留作第15章关系入口。
- 不能让零被写成任的等级对应物；零在场，但它的行为不解释任的 0 或 Undefined。
- 不能让长老直接说“这很危险，因为你是……”；他的异常只体现在表情、停顿、封存和命令上。
- 不能把数字测试写成电子游戏面板；装置必须有石盘、金属环、光线、记录槽和抄写动作的物质感。

## 测试装置规则（作者侧）

- 石盘、金属环、固定光源和记录槽是同一套装置；前排读数稳定时，光线和刻度会同步收束。
- 读数 0 是装置可以记录、可以归档、可以被旁观者理解的输出，因此先被社会化为“零级”。
- `Undefined` 不是第二个更低的分数；它发生在 0 之后，固定表现为：金属环尝试闭合却停住，记录槽的炭笔落下又抬起、无法留下完整笔画，随后石盘上显出正式词 `Undefined`。固定光照不变，任的视觉不进入白界。
- 任不能控制任何一个输出；他只能注意到 0 之后装置状态发生了性质变化。
- 测试长老可以中止公开流程、封存第二份记录并安排后续复验，但不宣布真相。

## 场景推进

### 场景一：别人有数字

- 第13章末任的手还悬在石盘上方；测试长老命令记录员先完成其他新生，避免让异常刻线影响全场秩序。
- 其他新生依次触碰石盘：第一个读数为 23，第二个为 57，第三个为 108。数字不是屏幕跳出，而是石盘内圈的刻痕逐格亮起，记录员用炭笔将结果抄到木牌上。
- 每个稳定结果都会得到不同程度的反应：有人松气，有人向同伴炫耀，有人因为低读数而提前移开视线。测试场形成一种不需要教师宣布的比较秩序。
- 一名礼貌的高值新生进入装置；金属环亮过常见刻度，教师彼此看了一眼，记录员抄写时手变慢。不给出姓名，不写家庭，不写他与任的正式关系，只让读者知道他“异常高”。
- 任看见那些数字被顺利放进记录：数值、姓名、起始课程。自己身旁的木牌却仍然有“无源”和“共同看护责任”两道额外的浅线。

### 场景二：0

- 记录员重新叫任。任把手放在石盘上，固定光照覆盖他的指节；这一次没有白界，只有石盘内部一圈冷光向内收束。
- 装置吐出清晰的 `0`：内圈没有亮起任何刻度，记录槽落下一枚刻有 0 的薄金属片，金属片撞在石盘下方的浅槽里，发出清脆的一声。
- 记录员确认：“零级。”旁边有人笑出声；有人把“零”误听成对任的称呼，也有人把它与零的存在混为一谈。任听见后者时产生尖锐不适。
- 任没有反驳“零级”这个词，因为他不知道学院如何定义它；他只知道装置确实给出了一个能被记录的结果。
- 测试长老保持平静，命令记录继续。他的平静让笑声持续得更久，也让任第一次感到“低值”不仅是能力评价，而是一种会改变别人站位的社会事实。

### 场景三：零不是任的零

- 外院侧廊的阴影里，零听见人群笑声。它没有靠近任，也没有低头安慰，只把自己的轮廓压到墙根的暗线上，避开测试场所有人的视线。
- 任想叫它，但停住。若他现在把零拉到自己身边，旁人会把“任的零级”和“零”写成同一个故事。任第一次主动拒绝用关系替自己解释结果。
- 一名新生问：“你的东西也叫零？”任回答：“它不是我的东西。”这句话让人群短暂安静，但不能改变记录板上已经写下的“零级”。
- 任看向记录槽：0 已经成为一个稳定的结果，稳定到不需要任何人理解他的过去。这个稳定反而让他不安。

### 场景四：Undefined

- 记录员正要把 0 的薄片收入公开记录匣，石盘内部忽然发出一声轻响；不是白界的嗡鸣，而是测试装置自己的金属环开始寻找闭合位置。
- 刚才清晰的 0 没有消失。金属环闭合到一半便停住，记录槽里的炭笔落下又抬起，无法在纸上留下完整笔画；固定光照仍然照着任的手，颜色没有改变。
- 任本能地想从声音和边缘判断装置哪里出了问题，却发现这一次没有可供他追踪的对象；不是目标隐藏，而是输出本身失去可重复的形状。
- 金属环停住后，石盘上出现一行学院使用的正式字样：`Undefined`。本章不把它翻译成完整技术解释；读者只需知道它不是 0 的同义词，也不是一个更低的数字。
- 现场笑声停止。有人后退，有人看向教师，有人小声说装置坏了。测试长老第一次改变表情：不是惊恐，而是像看见一份不该在公开场合出现的旧记录。

### 场景五：长老封存第二份记录

- 测试长老命令所有人离开安全线，要求记录员不要把 `Undefined` 直接写入新生木牌；他让另一名教师盖住石盘的刻度，固定光源也被收窄。
- 任问：“刚才不是 0 吗？”长老不回答“是”或“不是”，只说：“先记住顺序。”
- 记录员将 0 的薄片收入公开记录匣；另一张纸板被长老亲自折叠、封蜡，写上 `Undefined`。两个结果第一次被物理地分成两份。
- 长老对任说：“零级先成立。”停顿后又补充：“后面的东西，不在今天的公开记录里。”这不是解释，而是一道制度性遮挡。
- 任感到羞耻、愤怒和好奇同时出现。他想证明装置错了，又想知道为什么 0 之后才出现这个词；他最后只问：“复验什么时候？”长老回答：“会通知你。”
- 共同看护责任使任不能留在普通新生宿舍，`Undefined` 又使他被单独标记；他的入学从“低值”变成“低值且不可归类”，但学院没有正式宣布这意味着什么。

### 场景六：高值新生的礼貌

- 测试流程被迫暂停后，其他新生在教师指引下离场。那名异常高值的学生经过任身边，停了一下。
- 他停步看了一眼长老掌下尚未干透的封蜡纸板，再礼貌地点头，像是承认任刚才经历了一件值得记住的事；不要在本章给出正式姓名或长对话。
- 任对这种礼貌产生比嘲笑更复杂的不适：如果对方不是轻蔑，而是认真观察，那么自己就不再只是一个笑话，而成为别人研究或比较的对象。
- 高值新生离开，边境视术师在远处看见任的公开木牌和长老掌中的封存纸板；他没有替任解释，只提醒任不要把装置的输出当成自己的全部。

### 场景七：零的选择与章末钩子

- 任走到外院侧廊找零。零没有安慰他，也没有靠近测试场；它正在观察一块被固定光照切开的墙面，像在比较“看得见的部分”和“没有被照到的部分”。
- 任说“他们叫我零级”，零不作出可被翻译的回答；它把一小片阴影从墙根移到更深处，选择不回到测试场旁边。
- 任没有追问，也没有要求零证明自己不是他的零。他第一次允许一个相似的词停在两个不同的对象上，而不急着把它们合并。
- 测试长老在记录厅封存第二份纸板时，从门缝看向任一眼；他的表情已经恢复平静，但手指仍压在封蜡上。`Undefined` 只留在长老掌握的独立封存记录里，不进入任的公开木牌。
- 章末落在任的木牌与长老的封存纸板之间：任的公开木牌写着“0 / 零级”，远处尚未干透的封蜡纸板上只有一个词：`Undefined`。
- 第15章《赛恩》承接高值新生的正式登场和任第一次被礼貌比较；本章不解释测试装置和第二份记录的来源。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 带着共同看护责任进入测试，期待学院给出可理解答案 | 被公开归为零级，私下记录为 Undefined；开始怀疑数值能否代表身份 |
| 零 | 观察任进入测试，拒绝被任的档案定义 | 不把任的零级当作自己的身份；继续保持独立观察和行动 |
| 测试长老 | 负责维持公开测试秩序 | 因 Undefined 第一次改变表情并封存第二份记录，但不揭示原因 |
| 高值新生 | 读数异常高，尚未正式进入主线 | 以不带嘲笑的礼貌观察任，为第15章赛恩线留下入口 |
| 学院同学 | 通过数字建立比较秩序 | 将任同时当作零级笑话和异常对象，态度开始分裂 |

## 读者此时应该误判什么

- 0 就是任的真实能力值，Undefined 只是装置在 0 后短暂坏掉。
- 任越是特殊，学院就越会立刻保护他或给他特权。
- 零和任的“零”必然来自同一底层原因。
- 测试长老已经理解任的本体，只是在掩盖真相。
- 高值新生对任的礼貌只是更高级的羞辱。

## 本章新增或推进的世界规则

- 学院的等级测试能产生可被社会使用的数值；数值一旦进入木牌和队列，就会改变旁人对人的判断。
- 0 是可记录、可比较的稳定输出；`Undefined` 在 0 之后出现，属于另一种状态，不等同于更低等级。
- 学院可以把同一测试拆成公开记录和封存记录；制度保存信息的方式本身会制造差异。
- 观察到任的异常不等于理解异常；测试长老的表情变化、封存和复验命令只说明制度压力上升。
- 零与任的等级词保持分离；相同词语可以被社会强行连在一起，但两个对象不因此同源。

## 技术概念与魔法翻译

- 先出现的现象：稳定数值帮助学院比较新生；任得到 0 后装置从可记录状态转入 `Undefined`，社会记录与异常状态分裂。
- 任的私人理解：这不是“数值更低”，而是装置无法把后续状态放进同一类输出；他只观察顺序，不命名 API。
- 对应方向：`S-01` 的 0 / Undefined 区分；这是表示层和分类制度的第一次明确冲突，不解释测试装置底层。
- 失败或代价：任不能控制输出，不能立即洗清零级标签，不能要求学院公开封存记录；零也不会替他解释。

## 连续性与伏笔登记

- 延续 `ACAD-02`：测试装置以稳定输出安排课程，但输出不等于身份本体。
- 延续 `SOC-03`：界视者字段、共同看护责任和零级标签共同展示行政记录如何影响权限。
- 延续 `S-01`：0 与 Undefined 是不同状态；第14章只建立差异，不解释原因。
- 延续 `REL-02`、`Z-07`：任不把相似标签等同同源，零保持独立行动。
- 新增候选 `REN-04`：任第一次被公开数值化并私下封存，未来回收为身份与自我价值焦虑。
