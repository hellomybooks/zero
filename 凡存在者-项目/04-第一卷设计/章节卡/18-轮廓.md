# 第18章场景卡：《轮廓》

## 章节身份

- 卷：第一卷《白色边缘》
- 篇章：ARC 02《凡存在者》
- 章节：Chapter 18
- 状态：场景卡与正文已完成审校，定稿候选
- 视角：任的近距离第三人称；正式技术词可在事件之后作为任的私人联想出现，但不向课堂解释成 API
- 承接：第17章的夜间许可只在当晚有效；次日下午，任进入复杂目标辨识课。零回到既有的外院侧廊非照明侧，不进入课堂。露米知道任话多却愿意把问题拉回现实；赛恩继续对任的分析方式保持研究兴趣。
- 核心功能：把前5—7章的 Edge、前16章的颜色差异和第15章的几何条件汇入第一次“闭合轮廓”事件；让任从看见边缘，进化为判断哪些边缘属于同一个目标；首次出现 Contour 作为任对现象的私人翻译；同时明确闭合轮廓不等于知道对象本体。

## 本章必须完成的事

1. 课堂先展示真实魔法对象和危险：学院让学生辨识一只真实活体、受学院术式限制的折尾兽。目标有躯干、贴近身体的尾部、反光水痕和背景暗线，普通边缘会彼此混合。
2. 教师要求学生用细灰粉和短铜线建立一个“闭合的外沿”：细灰粉受术力显出白线，短铜线牵引白线；三枚白色固定钉只负责稳定石槽平面和安全边界，白线不能碰钉，也不能把水面反光或背景暗线算进去。
3. 学生失败必须具体：有人闭合了水面反光，形成空环；有人把尾部当成第二个目标，环线分裂；有人追着折尾兽当前的位置画，目标一动，线头撞上固定钉，热光反弹。
4. 任不能一开始就想到 Contour 或自动施法。他先通过 Edge 观察边缘的连续性、相邻两次观察中的局部位移、间隙和重叠关系，提出“这些线是不是同一个东西留下的”这一具体问题；他不能预言目标下一步，也不能把少数边缘的变化扩展成完整运动规律。
5. 赛恩只负责用课堂三枚白色固定钉稳定石槽平面和安全边界，不能替任选择转向的边缘；露米用颜色差异指出水面反光与折尾兽外沿不在同一层，但不能替任闭合形状。三人形成互补，不立刻成为固定队伍。
6. 任第一次成功闭合一条复杂目标轮廓：他不画出内部，也不证明折尾兽的身份，只沿连续、同向变化的边缘收拢白线，让它绕过反光、接回尾根，形成稳定闭合环。术式只能维持短时间，且只触及当前可观测部分。
7. 成功必须伴随限制或代价：闭合环虽然稳定，却没有触及目标尾端伸出的另一部分；折尾兽仍能用尾部碰到白线尚未触及的灰粉，教师必须收束术式。任意识到闭合轮廓是对可见边界的操作，不是“目标本身”。
8. 章末让任脑中第一次自然出现一个熟悉词：`Contour`。他不把它当咒语，也不向别人解释，只把它写在自己的旧笔记角落或记在心里；下一章《那个问题》从“边缘是否定义物体”推进，不提前进入 Bounding Region。

## 本章不能做的事

- 不能让任念出 Contour 就释放术式；必须先经历边缘连续性、错误闭合、目标运动和物理危险，术语只能是事后的私人翻译。
- 不能把闭合轮廓写成识别折尾兽名字、读取本体或证明身份；它只把一组可观测边缘收成一个封闭结构。
- 不能把目标写成静止图像；目标必须移动、遮挡、反光或被背景切断，迫使任只比较相邻观察中的少数边缘变化，判断哪些边缘暂时同向。
- 不能让赛恩直接解决“哪条边属于目标”；他的几何强在支点和平面稳定，不能替代对象归属判断。
- 不能让露米直接看见完整轮廓；她只能指出颜色层、反光和目标外沿的差异，水面、灯位或观察距离改变时也会失效。
- 不能让零成为攻击或自动侦察工具；第17章的一晚许可已经结束，零不在本章课堂现场，不替任完成辨识。
- 不能提前引入 Bounding Region、Mask、Inside / Outside、Ground Truth 或“世界源码”；只保留“闭合”“外沿”“白线没有触及的部分仍未被确认”的奇幻问题。
- 不能让任在章末彻底掌握 Contour；本章成功只针对一个短时间、有限范围、边缘尚连续的目标。

## 轮廓练习规则（作者侧）

- 练习场中央有一条浅黑石槽，槽内限制着一只真实活体折尾兽。折尾兽是独立的课堂活体练习兽，不是第21—23章的火兽；它外形不必完整展示，只让读者看到背甲、四足留下的短亮痕、贴身尾部和被水盘反射出的第二道边。课堂人物第一次只称它为“目标”或“槽中活物”，不知晓“折尾兽”这一作者侧称谓。
- 槽底铺着细灰粉，浅水只浸过灰粉表面；槽外三枚白色固定钉只负责稳定石槽平面和安全边界，和赛恩在第15章交给任的普通金属固定钉不是同一组器具。学生以短铜线牵引由细灰粉显出的白线，从一个可靠起点沿目标外沿走一圈，再回到起点；白线闭合后才能形成短时稳定环，且不得碰到固定钉。
- 真实目标的边缘与水面反光会同时出现，但二者变化不同：在相邻的两次观察中，折尾兽的少数边缘会随躯干和尾部朝同一方向挪动一小段，反光受水面波动影响，方向会延迟或相反；背景暗线固定在石槽上。任只能使用眼前这几次局部变化，不能据此预言目标下一步。
- 闭合术式需要边缘连续到足够程度。缺口太大、目标被遮挡、反光加入、背景混入或目标突然改变方向时，白线会断裂、分叉、围错区域或反弹。
- 任的第一次成功依赖三个条件：他承认目标边缘存在缺口，利用几条边缘在相邻观察中的同向变化暂时跨过最小间隙；赛恩稳定三枚白色固定钉与当前石槽平面；露米指出水面反光在另一层并不跟随目标。
- 成功的白环只维持十余息，且有一截尾端始终未被白线触及；教师收束后，白线消失，折尾兽仍然是未被完全理解的活物。

## 场景推进

### 场景一：复杂目标

- 复杂目标课在一个有顶的石室内进行，地面比几何练习场更低。中央浅黑石槽外钉着三枚白色固定钉，槽内有只浸过细灰粉表面的浅水；细灰粉沿槽底铺开，等待术力将它显成白线。
- 教师没有告诉学生目标名称，只说学院要测试他们能否从多条边缘中找出属于同一个对象的连续外沿。
- 那只活物在石槽内移动。任先看见背甲的暗边、四足压过槽底灰粉留下的亮痕和贴着身体的尾部；水面又映出一条延迟半息的反光，背景石缝形成第三组稳定暗线。
- 教师要求学生不要追着目标内部看，只建立闭合外沿。任听见“闭合”二字时，脑中闪过的不是咒语，而是某种必须让线回到自身的约束。

### 场景二：错误的闭合

- 第一名学生从水面亮点开始画线。她的白线绕过一圈反光，最后闭合成一个空环；白线圈住的地方没有活物，只有一片晃动的水光。教师让她立即收束，否则空环会把热力积在水面。
- 第二名学生把折尾兽的尾部当成独立对象，画出两个相邻的小环。两环都短暂亮起，随后在尾根处相互拉扯，白线分裂，安全钉发出短鸣。
- 第三名学生按着目标当下的位置画线，没有把起点固定在可靠边缘。槽中活物突然转身，白线被拖到固定钉旁，反弹的热光擦过他的手背，留下红痕。
- 任站在三枚固定钉外，看见所有人都在试图把“现在看见的线”立刻围起来，却没有先比较前后两次看见的那一小段变化。
- 教师说：“你们画出了形状，却没有问形状从哪里连续。”这句话是课堂要求，不是世界本体解释。

### 场景三：三种观察

- 赛恩先检查课堂三枚白色固定钉、石槽平面和灰粉的倾斜。他可以让白线在被固定钉稳住的石槽平面上转向，却不能判断反光属于目标还是水面。
- 露米站到侧面，看见折尾兽背甲外沿的颜色与水面反光存在细微差异；她说反光在目标转身后慢半息，且位于另一层薄光里。她不能把这个差异画成完整轮廓。
- 任看见两种边缘在前后两次观察里朝同一个方向挪动，也看见尾部与躯干之间有一处几乎断开的暗缝。他问：“如果它们不是同一个连续形状，为什么每次都一起转？”
- 教师没有回答，只让下一组继续。
- 赛恩对任说：“如果你要闭合，先选一个能回来的起点。”露米补充：“别把水里的那条算进去。”两句话分别给出几何支点和层次排除，任仍必须自己决定目标外沿。

### 场景四：任的第一次闭合

- 折尾兽突然撞向石槽一侧，背甲边缘在灰粉里断开。白线从任手中引出，先沿背甲，再绕过一段被水面遮住的间隙。
- 任没有把缺口当成目标消失，也没有把反光硬接进来。他观察折尾兽的四足和尾根同向变化，判断那一小段暗缝是遮挡造成的短缺口。
- 他让赛恩把课堂的第一、第二枚白色固定钉重新压稳，再把第三枚挪到石槽刻痕旁。赛恩照做，白线不再因石槽倾斜而抬起。任袖口里的那枚普通金属固定钉被手腕带动，硌过皮肤；那不是课堂三枚白色固定钉中的任何一枚。
- 露米指出水面反光向后退了一点：“现在接，不是刚才。”任等反光错开，沿背甲边缘把线收向尾根。
- 白线在尾根处几乎断开。任的手腕被术力反震，袖口里的普通金属固定钉撞到皮肤。他没有用更大力量拉直，而是等那几条边缘再次朝同一个方向挪动，才顺着留下的短暂迹象把线弯回起点。
- 最后一小段白线悬在半空，像一根没有找到落脚处的细丝。折尾兽的四足先后压过灰粉，尾根跟着躯干偏了一寸；那根白线忽然自己抖了一下，贴回任刚才留下的亮痕。
- 白光闭合。石槽里出现一个不规则的稳定环。它不像完美圆形，边缘有细小起伏，却把背甲、四足外沿和贴身尾部暂时收在同一圈内；白线绕过了水面反光，也没有沿背景石缝延伸。
- 白线圈住的浅水忽然静止，尚未触及的水纹却仍一圈圈撞向石槽；折尾兽的四足同时收紧，像有什么看不见的东西只牵住了那些被白线选中的边。任听见自己的心跳被白光截成一段一段，直到尾端在白线尚未触及的灰粉上扫过。

### 场景五：闭合不等于本体

- 稳定环只维持十余息。折尾兽的尾端忽然向白线尚未触及的地方伸去，碰到那里的灰粉。白环没有立刻崩溃，却无法接上那一小段新增部分。
- 任想把环再扩大，教师立刻喝止：“不要改变已经闭合的结构。”
- 尾端敲在白线尚未触及的灰粉上，热光沿白线跳了一下。任收回手，白环随即熄灭。
- 折尾兽仍在石槽里走动。它没有因为被围过一次就变成一个已知名称，也没有因为环消失就失去刚才的边缘。
- 教师问任：“你刚才闭合了什么？”
- 任看着黑石槽里的折尾兽，回答：“我能连续看见的那一部分。”
- “不是它？”
- 任没有立刻回答。
- 赛恩看向白环消失后的灰粉，露米看向水面还未散尽的反光。三个人都没有替他填上答案。

### 场景六：私人翻译

- 教师把细灰粉收回盒子，要求学生记下失败原因：反光误合、尾部误分、起点不稳、目标突然改变方向。
- 任在旧笔记角落画了一圈不规则闭环，旁边写下“不是画圆，是让边回到自己”。
- 他看着那一圈线，脑中忽然浮出一个熟悉的词：`Contour`。
- 这个词没有从石槽里发出，也没有让白环再次亮起。它只是像一枚旧世界里的标签，被他暂时贴在刚才发生的事情旁边。
- 露米凑过来看了一眼：“你又在给东西命名？”
- 任合上笔记：“只是记一下。”
- 赛恩问：“这个词是什么意思？”
- 任想解释，嘴唇动了一下，却把话咽了回去。这个词太像他自己的旧世界，不该在这里变成一条未经验证的规则。
- 露米没有追问。赛恩只把“闭合条件”写进木记板。

### 场景七：章末问题

- 下课时，折尾兽被教师带回石槽后方的暗门。白环留下的浅光已经散了，只在灰粉里留下一个不完整的闭环痕迹。
- 任站在三枚白色固定钉旁，看着尾端曾经越过白线的那一小段灰印。
- 他已经能让一组边缘闭合，却仍不知道那一小段没有被白线接上的尾端，是否仍属于刚才那只折尾兽。
- 赛恩走到他身边，没有追问答案，只把“尾端未接”写进木记板。
- 露米看着灰粉里的断环：“先记住它没有被接上。”
- 任没有回答。
- 章末停在那道不完整的白痕和尾端灰印上：白线曾经闭合过，却没有因此替那一小段尾端决定归属。下一章进入“边缘是否定义物体”的问题，不提前出现 Bounding Region。

## 读者此时应该误判什么

- 闭合的白环就是活物的真实身体或完整身份。
- 任只要看见足够多的边缘，就能永远把复杂目标正确闭合。
- 赛恩的几何支点或露米的颜色差异可以单独替代任的判断。
- 轮廓闭合后，白线圈住的地方就必然只有一个对象，白线尚未触及的地方就必然没有它的部分。
- `Contour` 是一个可以直接施放的咒语名称。

## 本章新增或推进的世界规则

- 复杂目标的边缘可以因遮挡、反光、背景暗线和局部变化而断裂或混合；闭合轮廓需要选择哪些边缘共同属于一个暂时结构。
- 闭合轮廓依赖当前观察条件、可靠起点和足够连续的边缘；目标突然改变方向、缺口过大或层次混入时，闭合会失败、分叉或围错区域。
- 稳定闭合的边界只描述白线当前触及的可观测范围，不证明被圈住的对象本体，也不保证目标的所有部分都被白线接上。
- 传统几何、颜色层分离和边缘连续性可以互补，但没有一种观察自动成为完整现实。

## 技术概念与魔法翻译

- 先出现的现象：学生在活性目标、反光和背景暗线中失败；任沿同向变化且连续的边缘收拢白线，第一次形成不规则闭合环。
- 任的私人理解：闭合不是画一个漂亮形状，而是让一组被判断为同一目标的边缘回到自身；本章后才浮出 `Contour` 这个旧世界词。
- 对应方向：`findContours / Contour` 从第一卷第18章进入；后续可连接复杂目标、内外轮廓和边界定义，但本章不命名 API 或讨论源码。
- 失败或代价：反光会形成空环，尾部会被误分，目标突然转向会让闭合边界滞后；第一次成功只维持十余息，且无法接上白线尚未触及的尾端。

## 连续性与伏笔登记

- 延续 `EDGE-01`、`EDGE-02`、`VIEW-01`：任仍从边缘和变化寻找线索，但开始主动判断边缘的归属关系。
- 延续 `GEO-01`、`SAIN-01`：赛恩的支点帮助稳定白线，但不能决定对象归属；他继续保持研究兴趣，不提前进入嫉妒。
- 延续 `COLOR-01`、`LUMI-01`：露米用色差排除水面反光，能力受层次和条件限制，不解释来源。
