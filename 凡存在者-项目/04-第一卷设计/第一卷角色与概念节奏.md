# 第一卷角色与概念节奏

## 角色中心

| 章节段 | 情绪中心 | 主要关系变化 |
|---|---|---|
| 1—12 | 任 / 零 | 从陌生、互相利用到第一次不能失去 |
| 13—24 | 任 / 赛恩 / 露米 | 从垫底、比较到学院中的认可与嫉妒萌芽 |
| 25—36 | 零 / 伊莉亚 | 能力失效、价值焦虑、从寻找边界到定义边界 |

## 概念出场顺序

| 段落 | 先出现的现象 | 任的译名 | 必须保留的限制 |
|---|---|---|---|
| 1—4 | 看不见的存在只留下痕迹 | 尚不命名 | 只能通过后果推断 |
| 5—7 | 白线、边缘、完整轮廓 | Edge / Canny | 噪声、过载、不能自动成功 |
| 8—12 | 源痕、映入者、界视和群体魔兽 | 不是新 API，而是世界规则 | 任没有本地源痕，社会态度会变化 |
| 13—17 | 等级、颜色异常、学院术式 | 尚不急于命名 | 任从专业人士变成零级新人 |
| 18—20 | 复杂目标的闭合边界 | Contour | 目标必须有足够连续边缘 |
| 21—23 | 火焰中识别属于火兽的区域 | Bounding Region | 只能圈定范围，不能证明内部只有目标 |
| 25—26 | 破损区域重新连接 | Morphology / Closing | 修复暴露伊莉亚的控制欲 |
| 27—31 | 敌人和背景无法分离 | Foreground / Background | Edge、Contour、Bounding 全部失效 |
| 32—35 | 人为指定内外区域 | Mask / Inside / Outside | 定义边界同时拥有排除和伤害的权力 |
| 36 | 遗迹文本和视觉异常 | Representation | 第一卷只给出合理但错误的解释 |

## 文字与视觉节奏

- 前 4 章：可见世界仍然有颜色，读者先学习恐惧。
- 第 5—7 章：白线逐渐变成理解世界的方式。
- 第 8—12 章：从个人逃生转向社会接触。
- 第 13—24 章：能力开始可训练，但任遭遇排名和比较。
- 第 25—30 章：能力失效，技术优势被夺走。
- 第 31—36 章：任不再只寻找边界，而是尝试定义边界。
