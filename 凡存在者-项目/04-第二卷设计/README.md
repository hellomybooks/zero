## 使用规则

- 先读取第一卷收束审计，再读取第二卷总控和当前章节卡。
- Threshold 必须先以城市制度、入城规则、检测、等级、群体行动或具体危险出现，再由任翻译为技术概念。
- 第一卷卷末的“世界存在可处理显现结构”是错误但有用的模型；第二卷不能把它直接写成真相。
- 学院、王都和城市制度不是天然客观的背景板；分类会改变权限、资源、羞耻和暴力分配。
- 任仍然会分析，但不能只把人的痛苦处理成分类问题；零的定界态不能被行政标签直接取代。
