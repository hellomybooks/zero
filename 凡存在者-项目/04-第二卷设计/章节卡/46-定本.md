## 状态

- 状态：通过 / 定稿候选，可进入正文生产。
- 承接：第二卷第45章《不必第一》正文与正文审校。
- 篇章：ARC 04《回到王都》。
- 本章功能：把赛恩在父亲旧房里留下的私人裂缝，推进为一次公开的选择；让他在一项会延误外城药运和饮水的旧门修缮中，亲眼见到一种“只要条件被固定，就能反复得到同一答案”的制度与器具，并因此开始相信世界也许存在不依赖亲情、前例和身份的正确答案。
- 本章主概念：定本 / 校准——一套被承认的参照能把不同人的说法压到同一条可办理的线，但“每次得到同一结果”仍不等于世界本身只有这一种答案。

## 一句话梗概

赛恩带着父亲留下的儿童画，凭旧家档案书记员为一项单案责任申请的协验牌进入王都内层定本厅，参与一组关系到外城药运和饮水的远古门纹残片复原；任因“待担保复验”只能隔着外廊观看。定本厅用固定灯位、卡槽和甲号参照框把三份彼此不齐的记录压成一份“可入定本”的标准形，赛恩看见只要所有人站到同一位置，争执就会停止，因而相信自己多年追逐的精确并非徒劳；任却用保管室的乙号旧参照框做不入档演示，让另一份残片在另一套条件下完整贴合。赛恩没有因此立即加入任何组织，却在校验簿上签下自己的名字，选择先站到“寻找正确答案”的一侧。

## 本章不能做的事

- 不能让定本厅证明世界确实存在唯一正确答案；它只能证明一套参照、器具和办理规则能够稳定地产生同一个结果。
- 不能让任一句“这是人为标准”就推翻定本厅的行政后果；他只能展示另一种条件下的不同结果，不能马上获得内层权限或撤销定本。
- 不能让赛恩因为父亲的一张儿童画立即放弃精确、规则与结构；儿童画此处只在他身边形成反差，不提前完成第47章的动摇。
- 不能让赛恩把父亲私人道歉写成家族制度变更；“第一”仍留在牌册里，公共责任簿仍保留“外部责任未结”。
- 不能让任进入定本厅核心桌，也不能让赛恩用家族姓氏替任取得正式阅览权；任的“待担保复验”只允许他站在外廊观察和提出一次异议。
- 不能把“单案协验牌”写成第45章后恢复的家族权限；赛恩拿到的是旧家档案书记员向王都旧门修缮署申请的一次性牌，只允许本次残片校验和后续责任说明，不恢复印记借用、禁书库、会客廊或任何公共通行权。
- 不能把定本厅写成全知、恶毒或阴谋组织。里面的人相信固定参照能减少争执和伤害，但他们会把未对齐的差异推出可见范围。
- 不能提前让赛恩正式加入教会、宣布守护某种真值或知道 Ground Truth；本章只建立他对客观正确答案的情感依附和制度入口。
- 不能提前揭示 Copy、Observed、Original、旧页、空册、门内刻痕或世界本体；远古残片只是被不同人复原的材料，不是终极答案的证据。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

## 核心规则

### 1. 定本厅只能在固定条件下给出结果

- 残片必须放入固定卡槽，灯必须降到规定高度，参照框必须由当值校验师锁定；任何人不能在结果出来后随意换位置再要求保留原结果。
- 校验师先在簿上写下参照框编号、灯位、残片顺序和允许的细小偏差，再让候选复原件进入卡槽；缺少其中一项，结果只能记为“未定”。
- 复原件若能同时贴合参照框左上、右上、左下、右下四个固定点，以及外侧缺口、内环缺口两道缺口，就可以获得“可入定本”；六处有一处不合，材料不被宣判不存在，只会被放到“旁存差异”栏，暂时不能进入主档案和内层调用。
- 这套规则让不同人可以重复得到相同结果，却没有证明参照框本身来自世界的唯一标准。

### 2. 身份决定谁能提出条件，谁只能接受结果

- 定本厅只允许中央档案员、持有内层阅览印记的人和本案获得一次性单案协验牌的人触碰参照框；赛恩的牌由旧家档案书记员向王都旧门修缮署申请，只对本案生效，不恢复他的家族印记、禁书库资格、会客廊通行或其他公共权限；任只能在外廊观察。
- 任可以提出一次“换参照框复验”的异议，但异议会被记成他的个人请求，不会自动改变本次定本结果；若要正式改动参照框，必须由两名内层校验师共同签名。
- 赛恩可以为任申请旁观，但不能替任获得触碰残片、读取旁存差异或进入核心桌的权限；他能调用的只是旧家档案中的一份来源和本案协验牌，代价是签名后要承担修缮追问。
- 外廊旁观者可以看见灯、框和残片，却看不见保管室里被推出主档案的差异页；“看见过程”不等于拥有完整材料。

### 3. 定本不是摧毁差异，而是重新安排差异的位置

- 被定为主形的复原件进入主档案，其他版本进入旁存差异栏；后续办事人默认先读主档案，只有具备权限者才能申请调出旁存差异。
- 校验师认为这能减少同一残片被多人反复争论的成本；任看到的却是，一旦主形被写入定本，未对齐的版本会越来越难抵达下一扇门。
- 赛恩认为“至少所有人知道从哪里开始”，任认为“从同一个地方开始”可能正是把其他可能性关在门外；两种判断都必须有现实代价，不能由作者直接宣布谁正确。

### 4. 赛恩的签名会把私人信念变成公共责任

- 赛恩若在校验簿上签名，表示自己认可本次参照条件足以形成“可入定本”，并承担有人追问残片差异时的说明责任；签名不代表家族承认远古残片的全部含义。
- 他可以拒签，让本次复原停在“未定”，但这会使一份需要进入城市防护修缮的残片继续等待，影响下一轮资源调度。
- 赛恩最终签下自己的名字，并在附注写明“旁存差异不得销毁”；这不是公平胜利，而是他选择相信固定规则同时试图保留一点未定空间的第一次公开动作。

## 场景推进

### 场景一：一扇门因没有定本而关闭

- 现实事件：北侧旧药运门的修缮队把三份门纹残片送到王都旧门修缮署。旧门的防护纹无法确认，药车和饮水车只能绕行；修缮署说明，若本次继续记为“未定”，外城药运和北侧贫民街的饮水还要继续等待。
- 责任桥梁：旧家档案书记员从赛恩父亲留下的旧牌册中找到一份与该门维护有关的家族存档，又看见赛恩身上的“外部责任未结”。修缮署不把家族姓氏当作真相担保，只给赛恩发出一次性“单案协验牌”：他可以触碰本次残片，若签名，日后必须出席说明；本案结束后牌立即失效。
- 现实代价：赛恩可以拒绝，旧门就继续关闭，修缮队无法把任何一份门纹送入主档案；他也可以接受，但这不会恢复家族印记、禁书库、会客廊或其他公共通行权，只增加一项公开责任。
- 任陪赛恩来到内层外廊，门卫收走任的临时牌，只允许他在一条灰线外等候；赛恩的单案协验牌被换成一枚只能触碰本案核心桌的窄牌。
- 任的反应：他问赛恩是不是又要用家族门把问题关起来。赛恩没有反驳，只说“这次不是进去，而是看它怎么把不同的东西变成同一个结果。”
- 赛恩的状态：他反复确认衣内儿童画仍在，随后把手放回身侧；任第一次看见他把私人伤口与一场公共校验放在同一件衣服里，却不知道二者是否相连。
- 门卫的规则：任可以在外廊看灯位变化，但不得记录参照框上的刻点；若想提出异议，只能等第一次结果完成后，由校验员把异议栏推到灰线外。
- 章内钩子：定本厅内传出一声木卡扣合的轻响，三块形状不同的残片被放到同一张黑桌上。

### 场景二：三份残片与一只参照框

- 现实事件：核心桌上放着三份来自不同保管处的门纹残片：甲片边缘完整但中线缺失，乙片中线清楚但角部破损，丙片只有拓印留下的浅痕。三份材料都声称来自同一座北侧旧药运门，却从未被同时校验。
- 校验动作：校验师先锁定甲号参照框，框上明确标出左上、右上、左下、右下四个固定点，以及外侧、内环两道缺口；再降下低灯，把三份残片逐一压入卡槽。每次压入前，书记员都读出参照框编号和灯位，避免事后更改条件。
- 赛恩的参与：他没有先挑自己喜欢的版本，而是按照规定把三份残片分别放入；当第一份与铜框的两道缺口同时贴合时，他的手指轻轻收紧。
- 结果：甲片六处全部贴合，获得“可入定本”的白签；乙片四个固定点与内环缺口贴合，但外侧缺口错开，丙片只有三个固定点与内环缺口贴合，另一个固定点和外侧缺口都错开，因此乙、丙被放进“旁存差异”格。残片没有被烧毁，也没有被宣布为伪造，但主档案只留下甲片的线形。
- 赛恩的震动：他看见校验师没有询问家族声望，也没有让最会说话的人获胜；只要参照框、灯位和卡槽一致，三个人轮流复验都能得到同一结果。
- 章内钩子：校验师说：“这不是谁说服了谁。是它自己每次都回到这里。”

### 场景三：任提出一次异议

- 现实事件：第一次结果完成后，任被允许站到灰线边，由校验员把异议栏推出门外；他看见甲片的浅痕在铜框下显得完整，却注意到乙片的缺口方向与外廊墙上旧刻痕更接近。
- 任的请求：他要求由校验员把铜框旋转半格、把灯移向墙侧，再让乙片进入一次；他没有说甲片一定错，只说“条件换了，结果可能会换。”
- 制度回应：校验师拒绝当场改变参照框，理由是本次校验已经锁定条件；任的请求被写入异议栏，成为“待另行申请的个人观察”，不会阻止第一份进入主档案。
- 任的证据：任指出保管室里还有一只乙号旧参照框。校验师让保管员把乙号框取到外廊下的演示桌，再由校验员把灯移向墙侧，并明确写下“只作不入档演示”；任只能指定自己要看的条件，不能触碰参照框或移动灯具。乙片在乙号框的六处都贴合，甲片只贴合三个固定点和一道缺口。这个结果既不能推翻甲号框下的定本，也不能让乙片获得主形资格，因为本次修缮已经锁定甲号框，且乙号框的来源没有经过本案确认。
- 关系冲突：任说“你们不是发现了唯一的形，你们只是先规定了什么叫贴合。”赛恩回答：“如果没有规定，所有人都可以把自己的错说成另一种可能。”
- 赛恩的刺：任说自己只想保留不确定，赛恩反问：“不确定能替谁挡住下一次门塌？”这句话把他的追求从性格偏好推进到现实防护和责任问题。
- 章内钩子：校验师把第二份残片放回旁存格，提醒任：“异议可以留下，但主门只认定本。”

### 场景四：主档案与旁存差异

- 现实事件：赛恩跟随书记员进入残片保管室，任只能从外廊的窄窗看见两排木匣；主档案匣有白色封绳，旁存差异匣没有封绳，只有可追问的灰签。
- 书记员的说明：主档案用于修缮、调度和后续抄录，旁存差异只有在申请人说明用途后才能调出；这不是销毁差异，而是让差异排到后面。
- 赛恩的选择：他问如果旁存差异以后证明主形错了怎么办。书记员回答可以重新开定本，但必须由新的参照框和两名内层校验师重新签字；旧主档案不会自动消失，只会旁边加一条更改记录。
- 任的发现：他从窄窗看见旁存匣中还有数十只没有进入主门的残片，外廊的普通修缮申请却都在等主档案的形线；一份“暂不销毁”并不等于一份“仍然容易被使用”。
- 赛恩的内心：他第一次感到这套规则有一种家庭没有给过他的稳定：至少它把“你应该懂”写成了可重复的条件，而不是让他猜父亲的沉默。
- 章内钩子：书记员递给赛恩校验簿：“协验席只有最后一栏还没有签。你签，定本就能送入城市修缮队。”

### 场景五：赛恩签下自己的名字

- 现实事件：赛恩面对“签名后承担后续差异说明”的空栏。若他拒签，北侧旧药运门继续关闭，外城药车和饮水车继续绕行；若他签，甲片线形会成为修缮匠人首先使用的标准。
- 任的劝阻：任说他可以签下“条件已固定”，但不要签成“只有这一种形”；校验簿没有这样的现成栏，只有“认可本次定本”的签名格。
- 赛恩的选择：他先要求书记员在附注加上“旁存差异不得销毁、异议可另案复验”；书记员说这会让后续抄录多一行，但可以写。赛恩随后签下自己的名字。
- 现实代价：他的签名进入旧门修缮署和内层责任册，家族长辈会知道他参与了不是家族私产的城市修缮；如果主形后来被改，他必须出席说明，不能把责任推回父亲或定本厅。
- 信念落点：赛恩没有说“世界一定有唯一答案”，只说“至少有些答案，不该因为每个人站得不一样就全部失效。”他把这句话当作暂时能站住的地面。
- 任的反应：任没有把签名称为背叛，也没有承认定本就是正确；他第一次意识到赛恩不是为了家族荣耀守住规则，而是在用规则挽救自己过去二十年的意义。
- 章内钩子：赛恩签完后，校验厅把第一份残片的线形抄进主档案；儿童画从他衣内滑出一角，歪斜的太阳与铜框上的圆孔同时落进他的视线。

### 场景六：向“正确答案”靠近，而不是得到答案

- 现实事件：离开定本厅时，一名没有展示身份的校典使者在外廊递给赛恩一张没有正文的邀请牌，只写“若愿继续校验，可申请进入更深一层的参照室”。邀请牌没有写明所属组织，也没有承诺真相。
- 赛恩的选择：他没有当场答应，也没有撕掉邀请牌；他把它夹进责任牌背面，表示自己愿意继续寻找能重复、能解释、能承担后果的规则。
- 任的追问：任问他是不是相信只要把条件固定，世界就会自动变得正确。赛恩回答：“我相信没有条件的善意更不可靠。”他仍未说出父亲的全部对话。
- 零的边界：零在窄庭边缘看见邀请牌的白角，暗边短暂压住它的影子，却没有靠近或替赛恩做决定；任何人都不把这一动作解释成警告、认可或预言。
- 赛恩的未决：他摸到衣内儿童画，却没有把它拿出来与定本残片比较；歪画暂时没有被判为错误，也没有被宣布为例外，只在他身上保留一个不能进入主档案的私人形状。
- 章末事实：赛恩签下单案定本协验责任，任仍被挡在核心桌外，甲片进入主档案，乙、丙片被保留但排在旁存差异；赛恩开始向一种“客观正确答案可能存在”的秩序靠近，却还没有得到答案。
- 章末钩子：只有本案校验门为赛恩的协验牌亮起，门缝里的光在儿童画歪斜的太阳上停了一瞬；牌失效后，这扇门不会因他的姓再次开启。赛恩回头看任：“明天还来吗？”任回答：“我来看看你们明天固定什么。”

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 对赛恩隐瞒父子对话不满，认为定本厅可能只是另一扇家族门 | 证明参照条件改变会产生不同局部结果，却不能撤销本次定本；开始理解赛恩是在寻找人生意义，不只是争夺权限 |
| 赛恩 | 带着儿童画和“外部责任未结”寻找不依赖家庭沉默的可靠答案 | 因北侧药运门修缮责任签下单案定本协验，第一次主动靠近客观正确答案的制度入口；精确偏好没有被治愈，也没有完全变成教会立场 |
| 零 | 保持不进入家族与内层核心桌的边界 | 继续不接受登记或代答；看见邀请牌但不作选择，空白保持为主动边界 |
| 露米 | 留在外来者区处理关联说明后果 | 不直接进入本章；她的缺席保留“定本”无法覆盖普通人的资源等待这一反差 |
| 伊莉亚 | 留在外来者区处理急救位置追问 | 不直接进入本章；她的现实照护线没有被“正确答案”暂停 |

## 读者此时应该误判什么

- 只要所有人站到同一位置，得到同一结果，就说明这一定是世界本身的唯一答案。
- 任提出异议只是因为他不愿接受赛恩拥有的权限，而不是因为他看见了参照条件对结果的影响。
- 赛恩签下定本协验责任，是为了恢复家族荣耀或证明自己比任更强。
- 旁存差异没有被销毁，就说明它们与主档案享有同等实际机会。
- 父亲留下的儿童画会立即让赛恩怀疑精确与规则。
- 邀请牌来自一个已经掌握终极真相的组织；实际上它只提供了更深的参照室入口，没有提供答案。

## 章末必须留下的事实

1. 定本厅以固定卡槽、灯位、参照框和允许偏差把三份不齐的远古门纹残片压成一份“可入定本”的主形；结果稳定，但参照条件本身没有被证明为世界唯一标准。
2. 甲片在甲号参照框下六处全部贴合，进入主档案；乙片五处贴合、外侧缺口错开，丙片四处贴合，乙、丙进入旁存差异；差异没有被销毁，却必须经过更高权限才能抵达实际修缮和办理路径。
3. 任在外廊提出一次改变参照框与灯位的异议；乙号旧参照框的六处条件下乙片也全部贴合，但这只是未入档演示，不能推翻甲号框下的定本，也不能给任取得核心阅览权。
4. 赛恩签下定本协验责任，并要求附注“旁存差异不得销毁、异议可另案复验”；他把自己的名字写进公共后果，而不是只使用家族便利。
5. 赛恩开始相信客观正确答案可能存在，但本章不揭示 Ground Truth、组织真相、世界本体或唯一制定者。
6. 父亲的儿童画仍由赛恩保管，歪斜的太阳与定本厅的圆孔形成视觉和情绪反差；画没有被判为错误，也没有完成第47章的动摇。
7. 任仍被挡在定本厅核心桌外；赛恩的权限没有转移给任，两人的冲突从“谁能进门”推进到“什么条件才算可靠”。
8. 零没有进入定本厅、没有被写入残片栏，也没有替赛恩决定是否接受邀请；邀请牌只构成下一步诱因，不是终极答案。

## 第47章接口

- 任需要面对一套能够稳定运作、确实减少部分争执的定本制度，不能只用“人为标准”轻易击败赛恩；下一章的冲突必须让赛恩亲眼看见精确结构如何制造没有误差却没有生命的世界。
- 赛恩的签名使他获得本案后续更深参照室的申请资格，也把他写入定本修改的后续责任；他不是被教会一句话说服，而是主动把个人痛苦投向可重复的规则。
- 儿童画成为唯一不进入定本厅的“不合格形状”；下一章可以让它与完美几何并置，但不能由任一段解释直接替赛恩完成觉醒。
- 任与赛恩仍不完整互信：任知道赛恩正在靠近某种答案，却不知道父亲的对话如何参与其中；赛恩知道任看见了条件问题，却拒绝承认这已经足以让自己放弃精确。
- 零继续不进入任何一方的答案结构；它的主动空白与赛恩的答案渴望保持并置，不合并成同一哲学立场。

## Canon 检查清单

- [ ] 定本稳定的是办理结果，不证明世界唯一真值。
- [ ] 主档案与旁存差异的资源不对称必须在正文中发生，而不只是设计说明。
- [ ] 任只能观察、提出一次异议并得到局部反例，不能凭解释撤销制度后果。
- [ ] 赛恩签名承担后续责任，不能把家族资源写成无代价捷径。
- [ ] 赛恩开始靠近客观正确答案，但不正式加入教会、不命名 Ground Truth、不获得世界本体知识。
- [ ] 儿童画只作为未被定本的私人形状存在，不提前完成第47章动摇。
- [ ] 任、赛恩、零的边界分别保留；零不被登记或代答。
- [ ] 正文以校验厅、灯位、卡槽、参照框、残片、主档案和旁存差异承载规则，不出现 API 或说明书式讲解。
