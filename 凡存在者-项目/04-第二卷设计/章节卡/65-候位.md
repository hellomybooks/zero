# 第二卷第六十五章《候位》场景卡

## 状态

- 状态：场景卡已完成两轮独立 Canon / 文学审校与最终窄范围回归，定稿候选。
- 承接：第二卷第六十四章《退线》正文与正文审校。
- 篇章：ARC 06《阈值战争》第五章。
- 情绪中心：伊莉亚 / 阿尔德，任与露米承担记录和传播后果。
- 本章功能：把第64章的“下一次复核未定”变成一个有限的候位；让等待通过木板上的数字、水桶的方向和一名守备的脚步改变现场；让阿尔德第一次用一个没有正确答案的次序决定谁先被重新看见。
- 本章主概念：候位不是保护；先被排进等待，不等于先获得救援；一个人愿意替你传一句话，也不等于他愿意替你承担全部责任。
- 本章情绪：天亮后的疲惫、排队带来的羞耻、一个名字被当作位置的争夺，以及伊莉亚把一句话停在个人转告边缘后仍想继续接住它的犹疑。

## 一句话梗概

换班钟响后，只有一名新的守备从上城坡道赶到调度处，东十四巷、下渠区和封石却都在等待下一次复核。调度处把“下一次复核未定”压成“候位”，并在一块旧换班板上排出先后：东十四巷可以得到一次门边复核，下渠区只能等第二个没有时刻的空位，封石不进入候位。任看见一个方便传递的词正在变成谁可以先占据时间的凭据；露米看见居民把候位当成资格，开始互相挪动水桶和站位。东十四巷的门内只回应“别开”，新守备消耗了候位却没有确认身体；赛恩面对已经被人群当作优先标记的家族印记，阿芙拒绝用自己的名字替门后人报姓。下渠区的线外来者请求伊莉亚替她向下一班传一句“我还在”，伊莉亚答应做一次个人转告，却明确不把这句话写成签名或照护。阿尔德让新守备先去东十四巷，因为那条路线可以在一段时间内返回一条清楚的现场报告；这会把下渠区三名身体和线外来者再推迟一次。章末，候位一已经被人群拿来争位置，候位二仍没有时刻，封石仍无候位；等待没有变成安全，却开始有了价码。

## 本章不能做的事

- 不能把“候位”写成新的魔法、结界或世界本体；它只是调度处把有限的下一次复核时间写成顺序的临时行政词。
- 不能让候位等于保护、救援、稳定护灯或通行资格；候位只表示有人可能在某个尚未确定的时间重新到达。
- 不能让换班后凭空出现一整队守备；本章只有一名新到的守备，东十四巷、下渠区和封石不能同时获得新的现场人手。
- 不能让赛恩的私人礼灯复燃；礼灯已经熄灭，家族使者只能提出印记与归属交换，不能凭空提供新的灯油或正式护灯。
- 不能让东十四巷因候位一自动确认门后人数；门内只回应“别开”，手、声音、姓名、人数和伤势仍需分开记录。
- 不能让阿芙替门后所有人作证；她可以为自己说话，也可以拒绝被人群要求为陌生人报姓。
- 不能让下渠区的三名身体获得新的水、药粉、布、固定木片、担架或通行路线；既有照护线和门边裂木板状态保持连续。
- 不能让伊莉亚把线外来者写进三人签名；她只能承诺一次个人转告，转告不产生候位、不产生资源，也不改变来者的身份与归属。
- 不能让阿尔德把东十四巷排在第一位解释成更值得救；他的理由只能是当前路线、返回时间和可交付报告的差异，决定仍然会让下渠区等待。
- 不能让任的“候位一 / 候位二”消除等待，或让他靠重新拆字段撤销已经发生的挪水、推搡和排除。
- 不能让露米删除“先来的人”“有名字的人”“候位占着”等口头说法；她要记录传播，也要承认记录会给它们更长的生命。
- 不能让第三声进入候位；当前没有一份能被候位体系接收的完整确认记录，仍然只保留“来源未确认”和火绳受力。
- 不能让零成为候位规则的判断者；它可以在候位板附近出现或离开，但不提供方向、身份或优先级。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 核心规则与本章新增边界

### 1. 候位是时间的占用，不是保护

- “下一次复核未定”被调度处压短为“候位”，只是让下一班知道某处可能需要人，不代表人已经在路上。
- 候位可以有先后，但没有自动时刻；候位一只占据一次可交付的复核机会，候位二只表示它在候位一之后，不能保证今天发生。
- 候位不产生正式护灯、守备、药粉、担架或通行线；一处进入候位后，现场仍可能被风、门、伤势或人群改变。
- 候位的顺序由当前能否完成一次有限动作、是否有可接收报告的人和路线是否能在班次内返回等现实因素决定；这些因素不能被总结成“谁更重要”。

### 2. 候位一会被街面读成资格

- 调度处只在板上写“东十四巷 / 候位一”“下渠区 / 候位二”；居民会把它读成“东十四巷先被保护”“下渠区只能等”。
- 没有人宣布候位可以转让，但人群会挪水桶、挪站位、交换名字和承诺，试图把自己移进更前的位置。
- 候位记录可以准确描述次序，却不能阻止有人把顺序变成羞辱、排除或推搡。
- 任可以把“候位”与“正式处置”“照护线”“通行线”分栏，却不能阻止候位成为街面武器。

### 3. 一次个人转告不等于照护签名

- 伊莉亚可以替线外来者把一句话带给下一班，但这句话只说明她在某个时刻仍然等待，不说明她的姓名、归属、伤情或照护资格。
- 个人转告不占用正式候位，除非有人另行承担一次复核；它也不允许伊莉亚把签名范围从三名身体扩大到第四个人。
- 如果伊莉亚答应传话，她会在一段时间里成为这句话唯一的携带者；她不能把责任全部推回调度处。
- 线外来者可以改变自己的说法、拒绝给名或在转告前离开；转告失败不是世界替她补上的答案。

### 4. 新守备只能完成一条短路线

- 换班守备没有新灯、药、担架或车辆，只能带着自己的身体，沿用调度处已有牌面完成一次短现场动作。
- 阿尔德可以让他去东十四巷或下渠区，不能让他同时出现；封石处的原东十四巷守备已经驻在封石，不能因此离开，也不能被读成东十四巷仍有现场守备。
- “能返回一条报告”是调度选择的理由，不是地点更有价值的证明；报告返回后，现场仍可能没有获得救援。

### 5. 第三声不在候位体系内

- 第三声当前没有一份能被调度处交给候位的完整确认记录，因此不获得候位一或候位二；这不是对石后本体的判断。
- 火绳再次收紧只说明封石承受了力量；任何人把“候位”写到第三声牌旁，都是把未知强行变成可排队对象。
- 阿尔德可以加固封石、保留来源未确认，也可以承受人群指责；他不能用候位决定石后是什么。

## 读者此时应该误判什么

- 误以为候位一意味着东十四巷比下渠区更值得救；实际它只意味着一次短路线更容易返回报告。
- 误以为候位二就是今天的第二次复核；实际它可能只有顺序，没有时刻。
- 误以为换班守备到达就等于东十四巷重新获得保护；他只有一双手，没有新灯和完整路线。
- 误以为赛恩拒绝家族印记是在拒绝帮助；实际他拒绝的是把居民归属交给尚未同意的名字。
- 误以为伊莉亚答应替线外来者传话，就已经把她收进照护范围；实际她只把一句话暂时放在自己身上。
- 误以为门内说“别开”说明里面没有人或有危险物；这只说明门内有人拒绝当前动作，身体和人数仍未确认。
- 误以为任把候位拆成栏位就已经找到了公平的排列方式；栏位只让不公平更容易被看见和复制。
- 误以为露米把人群口号写下来就是赞同；她记录的是传播与后果，不是免除自己的判断责任。
- 误以为第三声没有候位就等于没有威胁；未知不进入队列，不代表它停止改变封石压力。

## 场景设计

### 场景一：换班钟后的一名守备

- 现实事件：换班钟响后，只有一名新守备从上城坡道下来。他没有新灯、药粉、担架或车辆，只带着自己的编号，使用调度处已有的换班板记录。
- 东十四巷守备仍在封石，下渠区守备仍在照护线附近；新守备停在调度处，问应该先接哪一个。
- 阿尔德没有马上回答。书记员把“下一次复核未定”压成“候位”，在旧换班板上写出三个位置：东十四巷、下渠区、封石。
- 写到封石时，他停下；“来源未确认”旁没有候位栏。任指出这不是遗漏，封石没有可接收复核的人，但也没有人因此更安全。
- 阿尔德把封石从候位板上移开，只保留“火绳受力 / 守备留置”；他知道移开一个词会让人群以为石后不值得等待。
- 章内钩子：书记员在东十四巷旁写下“候位一”，在下渠区旁写下“候位二”，没有写任何时间。
- 阿尔德在新守备面前把东十四巷的候位一交给他：“先去门边，只做一次复核，不破门。”这次派遣发生在任何现场行动之前；下渠区守备继续留在原处，封石守备也不能离开。

### 场景二：板上的一和二

- 现实事件：任看到旧换班板上的两个数字，问书记员“二什么时候到”；书记员回答“等一完成以后”，却说不出一完成需要多久。
- 任把“候位一”“候位二”分别拆成“次序已写”“时刻未定”；他没有删掉数字，因为删掉只会让人群自己写得更快。
- 露米走到板外，看见居民已经把两个数字抄到水桶旁的墙上；有人在二的旁边画了一道叉，说“二不用分水”。
- 一名下渠区居民想把二改成一，声称那里有三个人；东十四巷有人回应“我们有一扇门，门开了会放出整条街的风”。双方没有立刻打起来，但水桶被两边各拉住一只耳。
- 露米记录谁先说“先来的人”，谁先说“有名字的人”；她没有替任何一句话盖章。
- 任发现自己昨夜的“线外等待”被人抄成“候位二也不算等”，他想把这句话写回原处，却找不到原处在哪里。
- 章内钩子：新守备站在板前问“我先去哪”，两边的人同时伸手指向不同的数字。

### 场景三：印记已经在板旁

- 现实事件：赛恩家族的使者赶到，手里没有新灯油，只有一枚尚未盖下的家族印记和一张空白的家族责任页；印记已经被放在东十四巷候位一旁，居民开始按照它挪动站位。
- 使者说印记还没有盖下，因此还不算家族接收；人群却已经把它当成一盏没有点燃的灯，认为它能让这扇门在下一次调度时排得更前。
- 赛恩问“门里的人同意了吗”，使者说“门里的人还没有名字，正好由你决定”。
- 赛恩先说：“这不是家族的门。”这句话被旁边的人听成“门里的人不归任何人管”。他看向熄灭的礼灯，伸手把印记从候位板旁拿回，却没有立刻交还使者。
- 阿芙在门后听见“家族”两个字，问赛恩是不是要把他们交出去；她没有说“我们不是”，因为她仍不知道里面有几个人。
- 赛恩把印记放在个人礼灯账牌旁，不盖。他说：“先让他们自己决定要不要被写进去。”
- 使者说：“等他们说出名字，候位已经没了。”
- 章内钩子：门内有人忽然说：“别开。”新守备和人群同时安静下来。

### 场景四：一次复核抵达门边

- 现实事件：新守备沿着门边残留的灰痕走到东十四巷，阿芙把肩膀从门上移开一瞬，又重新顶回去；赛恩在熄灭的灯旁，家族印记没有盖下。
- 守备不要求破门，只要求门内回答三个互不相同的问题：门是否能在无风时合住、里面是否愿意让一只手被看见、是否有人愿意接受下一次复核。
- 门内只说了一句“别开”。声音清楚，但没有名字；手在门缝附近出现又退回。
- 人群把“别开”喊成“里面有人”，又喊成“里面有东西”；阿芙只说：“这句话是真的，其他的我不知道。”
- 守备记录“复核抵达 / 门内拒绝当前开口 / 手未确认 / 人数未确认”。这一趟没有让门获得处置线，也没有让礼灯变成正式灯。
- 赛恩问守备这算不算候位一完成。守备说：“我到了，不等于他们被处理。”
- 守备在门边停留过久，坡道上的人开始催他去下渠区；候位一因此占据了时间，却没有产生安全。
- 章内钩子：阿芙把自己的名字从门牌上划掉一半，又停住，没有让它完全消失。

### 场景五：伊莉亚的一个句子

- 现实事件：下渠区的线外来者听见东十四巷候位一已被占用，问伊莉亚是否也能替她排一个位置；伊莉亚说她没有这个权力。
- 来者没有要求名字，只说：“那你替我告诉下一个人，我还在。”
- 伊莉亚差一点说“我来”，看见托恩、阿瑟和“旧牌旁的人”后把话咽回去。她说自己可以传一句，但那句话不能进入三人签名。
- 她写下：“个人转告：此人自述仍在石角等待；非姓名、非伤情、非照护签名、非候位。”
- 她没有把来者的名字写在灰地上，也没有要求她再次交出刚刚抹掉的名字。
- 来者问：“你会真的说吗？”伊莉亚回答：“我会说一次。”
- 守备问她如果下一班没有时间怎么办。伊莉亚说：“那就说没有时间。”她没有承诺一定让对方被接收。
- 托恩在里面咳了一声。伊莉亚转身先看三名身体，没有把自己的句子变成新的照护资源。
- 章内钩子：来者把一小块湿泥捏在手里，像在保存一个没有写出来的名字。

### 场景六：谁在占用候位

- 现实事件：调度处外有人把东十四巷既有报告牌边的候位一标记挪近第64章沿用的公共水桶，说“候位一先取”；下渠区居民把同一张下渠区报告牌边的候位二标记按在桶底，水桶因此向两边倾斜。
- 没有人授权候位决定取水，但数字已经成了最方便的借口。
- 露米伸手去分开标记和水桶，旁边的人要求她先说自己站哪一边；她脱口说“谁先来谁拿”，话一出口便知道自己替人群添了一条规矩，只好把自己的这句话也写进现场旁注。
- 任想写“候位不等于取水权”，发现这句话会让人以为自己已经宣布了一条新规；他改写为“现场出现按候位分水行为，非正式，未改变水量”。
- 一个下渠区居民说三个人不能排在一个二字后面；一个东十四巷居民说一扇门也可能压着十个人。两个人都没有证据证明数字，争吵因此更快变成彼此指认。
- 一个孩子从两边的手之间钻过去拿水，水桶被碰翻一角；露米没有把孩子写成“线外”，先把他拉开，再记录水洒在两张既有报告牌上。
- 抢回下渠区既有报告牌的人手掌被牌边划破，血落在“候位二”旁边；露米先按住他的手，再把“水桶被两边同时拉动、报告牌被水浸、手掌破裂”分开记录。
- 章内钩子：被水浸透的下渠区报告牌上，“候位二”三个字剥开一角，露出背面原本的“下一次复核未定”。

### 场景七：阿尔德承担先后

- 现实事件：新守备从东十四巷回到调度处，带回报告：门内拒绝开口、手未确认、人数未确认；下渠区的报告则是三名身体仍在、线外来者等待、门边裂木板无法恢复。
- 书记员要求阿尔德把东十四巷候位一改成“失败”，再让新守备去下渠区；阿尔德没有把“未确认”改成“未发生”，也没有把刚才的派遣重新说成一次选择。
- 下渠区守备说如果新守备来，至少能帮他看住风口；新守备离开门边前留下的补报说，门内的手已经再次碰到门缝。两边都是当前事实。
- 阿尔德在板上写下：“东十四巷候位一已复核抵达；下渠区候位二，时间未定。”他没有为这两行补上哪一处更值得救的解释。
- 新守备问：“我现在回下渠区吗？”阿尔德说：“不。先留在调度处。”新守备的脚步停在调度处门槛，三名身体仍在下渠区。
- 阿尔德知道人群会把这个先后解释成偏袒；他没有找到一句能把伤害从命令里取出来的话，也没有把已经返回的报告再说成一次新的行动。
- 章内钩子：下渠区的候位二没有时刻，线外来者的个人转告却已经被伊莉亚握在手里；两种等待开始不平等。

### 场景八：阿芙不替门后人占位

- 现实事件：有人要求阿芙把自己的名字写在候位一旁，说只要有一个完整姓名，门后就能被“整户”暂时接住；阿芙知道自己的名字可能真的能让队列更稳定。
- 她问“整户是谁”，对方回答“你知道里面的人”。阿芙说她只知道门后有声音和一只手。
- 人群开始逼她说出一个姓。她的旧伤发痒，手背重新渗出一点血；有人说血可以证明里面不是空的，也有人说血只证明她在外面。
- 新守备仍留在调度处门槛；没有新的守备替阿芙清出人群，也没有人能替她写下她不愿意承担的名字。
- 阿芙先脱口说：“我知道他们是谁。”人群立刻逼近，要求她报姓；她咬住舌头，把话改成：“我只知道门里有声音和一只手。”
- 她在既有报告牌旁只写自己的名字和一句“本人自证，不代表门后人数”；她没有把自己从牌上完全划掉，也没有把未知者加进来。
- 赛恩看见她的笔停在“本人”两个字上，说：“如果你不写，他们会替你写。”阿芙回答：“那也不是我写的。”
- 章内钩子：门内再次说“别开”，这一次声音更低，候位一的标记却被人群推向门槛。

### 场景九：封石没有候位

- 现实事件：阿尔德从调度处走到封石，发现火绳受力比上一班更紧；第三声牌仍在护石旁，牌面没有新的来源或身份。
- 一名记录员建议在第三声记录旁写“候位三”，说只要先占一个位置，下一班就不会把它忘掉；阿尔德拒绝把一个当前无法交给人复核的记录写成候位。
- 他只在记录旁补写“本班未派开石队 / 火绳承力继续观察”，没有写“石后无人”，也没有写“石后有敌”。
- 零在坡下灰线外出现，靠近候位板投在泥里的影子；阿尔德没有问它是否也在等待，零没有看他。
- 火绳又收紧一次，守备的手背被勒出红痕；没有新的声音，只有绳结和石灰的变化。
- 阿尔德知道东十四巷的候位一和下渠区的候位二已经在街上变成了可占据的顺序；封石不在这张板上，也没有因此停止影响人。
- 章内钩子：封石记录旁一处被划掉的空白被风掀开，下面仍然只有“来源未确认”，不是新的候位栏。

### 场景十：个人转告被带上路

- 现实事件：伊莉亚把线外来者的一句话交给徒步传令员，请他在下一次经过调度处时只传“她还在石角后”，不附加名字、伤情、归属或候位要求。
- 传令员问这句话是否算一份报告。伊莉亚说：“算我说过的话，不算她被接收。”
- 他问如果调度处没有空位怎么办。伊莉亚说：“把没有空位也带回来。”她先把可能失败的话摆到传令员面前，却没有因此放下对结果的牵挂。
- 线外来者听见以后，没有道谢，只说：“如果我先走了，就别替我说还在。”
- 伊莉亚点头。她没有追问对方要去哪里。
- 传令员走后，伊莉亚回到三名身体旁；托恩的腿开始发冷，阿瑟胸口固定木片旁的皮肤变色，第三个人仍然抓着旧牌。
- 传令员在调度处只把这句话放进非正式旁注：“她还在石角后”；旁边的人却把它抄成“候位二有人”。伊莉亚的转告没有进入正式候位，误写却已经落在板边。
- 她没有把第四个人的等待写进三人，也没有把自己的转告擦掉；两种责任同时留在她身边。
- 章内钩子：下渠区守备把那张被水浸过的下渠区报告牌从门外拿回来，背面的“未定”已经被人用指甲刮薄。

### 场景十一：候位被人拿走

- 现实事件：东十四巷“复核抵达、身体未确认”的报告已经摊在调度板上；人群要求把候位一改成“已处理”，否则他们认为守备浪费了时间。
- 任把“复核抵达”“门内拒绝开口”“身体未确认”分成三行，不让“已处理”吞掉失败。
- 露米听见有人说“候位一是我们的”，有人说“候位二没有人认领”；她把“拥有候位”的词原样记下，看见等待已经被人拿来互相驱赶。
- 候位板旁没有家族印记，只有赛恩熄灭的私人礼灯账牌；使者把印记收在手里，仍站在人群后面等待赛恩改变主意。
- 阿尔德让新守备暂不去下渠区，把东十四巷的失败报告和下渠区三名身体的现状并列留在调度板上；这延长了下渠区的等待，也没有把失败写成完成。
- 下渠区的线外来者没有出现在正式板上，只有伊莉亚的个人转告在传令员手中；她成为最容易被下一次传递丢掉的人。
- 章内钩子：任在候位二旁写下“时间未定”，有人立刻把“未定”划掉，改成“等一结束”。

### 场景十二：等一结束

- 现实事件：天色从白转向更亮，东十四巷的灰线旁仍有人守着候位一，水桶却先被拖向候位一的人群；下渠区候位二没有新守备，三名身体仍在照护线内。
- 徒步传令员返回下渠区，带回调度处的原话：“没有正式空位，个人转告未进入候位。”这句话仍是传令员带回的口头结果，不是新的正式牌面。
- 伊莉亚没有把线外来者写成“失联”，只把自己的那一句保留在门边：“她还在石角后，直到我最后一次看见她。”
- 线外来者听见这句话，问伊莉亚为什么要加“最后一次”。伊莉亚说：“因为我不能替下一次保证。”
- 伊莉亚的手停在“最后一次”上。她仍想把后面所有时间也接过来，却只把这一句留下，没有替下一次保证。
- 阿尔德在调度板上留下：东十四巷候位一 / 复核抵达、身体未确认；下渠区候位二 / 时间未定；封石 / 无候位、来源未确认。
- 任把“候位”与“处置线、照护线、通行线”分开；他没有删掉“候位一先”的现场行为，也没有把它升级为正式法规。
- 家族使者已经收回印记，熄灭的私人礼灯仍留在东十四巷门边；阿芙的本人自证没有扩大成整户姓名。
- 章末画面：写着“候位二 / 时间未定”的那行字被水浸透，板上的“未定”逐渐淡去；封石火绳再次收紧，第三声没有进入候位；伊莉亚站在三名身体和石角之间，手里只剩一句不能保证下一次仍然成立的话。

## 章末必须留下的事实

1. 换班后只有一名新守备到达；东十四巷原守备仍在封石，下渠区仍有原守备，三处不能同时增加现场人手。
2. 调度处把“下一次复核未定”压成“候位”；候位一有先后但没有自动时刻，候位不等于保护、处置线或通行资格。
3. 东十四巷获得一次候位一复核；门内只说“别开”，手、姓名、人数和伤势仍未确认，赛恩礼灯熄灭、家族印记未盖，阿芙只为自己作证。
4. 下渠区标为候位二、时间未定；托恩、阿瑟和“旧牌旁的人”仍在照护线内，通行线关闭，既有材料和灯具不变。
5. 线外来者未进入正式候位或三人签名；伊莉亚只承担一次个人转告“她还在”，并在章末写出这句话只到最后一次看见为止。
6. 任把候位与处置线、照护线、通行线和来源未确认分开；居民把候位复制成水桶、站位和“拥有时间”的争夺，未被升格为正式规则。
7. 阿尔德先让新守备去东十四巷，理由是路线与报告交付，不是价值判断；下渠区因此继续等待。
8. 赛恩拒绝家族印记，没有新的灯油、正式护灯或家族归属进入东十四巷。
9. 第三声不进入候位体系；实体牌仍在封石火绳下，来源、性质、是否为人声仍未确认，火绳受力继续存在但不产生答案。
10. 零不成为排序、方向或身份判断；它仍是被人群误读的线外存在。

## 第二卷第六十六章接口

- 候位一已经被人群当成可以争夺的先后；下一章可以写“候位”是否进入正式城防文书、谁能把自己挪进前面、以及候位二的等待如何产生更直接的群体压力，但不能让一纸顺序自动解决资源不足。
- 东十四巷复核抵达却未确认身体；门内拒绝“别开”的原因仍未知，阿芙的本人自证和赛恩的私人责任都会被要求扩大。
- 下渠区的候位二没有时刻；伊莉亚的个人转告可能失败、失真或被人群利用，她不能靠再次签名恢复通行线。
- 封石仍无候位；第三声只改变火绳和人群对封线的态度，下一章可以让石灰、绳结或墙外结构带来物理后果，但不能直接确认本体。
- “等待”已经有先后、有声称者、有被挪动的板上字；任、露米和阿尔德必须继续面对正式记录、现场行为和街面口号的三层传播差。

## Canon 检查清单

- [ ] 候位是临时调度顺序，不是魔法、保护、处置线或通行线。
- [ ] 换班只增加一名新守备，不增加新灯、药、担架、车辆或水。
- [ ] 东十四巷候位一只完成一次门边复核，未确认门后身体、人数或姓名。
- [ ] 下渠区候位二没有自动时刻，三名身体和线外来者的正式范围保持分开。
- [ ] 伊莉亚的个人转告不是签名、候位或照护接收，且有明确失败边界。
- [ ] 阿尔德先派东十四巷的理由是路线与报告交付，不是价值判断；下渠区等待产生真实代价。
- [ ] 赛恩礼灯已熄、家族印记未盖，拒绝归属交换不被写成无代价胜利。
- [ ] 任不让候位吞掉“复核抵达 / 身体未确认”，露米不抹掉候位造成的群体行为。
- [ ] 第三声牌仍在封石火绳下，不进入候位，不获得身份或方向；零不成为判断者。
- [ ] 正文通过木板数字、水桶、门缝、家族印记、个人转告、湿掉的报告牌和等待的延长呈现本章冲突。

## 五问自检

1. 本章首先发生在人身上的，是阿尔德把一个新守备的时间交给一扇门，伊莉亚只承诺传一句话，赛恩拒绝把未知者交给家族名字。
2. 阿尔德把下渠区排到候位二，伊莉亚让个人转告带着失败边界，阿芙拒绝扩大自证，露米留下可能扩散的口号；每个人都做了未来可能后悔的事。
3. 不让人物说出“等待就是政治”或“我终于明白边界”；让报告牌被水浸透、数字被挪动、传话可能丢失来完成主题。
4. 不提前支付候位制度的终局、伊莉亚最终麻木、阿尔德最终政治立场或第三声本体；本章只让时间进入可争夺的顺序。
5. 删除所有技术隐喻后，一名守备、两处等待、一扇不肯开的门、一句被携带的话和一张被水浸透的报告牌仍构成冲突。
