# 第二卷第六十九章《移脚》场景卡

## 状态

- 状态：场景卡已通过独立 Canon / 文学审校，定稿候选。
- 承接：第二卷第六十八章《不够》正文与正文审校。
- 篇章：ARC 06《阈值战争》第九章。
- 情绪中心：阿尔德 / 伊莉亚；任与露米第二次面对“记录已经准确抵达，但完成的词先于完成的事”。
- 本章功能：把第68章的“记录无误，照护位不增”推进为上坡的“本班后续不派，现场封闭待确认”；让阿尔德决定是否移动自己的脚；让提空碗男人用一个不在场的母亲要求被计入，制造“亲属转述”与“身体到场”的冲突。
- 本章主概念：行政状态可以先于物理状态成立；准确区分“有人被说起”和“有人在场”，不能替任何一方制造位置。
- 本章情绪：阿尔德知道自己不该把身体写成门，却又知道脚一移开，人群会把缺口变成路；一个男人知道自己的母亲没有到场，却不愿意让“未到”变成“没有”。

## 一句话梗概

下渠区收到同一张副页的新回话：“本班后续不派，现场封闭待确认。”上坡把第68章的前一项回话视作已处置，却没有送来灯、药或守备；传令员要求阿尔德移开脚，以便在纸上确认封闭。提空碗男人带着母亲的口述要求进入记录，任准确写下“亲属转述，身体未到”，街面却把它压成“未到，不计”。男人把同一只空碗推过缺口当作母亲的位置，阿尔德没有移脚，碗在灰线边裂开。阿尔德在副页旁注写下“现场未封，阿尔德留守”，正式范围仍未扩大；纸面同时保存“本班后续不派”和“现场未封”，而现场没有多出一盏灯或一个人。

## 本章不能做的事

- 不能把“本班后续不派”写成上坡主动撤销照护；它只表示没有新的派遣，不能治好三名身体，也不能清除缺口。
- 不能新增灯、药、守备、担架、车辆、水、固定木材或新的稳定护灯；传令员只带回同一张副页上的新回话。
- 不能让阿尔德移动脚以后缺口自动合上；脚是临时站位，不是结界、封线或许可。
- 不能让阿尔德因写下“现场未封，阿尔德留守”而获得救援、受领、责任人或正式照护范围；这只是现场报告旁注。
- 不能把提空碗男人的母亲写成新到场人物；她只有亲属口述，没有身体、姓名确认、位置或候位。
- 不能把“亲属转述，身体未到”写成解决歧义的万能字段；街面必须把准确区别压成“未到，不计”，产生具体排除后果。
- 不能把空碗写成第四个照护身体；它是男人试图为母亲占一个可见位置的物件，最后因站位冲突裂开。
- 不能让伊莉亚突然拥有第四双手；她仍只维持托恩、阿瑟和旧牌旁的人。
- 不能让男孩和女人回到现场确认安全；男孩去向、木刺和女人之后的位置保持未确认。
- 不能让第三声、浅弧、零、东十四巷抄联和线外来者在本章获得答案或与下渠区事件建立因果。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 开场状态

- 时间：第68章之后，天光已完全越过坡道，但下渠区仍在封石阴影中；下一班资源没有抵达。
- 下渠区：裂玻璃照护灯仍熄灭；照护线仍缺一掌宽；通行线仍关闭；风从缺口进来。
- 三名身体：托恩仍在旧夹板上；阿瑟胸口固定木片旁的暗色仍越过旧线；旧牌旁的人仍抓着裂木板；伊莉亚的手、膝、肩仍分别承担三处动作。
- 阿尔德：一只脚仍压在缺口边，脚底被碎石硌疼；他挡住人群，但尚未把站位写成正式受领或照护。
- 任与露米：任保留第68章同一张副页；露米保留“男孩去向，之后未确认”和街面词来源；二人都没有男孩的新消息。
- 提空碗男人：仍在下渠区外，空碗沿用第68章同一只；他听见“后续不派”，开始要求为不在场的母亲留下位置。
- 封石与东十四巷：封石守备不离位，第三声牌仍在火绳和护石旁；东十四巷抄联继续上坡；本章不切入两处现场。

## 核心规则与本章新增边界

### 1. “已处置”不等于现场完成

- 上坡回话可以把第68章记录标成“本班后续不派”，表示本班没有新增派遣。
- “现场封闭待确认”是一个等待确认的行政状态，不是已经合上的灰线，也不是安全或撤离许可。
- 纸面同时写着“照护位维持”和“后续不派”时，三名身体仍在现场继续恶化；两句话都可能准确。

### 2. 移脚不等于封线

- 阿尔德的脚暂时占住缺口边缘，能减慢人群靠近，却不能恢复灰线。
- 传令员要求阿尔德移脚，是为了让纸面状态看起来与现场一致；阿尔德不移脚，也不能因此获得新的正式权限。
- 阿尔德可以在副页旁注写“现场未封，阿尔德留守”，但该旁注不能变成救援、受领、责任人或照护扩张。

### 3. 亲属转述不等于身体到场

- 提空碗男人可以说母亲在哪里、为什么没来，也可以请求任在副页旁注记下她；这不是正式主册字段，也不确认母亲的身体、姓名、伤势、位置或候位。
- 任必须把“亲属转述”和“身体未到”分开写；准确分开不能让母亲获得照护。
- 街面把“身体未到”压成“未到，不计”，并用这句话决定谁可以靠近缺口；它不是正式字段，却产生排除。

### 4. 物件不能替代身体，但会承担社会后果

- 空碗不是第四名照护身体，也不能使母亲进入三名照护。
- 男人把空碗推过缺口，是为了让一个不在场的人拥有可见的位置；阿尔德阻挡人群时，空碗在灰线边裂开。
- 碗裂开不产生新的水、药、位置或受领，只给男人留下一个无法恢复的损失。

## 读者此时应该误判什么

- 误以为上坡写下“后续不派”就是已经把下渠区处理完；实际三名身体、缺口和熄灭的灯都没有改善。
- 误以为阿尔德只要移脚就能恢复正常通行；实际他的脚只暂时改变站位，移开后缺口仍在。
- 误以为任写清“身体未到”就公平解决了男人的请求；实际记录准确却让街面更容易制造“未到，不计”。
- 误以为男人把空碗推入是要抢第四个照护位；实际他想让不在场的母亲不被当作没有，结果仍然伤害了自己。
- 误以为阿尔德写“现场未封”是在扩大责任；实际他只留下现场报告旁注，正式“仅现场报告”不变。
- 误以为男孩会因记录被找回；本章不确认男孩或女人的去向。

## 场景设计

### 场景一：同一张纸又回来了

- 现实事件：下一班钟后，传令员从坡道下来，手里没有灯、药或守备，只拿着第68章同一张副页。背面在原有“三名照护位，维持；灯、守备、药，不增”下面多了一行：“本班后续不派；现场封闭待确认。”
- 来源闭合：任把第68章仍在手里的同一张副页交给传令员；传令员沿原有传令链带上坡，上坡补写新回话后再带回，纸角、折痕和原有墨点不变。
- 任先确认纸角、折痕和自己的墨点，再问：“现场封闭了吗？”传令员说：“上面说待确认。”
- 阿尔德的一只脚仍在缺口边。下渠区守备仍在裂玻璃灯与灰线之间，封石守备没有下来。
- 章内钩子：传令员把笔递给阿尔德：“你移开脚，我就能把‘待确认’改成‘已封’。”

### 场景二：纸上的封闭没有压住风

- 现实事件：传令员解释，上坡把第68章视为已完成处置；“后续不派”不是惩罚，也不是新的资源承诺，只是本班不再派人。
- 阿尔德看着缺口。风仍从他脚边进来，吹到阿瑟固定木片和托恩旧夹板。
- 传令员要求他先把脚移开，再在副页旁写“现场已封”；阿尔德问：“脚移开，线会自己回来吗？”传令员没有回答。
- 伊莉亚没有看纸，只说：“阿瑟的木片又动了。”她不评价封闭是否正确，只把手压回去。
- 后果：上坡状态与现场身体同时存在；纸可以等待确认，三名身体不能等待。

### 场景三：他母亲还没有到

- 现实事件：提空碗男人听见“后续不派”，把空碗抱在胸前，要求任把他的母亲写进去。
- 他说：“她在北坡背面，不是没有，是我先过来找水。”他没有带母亲的姓名、伤势或身体，只带着一只已经干掉的空碗。
- 任问：“她现在在哪里？”男人说不清；他只知道她最后在一处旧墙后等他。
- 任写下：亲属转述；母亲；身体未到；位置未确认。
- 男人看着那几行：“你写她了吗？”
- 任说：“写了你说的。”
- 男人说：“我问的是她。”
- 后果：记录保存了一个人被说起，却没有让那个人获得在场、候位或照护。

### 场景四：未到，不计

- 现实事件：人群听见“身体未到”，有人把它压短成“未到，不计”。这句话先落在空碗上，再落到男人身上。
- 男人说：“不计的是她没到，不是她没有。”没人接住这句区别。
- 提空碗男人把空碗推向缺口：“先给她留着。”
- 阿尔德用脚挡住碗沿。碗没有进入三名照护，灰线也没有恢复。
- 男人的手被碗口划了一下。他没有收回空碗，反而把手指压到碗底，想把它送过阿尔德的脚。
- 伊莉亚看见旧牌旁人的手往下滑，却不能伸手去接碗；她只能把肩膀压回去。
- 章内钩子：阿尔德必须选择移脚让碗过去，或不移脚让碗在缺口边裂开。

### 场景五：碗裂开了

- 现实事件：提空碗男人又用力把碗往前送。阿尔德没有拔剑，也没有把脚抬起。
- 空碗卡在靴底和灰线之间。男人用力一推，碗沿先裂，裂纹沿着碗底爬开。
- 碗没有完全碎成两半；一片带着碗口的碎片留在男人手里，另一片落在缺口内。
- 男人看着碎片，说：“她回来以后用什么？”
- 没有人回答。
- 旧牌旁人的手在裂木板上重新抓紧；伊莉亚的肩膀被重量压低，托恩旧夹板又从膝下滑出半寸。
- 阿尔德的脚没有移开。这个选择挡住了碗，却没有救下男人的母亲，也没有让现场多出一件物资。
- 后果：一个家庭用来取水或等待的物件破损；“只收三人”没有扩大，却获得了一个可见的损失。

### 场景六：把未封写下来

- 现实事件：传令员再次把笔递给阿尔德，要求他在“现场封闭待确认”旁边确认。
- 阿尔德没有写“已封”。他在副页旁注写：现场未封；阿尔德留守；未扩大受领范围。
- 传令员问：“你知道这会留下什么吗？”
- 阿尔德说：“知道。”
- “知道还写？”
- 阿尔德看着自己的脚：“纸上不能替我移。”
- 这句话不是顿悟；他仍没有决定下一班怎么办，只把此刻的未封留下。
- 后果：上坡文书现在同时保存“本班后续不派”和“现场未封”；阿尔德的名字再次被置于两种状态之间，但正式“仅现场报告”没有被改成责任人。

### 场景七：记录保存不了一个人

- 任在同一张副页下缘补记：亲属转述；身体未到；位置未确认；空碗于缺口边破损。
- 露米在旁页记下：“未到，不计”——街面用语；并保留男人原话：“不计的是她没到，不是她没有。”
- 露米看向缺口内的半只碗。她没有把碎片归入资源，也没有把男人的母亲归入伤者。
- 后果：记录比街面话更准确，但它只能保存两句话的差异，不能替母亲来到现场。

### 场景八：移脚

- 现实事件：人群暂时退开。提空碗男人把剩下的碗片贴在胸前，退到风口；他没有说母亲死了，也没有说她安全。
- 传令员收回副页。上坡新回话与阿尔德旁注留在同一张纸上，两个状态没有互相抹掉。
- 伊莉亚继续维持三名身体。她没有看男孩和女人离开的方向；那方向仍未确认。
- 阿尔德的脚已经麻了。他可以移开，却没有移开。不是因为缺口被他封住，而是因为他知道有人会把移开读成允许。
- 章末画面：灰线没有合上；纸面写着“后续不派、现场未封”；半只空碗在风里发出轻响；下一班仍没有灯、药或守备。

## 第二卷第七十章接口

- “现场未封 / 阿尔德留守”可能被上坡解释为拒绝执行“现场封闭”，也可能被街面解释为阿尔德承认自己就是门。
- “未到，不计”可能从街面压缩语进入候位、水桶或住房分配，但不能在下一章直接升格为正式制度；要先让它通过具体人的损失产生压力。
- 提空碗男人可能继续寻找母亲，也可能先处理碎碗和自己的手；不要立刻确认母亲生死。
- 伊莉亚仍没有完成麻木；她下一次可能把空碗、碎片或一个名字误当成自己必须承担的手。
- 任的记录保存了“她没有”与“她没到”的差异，却不能确认缺席者；后续不得把字段准确奖励成追踪成功。
- 阿尔德的脚、旁注和正式“仅现场报告”形成新的政治接口；上坡可能要求他移脚，也可能把未封责任推回他名下。
