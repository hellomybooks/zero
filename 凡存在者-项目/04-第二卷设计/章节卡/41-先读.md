# 第二卷第四十一章《先读》场景卡

## 状态

- 状态：通过 / 定稿候选，可进入正文生产。
- 承接：第二卷第40章《附页》正文与正文审校。
- 本章功能：把第40章的“附页先被看见”从一张家族文件推进到私人记录、药房队伍和救援表格的实际行动，证明不具正式权限的记录也可能先改变人如何被处置。
- 本章主概念：先读次序 / 私人记录的影子权限——纸面没有获得更高地位，不代表它不会先决定后来者做什么。
- 潜在技术隐喻：顺序改变后的局部解释、附加记录影响后续读取；只在结构化资料中记录，正文只写小纸、翻页、队伍、牌背、药量和签名。
- 本章情绪：迟到的羞耻、权限缝隙、记录责任、微小选择造成的实际伤害。

## 一句话梗概

见习书记员的私人小纸没有家族印记，却被下一名办事人先读到并自行强化成处置便笺，进而改变药房与阅读安排；赛恩从空册旧孔旁交出的木签确认曾有一页送件物未进入正式接收流程，但不知道它是否与当前空册或遗迹旧页有关；任要求把私人理解与正式报告分开，伊莉亚则提交一份包含未获药伤员的完整照护记录，第一次亲眼看见“写全”也会让资源更慢地抵达。

## 本章不能做的事

- 不能把见习书记员的私人小纸升级成比家族正文更高的正式记录；它只拥有传播上的先手，不拥有合法的定案权。
- 不能重复第40章的深层观察廊查阅；本章只处理赛恩带出的空册、旧孔和旧记录碎片，不再打开同一扇门看同一页。
- 不能让赛恩恢复家族印记借用权；第40章的即时损失已经发生，本章只能展示更长期的限制、问责、声誉和档案资格后果。
- 不能让妇人的临时药袋角变成永久通行凭证；重新提交医者签名只能改变一次领取结果，不能抹去她曾经被归入临时队伍的历史。
- 不能让伊莉亚的完整照护记录成为纯粹正确的答案；它会让未获药者被看见，也会使审核、配药和责任追查变慢。
- 不能让零替任判断牌背、药袋角或空白线的共同来源；零可以保护纸角，也可以拒绝把它并入任的记录。
- 不能提前揭示缺页内容、空册来源、门内刻痕、牌背残痕或世界本体；“曾有一页送件物未进入正式接收流程”只是新的制度事实，不是对遗迹的完整解释。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

## 开场状态

- 时间：第40章当夜之后的第二个办理时段；不使用精确日历。
- 地点：家族报告桌、外来者区药房外门、临时记录回收台、家族旧档案清点室。
- 任：持有主报告副本，没有附页原件；知道见习书记员的私人小纸先读到了附页，却不知道它已经被谁带入了什么决定。
- 赛恩：带出没有右半边的空册，但下一次借用家族印记的资格已失去；家族要求他说明空册是否属于允许带出的“无内容物”。
- 零：不进入登记室，仍保留不完整牌背和自己的沉默；它在新木牌背面观察“临时”纸角被谁翻看。
- 露米：想追踪纸角，却害怕再次把不同空白绑成同一批；她开始为每一片碎纸保留分开的容器。
- 伊莉亚：准备把前一时段的领取、剩余药量和两名未获药伤员写入更高层照护记录，知道这会让她承担更公开的失败。

## 核心规则

### 1. 私人小纸的影子权限

- 见习书记员的小纸没有家族印记、正文编号和封存标记，不能修改主报告，也不能决定附页的正式排序。
- 但读者和办事人常常先看见它；一旦它被抄入队列旁的便笺、口头交代或药房值班簿，私人理解就会先改变行动。
- 任可以要求把“先读到附页”与“因此认定附页为事实”分开记录，却不能让已经发生的行动从人们的记忆里消失。
- 赛恩可以先要求家族收回私人小纸，也可以在听见声誉代价后改为保留它作为见习书记员的个人见证；收回会制造“家族害怕私人记录”的声誉，保留会让未经核准的解释继续扩散。

### 2. 空册与缺页旧记录

- 空册的装订孔只能证明它曾经装过某些纸，不能说明被撕掉的内容是什么。
- 赛恩在旧档案清点室找到一枚“未接收”木签和半句登记：曾有一页送件物到过门外，但没有进入正式接收流程。
- “未接收”不是“内容不存在”，也不是“内容被家族确认”；它只说明当时的保管流程没有把那一页纳入正式记录。
- 不知道那一页是否属于当前空册，不知道是否属于遗迹旧页，不知道是谁送来，也不知道被拒收的原因；“右页随附”只是残缺登记词，不是当前缺页的身份确认。
- 赛恩若把这枚木签交给任，家族会认为他把内部清点规则外传；若不交，任只能继续从空册孔和空白线猜测，赛恩承担隐瞒的关系代价。

### 3. 药房的历史标签

- 妇人重新提交医者签名、领取时段和剩余药量后，孩子可以再次领到低额度药物，但领取牌背仍保留“临时”纸角。
- 临时纸角不能带人进入内院，也不能清除曾经领取过临时药物的记录；它会让下一名检查员先把母子放进更窄的外门队伍。
- 若重新取得内院资格，一次仍只能由母子其中一人进入，另一个必须在外门等候；这是一条分流规则，不是永久身份判决。
- 零与露米可以发现纸角被翻看、重新钉过或换了位置，但不能据此确认谁改变了牌面。

### 4. 完整照护记录的代价

- 伊莉亚提交的记录必须同时包含已经领到药的人、领取时段、剩余药量和已知未获药的伤员。
- 完整记录会触发更高层复核：药房暂缓下一批非紧急药物的统一分配，等待确认数量和责任；当前台面上的紧急备用药仍可由值班者按伤势发出，但这可能让一部分人更晚拿到本可先发出的普通药。
- 伊莉亚可以删去未获药者以换取更快的发药，也可以保留完整记录承担延迟与问责；两条路都不能让所有人同时获救。
- 任不能用“完整”替伊莉亚证明记录正确；他只能指出记录中哪些是亲眼见到、哪些来自别人转述。

## 场景推进

### 场景一：先读到的人已经做了决定

- 现实事件：交班时，见习书记员把自己的小纸摊在值班桌角；值班文书先看到“先读到附页中的‘疑似灯影残差’”，又把自己的处置意见另写成便笺：“先按灯影残差处理，再看主报告”。
- 具体后果：一名申请监督阅读的外来者被要求先填写“灯影相关”栏目，原本可以直接提出观察条件的空白栏被划掉；私人理解已经改变了排队和填表方式。
- 任的反应：他要求把“先读到附页”与“按附页处置”分成两行；文书承认两者不同，却说已经按便笺叫过下一名人。
- 见习书记员的处境：文书看到的是他的原文，却把“疑似”删掉，认为值班便笺必须给出更快的方向；见习书记员既害怕被追责，又不愿承认自己的字正在影响陌生人。
- 赛恩的行动：他先要求家族把便笺收回，但长辈指出收回会让外来者相信家族在遮掩排序过程；赛恩听见这个代价后撤回要求，选择让便笺和原小纸都留下，并承认这只是文书的私人再解释，不是小纸恢复了旧误读。
- 章内钩子：便笺背面出现一个不是见习书记员写的箭头，指向“先看药房牌背”。

### 场景二：正式记录与私人页分开

- 现实事件：任把主报告副本、见习书记员的小纸和自己的薄木并排放在桌上，要求书记员分别写明“正式记录”“个人理解”“亲眼见证”。
- 书记员的限制：家族可以给三者不同颜色的绳结，却不能保证后来的人按三种颜色分别阅读；颜色本身也可能成为新的先后标记。
- 任的要求：他不要求删掉私人小纸，只要求在小纸上加一句“此页不改变主报告”；见习书记员拒绝，因为那会让他的个人页看起来像家族附页。
- 关系推进：任第一次接受“私人理解可以保留，但必须承担它影响行动的责任”；见习书记员第一次承认自己写下的不是中性的抄录。
- 赛恩的选择：赛恩不收回小纸，只在家族主簿旁增加一条“私人页已被先行引用”的记录；此举让家族无法假装先手没有发生，也让赛恩承担放任传播的长期问责，而不是重新冻结已经冻结的研究申请。
- 见习书记员的代价：他必须在主簿旁签下自己的名字，接下来三次值班不能独自抄录附页；他的名字、便笺和后续误读会被追溯到同一张私人页。
- 章内钩子：主簿的旁栏出现“已先行引用，未正式采纳”八个字，旁边却没有写谁负责下一次解释。

### 场景三：空册里的未接收木签

- 现实事件：赛恩带任进入旧档案清点室外侧，不重复深层查阅，只在长桌上拆开空册封皮的旧线；一枚小木签从夹层里掉出来。
- 木签内容：木签上只有“未接收”，下方缺了日期和送件人的名字；半句旧登记似乎写着“右页随附，门外候验”，后半句被刮掉。
- 任的判断：他指出这只能说明一页送件物曾到过门外却未进入正式接收流程，不能说明它属于当前空册、遗迹旧页或任何已经见过的裁边，也不能说明家族主动撕掉了它。
- 赛恩的犹豫：他可以把木签交给任，承认家族正文之外存在未被正式接收的路径；也可以将木签放回空册，保住家族清点规则，却让任继续只看见结果而看不见流程。
- 赛恩的选择：他把木签交给任，但要求任只记录“未接收”三个字，不记录缺失内容的猜测；家族随后收回他的旧档案清点资格，并在既有研究申请冻结旁加上“擅自外传内部清点物”的长期问责记号，不作为新的冻结理由。
- 章内钩子：任把木签放在薄木旁，木签长度比空白线短一截；装订孔仍与空白线等长，三者不再能被简单拼成同一件物。

### 场景四：临时纸角改变队伍

- 现实事件：妇人带孩子重新到药房外门，交上医者签名、领取时段和剩余药量；检查员承认孩子可以领取低额度药物，却先看新牌背面的“临时”纸角。
- 具体分流：检查员把母子安排到比上一回更窄的外门队伍，要求他们等待前面三名“无历史临时记录”的人先领；重新提交签名改变了今日的领取结果，却没有抹去过去的记录。
- 妇人的选择：她要求把孩子的领取和自己的等待分开记录，不让孩子被写成母亲的附属；检查员却说同一张牌背必须保持同一户的顺序。
- 零与露米的行动：药房小童想用木镊撬起旧纸角，在旁边钉入新的复验绳结；零让暗边卡住木镊，阻止纸角再次脱落。新钉线被拉断一小截，露米没有把纸角取走，只在另一只小袋里单独收集这次新掉落的线头；第40章留在伊莉亚空药袋里的旧线头不在其中。
- 现实危险：前方有人因等待过久昏倒，队伍开始抱怨“临时的人总要插队”；妇人和孩子并没有插队，却成为最容易被指责的那一段。露米为了保持碎片分开，没有把新线头绑到纸角旁，结果错过了检查员换牌时的一次判断，药房小童差点把纸角连同废线丢掉。
- 关系推进：任想指出队伍的时间顺序被牌背历史改变，却被妇人阻止：“先让我把药拿到，再替我证明他们错了。”任第一次把解释让位给当下的资源选择。
- 章内钩子：检查员在新牌背面添了一行“已复验，仍从外门起”，这行字比“临时”纸角更靠近牌边。

### 场景五：完整记录让药来得更慢

- 现实事件：伊莉亚把照护记录交到更高层的药房台，记录中同时写有孩子领到的低额度药、剩余药量和两名未获药伤员。
- 复核后果：药房暂缓下一批非紧急药物的统一分配，要求核对数量与责任；几个原本可以先领到普通药的人被迫在旁边等待。伊莉亚交出的那一小包药来自台面上已经登记的紧急备用药，不是妇人为孩子领取的低额度药，也不是被暂停的下一批普通药。
- 伊莉亚的动摇：有人要求她撕掉未获药者那一行，声称只要先把药发出去，后面的名字以后可以补；她知道删掉会让两名伤员从这次记录里消失。
- 伊莉亚的选择：她保留完整记录，却将台面上已经登记的紧急备用药交给值班者先救最重的人；这个动作没有获得正式许可，也使她承担“越过统一分配”的问责。
- 任的边界：任指出她的记录包含亲眼见到、妇人告知和药房称量三种来源；伊莉亚承认自己不能把三者写成同一种确定性。
- 现实结果：完整记录被收下，药物复核继续；最重的伤员得到一小包药，其他人并没有立即得到保证。
- 章内钩子：记录末尾出现一个新的空栏：“因完整记录产生的延误，由谁承担。”伊莉亚没有替任何人填上名字。

### 场景六：不是所有先读都会变成真相

- 现实事件：夜里，见习书记员找回自己的小纸，想把“灯影误差的早期记录”那一行重新写回去；他认为如果不补，别人会以为他故意隐瞒。
- 任的回应：任要求他保留划掉的痕迹，而不是恢复错误句子；被划掉的内容仍然属于这张纸发生过的一部分，但不能再被当作当前结论。
- 赛恩的代价落地：长辈让赛恩在主簿旁签下“私人页先行引用，责任待定”；这不是恢复印记，也不是新的查阅许可，只把他的问责延长到之后每一个使用这张小纸的人。
- 零的边界：露米想把药袋纸角、木签和见习书记员小纸放在一起比较，零阻止她，只说“不要把先后绑成同一个来源。”露米没有因此把碎片重新绑在一起，而是接受自己错过一次追踪机会。
- 任的发现：小纸、木签、药牌和薄木上的空白线都涉及“先被看见”或“未被接收”，但没有任何一件能证明它们来自同一个地方。
- 章末事实：主报告仍在正文架上，附页的阅读顺序没有被撤销；私人小纸被标成“已先行引用，未正式采纳”；临时药袋角仍在新牌背面；完整照护记录进入复核；空白线与装订孔的关系更加复杂而非更确定。
- 章末钩子：任把“先读”和“未接收”写在薄木两侧，薄木中间那条未由他写下的空白线没有变长，却在灯下比之前更容易被看见。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 想追究附页先读造成的误解 | 接受私人理解可以保留，但要求区分来源；在药房现场先让位给妇人的领药需要 |
| 赛恩 | 带着空册，失去下一次印记借用权 | 交出“未接收”木签，承担更长期的内部清点问责；没有恢复任何权限 |
| 零 | 拒绝进入登记室，保留牌背痕迹 | 阻止纸角被撬下，却拒绝把药袋、木签和空白线拼成共同来源 |
| 露米 | 害怕再次把不同空白绑成一类 | 分开保存纸角、线头和碎片，因不合并而错过一次追踪判断，开始把“不替它们合并”当作有代价的保护 |
| 伊莉亚 | 准备提交完整照护记录 | 保留未获药者记录，同时承担复核延误与越过统一分配的双重问责 |
| 见习书记员 | 以为个人小纸只是自己的理解 | 承认私人记录也会先改变行动；签名承担可追溯责任，接下来三次值班不得独自抄录附页 |

## 读者此时应该误判什么

- 只要把私人小纸收回，已经发生的先行处置就会消失。
- “未正式采纳”意味着私人记录没有造成任何后果。
- “已复验，仍从外门起”是一次性的队伍安排，不会成为下一次身份历史。
