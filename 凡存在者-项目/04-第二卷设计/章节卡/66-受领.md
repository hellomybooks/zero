# 第二卷第六十六章《受领》场景卡

## 状态

- 状态：已完成两轮独立 Canon / 文学窄回归，标记为定稿候选；正文生产时需保留审校中的 P3 提醒。
- 承接：第二卷第六十五章《候位》正文与正文审校。
- 篇章：ARC 06《阈值战争》第六章。
- 情绪中心：伊莉亚 / 阿尔德；任与露米承担正式文书进入街面的后果，赛恩与阿芙承担名字和归属压力。
- 本章功能：让第65章的街面候位被上城文书正式收编；把既有的“受领人”字段延伸到候位调度，明确受领不是救援、资源、时间或归属；让阿尔德第一次以“受领人”身份用自己的名字把一处等待留在正式文书里。
- 本章主概念：有人接住一份报告，不等于有人能接住报告里的人；空白栏不是没有人，却会被人读成没有人要。
- 本章情绪：纸面正式化带来的短暂安心、名字被要求承担未知者的羞耻、伊莉亚拒绝扩展照护后的不适，以及阿尔德签下有限受领并接到真实补记后无法退回的沉重。

## 一句话梗概

上城传下一本候位册，要求把东十四巷的候位一、下渠区的候位二，以及封石“不入候位／来源未确认”的记录一并抄入正式调度文书；受领栏只针对候位行填写，封石不进入候位，也不填写受领人。文书说明受领只代表有人接收下一次报告，不代表守备、救援或时刻；可人群很快把“无受领”听成“没人要”。赛恩拒绝用家族印记替门后人受领，阿芙只保留本人自证；伊莉亚拒绝把线外来者的个人转告变成受领，却因此被旁人称为不肯接人。任把“受领、照护、归属、处置”分开记录，正式册页却只给一行；阿尔德最终在下渠区一栏签下“仅现场报告”的有限受领，并实际接到一份身体状态补记，候位二因此留下正式位置，却没有得到新的守备或时间。章末，候位册被带回上城，街面已经开始寻找可以借来的名字。

## 本章不能做的事

- 不能把“受领”写成新的魔法、保护、治疗或通行许可；它只是某个人或某个处所同意接收下一次报告的行政动作。
- 不能让候位册制造新的守备、灯、药粉、担架、车辆、水或路线；正式化只改变纸面归档和责任可见性。
- 不能让受领自动等于处置、照护、归属、姓名确认或身体接收；四种关系必须继续分开。
- 不能让上城文书成为全知反派；他只执行一张需要填写的表，也会受表格限制，不负责解释制度为何这样设计。
- 不能让赛恩用家族印记替门后未知者受领；没有门内同意，家族只能提出责任，不得制造归属。
- 不能让阿芙用本人自证代替门后人数；她可以承认自己在门边，不可以替陌生人接受后续报告。
- 不能让伊莉亚把线外来者纳入三名身体的受领或照护；个人转告仍然只是一句话，失败、失真和离开都可能发生。
- 不能让阿尔德的有限受领变成“下渠区已经得到救援”；他的签名只承担现场报告回收，不承诺时刻和人手。
- 不能让任用精确拆分撤销“无受领”在街面造成的羞辱；露米要记录词语如何从册页旁注进入人群。
- 不能让第三声获得“无受领”身份；封石不进入候位，不等于封石有一个没有签名的候位。
- 不能让零成为受领人、见证人或候位册的判断者；它可以被人群误读，但不替任何一栏作答。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

- 调度处：新守备仍暂留门槛内，没有增加现场人手；原东十四巷守备仍驻封石，下渠区原守备仍守照护线附近；任手里的木片仍保留第65章的两行，只在旁边补写“受领待定”旁注。
- 东十四巷：候位一临时标记仍在既有报告牌边；东十四巷新木闩仍能短时顶门，断门闩靠墙；门后一只手和“别开”仍在，姓名、人数、伤势未确认；阿芙门牌上的名字被划掉一半，未完全消失；赛恩私人礼灯已熄，家族印记仍未盖下。
- 下渠区：候位二的炭痕被水浸软，背面“下一次复核未定”可见；托恩、阿瑟和“旧牌旁的人”仍在照护线内，通行线关闭；下渠区门边裂木板未恢复，裂玻璃照护灯仍亮；线外来者仍在石角后，没有姓名、归属、伤情或正式受领人。
- 封石：第三声牌仍由火绳压在护石旁，火绳受力、石灰变化、来源未确认保持；零可能出现在坡下灰线外，不进入任何正式册页。
- 上城来件：一名城防文书带来一本薄候位册和一张交班副页；这是调度处已有的行政链向下延伸，不带来救援资源。

## 核心规则与本章新增边界

### 1. 受领只接收报告，不接收人

- 受领表示某个人或处所愿意在下一次复核、回报或状态变化出现时接住消息，并在册页上留下可追溯的名字。
- 受领不表示受领人承诺亲自抵达、提供资源、打开门、承担身体照护或改变对方归属。
- 受领可以限定范围，例如“仅现场报告”“仅转交调度处”；限定必须写出来，否则街面会把它读成全面承诺。
- 没有受领人不等于没有身体、没有声音或没有发生过事；但正式册页会把“待受领”放在更容易被下一班跳过的位置。

### 0. 本章延伸既有字段，不新造“受领”制度

- “受领人”此前已经是与“责任人”并列的记录字段；本章只是把它延伸到候位调度文书，不把责任分支补进受领栏。
- 阿尔德签的是下一次现场报告的受领范围，不等于第52章的责任分支；他不因此承担资源、照护、处置或归属。

### 2. 候位正式化不改变先后

- 上城候位册沿用第65章的候位一、候位二，不补时刻，不增加名额，不把候位一的复核抵达改成救援完成。
- 东十四巷可以记为“候位一 / 待受领”；下渠区可以记为“候位二 / 受领仅现场报告”；二者仍没有自动轮到的时间。
- 封石记为“不入候位 / 来源未确认”，不写成“候位三 / 无受领”；“无受领”只能描述已进入候位而没有接收人的行，不能套到未知记录上。
- 候位册离开调度处以后，街面抄联可能先于原册传播；正式文字不会自动控制旁注和口头词。

### 3. 四种关系不能互相替代

- 受领：谁接下一次报告。
- 照护：谁在现场见证或照看身体。
- 处置：谁在有限动作中实际到达并改变现场。
- 归属：谁有权以姓名、家族或关系把人写入某条制度链。
- 任必须把四种关系分开；文书只给一行时，他可以把差异写在副页，但不能让主册因此多出空间。

### 4. 签名会留下责任，但不会变出资源

- 阿尔德可以以“调度处 / 阿尔德”签下下渠区的“仅现场报告”，这会让下渠区候位二留下正式受领人和一个可被追问的名字，却不会增加守备、护灯、药物、时刻或路线；这不是第52章的责任人字段。
- 伊莉亚的三人照护见证不自动成为候位受领；她如果拒绝扩大，线外来者仍不进入正式栏位，她也要承受旁观者对“不肯接人”的误读。
- 赛恩的个人礼灯责任和家族印记互不替代；他可以说明自己承担礼灯账，却不能以家族名义受领门后未知者。
- 阿芙的本人自证只能说明她在门边，不等于她愿意接受门后人的后续责任。

## 读者此时应该误判什么

- 误以为候位册出现就意味着下一班已经确定；实际它只把等待的责任写得更清楚。
- 误以为受领人就是救援者；实际受领人可能只接一张报告，并没有能力改变现场。
- 误以为阿尔德签名是他终于选择下渠区；实际他只是让一条现状不被册页删掉，东十四巷仍在候位一。
- 误以为伊莉亚拒绝受领是冷漠；实际她拒绝的是把线外来者重新塞进三人的照护范围，但她仍会因此感到自己在推开人。
- 误以为赛恩不盖印记就是不愿承担责任；实际他愿意承担自己的礼灯账，却不愿替未知者制造未经同意的家族归属。
- 误以为“无受领”说明某个人没有人要；实际它只说明没有人在册页上接受下一次报告。
- 误以为封石的空白和下渠区的无受领是同一种空白；前者没有进入候位，后者只是候位中的责任空缺。
- 误以为任把四种关系拆开就能阻止旁注扩散；精确副页不能替人群收回已经喊出的“没人要”。

## 场景设计

### 场景一：册页从上城下来

- 现实事件：天亮后，一名城防文书沿上城坡道来到调度处。他没有带新的守备，只带候位册、交班副页和一支封蜡已裂的短笔。
- 文书说上城要把“下一次复核未定”收进候位册；他不解释谁制定了这条命令，只问调度处现有的候位一、候位二和封石记录。
- 任把第65章留下的两张既有报告牌放在册页旁，强调数字写在牌边，不是新牌；文书只问“这一笔现在是否仍成立”。
- 阿尔德回答东十四巷候位一复核已抵达、身体未确认；下渠区候位二仍无时刻；封石不进入候位。
- 文书翻到受领栏，问：“谁接下一次？”这句话让门外的人群第一次同时看向不同的人。
- 章内钩子：候位册上有四栏——地点、候位、受领、时刻；第四栏仍是空的，前三栏却已经足够让人开始争名字。

### 场景二：受领不是救援

- 文书要求在册页边写一句解释。任说受领只接收报告，不接收身体；文书让他把这句话写在副页，不写进主册。
- 任问：“如果受领人收到报告以后不能行动呢？”文书说：“那是下一次的事。”
- 任问：“如果没有下一次？”文书看了他一眼：“所以要有受领。”
- 这句话听起来像责任，也像把不能发生的事先写成了人的缺席。
- 露米站在门外，听见人群把“受领”念成“有人管”；她把这两个词并列记下，却没有替它们决定是不是同义。
- 文书把“候位一 / 候位二”从旧换班板抄入候位册，候位顺序没有改变，时刻栏仍空着。
- 推进：文书在“受领”两字旁写下“待填”，旁边一个女人立刻说：“待填就是没人要。”

### 场景三：东十四巷的空栏

- 现实事件：文书带着候位册来到东十四巷，要求为候位一填写受领人；阿芙门牌上的半个名字仍在，门后一只手没有再次出现。
- 文书问阿芙：“下一次复核回来的话，你能接那份报告吗？”阿芙回答：“我能接我自己的话。”
- 文书问：“门后的话呢？”阿芙说：“他们没有给我。”
- 旁边的人群开始把她半个名字读成一个完整姓氏；有人说只要她写满，候位一就不会被退回。
- 阿芙的手碰到门牌上那道未划完的笔痕。她想把名字重新补全，又想把整块牌撕下来。
- 门内传来“别开”，文书的笔停住；他在受领栏写“待定”，没有把“门内拒绝”写成无人存在。
- 赛恩站在熄灭的私人礼灯旁，家族使者把印记递给他。使者说家族可以成为受领人，不必现在确认门后人数。
- 赛恩问：“受领以后，家族能替他们决定名字吗？”文书说：“那是归属栏，不是受领栏。”
- 赛恩伸手接过印记，却没有盖下；他只在礼灯责任页上确认自己的灯账，不把家族名写进候位册。
- 后果：候位一一栏留下“受领：待定”，人群却先把它喊成“东十四巷没人接”。

### 场景四：下渠区的三个人

- 现实事件：文书在调度处查看下渠区既有报告牌和牌背，不进入照护线；他要求确认三名身体的候位受领是否与伊莉亚的照护见证相同。
- 伊莉亚说照护见证写的是她看到的身体状态，不是她承诺在下一次复核时接收全部消息。
- 文书把笔放在“受领人”一栏，问她：“你签过三个人的状态，为什么不能接下一次？”
- 伊莉亚看向托恩、阿瑟和旧牌旁的人。她想说因为她已经在这里，却没有说出口。
- 线外来者坐在石角后，听见“受领人”三个字，问：“我算不算在你签过的三个人里？”
- 伊莉亚回答：“不算。”
- 线外来者笑了一下，不像感谢，也不像嘲笑：“那我连没人接都不算。”
- 文书想把个人转告旁注抄进候位册；伊莉亚按住他的笔，说个人转告只说明她曾传一句话，不产生候位或受领。
- 文书在下渠区一栏先写“候位二 / 待受领”；三名身体的照护线仍在，通行线仍关闭，裂木板、照护灯和既有材料不变。
- 推进：阿尔德看见自己的名字还没有写在册页上，文书却已经把下渠区的空栏留给他。

### 场景五：无受领被喊出来

- 现实事件：露米把文书写下的“待受领”记录在旁注里；一个站在册页旁的居民把它改口成“无受领”。
- 另一个人接着说“无人要”，这句话很快从候位二旁边传到石角后。
- 线外来者没有站起来。她只是把手里的干泥捏碎，碎片落在脚边。
- 伊莉亚听见有人让她“既然不受领，就别再传话”；她没有立刻反驳，只把自己的个人转告纸折回去。
- 露米想把“无人要”划掉，文书阻止她，说那不是主册内容，却已经是街面发生的事。
- 露米问：“那我该写它是什么？”
- 文书说：“写来源。”
- 露米说：“来源是很多人。”
- 她把“待受领 → 无受领 → 无人要”写成三行，并注明每一行出现的嘴不相同。
- 一个女人把孩子从线外来者身边拉开，孩子回头问：“她不是还在吗？”女人说：“在不等于有人接。”
- 这句话让线外来者第一次抬头看候位册。
- 后果：候位二的空栏没有改变，街面却已经为它填上了一个人的价值。

### 场景六：任的副页

- 现实事件：任要求在候位册后附一页，把受领、照护、处置和归属四种关系分开；文书说副页可以存在，但下一班先看主册。
- 任把东十四巷写成“候位一 / 待受领 / 身体未确认”；把下渠区写成“候位二 / 照护线内 / 受领待定”；把封石写成“不入候位 / 来源未确认”。
- 文书提醒他：副页不能改变主册顺序，也不能把候位二变成候位一。
- 任说：“我没想改变顺序。”
- 文书问：“那你为什么写这么多？”
- 任说：“因为你们的一行会被人当成全部。”
- 文书把副页压在主册下面，恰好遮住“受领待定”几个字；任伸手把它抽出来，动作比他说话更快。
- 露米看见任的手停在纸边。他没有把副页撕掉，也没有把主册翻过去。
- 后果：副页准确保留了差别，却被主册的重量压出一道折痕。

### 场景七：阿尔德的签名

- 现实事件：文书告诉阿尔德，如果下渠区没有受领人，候位二会被记为“待受领／下一班复核”；这不代表三名身体消失，但下一班可以不先看这一行。
- 阿尔德问：“东十四巷呢？”
- 文书说：“候位一仍在前。受领待定只影响这一行是否能在下一次交班时继续占板。”
- 这不是价值判断，实际效果却会让下渠区更容易被跳过。
- 下渠区原守备的既有牌背写着风口、三名身体和裂木板；没有新的守备出现，调度处也没有收到可以调人的新命令。
- 阿尔德拿起短笔，在受领栏写：调度处 / 阿尔德。
- 文书问：“范围？”
- 阿尔德写下：仅现场报告。
- 文书问：“是否承诺下一次到达？”
- 阿尔德说：“写我。别写守备。”
- 文书等了一下：“是否承诺下一次到达？”
- 阿尔德说：“没有。”
- 文书问：“是否承诺资源？”
- 阿尔德说：“没有。”
- 他仍然没有把笔收回。
- 他刚收笔，既有传令链送来下渠区牌背补记：阿瑟胸口固定木片旁的暗色已经越过上一道旧线；托恩的脚趾仍然没有动。
- 文书把补记推给阿尔德：“这张也接？”
- 阿尔德把牌背看了一眼，接过来，在副页上记下“受领：仅现场报告”；传令链没有带来新的守备、药物或时刻。
- 门外有人问：“你既然受领，什么时候来？”
- 阿尔德先说：“我接这张。”他看见补记上的暗色，后半句没有说出来。
- 伊莉亚看见他的名字落在下渠区一栏，第一反应不是安心。
- 她问：“你接的是谁？”
- 阿尔德说：“下一份报告。”
- 伊莉亚说：“报告里有我们。”
- 阿尔德没有回答。
- 转折：阿尔德的名字让下渠区留在主册，却也让所有人有了一个可以追问“为什么还没来”的人。

### 场景八：被借走的家族名

- 现实事件：阿尔德签名的墨还没干，调度处外的一张抄联已经有人把“赛恩”从私人礼灯责任页抄到东十四巷受领栏旁，又添上“家族代领”。那不是主册原笔，却先于解释传开。
- 仍在旁边的家族使者把印记递过来，说既然抄联已经这么写，盖印只是在让下一班相信。
- 赛恩抓过抄联，先要把“家族”两字划掉；笔尖落下时他停住——只剩“赛恩”也会被人当成家族名。
- 阿芙从门边说：“门里没给你。”
- 赛恩说：“我知道。”声音太快，像是在回答别的事。
- 使者把印记往前递：“只差一下。”
- 赛恩把既有礼灯账牌压住印记，只在账牌上确认已经存在的个人油料、磨损和归还责任，不改主册，也不盖家族印记。
- 他最后只说：“别替我写家。”
- 使者没有收回抄联；旁边的人已经把“赛恩家族代领”喊成一个完整的决定。
- 后果：东十四巷主册受领栏仍是“待定”，街面抄联却多出一个未经同意的名字，赛恩必须承担清不干净的误读。

### 场景九：湿指印被当成签名

- 现实事件：文书把候位册带到伊莉亚面前，要求她只在副页的“个人转告”旁注处确认，不另设“线外转告受领人”栏；个人转告仍不进入主册。
- 伊莉亚伸手按住副页，想把“来者保留离开和改口权”补全；水汽在纸边留下一个湿指印，恰好压在主册受领栏的下方。
- 旁边有人立刻喊：“她按过了，就是她受领。”
- 伊莉亚看向阿瑟。补记上的暗色已经越过上一道旧线，固定木片边缘的皮肤绷得发亮。
- 她脱口说：“我已经有三个了。”
- 线外来者低头看着自己的手。伊莉亚意识到这句话已经落下，想改口，却只说出：“不是……我不是说你。”
- 线外来者说：“别替我。”这次不像请求，像是在把一扇门关回去。
- 伊莉亚没有把线外来者的名字写进去，也没有把“无人要”划成“有人要”；她只在副页留下个人转告未形成受领的补记。
- 文书说：“这行不在主册。”
- 伊莉亚把湿指印旁的纸折回去：“那就别让它装成主册。”
- 后果：她没有签名，湿指印却被抄联当成了受领痕迹；阿瑟的身体状态已经恶化，而她没有因此扩大自己的照护范围。

### 场景十：封石的空白不能叫无受领

- 现实事件：文书回到封石记录旁，准备在候位栏下方加写“无受领”，以便下一班知道没有人接这份记录。
- 阿尔德拒绝；他指出封石根本没有进入候位，不能把“未被排队”改写成“排队后无人接收”。
- 文书说：“对下一班来说，都是不用先去。”
- 阿尔德说：“对牌上的事，不是。”
- 第三声牌仍被火绳压住，火绳比上一次更紧；石灰沿护石边落下，来源、性质和是否为人声仍未确认。
- 文书问是否至少可以写一个受领人“阿尔德”。
- 阿尔德张了张口：“我能受领火绳和石灰。”他看向封石，“石后面的……不行。”
- 任把这句话写进副页，没有写入候位册。
- 零在坡下灰线外出现，候位册的纸角被风吹起；它没有靠近，也没有碰纸。
- 后果：封石栏最终写成“不入候位 / 来源未确认”，空白保留下来，却不再是受领空白。

### 场景十一：名字开始借用

- 现实事件：候位册暂时摊在调度处外，居民发现受领栏需要一个可以被追问的名字；有人开始提出借用阿尔德、赛恩、伊莉亚或下渠区守备的名字。
- 一个东十四巷居民说：“先借赛恩的家族名。”使者立刻把印记收紧。
- 一个下渠区居民说：“阿尔德已经签了，就让他把候位二变成一。”
- 阿尔德说受领不改变先后；人群听成他不肯让出自己的位置。
- 露米把“受领人”“占位人”“救援人”三种叫法写在同一张副页上，文书要求她删掉街面词。
- 露米没有删。她把文书的要求也写下。
- 任看见几个人围在受领栏旁，开始互相询问“谁的名字更能让下一班相信”。
- 这一次没有水桶被拖动，也没有人立刻受伤；伤害先表现为一个名字的价格开始出现。
- 线外来者站在石角后，没有向任何人借名字。
- 她问伊莉亚：“你的名字能让我快一点吗？”
- 伊莉亚说：“不能。”
- “那你为什么还留在这里？”
- 伊莉亚没有回答。
- 转折：有人在候位二旁边写下“阿尔德已受领”，又把“仅现场报告”四个字刮掉。

### 场景十二：册页离开调度处

- 现实事件：上城文书收回候位册，准备带回上城归档；他在离开前读出三行最终记录：东十四巷候位一 / 受领待定 / 时刻未定；下渠区候位二 / 阿尔德受领仅现场报告 / 时刻未定；封石不入候位 / 来源未确认。
- 文书把“待受领”解释为“下一次交班需重新确认”，没有说它会被删除，也没有保证它会被保留。
- 任将副页交给文书，提醒主册上的“阿尔德受领”不能单独传播；文书说副页会随册，但先到的抄联可能只有主册三行。
- 露米听见“阿尔德受领”已经被人群喊成“阿尔德负责下渠区”；她没有替阿尔德辩护，只把这句话记下。
- 伊莉亚回到三名身体旁，仍未把线外来者加入照护或受领；阿瑟胸口固定木片旁的暗色已经越过上一道旧线，托恩的脚趾仍不动，旧牌旁人的手和裂木板继续恶化或等待，但本章不新增资源。
- 阿尔德的签名留在册页上，不能在文书离开后追着改掉；他没有因此得到新的守备。
- 赛恩的个人礼灯责任页仍在东十四巷门边，家族印记没有盖；阿芙的半个名字仍在门牌上，门后仍只说“别开”。
- 封石火绳又收紧一次。没有人把它写成受领失败，也没有人把它写成安全。
- 章末画面：候位册被带上坡，调度处的主板留下三行副抄；“待受领”被风吹向街面，“没人要”已经有人在另一面墙上写下，而阿尔德的名字第一次成为一处等待的公共追问。

## 章末必须留下的事实

1. 上城候位册把第65章的候位一、候位二正式收编，但不提供守备、资源、时刻、保护或通行资格。
2. “受领”只表示接收下一次报告；受领不等于处置、照护、归属、姓名确认或身体接收。
3. 东十四巷：候位一 / 受领待定 / 时刻未定；门后仍只说“别开”，身体、人数、姓名和伤势未确认；阿芙只为自己作证，赛恩家族印记未盖。
4. 下渠区：候位二 / 阿尔德受领仅现场报告 / 时刻未定；三名身体仍在照护线内，通行线关闭，既有材料与灯具不变。
5. 伊莉亚没有把线外来者写入受领或三人照护；个人转告仍不产生候位、资源或归属，线外来者保留离开和改口权。
6. “待受领”在街面被改口为“无受领”“没人要”；任与露米记录了差异，却没有撤销已经发生的羞辱传播。
7. 封石不入候位 / 来源未确认；第三声牌仍在火绳下，火绳受力和石灰变化继续，不写候位三、不写受领失败、不确认本体。
8. 零不进入候位册，不成为受领人、见证人、方向或身份判断。
9. 阿尔德的有限签名留下不可随意撤回的受领范围和公共追问，但没有带来任何新的人、灯、药、担架、车辆、水或时间；旁注和抄联不能扩大他的正式范围。

## 第二卷第六十七章接口

- 受领人的名字开始被借用、抄错或要求转让；“阿尔德受领”可能被写成“阿尔德负责下渠区”，但不能让误写自动成为正式责任扩大。
- 东十四巷的受领待定会继续逼迫阿芙、赛恩和门后人给出名字或同意；门内“别开”的原因仍未知，候位一仍无时刻。
- 下渠区候位二留在主册但没有新守备；伊莉亚要面对三人照护与线外来者的更尖锐分离，阿尔德要承受签名被追问。
- “无人要”可能成为新的街面词，但不能直接替代“无受领”的正式含义；任和露米要继续处理主册、副页、旁注和口号的传播差。
- 封石不入候位；火绳、石灰或墙外结构可带来新的物理后果，但第三声仍不能被命名、归类或交给零解释。

## Canon 检查清单

- [ ] 受领是接收报告，不是救援、保护、处置、照护、归属或时间保证。
- [ ] 候位册不增加人手、灯、药、担架、车辆、水或路线。
- [ ] 东十四巷候位一保持受领待定，阿芙只为自己作证，赛恩不以家族印记替未知者受领。
- [ ] 下渠区候位二保持时刻未定，阿尔德签名范围限定为“仅现场报告”。
- [ ] 伊莉亚不把线外来者纳入受领或三人照护；个人转告仍可失败、失真或撤回。
- [ ] 任分开受领、照护、处置、归属；副页不能替主册恢复资源或撤销街面词。
- [ ] 露米记录“待受领 → 无受领 → 没人要”的来源和后果，不抹掉传播。
- [ ] 封石不入候位，不被改写成“无受领”；第三声与零保持未知和不可登记。
- [ ] 正文通过候位册、受领栏、半个名字、私人礼灯账牌、个人转告和被借用的名字呈现冲突。

## 五问自检

1. 本章首先发生在人身上的，是一张正式册页要求某个人把自己的名字放到未知者旁边；伊莉亚的湿指印被误读、阿尔德签下、赛恩处理被借走的名字、阿芙停笔。
2. 阿尔德签下会被追问的有限受领，伊莉亚在看见阿瑟状态恶化后仍不扩大范围，赛恩让抄联上的“家族”两字无法得到印记，露米保留会扩散羞辱的词；每个人都做了可能后悔的选择。
3. 不让人物说出“受领不等于存在”或“我终于允许裂缝”；让空栏、湿指印、半个名字和被借用的签名承担主题。
4. 不提前支付候位制度的终局、阿尔德最终政治立场、伊莉亚最终麻木或第三声本体；本章只让正式责任开始进入街面。
5. 删除所有技术隐喻后，一本候位册、一个空栏、三处等待、一个不肯盖下的印记和一个被借用的名字仍构成完整冲突。
