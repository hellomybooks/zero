# 第二卷第三十九章《半页》场景卡

## 状态

- 状态：场景卡草案，待 Canon / 连续性 / 文学性 / 奇幻感独立审校。
- 承接：第二卷第38章《家门》正文与正文审校。
- 本章功能：让任第一次在家族严格限定的“可见区域”内阅读旧登记页，确认记录不是被动保存过去，而是主动决定谁能看见哪一部分；同时让赛恩和零分别面对报告权与未归档路径。
- 本章主概念：被允许的区域 / 选择性可见——不是整张记录都能进入阅读，观看范围本身也是制度处置。
- 潜在技术隐喻：ROI / 世界区域、局部读取；只在结构化资料中记录，正文只写门框、灯窗、纸面和可见范围。
- 本章情绪：受限好奇、证词羞耻、保护与隐瞒的分界、门外的孤独。

## 一句话梗概

任在赛恩陪同下获得一次限时阅读，却发现家族不是把旧页交给他，而是用木框、灯位和距离规定他能看见哪一块；当旧页的缺失边在规定范围内出现两种互不相同的记录痕迹时，赛恩必须决定报告“家族允许的半页”，还是报告任真正看见的不一致。

## 本章不能做的事

- 不能让任直接触摸或带走旧页，不能让他一眼读出被裁掉内容。
- 不能把“可见区域”写成任主动施放的新能力；范围由家族门框、灯窗、观看距离、页架和书记员共同规定。
- 不能让旧页自行完整复原、显出 Copy、Observed、Original 或世界本体答案。
- 不能把赛恩的报告选择写成纯粹背叛或纯粹正义；他必须在保护任、保护家族和保留异议之间承担具体代价。
- 不能让零在门外直接知道旧页内容；它只能接触被丢弃的牌角、药袋、擦除屑和记录背面。
- 不能重复第37章的白灯、黑水盘和外门排队；本章的危险来自“只允许看一部分”造成的误判和权力后果。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

## 开场状态

- 时间：第38章之后的当日，距离日落还有一段时间；不使用精确日历。
- 地点：家族禁书库的监督阅读室、外来者区后侧的弃牌沟、家族报告桌。
- 任：持有“遗迹共同见证者 / 赛恩陪同”的临时阅读牌；不能传抄、触碰原页、带走封存物，也不能带零进入。
- 赛恩：承担监督阅读、家族报告和泄露责任，研究申请优先权已经下降；他必须在书记员的记录格式内说话，并面对进一步降级的风险。
- 零：留在外来者区，不被登记为研究对象；它沿着屋檐、药袋和弃牌沟移动，寻找没有被门牌收拢的痕迹。
- 露米：陪零留在外来者区，观察被擦掉的颜色、被撕去的牌角和人们丢弃记录的方式。
- 伊莉亚：确认临时送药已到，但药袋上的“外来者区”标记使取药者在下一次领取时仍要重新解释；她开始记录照护如何被标签追着走。

## 核心规则

### 1. 监督阅读区域

- 旧页平放在窄石台上，外面有一层不可触碰的细线；任只能站在指定的浅色石砖上。
- 书记员通过木框、灯窗和页架固定可见区域；任不能自行移动灯、纸或身体超过标记线。
- 旧页右半边已经被裁掉；可见区域不是“剩余半页的全部”，而是家族允许当前读者获得的部分。移动一小步会让一行字进入阴影，但不会自动显示缺失的右半边。
- 同一块裁齐边可能在不同灯位下呈现不同厚度、残墨或刮痕；这些是观察结果，不是被裁内容的可靠复原。

### 2. 报告权

- 监督阅读结束后，赛恩必须在家族报告桌填写一份短报告。
- 报告至少有三种可选标题：旧档案改名、见证者观察异常、家族保管争议；标题会改变报告进入哪一层档案和谁能继续查阅。
- 任可以要求自己的见证记录附在报告后，但不能强迫赛恩使用某一标题；赛恩也不能删掉任的异议后把报告称为完整记录。
- 若赛恩如实写出可见区域改变了残墨判断，家族会进一步暂停他的研究申请；若他只写旧档案改名，他可以避免深层档案权限继续冻结，但任的观察会被压到附页；若他拒绝提交，家族会收回后续陪同资格。

### 3. 门外的弃牌沟

- 外来者区后侧有一条排水沟，家族仆役把失效门牌、剪下的药袋角、封蜡碎片和擦除后的薄木屑丢进去。
- 零不能从碎片中读出旧页内容，但能让某些被丢弃的边缘暂时保持，不被雨水冲走。
- 露米发现弃牌沟里存在几种不同的“空白”：被剪掉的、被刮掉的、从未填写的、写过后被重新磨平的。
- 这些空白不能直接证明谁删了什么，却让零第一次接触到“不被记录”也有不同形状。

## 场景推进

### 场景一：门框里的半页

- 现实事件：任被带入监督阅读室，旧页固定在石台上；门框只打开一条窄缝，灯光从缝中照入，纸面右半边始终在暗处。
- 具体限制：任只能站在一块浅色石砖上，不能靠近，不能侧身绕过门框；书记员每次移动灯窗前都要重新记录时间和位置。
- 任的观察：第一种灯位下，他看见遗迹名称被改过两次；第二种灯位下，第二行旧墨的边缘变厚，像曾经有一段字被刮去；两种结果不能合并成完整句子。
- 赛恩的行动：他想提醒任不要把“像”写成“是”，但自己也在用家族规定的距离限制任能观察到的东西。
- 文学推进：任意识到自己不是在读一张旧页，而是在读家族为他截出的一个区域；家族把“看见”与“能够证明”分成两道门。
- 章内钩子：任在残留的“见证者：”后看见一小段与纸边平行的暗痕，暗痕不属于任何可读文字。

### 场景二：两种残墨

- 现实事件：任要求书记员只把两次观察并列记录，不要把第二次写成对第一次的修正；书记员允许并列，却把它们放在不同的附栏。
- 制度后果：正文档案只保留第一栏，附栏需要家族成员签名才能被下一层阅览者看见；任的观察被承认存在，却被安排在更难抵达的位置。
- 赛恩的冲突：他必须签名才能让附栏保留，但签名会使家族知道他承认“可见区域改变判断”；不签名，任的第二次观察会在日落后失去临时阅读牌背面的追踪栏，后续阅览者无法确认它曾被记录。
- 任的选择：任不要求赛恩替他承担全部责任，只要求书记员记录“第二次观察不是第一次的错误，而是另一种条件下的结果”；这句话仍可能被归入异议。
- 书记员的边界：他说明自己可以保存两种写法，却不能保证两种写法在同一扇门后同时被看见。
- 章内钩子：赛恩签下自己的名字，却把报告标题留空，导致家族报告桌拒收整页。

### 场景三：弃牌沟的空白

- 现实事件：零在外来者区后侧沿排水沟移动，追上一块被剪掉的药袋角；药袋上的字只剩“临时”两个字，后半边被整齐剪走。
- 露米的观察：她把四种空白分开放在石板上：剪掉、刮掉、未写、磨平；她拒绝把它们统称为“没有记录”。
- 零的选择：零让一片被雨水冲动的薄木屑停在自己暗边旁，却不把它拼回原牌；它可以保护痕迹，但不替痕迹决定原来的名字。
- 现实危险：排水沟突然开闸，碎片即将被冲入城下；零若保持边缘，可能再次被水流撕裂，若后退，所有空白会消失。
- 露米的错误：她为了保住碎片，擅自用颜色不同的布条把四类空白绑在一起，结果让仆役把它们当作同一批废牌，准备全部烧掉。
- 关系推进：零没有责怪露米，只说“你把不同的空白绑成了一种”；露米第一次意识到，保护痕迹也可能制造新的分类。
- 章内钩子：零从未烧掉的牌背上看见一段与家族旧印记相似、却不完整的刻痕；写着“临时”的药袋角卡在排水沟铁栅内，被露米取出交给伊莉亚；零不知道那是否与任正在看的纸有关。

### 场景四：报告桌前的选择

- 现实事件：监督阅读结束，赛恩被带到报告桌前；家族要求他在“旧档案改名”“见证者观察异常”“家族保管争议”三个标题中选一个。
- 第一种代价：选“旧档案改名”，赛恩避免深层档案权限继续冻结，但任看到的两种残墨被降为附页，后续阅览者可能永远看不到。
- 第二种代价：选“见证者观察异常”，任的观察进入正文，赛恩的下一次研究申请被暂停，家族会调查他是否让外来者接触了不该看的区域。
- 第三种代价：选“家族保管争议”，拓印和旧页被暂时封存，任的监督阅读资格可能被收回，赛恩必须解释为什么质疑家族保管权。
- 任的行动：任把自己的薄木见证记录放到桌上，但不替赛恩选择标题；他只指出“把两种残墨合成一种”会抹去阅读条件。
- 赛恩的选择：赛恩选择“见证者观察异常”，但要求把“观察区域由家族规定”同时写入报告，不让家族把异常完全归给任个人。
- 现实后果：家族收回赛恩下一次研究申请的优先顺位，并暂时冻结他使用家族印记进入更深档案层的资格。
- 章内钩子：长辈问赛恩：“你是在保护见证者，还是在保护自己的错误？”赛恩没有立刻回答。

### 场景五：同一扇门后的两种看见

- 现实事件：任离开报告桌前，回头看监督阅读室；木框已经合拢，旧页只剩一条窄边可见。
- 魔法现象：那条窄边上的暗痕与门槛暗线、家族内侧刻痕不同形，却在任离开指定石砖后同时变淡；任不能确认这是纸、灯窗、距离还是自身影子的条件。
- 赛恩的代价：他把报告副本交给任，但副本缺少家族附栏；他承认自己选择了会让家族不满意的标题，却没有把所有内容都带出来。
- 任的反应：任没有把赛恩写成背叛者，也没有把“见证者观察异常”当成胜利；他问赛恩被删掉的附栏里是否也有一个名字。
- 门外并行：零把那块不完整刻痕留在屋檐阴影下，没有带回任身边；它第一次主动选择不把看到的东西交给任。
- 章末钩子：任的薄木见证记录上，两次残墨之间出现一条他没有写过的空白线；线的长度刚好等于监督阅读室门框没有打开的那一段。

| 赛恩 | 承担监督和报告责任，研究权限已经下降 | 选择让任的观察进入正文，进一步失去家族研究优先权；仍保留部分信息，没有变成无条件盟友 |

## 读者此时应该误判什么

- 只要让灯光照到另一侧，旧页缺失的内容就会自动恢复。
- 赛恩选择把任的观察写入正文，意味着他已经完全站到任这一边。
- 零保护了牌角，就会把它拼成旧页的一部分。
- 四种空白只是同一种被删记录的不同外观。
- 家族报告标题只是文书形式，不会改变后续权限和危险。

## 章末必须留下的事实

1. 家族允许任看到的只是受木框、灯窗、距离和页架限制的局部区域。
2. 两种灯位产生两种残墨观察，二者被并列保存但分属不同可见层级。
3. 赛恩选择“见证者观察异常”，任的观察进入正文，但赛恩的研究申请和深层档案权限进一步下降。
4. 任得到报告副本，却没有附栏；报告没有包含所有家族内部内容。
5. 零保护不完整牌背，却拒绝替痕迹拼回原名，也没有把信息交给任。
6. 任的薄木记录出现一条未由他写下的空白线，长度与监督阅读室未打开的门框区域相合；原因未定。
7. 写着“临时”的药袋角没有被烧掉，由露米取出交给伊莉亚，作为后续群体判定线可回收的具体记录。

## 第40章接口

- 任调查“空白线”是否与门框区域、旧页裁边和第37章门槛暗线存在条件关系，但不能直接认定同源。
- 赛恩面对家族冻结的深层档案权限，必须决定是否以事后补充材料为代价隐去一项附带观察；这不能撤回、篡改或否定第39章已经提交的主报告。
- 零与露米继续处理弃牌沟烧毁后的残留，群体开始把“没有记录”说成“没有发生”。
- 伊莉亚发现临时送药记录让妇人下一次领取时被自动归入更窄的队伍，为第49章群体判定线提供具体入口。

## Canon 检查清单

- [ ] 任的阅读范围由家族器具和站位规定，不是主动新能力。
- [ ] 两次观察并列存在，但不能复原旧页缺失内容，也不能解释裁边来源。
- [ ] 赛恩的报告选择产生研究权限和家族责任代价，不能写成无条件站队。
- [ ] 零保护痕迹但不替痕迹命名，也不把信息交给任；其主体性与第38章拒绝归档连续。
- [ ] 露米的错误来自真实保护冲动，而不是为了演示概念；错误造成烧毁危险。
- [ ] 第37—38章行政字段不被改写成世界本体结论。
- [ ] 正文保持奇幻事件优先，禁止出现技术 API 或说明书式解释。
