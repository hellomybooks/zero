# 第二卷第六十八章《不够》场景卡

## 状态

- 状态：回修稿，待第二轮独立 Canon / 文学审校。
- 承接：第二卷第六十七章《借名》正文与正文审校。
- 篇章：ARC 06《阈值战争》第八章。
- 情绪中心：伊莉亚 / 阿尔德；任与露米第一次面对“记录已经准确抵达，但资源仍然没有抵达”的失败。
- 本章功能：让第67章留下的缺口成为会被既有孩子主动使用的危险位置；让孩子做出一个小而真实的选择，短暂扶住第三个人；让准确记录被传回上城并得到明确回应，却仍换不来第四双手、灯、药或时间。
- 本章主概念：边界断了，不等于所有人都获得进入；记录清楚，不等于现实因此多出一处能被照护的位置。
- 本章情绪：一个男孩以为自己只要帮上一点忙就能留下，成人却必须把他的手从自己短暂承担的动作中拿开；没有人因此变成纯粹的恶人，也没有人得到干净的选择。

## 一句话梗概

下一班钟响后，下渠区的裂玻璃照护灯仍未亮，照护线缺口也没有恢复。第66章水桶旁那个追木轮的男孩跟着拉住他的女人来到缺口；他没有要求被照护，而是从女人手里挣开，钻入缺口，替旧牌旁的人扶住快要滑落的手。任把“孩子短暂扶持、未纳入照护”写清楚，传令员将记录带上坡后带回一句“记录无误，照护位不增”。阿尔德站到缺口前挡住顺着缺口涌来的人群，女人在伊莉亚的低声提醒下掰开男孩的手；男孩被带到风口，墙上出现“阿尔德不受领”和“只收三人”。章末，记录比上一班更准确，现场却没有多一盏灯、多一名守备或多一分钟。

## 本章不能做的事

- 不能让照护线缺口自动成为通行资格；孩子进入缺口只改变他的站位，不改变候位、受领、照护、归属或安全。
- 不能新增一组陌生的成人与孩子：本章沿用第66章水桶旁追木轮的男孩和拉住他的女人；第67章人群中若出现牵着孩子的人，也按这一对连续处理。
- 不能让孩子只是“第四个资源单位”；他要主动挣开、扶住第三个人，并在被带离时保留自己的反应。
- 不能让伊莉亚获得第四双手，也不能用一句正确的话同时保住三名既有身体和孩子。
- 不能增加守备、灯、灯油、药粉、担架、车辆、水、灰料或新的固定木材；传令员带回的是上坡回应，不是资源。
- 不能把阿尔德写成主动驱赶孩子的人；他要挡住顺着缺口进入的人群，并承担孩子因现场选择被带离的后果。
- 不能把任的准确记录写成解决方案；记录必须真正被传递、被读取、被回应，但回应只能确认事实并维持“不增位”。
- 不能让露米把“没人要”清理成漂亮的词；她要记录这个词如何把孩子和女人推到更危险的站位。
- 不能让阿尔德在本章完成政治立场或主题顿悟；他只在现场做出一个可被误读的身体选择。
- 不能让第三声、浅弧或零参与下渠区事件；封石变化只延续为独立物理事实。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 开场状态

- 时间：第67章之后的下一班钟；天已经亮，但下渠区仍被坡道和封石的阴影压住。
- 下渠区：裂玻璃照护灯熄灭后没有重新亮起；照护线缺了一掌宽，风和灰从缺口进入；通行线仍关闭。
- 三名身体：托恩仍在旧夹板上，阿瑟胸口固定木片旁的暗色越过上一道旧线，旧牌旁的人仍抓着裂木板；三人仍是伊莉亚正在维持的照护范围。
- 人员：下渠区仍只有既有守备；阿尔德留在现场；没有新的灯、药或守备随下一班钟到来。
- 连续人物：第66章水桶旁追木轮的男孩和拉住他的女人仍在下渠区外；男孩记得石角后的人，也记得有人问过“谁接她”。他们没有正式姓名或候位。
- 任与露米：任持有主册副抄与副页，露米保留第67章“持残角离开照护线，方向未确认”的记录；两人可以增加旁注，但不能改动主册三行。
- 东十四巷：原抄联随邻居上坡，赛恩没有追回；家族印记未盖，门后仍只留下“别开”。
- 封石：第三声牌仍由火绳压在护石旁，旧灰痕外的新浅弧存在；零可在坡下灰线外出现，但不触碰、不判断。

## 核心规则与本章新增边界

### 1. 缺口是物理开口，不是许可

- 线被抹开后，风、人群和脚步可以更容易靠近；这不意味着谁已经进入照护，也不意味着照护范围扩张。
- 一个孩子可以短暂用身体填补缺口附近的动作，但灰线没有因此恢复，主册也不会因此增加一栏。
- 缺口的危险表现为站位互相挤压：守备要看住三名身体，阿尔德要挡住人群，伊莉亚要维持手、膝和肩；没有一项动作能完成全部任务。

### 2. 看见、帮忙和被照护不是同一件事

- 男孩可以看见旧牌旁人的手滑落，可以主动伸手扶住；这不等于他进入三名照护，也不等于他被正式接收。
- 伊莉亚可以承认男孩短暂帮上了忙，却不能因此把男孩留下；她的拒绝会伤害男孩，但不能被写成对男孩价值的判断。
- 男孩被带离现场，不等于获救；记录只确认他离开了这处缺口，不能确认他得到光、药、位置或新的入口。

### 3. 准确记录可以抵达决定，不能制造资源

- 任要把“孩子短暂扶持、未纳入三名照护、被陪同者带离”分开写；这份记录会由传令员带上坡并得到明确读取。
- 上坡回应必须承认记录准确，却只维持“三名照护位、不增灯、不增守备、不增药”；这不是记录失效，而是资源没有随事实增加。
- 露米记录“没人要”从谁口中出现、指向谁、怎样改变站位；她不把它抹掉，也不承认它是正式字段。

### 4. 阿尔德的身体可以挡住人群，不能替所有人受领

- 阿尔德可以站在缺口前挡住顺势涌入的人群，替守备争取时间；他不能同时修线、护灯、照护三名身体或带孩子离开。
- 他站在缺口前挡住后面想借孩子进入的人群；孩子由陪同者从缺口边缘带离，不等于阿尔德亲自接手或驱逐孩子。
- 人群可以把他的站位读成“阿尔德不受领”，也可以把“三名照护位”读成“只收三人”；这些口号不进入主册，却会改变危险分配。

## 读者此时应该误判什么

- 误以为孩子进入缺口就已经获得照护；实际他只是短暂承担了一个动作，随后被陪同者带回线外。
- 误以为伊莉亚不留下孩子就是已经麻木；实际她仍在三名身体之间维持动作，并亲眼看见孩子确实帮上了忙。
- 误以为阿尔德站在缺口前就是在拒绝孩子；实际他要挡住的是借缺口涌来的整群人，而孩子会承受这个决定的表面后果。
- 误以为准确记录既然传到上坡，就会换来灯、人或药；实际上坡只确认“记录无误，照护位不增”。
- 误以为“没人要”是孩子的身份；实际它是人群把“未纳入照护”压成的一句街面话。
- 误以为“阿尔德不受领”改变了正式责任；实际正式范围仍是“仅现场报告”。
- 误以为封石浅弧与下渠区孩子的动作相互回应；两处只有时间上的并置，没有确定因果。

## 场景设计

### 场景一：同一个孩子还记得石角

- 现实事件：第66章水桶旁追木轮的男孩和拉住他的女人仍在缺口外。女人没有把孩子往前推，只把手握得很紧；男孩看见裂木板上那只快要滑落的手。
- 风把裂玻璃灯罩里的冷灰吹向三名身体。伊莉亚用一只手压住阿瑟固定木片，膝盖挡住托恩旧夹板，肩膀抵住旧牌旁人的手臂。
- 男孩问女人：“她还在里面吗？”女人说：“别看。”男孩却看见旧牌旁人的手从木板上滑下。
- 缺口外有人说：“阿尔德接了。”这句话不是纸上的原文，而是第67章墙面和人群重新抄出来的版本。
- 章内钩子：男孩把手从女人掌中一点点抽出来，先不是向里面走，而是向裂木板伸手。

### 场景二：他只扶住一只手

- 现实事件：男孩从缺口钻进去，膝盖擦过湿灰，伸手抓住旧牌旁人的手腕和裂木板交界处。
- 旧牌旁人的手不再往下滑。男孩低头说：“我按住了。”他没有要求名字，也没有要求进入主册；他只是做了一个他看见伊莉亚做过的动作。
- 女人从外面伸手：“回来。”男孩摇头：“她的手要掉了。”这是男孩自己的理由，不是大人的口号。
- 伊莉亚看见男孩的手指在发抖。她没有把男孩的手拨开，也没有把男孩写进三名照护；她只说：“别压木头，压住手。”
- 这一刻男孩确实帮上了忙：旧牌旁人的肩膀少往下坠了一点，伊莉亚多出半口气去稳住阿瑟。
- 后果：男孩短暂进入一个不是他的照护动作；他的帮助真实存在，却没有因此生成位置。

### 场景三：记录先于决定抵达

- 现实事件：任看见男孩的动作，立即在副页写下：儿童一名；陪同者一名；短暂扶持第三人手臂；未纳入三名照护；地点下渠区缺口。
- 露米问：“要写他自己进去的吗？”任说：“写。”
- 她又问：“要写他帮上了吗？”任停了一下：“也写。”
- 传令员把副页拿走，沿坡道把这份记录送去调度处。阿尔德没有阻止；他知道如果连这件事都不传，下一班只会听见“有人闯线”。
- 女人仍站在外面，男孩仍扶着那只手。没有灯来照男孩的掌心，也没有药来处理那道擦伤。
- 章内钩子：传令员回来的时候，手里拿回的仍是同一张副页，除此之外什么也没有。

### 场景四：记录无误，照护位不增

- 现实事件：传令员喘着气回来，把同一张副页递回任，说调度处看过副页：“记录无误。”副页背面多了一行上坡回话：三名照护位，维持；灯、守备、药，不增。
- 任问：“灯呢？”传令员摇头。
- “守备呢？”还是摇头。
- “药呢？”传令员把另一只手摊开。手里什么也没有。
- 他最后重复：“三名照护位，维持。不增。”
- 没有人能指出这句话哪一部分不准确。它把男孩的动作读到了，又没有给他留下能继续动作的地方。
- 露米看向男孩。男孩还在扶那只手，不知道上坡的人已经读过他。
- 后果：准确记录真正抵达了决定；决定也真正承认了事实；事实没有换来任何新增资源，且副页仍回到了任手里，等待现场最后的结果。

### 场景五：第四双手被拿开

- 现实事件：缺口外的人听见“记录无误，三名照护位”，开始把男孩短暂进入看成一个先例。一个提着空碗的男人把肩膀挤到女人身后：“他能进去，我母亲也能。”
- 守备要回头看三名身体，阿尔德站到缺口前。孩子的手被后面的人碰了一下，旧牌旁人的手又往下滑。
- 伊莉亚说：“把孩子带出来。”声音很低，像是怕这句话先伤到男孩。
- 女人伸手。男孩不肯松：“我还按着。”
- 伊莉亚没有说“你不算”。她把自己的手压得更紧，阿瑟胸口的暗色又向外推了一点；她对男孩说：“我知道。”
- 阿尔德把身体横在缺口前，挡住那个想挤进来的男人。女人终于把男孩的手从裂木板上掰开。
- 旧牌旁人的肩膀立刻向下坠。伊莉亚用肩膀顶回去，托恩的夹板同时向外滑了一寸。
- 后果：男孩确实扶住过一个人，但他被拿开以后，三名身体各自出现新的不稳定；没有谁能把这次短暂帮助完整保留下来。

### 场景六：孩子被带到风口

- 现实事件：女人把男孩抱回缺口外。男孩的掌心沾着灰，里面有一道细小的木刺；没有灯，伊莉亚看不清木刺有多深。
- 人群没有散。有人说“只收三人”，有人说“阿尔德不受领”。提着空碗的男人又说：“先把没人要的往后放。”他说的是男孩和女人，却没有看他们的脸。
- 他抬手把女人和男孩往坡道外推。女人想往回靠，守备抬手挡住：“别再挤。”他挡住的不是她，是后面连续往前的身体；女人仍然被迫后退到风口。
- 男孩回头看裂木板，说：“我的手还在里面。”女人把他的手按进自己怀里，没有回答。
- 露米把“没人要”和“只收三人”记成街面用语，把它们出现后女人和男孩被推到风口的动作也记下；她没有把墙字刮掉。
- 后果：口号没有进入主册，却改变了这两名同行者的站位和风；“未纳入照护”已经变成了谁可以靠近石角的实际差别。

### 场景七：阿尔德把脚留在缺口上

- 现实事件：那名提空碗的男人仍想借着人群向前。阿尔德把一只脚横在缺口上，另一只脚留在三名身体一侧；他不能同时看两边。
- 守备回到旧牌旁的人身边，伊莉亚重新压住三处动作。阿尔德的肩膀被撞了一下，没有拔剑，也没有喊出更大的命令。
- 有人问：“你到底接不接？”
- 阿尔德没有回答。他把那只脚往灰线里压深一点。
- 任想把“阿尔德站在缺口”写进正式主册，最后只写在副页旁注；正式受领范围仍然没有扩大。
- 提空碗的男人先从墙根抹来一点湿灰，在墙上写下“阿尔德受领”，像是在给自己的脚找一块可以站的地方。另一个人把“受领”抹掉，改成“阿尔德不受领”；下面又有人补写“只收三人”。
- 后果：阿尔德没有宣布任何新规则，身体却已经成为一处会被人解释、争夺和绕开的门。

### 场景八：不够

- 现实事件：女人抱着男孩退到坡道的阴影里。男孩没有哭，只把带木刺的手藏在衣襟里；他问女人：“我刚才算帮上了吗？”
- 女人说：“算。”过了一会儿又说：“别再进去。”两句话都没有让男孩得到药，也没有让他忘记那只手曾经被他扶住。
- 任把同一张副页的下缘补全：短暂扶持；未纳入照护；陪同者带离；之后去向未确认；“没人要”与“只收三人”系街面用语，非正式记录。
- 露米问：“这样写，能把他留住吗？”
- 任说：“不能。”
- 她没有删掉那一行。
- 伊莉亚先按住阿瑟，再用膝盖挡住托恩旧夹板，最后把肩膀压回旧牌旁人的手臂。孩子的手已经不在里面，三名身体仍然需要她。
- 阿尔德的脚留在缺口上。墙上的两个“阿尔德”被风吹湿，笔画慢慢融开。
- 章末画面：记录比上一班更准确，现场没有多一盏灯；男孩确实帮过忙，照护范围没有因此多出一个位置；同一张副页保存了前后两个时刻，缺口仍在，下一班还没有到。

| 任 | 试图用副页保护差异 | 把男孩的主动扶持、未纳入、带离和街面词完整传递上坡，并在原页补记后果 | 记录真的抵达了决定，却没有带回资源；同一张纸保存了两个时刻，他的准确不再等于控制 |
| 露米 | 已知道街面词会伤人 | 保留“没人要”“只收三人”的来源与站位后果，不替孩子解释 | 她不把脏词清理成漂亮历史，也不把孩子变成一条传播样本 |
| 赛恩 | 原抄联仍在上坡，家族印记未盖 | 本章不在下渠区出场；其未追回的名字继续成为墙面误读的来源 | 他的缺席仍在影响下渠区，却没有被强行拉回现场 |
| 线外来者 | 带着残角离开，方向未确认 | 本章不确认她的去向，不用孩子事件替她回场 | 她的选择保持开放，不被立即解释成善恶或死亡 |
| 零 | 在灰线外，与封石浅弧无因果确认 | 不进入人群，不碰墙字或缺口 | 未知继续存在，但没有替人物解释“不够” |

## 章末必须留下的事实

1. 下渠区裂玻璃照护灯仍未亮起；照护线缺口仍为一掌宽，风和人群可以从那里靠近，但缺口不是通行或照护许可。
2. 第66章水桶旁的男孩短暂从缺口进入，主动扶住旧牌旁人的手；他的动作真实有效，却未使他进入三名照护。
3. 任在同一张副页上先写下男孩的主动扶持，后补写未纳入照护、被陪同者带离和之后去向未确认；传令员带回“记录无误，三名照护位不增”，没有灯、药或守备。
4. 伊莉亚仍只维持托恩、阿瑟和旧牌旁的人三名身体；孩子的手被拿开后，三名身体出现新的不稳定，但没有人获得额外资源。
5. 阿尔德用自己的身体挡住借缺口涌来的人群；他没有追纸、修线、护灯或扩大“仅现场报告”的正式范围。
6. “阿尔德不受领”“只收三人”和“没人要”只作为街面传播出现，却把孩子和女人推到风口，改变了实际站位。
7. 东十四巷、封石和线外来者的既有接口不被解决：原抄联仍上坡，封石牌位偏移且来源未确认，线外来者方向未确认。
8. 零没有触碰缺口、墙字、纸或牌件；第三声仍未回答，浅弧没有与孩子或人群建立确定因果。

## 第二卷第六十九章接口

- “记录无误，三名照护位不增”可能被上城当作已完成处置；下渠区却仍没有灯、药或人手，阿尔德要面对纸面决定与现场黑暗的落差。
- “只收三人”把照护范围变成街面口号，可能诱发新的站位、推搡或先行排除；这不是正式规则，却已经产生危险分配。
- 伊莉亚第一次承认孩子确实帮上忙，却仍让他离开；她没有完成“我不再救所有人”的终局成长，下一次仍可能伸手。
- 任与露米的记录保留了孩子没有被正式污名化的证据，却不能确认他的安全；后续不能把准确记录奖励成现实救援。
- 阿尔德的身体成为缺口的临时门；下一章要处理他是否继续站在这里，以及谁有权要求他把脚移开。
- 封石继续保持独立未知线：牌位偏移、新浅弧、火绳受力和来源未确认不被解释成下渠区事件的原因。

## 五问自检

1. 本章首先发生在人身上的，是一个孩子主动扶住一只快要滑落的手，而成人不得不把他的手拿开；不是主册多了一种分类。
2. 伊莉亚承认孩子帮上了忙却仍让他离开；阿尔德挡住人群却让自己的身体成为缺口的临时门；任把准确记录送上坡却没有带回资源；这些选择都可能被他们自己记住并后悔。
3. 没有让人物总结“记录不能救人”；让孩子的木刺、传令员空着的手、三名身体重新失稳和墙上的湿灰承担主题。
4. 没有提前支付伊莉亚最终麻木、阿尔德政治崩塌、孩子的命运或第三声本体。
5. 删除所有技术隐喻后，缺口、孩子的主动帮助、记录回应、三名身体、拥挤和没有增加的资源仍构成完整冲突。
