# 第二卷第三十八章《家门》场景卡

## 状态

- 状态：场景卡草案，待 Canon / 连续性 / 文学性 / 奇幻感独立审校。
- 承接：第二卷第37章《门槛》正文与正文审校。
- 本章功能：把第37章的王都外门制度推进到赛恩的家族内部，让任看见“家门”不是一扇更容易打开的门，而是一套把人、证词、遗迹和资源重新归属的制度。
- 本章主概念：Threshold / Classification 的内部化——同一件事跨过不同门槛，会被换成不同的身份、责任和所有权。
- 本章情绪：雨后的羞耻、归家压力、资源交换、双向嫉妒、暂时的合作。

## 一句话梗概

任被留在外来者区，赛恩回家接受家族问询；家族提出用禁书库的一次监督阅读换取遗迹拓印的保管权和零的研究归档，但这个条件最终被任、赛恩与零拆开拒绝，赛恩第一次必须在“家族认可的见证者”和“真正同行的人”之间承担选择。

## 本章不能做的事

- 不能把赛恩写成一句话就能调动全家资源的人；家族印记给他的是预先获信任的责任，不是无限权限。
- 不能把家族档案写成比学院更接近世界真相的全知资料库；档案也会按家族利益分类、删减和改名。
- 不能把任的“遗迹共同见证者”直接升级为自由进入禁书库的正式资格；本章最多获得一次有条件、有人陪同的监督阅读。
- 不能让任用分析赢得辩论后立刻改变家族决定；他的发现只能暴露记录条件与权力关系，不能自动取得所有权。
- 不能让零被写成必须交给家族研究才能换取屋顶或药物的对象；照护和归档必须保持可以分开的选择。
- 不能解释门内暗线来自谁、为何合拢，也不能把它写成赛恩家族印记的证明。
- 不能提前揭示 Copy、Observed、Original、世界本体或遗迹残碑的完整含义。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

## 开场状态

- 时间：第37章入城当夜之后的次日清晨，雨已经停，王都石路仍湿；不使用精确日历。
- 地点：王都外来者区、赛恩家族内院与家族档案入口。
- 任：第37章章末身体仍在门外，影子已经越线，暗线合拢；随后外门官员依据临时担保把他行政引入外来者区。这次放行不是任真正跨过门槛，也不是暗线对他的承认。他的记录为“未定 / 待担保复验”，拓印箱仍在手中，禁书库仍不可自由进入。
- 赛恩：已回到家门内接受问询，家族配额已经为任与零付出；他的手套、称谓、站姿和笑幅重新受家族训练。
- 零：登记为“无对应类别 / 临时担保 / 外来者区”，不被带进家族内院；它的暗边在雨后石缝和屋檐阴影中保持局部稳定。
- 露米：观察外来者区的门牌、床位和取水线，发现不同记录对应不同的遮雨处和领取时段。
- 伊莉亚：先处理妇人孩子和队伍中伤员的药物问题，确认“有屋顶”不等于“有药物”，照护不能替代身份决定。

## 核心规则

### 1. 家族门槛

- 家族印记可以让赛恩及家族成员绕过外门的大部分复验，但不能让赛恩免于家族内部的问询。
- 家族内院有自己的门牌和称谓秩序；家族成员、受邀见证者、研究对象、临时担保者进入不同区域，资源和谈话权不同。
- 家族并不声称这些栏位是真实本体分类；它们只是决定谁可进入、谁可被引用、谁承担损失的内部处置方式。

### 2. 拓印的归属

- 赛恩家族要求遗迹拓印箱先进入家族档案保管室，理由是防止损坏、伪造和未经授权的抄录。
- 拓印箱的“保管”不等于任失去观察资格，但家族可以控制原件、复制品、引用方式和公开顺序。
- 任可以拒绝交出全部材料，但拒绝会让监督阅读和研究权限更难获得；他不能靠一句“这是我发现的”解决保管权冲突。

### 3. 见证者的资格

- “遗迹共同见证者”是赛恩为任争取的责任称谓，不是王都已经承认的自由通行身份。
- 家族愿意暂时承认任有一次监督阅读资格，但条件是：由赛恩陪同、不得抄录原页、不得带零进入、任何发现须先归入家族记录。
- 任必须明确区分“获得一次看见的机会”和“接受家族替自己解释看见了什么”。

### 4. 零的照护与归档

- 家族提出把零记为“研究相关对象”可以降低保管争议、换取内院药物和稳定房间；这不是无代价建议，而是把零的行动与拒绝交给家族记录的交换。
- 伊莉亚指出临时照护可以先发生，但不应以永久接受错误类别为条件。
- 零有权拒绝进入家族内院和白色归档室；任不能替零签字，赛恩不能用担保替零同意。

## 场景推进

### 场景一：外来者区的雨痕

- 现实事件：任醒来时发现门内外的雨水留下两种不同的痕迹；门槛外的水线被清扫，门内的水线被家族仆役按固定方向收拢。
- 具体资源：外来者区按牌面领取热水和药物，任的“待担保复验”牌只能领取低额度药物；露米发现同样的药物在内院门牌下不需要排队。
- 任的观察：他试图用鞋印、积水和门槛暗线复现昨夜结果，却发现清扫、灯位和人流已经改变现场；他不能把昨夜的影子重现成证据。
- 零的状态：零沿着屋檐下的暗处移动，拒绝靠近外来者区中央的白灯；它说“这里的雨也有被允许落下的地方”。
- 伊莉亚的行动：她为孩子争取药物，必须在“先用外来者区配额”与“保留申诉资格”之间选择；她先救孩子，但要求记录领取被暂停的原因。
- 关系推进：任第一次明白，门内的洁净也需要有人把门外的水扫到看不见的地方；他对赛恩的嫉妒从“有一扇门”变成“有人替他擦去门槛上的痕迹”。
- 章内钩子：一名家族仆役来取赛恩的外套，顺便要求任交出拓印箱，说“家里只保管自家的东西”。

### 场景二：赛恩回家接受问询

- 现实事件：赛恩在家族内院脱下外门手套，按家族礼仪向长辈说明学院、火兽、地下遗迹和无界存在受击记录。
- 问询规则：长辈不先问零是否受伤，而先问拓印是否完整、谁先触碰石门、谁能证明赛恩没有把家族印记带入未经登记的遗迹区域。
- 分类后果：赛恩被要求在“家族发现”“学院共同研究”“外来者证词”三种记录标题中选择一项；每个标题会改变家族能否优先保管拓印、谁承担失误和谁获得研究功劳。
- 赛恩的羞耻：他必须用正式称谓说出任是“遗迹共同见证者”，却不能说任已经理解了家族档案无法处理的那部分结构；家族认为过多强调任的贡献会削弱赛恩的担保可信度。
- 赛恩的反击：他说明自己已经使用家族配额为任与零担保，若家族拒绝承担相应记录责任，门外的“无对应类别”就会被视为他个人的失误。
- 家族代价：长辈同意暂缓追究，但扣留赛恩下一次研究申请的优先顺位，并要求他亲自负责监督阅读和后续解释。
- 章内钩子：问询结束时，长辈问赛恩：“你是把他们带回家，还是把家门带到了他们身边？”赛恩没有回答。

### 场景三：档案入口的两个名字

- 现实事件：赛恩带家族书记员来到外来者区，不是为了带任进内院，而是要在雨后的石台上给拓印箱重新挂上家族保管牌。
- 行政冲突：原记录可以写“遗迹共同见证者”，但家族保管牌只能写“家族档案关联对象”；两个名字看似相近，前者保留任的证词，后者把所有引用权交给家族。
- 任的选择：任指出同一块拓印在不同牌面下会被当作不同东西，但他不能因此拒绝所有保管；他要求在家族牌旁保留“任之见证”一行，承担被追问和被否定的风险。
- 书记员的限制：书记员不是恶意夺取，他认为没有统一编号，未来没人知道哪一份是原件；他承认编号同时会抹掉发现者的错误、犹豫和异议。
- 露米的判断：她发现家族不是记录所有差异，而是决定哪些差异可以进入家族记忆；她不同意任把问题简化成“谁的名字写在第一行”。
- 赛恩的动作：赛恩用自己的印记在保管牌上加一条附记，写明“见证者异议不得删去”；这一条不是改变家族制度，而是把他本人变成未来争议的责任人。
- 关系推进：任没有感谢赛恩，也没有把附记当作胜利；他问赛恩如果家族以后仍然删掉异议，谁能证明这条附记存在。
- 章内钩子：书记员从旧档案中取出一张被裁掉右半边的登记页，页上同一件遗迹曾被改过两次名字。

### 场景四：家门不是禁书库

- 现实事件：赛恩将任带到家族内院与禁书库之间的门廊，要求他在门外等待；零停在更远的屋檐阴影下，拒绝被带到门牌前。
- 规则展示：赛恩的家族印记能打开门廊，却不能同时为任、零和拓印箱提供同一权限；门廊会按同行人数、物品牌面和陪同人重新分流。
- 任的情绪：他看到赛恩只需触碰印记就能让门锁松动，却也看到赛恩必须在每一道门前报出同行者的名字和承担范围；便利与责任同时存在。
- 零的拒绝：家族书记员要求零在白石边缘留下临时印记，以便“避免误伤”；零问留下的是它的边，还是别人允许看见的它，随后退回暗处。
- 伊莉亚的界线：她不让任何人以治疗为理由强拉零过门，只要求家族提供雨后稳定的阴影和可用药物。
- 争论：任想把昨夜的门槛暗线告诉家族，以换取调查资格；赛恩阻止他立即说出，认为家族会先把异常写成家族财产。任指责赛恩把保护写成隐瞒，赛恩反问任是否愿意让零成为全城第一个被归档的“成功样本”。
- 零的表态：零在屋檐阴影里清楚说：“不把我写成研究对象。”书记员只能记录这句原话，不能把它改写成接受或拒绝某种完整身份。
- 关系推进：两人第一次明确承认，他们都在替别人决定什么应该被看见；争论没有和解。赛恩只能提出“不以零的研究归档作为监督阅读条件”，家族暂时接受这一条件变化，但不能替零同意进入、归档或接受照护。
- 章内钩子：家族长辈允许一次日落前的禁书库监督阅读，却要求赛恩先从被裁掉的旧登记页开始查，而不是查地下石门。

### 场景五：一次阅读的价格

- 现实事件：任在门廊外得到一块临时阅读牌，牌面没有写他的名字，只写“遗迹共同见证者 / 赛恩陪同”；他不能把牌带出门廊，也不能为零申请同样的牌。
- 条件：阅读时间只有一段日照；不得拓印、不得带走原页、不得直接触碰封存物；任的观察记录可以存在，但归档顺序由书记员决定。
- 任的判断：这不是自由权限，而是被允许在规定范围内看一次；他要求书记员记录家族曾提出“以零的研究归档换取权限”，但不替零签署拒绝。零此前已经亲口表态，书记员只记录零的原话。
- 赛恩的代价：赛恩必须当众签下监督责任，若任在库内发现的内容泄露，家族会先追究赛恩；他的研究优先权继续下降。
- 结尾事件：书记员把那张裁掉右半边的旧登记页交给任。缺失部分不是被撕走的空白，而是曾经有字、后来被重新裁齐的边；任无法知道被删的是对象名、见证人名还是处置结果。
- 章末钩子：任抬头看向禁书库门上的内侧刻痕，发现它与昨夜门槛的暗线没有相同形状，却在某一段距离上同时变暗。赛恩说：“今日日落前，你只能看这一页。”任回答：“那我先看它为什么不让人看完。”

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 处于“未定 / 待担保复验”，嫉妒赛恩拥有家门 | 在零明确拒绝后接受一次有条件的监督阅读；开始把“看见”与“拥有解释权”分开 |
| 赛恩 | 回家接受问询，家族配额已为同行者付出 | 以家族名声和研究优先权为代价争取任的见证者附记；不能再把担保说成私人帮助 |
| 零 | 被登记为“无对应类别 / 临时担保 / 外来者区” | 拒绝白石临时印记和研究对象栏；它的照护条件被保留，但没有获得内院自由 |
| 露米 | 观察外来者区的资源分流 | 明确家族记录会决定哪些差异进入集体记忆，开始怀疑“完整记录”本身是否中立 |
| 伊莉亚 | 负责药物、伤员和零的身体边界 | 让照护先于归档发生，同时阻止家族用治疗交换定义权 |

## 读者此时应该误判什么

- 家族档案比学院档案更完整、更接近遗迹真相。
- 赛恩只要愿意牺牲一点声望，就能让任进入所有禁区。
- 把拓印交给家族只是安全保管，不会改变发现者和见证者的意义。
- 零只要接受一个临时印记，就能换来稳定的照护和自由。
- 被裁掉的旧登记页记录的是某个早已解决的旧案。

## 章末必须留下的事实

1. 任获得一次日落前的禁书库监督阅读资格，但不能自由进入、抄录或带走原页。
2. 赛恩必须亲自承担监督阅读责任，家族研究优先权进一步下降。
3. 拓印箱进入家族保管体系，但任的见证异议被写入附记；家族仍掌握复制和公开顺序。
4. 零没有被登记为研究对象，也没有进入家族内院；它的照护条件与定义权被暂时分开。
5. 被裁掉的旧登记页存在被重新裁齐的边，删去的内容和删改者未知。
6. 禁书库内侧刻痕与昨夜门槛暗线存在相似的“条件性变暗”，但不能确认两者同源。

## 第39章接口

- 任进入一次监督阅读，接触被裁掉的旧登记页和家族对遗迹的历史命名。
- 赛恩必须在监督任阅读、向家族报告和保护任的异议之间做出具体选择。
- 零留在外来者区，可能从屋檐阴影、门牌或被丢弃的药物包装上看到另一种“不被归档”的路径；不要让它直接知道旧页内容。
- 露米开始关注“被记录的差异”如何变成集体记忆，为第49章群体判定线埋下伦理入口。

## Canon 检查清单

- [ ] 第37章的“未定 / 待担保复验”“无对应类别 / 临时担保 / 外来者区”保持原样，不被家族档案重写成任或零的本体结论。
- [ ] 赛恩的家族资源同时带来问询、责任、研究优先权下降和对外解释代价。
- [ ] 任获得的是一次受限阅读，不是能力升级或自由通行。
- [ ] 拓印保管权、见证权、复制权和公开权被拆成不同关系，不用一个“所有权”词解决全部冲突。
- [ ] 零拒绝被登记为研究对象，照护与定义权保持分离。
- [ ] 家族档案存在删改、命名和利益选择，但不能因此被确认成阴谋中心或世界真相中心。
- [ ] 被裁掉的旧登记页与第39章相连，但不提前解释删去内容。
