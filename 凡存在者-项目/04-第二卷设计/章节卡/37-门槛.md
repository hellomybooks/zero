# 第二卷第37章《门槛》场景卡

## 基本信息

- 卷：第二卷《阈值之城》
- 篇章：ARC 04《回到王都》
- 章节：Chapter 37
- 状态：场景卡已通过 Canon / 连续性 / Threshold 故事化 / 文学 / 奇幻感逐项审校，定稿候选
- 视角：任的近距离第三人称；读者先看到入城制度、门槛器具和人的现实反应，再逐渐理解“阈值”如何把连续差异切成身份类别
- 时间：第一卷战后数日，队伍抵达王都外门当日
- 地点：王都北门、入城检查廊、外来者等候区、赛恩家族车队的内侧门
- 承接：地下遗迹拓印、无界存在受击记录和零的定界态被学院封存；学院决定将少数人员与材料送往王都备案，赛恩必须回家处理家族权限，任、零、露米和伊莉亚随行。
- 核心功能：让 Threshold 首次成为城市制度事件，而不是任的新能力；让任看见“同一条门槛对不同人并不相同”，让赛恩的资源同时表现为便利、礼仪义务和羞耻压力，建立两人的双向嫉妒。

## 本章必须完成的事

1. 让王都首先通过城墙、门禁、记录牌、检查廊和等待队伍呈现规模与阶级，不用大段介绍王都历史。
2. 让入城判定有可理解规则：每个人都要让自己的通行牌、源痕记录或临时身份在门槛器具前经过；器具不是测量“真实本体”，而是把连续的光、影、颜色、标记和材料反应切成几类结果。
3. 让一个与主角团无关的普通家庭在检查中被判为“需留置/待复验”或等价类别；他们没有做错事，却立即失去原本的入城通道、住宿资格或药物领取权，具体后果必须出现。
4. 让任试图用第一卷形成的观察模型指出：门槛器具的结果依赖灯位、站位、牌面磨损和检查员选择，不能直接等于这个人的身份；但他的解释不能立即改变制度决定。
5. 让零遭遇无法归类的入城结果：它的定界态外沿比战场后稳定，却既不符合“人”的登记方式，也不符合“携带物/界兽”的处理方式；官员要求把它留在外侧或单独封存。
6. 让赛恩的家族车队抵达后，凭家族印记、礼仪和熟人关系绕过普通检查；同一名官员对赛恩和普通家庭使用不同速度、语气与证据标准。家族印记代表预先获信任的通行权限，不代表赛恩的本体更稳定。
7. 让任产生真实的不爽与嫉妒：赛恩一句话就能打开任申请多日的门，任感到自己的努力被资源轻易覆盖；但任不能立刻把赛恩写成坏人。
8. 让赛恩也产生双向嫉妒：任可以不遵守王都家族礼仪、直视问题、与零自然相处，并且在遗迹结构上拥有赛恩无法复制的理解；赛恩不承认羡慕，只用礼仪和讥讽掩盖。
9. 让赛恩的便利带有代价：他必须在家族车队前保持标准坐姿、称谓和笑幅，接受长辈安排；为了让任一行进入外来者通道，他必须以家族身份承担担保和解释责任。
10. 让露米和伊莉亚分别指出不同风险：露米发现门槛不是“看见颜色”，而是决定哪种差异值得被记录；伊莉亚发现被留置者的药物无法随身带入，制度正在制造新的伤口。
11. 让任在章末获得一个行政结果而非能力奖励：学院旧记录中的“无源/待复验”不被王都静默改名，王都只在自己的门禁字段新增“未定”，并因赛恩担保暂记为“待担保复验”；任不能自由进入王都内层。零被登记为“无对应类别”，必须由赛恩家族担保才能留在外来者区。
12. 章末钩子：赛恩家的内侧门对赛恩和家族成员自动开启，却在任跨过时落下一道细窄的暗线；任不能判断暗线来自门槛、灯位还是自己的影子。赛恩说“明天我带你进禁书库”，任看着门槛回应“先告诉我，谁决定我今天在外面。”

## 本章不能做的事

- 不能把阈值写成任念出一个术语就能改变的法术；它必须依赖器具、材料、站位、记录和行政权。
- 不能让王都官员全部恶毒或愚蠢；他们相信流程能减少风险，但流程会制造现实伤害。
- 不能把赛恩的家族资源写成无代价爽点；他必须被礼仪、担保、长辈和家族形象束缚。
- 不能让任靠一句“这是错的”立刻救出普通家庭或零；他只能发现判定条件和不公平后果，具体改变需要资源、证据和关系。
- 不能把普通家庭的留置直接解释成系统被修改、教会阴谋或世界本体异常；只留下制度问题和后续调查入口。
- 不能让零被城市记录完整定义；“无对应类别”是官署的失败字段，不是零的真实身份。
- 不能提前揭示 Copy、Observed、Original、世界本体或第一卷遗迹文字的最终含义。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码；任只能使用“门槛、分界、过线、归档、复验”等自然语言。

## 阈值规则

- 入城廊有三类器具：白灯照牌、黑水盘读影、门槛刻痕承接临时标记；三者结果必须由检查员合并为一个行政类别。
- 同一个人改变站位、抬高或压低通行牌、让灯光从不同方向照入，结果可能发生小幅变化；官署将连续差异压缩成“通过、待复验、留置”等离散决定。
- 家族印记可以替代部分复验，但不是因为家族成员本体更稳定，而是他们拥有被制度预先信任的凭证和担保人。
- “待复验”会暂时失去自由通行和部分资源领取权；“留置”会把人送入外门等候区，药物、住房和同行关系都可能被拆开。
- 零的定界态能让局部外沿稳定，却没有可被官署承认的源痕/身份字段；这本登记册当前可选的几栏只有“同行者、界兽、伤员、研究对象”等有限选项，任何强行归类都会造成不同伤害，但这些栏位不是维亚完整的本体分类。
- 任原有学院记录仍是“无源、待复验”；王都门禁另加“未定”字段，赛恩担保后又加“待担保复验”这一入城处置条件。它们是不同机构、不同用途的行政字段，不是对任本体的新解释。
- 任的这些行政字段不是能力等级，也不是本体判断；它们会影响进入王都内层和申请资料的权限。

## 场景推进

### 场景一：王都外门

- 现实事件：队伍抵达王都北门；城墙高得看不见顶，入城队伍分为三条，门外有饮水、药摊和临时铺位，所有价格与队伍类别相关。
- 人物反应：任先被城市规模震住，随后发现最醒目的不是城墙，而是地上三条不同宽度的等待线；同样站在城门前的人，等待时间和能否靠近城内水井不同。
- 零的状态：零的稳定外沿能在日光下保持一小段，但门口的固定灯让它被拉得更薄；它不愿主动靠近检查台。
- 赛恩的变化：车队尚未出现，赛恩在门外提前整理衣领、手套和称谓，言语比平时更少，任第一次看到他“回到另一种姿势”。
- 章内钩子：一名抱着孩子的普通妇人被赶出最短的入城线，只因为她手里的牌在白灯下没有立即显出完整边。

### 场景二：白灯、黑水与门槛

- 检查流程：妇人先把通行牌放到白灯下，牌面有磨损；再让孩子站在黑水盘前，水中影子因风变形；最后把临时纸牌压在门槛刻痕上，刻痕没有承接完整印记。
- 结果合并：检查员把三种不稳定结果合并成“待复验”，不承认这是三种不同条件造成的差异；妇人原本持有的药物领取凭证随之被收走，孩子被要求与她分开检查。
- 任的观察：任看见灯位、风、水盘和牌面磨损都在影响结果；他告诉检查员“换一个站位会不同”，检查员回答“所以才需要统一站位”。
- 制度逻辑：检查员不是恶意欺骗，他认为统一流程能让陌生人被公平比较；任第一次看见，公平的同一流程也可能把条件不同的人推向不同后果。
- 现实危险：孩子哭闹，妇人试图跨过第二道线，守门人立刻压住她的手；药摊老板把药收回，声称待复验者不能赊账。
- 章内钩子：任想拿出学院记录，却发现自己还没有被允许进入“可申诉”的内侧廊道。

### 场景三：任的解释没有用

- 任的行动：他只要求检查员再做一次白灯复验，并改变一次牌面高度；结果立即出现小幅变化，但最终类别仍然由检查员写成“待复验”。当任还想继续调整站位时，检查员拒绝把入城检查变成私人试验。
- 证据边界：任证明了结果会变，却没有证明妇人应当通过，也没有权限撤销官署决定；他第一次感到“发现规律”与“改变后果”之间隔着一扇真正的门。
- 露米的判断：露米说检查员不是在记录所有差异，而是在决定哪些差异值得被记录；她拒绝把问题简化成器具坏了。
- 伊莉亚的行动：她发现妇人的孩子需要药物，尝试以医者身份申请临时领取，却被告知待复验记录会暂停非内层居民的药物额度。
- 任的情绪：任想把制度写成一个待修复的流程，却看到妇人抱住孩子的动作，第一次不确定分析是否正在帮助任何人。
- 章内钩子：守门人把“待复验”牌挂到妇人脖子上，牌的重量让她低下头；任听见牌面碰到孩子额头的声音。

### 场景四：零没有可用的类别

- 检查要求：轮到主角团时，官员要求零先站到白灯下，再把它的边缘投进黑水盘；零的外沿在灯和水之间分裂成两种不同厚度。
- 官署困境：官员翻遍登记册，找不到“同行者、界兽、伤员、研究对象”以外的合适栏位；他问任零是否属于他的携带物。
- 任的反应：任说“它和我们同行”，官员追问“同行是关系，不是类别”；任无法用一句话让官署承认关系具有行政效力。
- 零的选择：零拒绝站到黑水盘中央；它说“如果我站进去，里面是谁由谁说？”任没有强拉它。
- 现实后果：官员要求把零留在外门隔离栏，任一行若要入城，必须把零交给外门看守；伊莉亚指出隔离栏没有遮雨和药物，赛恩第一次显出明显的怒意。
- 章内钩子：官员把零的临时牌写成“无对应类别”，墨迹在门槛刻痕上没有留下完整边。

### 场景五：赛恩的车队

- 现实事件：一列黑轮车队抵达外门，车上悬着赛恩家族印记；同一名检查员立刻改变站姿，向车门内的人使用正式称谓。
- 对比判定：家族成员不经过黑水盘，凭印记与担保人签章直接进入内侧门；检查员解释“家族印记已经承担过复验责任”。
- 任的嫉妒：任看见赛恩只说一句话，门就为他打开；他想到自己在学院申请禁书库时写过多份理由，仍被拒绝，心里出现真实的不爽。
- 赛恩的羞耻：赛恩上车前必须调整坐姿、低头角度、手套位置和笑幅；家族长辈问他是否带来“外门的异常同行者”，他回答得极其标准。
- 家族压力：长辈要求赛恩先进入家门接受问询，再决定是否为任和零担保；赛恩必须承认遗迹拓印归家族档案管理，不能公开交给任。
- 双向嫉妒：任嫉妒赛恩拥有门，赛恩嫉妒任能在门外直说“这不公平”而不必计算每个词会损害谁的名声。
- 章内钩子：赛恩对任说“别用刚才看检查盘的眼神看我”，任回答“我只是第一次看见你也需要别人替你开门。”

### 场景六：担保不是自由

- 赛恩的选择：他回到家族车前，向长辈提出让任、零、露米和伊莉亚进入外来者区；家族愿意担保，但要求零登记为“研究相关对象”，任登记为“遗迹证人”。
- 任的反抗：任拒绝让零成为物件字段，要求把“同行”写入记录；官员回答记录栏没有这个选项。
- 赛恩的解释：赛恩说先进入王都再争取，至少外来者区有屋顶和药摊；任反问“如果先接受错误类别，之后谁还会改？”
- 关系冲突：赛恩说任没有资格把所有风险都变成原则，因为他自己不承担城门后果；任说赛恩把拥有门的便利当成了合理。
- 赛恩的反击：他指出任可以在遗迹里不顾一切地试错，却把每次错误的代价留给陪他的人；任被击中，没有立刻反驳。
- 伊莉亚的实际判断：她选择先让伤员和零进入有屋顶的外来者区，要求争论延后；保护不等于接受标签，但今晚的雨和药物是现实。
- 章内钩子：赛恩在担保文书上按下家族印记，手指却在落印前停了半息。

### 场景七：内侧门与暗线

- 现实事件：家族担保生效，外来者区的侧门开启；赛恩和家族成员先进入，任抱着拓印箱跟在后面，零沿门槛边缘移动。
- 门槛现象：家族印记经过门槛刻痕时，刻痕亮起一整段；任经过时只亮出断续细线；零经过时没有亮，却在门内侧投下一道不属于灯位的暗边。
- 官署解释：官员说“未定记录只能走外侧”，要求任停在门槛外；赛恩家族长辈没有回头，赛恩却停住。
- 赛恩的行动：他回头向官员说明任是遗迹共同见证者，不是家族携带物；这句话仍然没有让任获得自由，只把他的行政类别从“未定”改成“待担保复验”。
- 任的观察：门槛不是发现任是什么，而是在决定谁可以被当作已知的人进入；同样的门，对赛恩是预先获信任的通道，对任是审查，对零是无法命名的登记失败。门槛上的暗线只是器具、灯位和影子的反应，不能证明任何人的真实边界。
- 关系落点：赛恩对任说“明天我带你进禁书库。”任看着门槛说：“先告诉我，谁决定我今天在外面。”
- 章末钩子：任低头时，发现自己鞋尖内侧的影子已经过线，身体却还在门外；门内的暗线慢慢合拢。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |

| 赛恩 | 作为王都家族成员回到熟悉秩序，试图用礼仪控制局面 | 资源让门为他打开，却要求他承担家族名声、担保和隐瞒；与任形成双向嫉妒而非单向对立 |
| 零 | 定界态外沿尚稳定，拒绝被战场或遗迹定义 | 被登记为“无对应类别”，拒绝进入黑水盘；行政分类无法替代其自主选择 |
| 露米 | 仍警惕被颜色和标签定义 | 看见制度决定哪些差异值得记录，开始与任的分析方式产生价值分歧 |
| 伊莉亚 | 负责战后伤势和队伍安全 | 先让人获得药物和屋顶，明确现实照护与接受错误标签可以暂时分开 |

## 读者此时应该误判什么

- 王都的入城器具只要校准好，就能公平识别每个人。
- 赛恩可以凭一句话解决所有制度问题。
- 任只要拿出遗迹证据，就能获得王都认可。
- “无对应类别”说明零不是一个真正的主体。
- 赛恩的家族礼仪只是装腔，和他的真实人格无关。

## 技术概念与魔法翻译

- 对应概念：Threshold / 阈值、连续差异被切成离散分类、分类结果影响后续权限。
- 故事现象：白灯、黑水、门槛刻痕产生连续变化，检查员把它们合并成通过、待复验、留置等类别；家族凭证绕过部分条件。
- 魔法语言：城市不是发现一个人真正属于哪一类，而是决定从哪一刻起把他按某一类处理。
- 关系语言：保护、担保和照护都可能先于自由发生；任必须学会区分“先救人”与“接受定义”。
