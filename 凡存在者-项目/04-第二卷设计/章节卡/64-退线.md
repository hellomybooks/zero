# 第二卷第六十四章《退线》场景卡

## 状态

- 状态：场景卡已完成两轮独立 Canon / 文学审校与最终窄范围回归，定稿候选。
- 承接：第二卷第六十三章《线外》正文与正文审校。
- 篇章：ARC 06《阈值战争》第四章。
- 情绪中心：伊莉亚 / 阿尔德。
- 本章功能：让“线”第一次在所有事实都清楚的情况下失效；让读者看见一次处置结束、下一名守备没有到来、私人灯油接近耗尽时，正确的记录也不能延长保护；让“退线”从一个行政动作变成街面水、门、等待和羞耻的具体变化。
- 本章主概念：线可以退，身体不会退；被记录不等于被留下；知道谁在门里，不等于手里多出一盏灯和一个人。
- 本章情绪：清晨换班前的疲惫、等待被挪成队列、照护者在拒绝与伸手之间摇摆，以及阿尔德把一名守备从一扇仍有人呼吸的门边撤走。

## 一句话梗概

东十四巷的“一门一次处置”在下一班到来前即将到期，新木闩仍能短时顶住门，断门闩已靠回墙边，阿芙仍愿意为自己作证，赛恩的私人礼灯却只剩一层低火，而替换守备没有出现。下渠区的照护线里，三名伤者仍然清楚可见；线外又来了一个只想在灯边站一会儿的人，伊莉亚知道她的身体不在自己已经签下的三人范围内，却也知道把她推回风里不等于她就不需要照护。中段封石的守备火绳被石面重新拉紧，阿尔德只能把东十四巷唯一的守备撤去加固封石。灰线没有被擦掉，街面却把守备离开理解成“线退了”，开始按线内 / 线外分水、分门和分谁值得被听见。章末，东十四巷的礼灯耗尽，正式线退为一段被水冲淡的灰痕；下渠区的第四个人仍在照护线外，伊莉亚没有把她写进三人，却把一小段责任写在自己名字之外；封石后的第三声只让火绳再紧一次，没有给出来源。

## 本章不能做的事

- 不能把“一门一次处置”写成保护结界；它只表示守备已经完成一次现场处置，守备离开后不自动续线。
- 不能把“退线”写成新的世界真理或魔法；它是城防把有限人员和灯移走后的行政结果，灰痕可以留下，正式优先级可以消失。
- 不能让替换守备凭空出现；第63章的两名守备仍是本章开场可用的人，一名在东十四巷、一名在下渠区，阿尔德只能重新分配他们。
- 不能新增正式护灯、裂玻璃灯、药粉、担架、布、固定木片或短绳；赛恩的私人礼灯继续使用同一盏，油耗下降并在本章末熄灭，不产生第二盏灯。
- 不能让东十四巷因为门仍固定、阿芙仍作证就自动获得下一次处置；事实清楚不等于本班有余力续线。
- 不能让下渠区的照护线变成避难所或通行线；线内仍只有托恩、阿瑟和“旧牌旁的人”的既有照护记录。
- 不能让伊莉亚替线外新来者写姓名、归属、伤情或把她自动纳入三名伤者；她可以做有限的、未纳入签名范围的现场动作，但不能凭善意扩张责任而增加资源。
- 不能让线外新来者成为第三声、零、敌军、魔物或任何谜底；她是街面上可见的人，却不因被看见而获得正式照护资格。
- 不能让水桶、街面队列和口号成为新的正式制度；它们是居民把“线内 / 线外”偷换成“先喝 / 不配喝”的临时行为。
- 不能让阿尔德因撤走东十四巷守备而成为单纯正确或错误的人；封石确有新的物理压力，东十四巷也确有仍在呼吸的人，他只能留下一个不能补偿的空处。
- 不能让第三声被确认成某种生物或人的呼救；它只留下守备火绳重新受力的现象，来源仍未确认。
- 不能让零成为检测器；它可以出现在封线外，也可以避开人群，但不提供第三声的方向、性质或身份。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 开场状态

- 时间：第63章结束后的下一班前，天色由灰转白，换班钟尚未响；一门一次处置的现场时间即将结束。
- 东十四巷：第63章留下的新木闩仍抵在门框上，断门闩已靠回墙边、不能作为完整门挡；门后仍有声音和一只手的身体迹象；阿芙只为自己作证，门后姓名、人数和伤势仍未确认；赛恩的同一盏私人礼灯还亮着，但灯油已接近底部。
- 东十四巷守备：只有第63章派驻的那一人仍在门边，没有替班人从坡道来；他的编号记录仍在，但编号不能替他留下身体。
- 下渠区：托恩仍靠墙，阿瑟胸口旁的固定木片仍在，“旧牌旁的人”仍靠近门槛；裂玻璃灯只作照护灯，门边既有木板已不能恢复为完整门挡，通行线仍关闭。
- 下渠区守备：第63章留下的另一名守备仍在照护线附近，负责阻止身体被风推出，并没有担架或完整路线可用。
- 线外来者：一个穿着湿外衣的人从下渠区外侧来到门边，只说自己想在灯边站一会儿；她没有主动提供姓名，也没有进入伊莉亚已签下的三名身体范围。
- 封石中段：石灰仍压在石缝上，守备火绳仍在；第63章末任已把第三声牌递还阿尔德，牌仍在封石护石旁并由火绳压住牌角，来源、性质、是否属于人声均未确认；本章任只接触调度板上的第三声记录。
- 阿尔德：知道东十四巷事实清楚、下渠区照护线未稳、封石受力在变；手边没有第三名可以调动的守备，也没有新灯。
- 伊莉亚：已经知道“签三个人”是一种范围，不是把所有需要帮助的人都收进来；她仍然想救线外来者，但没有决定自己愿意留下哪一种责任。
- 任：手里有东十四巷、下渠区两块牌和一块空白木片；第三声只以调度板记录和封石旁实体牌两种位置留在视线中，他正在把“已处置”“待续”“退线”分开；他还不知道“退线”是否已有正式名称。
- 露米：看见居民开始把第63章的非正式旁注当成取水顺序，知道自己留下的话正在从记录变成街面动作。
- 赛恩：礼灯的油耗已记在个人账上；家族印记仍未盖下，家族派来的口信要求他在灯熄灭前作最后一次确认。
- 零：在封石坡下的灰线外出现过一次，未进入东十四巷，也未靠近下渠区的新来者。

## 核心规则与本章新增边界

### 1. “一次处置”不是持续保护

- 三记满足两项可以让一处地点获得一次暂时处置，但“一次”指一段具体的现场动作，不指整班、整夜或下一次换班的持续守备。
- 守备完成一次固定门闩、听取、记录或短距离照护后，处置线可以继续存在于牌面，却不自动生成下一名守备。
- 线退时，正式牌可以写“本次处置已用 / 待下一次复核”；这不会把门后人改写成无人，也不会撤销已经发生的声音和身体迹象。
- 退线不是线条自己消失；它是人不再站在那里、灯不再继续承担见证、下一班没有人把事实再带进资源顺序。

### 2. 事实清楚仍可能没有资源

- 东十四巷的门、阿芙的名字、礼灯的归属和门后一只手都已经分别记录；这些事实仍不能变成正式护灯、第二名守备或通行路线。
- 下渠区三名身体的位置清楚，伊莉亚的签名范围清楚，照护线仍不能让水桶、担架或新来者自动通过。
- 阿尔德知道两处哪里需要人，却只能把已经存在的一名守备撤向封石；准确的牌面无法生成第三个人。

### 3. 线外不是“没有人”，但街面会这样说

- 居民开始把“线内 / 线外”偷换为“先喝水 / 不配喝水”“可以进门 / 不准靠近”“有人值得听 / 有人不必听”。
- 这些行为可以改变水桶位置、门口站位和一个人是否愿意作见证，但不能改变正式牌面。
- 露米可以把口号和行为记录下来，却不能用记录阻止所有人照做。

### 4. 照护范围必须有边

- 伊莉亚的签名继续覆盖本班已经接触的三名身体，不自动覆盖线外来者、第四个身体或第三声。
- 线外来者可以被看见、被听见、被暂时遮风，也可以被明确记录为“未纳入本班照护”；两者都不等于正式接收。
- 伊莉亚如果扩大签名，代价首先是责任和时间增加，不会自动增加药、灯、布或担架；本章不让她用签名制造资源。

### 5. 封石只会改变风险，不会提供答案

- 第三声只使守备火绳重新绷紧，不因此获得门记、身体记、灯记或见证人。
- 守备可以加固封石，也可以撤离封石；两种动作都不能确认石后有什么。
- 零与第三声同场不构成关系证据；任何人把零写进第三声牌，都是错误记录。

## 读者此时应该误判什么

- 误以为灰线还在，所以东十四巷仍然受到保护；实际守备离开后，正式优先级已经退去。
- 误以为阿尔德把守备撤向封石，就是判定东十四巷没有人；实际牌面仍保留手、声音和人数未确认。
- 误以为照护线外的人只要跨进去就能获得照护；实际她只是进入一条有限签名范围，资源仍然没有增加。
- 误以为赛恩的礼灯熄灭代表门后无人；实际只说明私人灯油耗尽，门后状态未被重新确认。
- 误以为伊莉亚不扩大签名就是冷漠；实际她第一次承认自己的名字有边界，但这个边界仍会让一个活人留在风里。
- 误以为水桶按照线内 / 线外分配是城防新规；实际是居民把行政语言变成自己的排除工具。
- 误以为封石火绳再次收紧说明第三声被封住；实际只说明石面或绳结承受了新的力量。
- 误以为“退线”是某种高级魔法；实际它只是守备撤走、灯耗尽、下一次复核没有发生。

## 场景设计

### 场景一：一门一次处置的时间

- 现实事件：换班钟未响，东十四巷守备在门边检查新木闩；木闩仍能撑住一阵，风一来就发出细响。
- 守备告诉阿芙，他的编号会在下一班交回，但没有人带着新的编号从坡道上来；阿芙问“线什么时候退”，他答不出具体时刻，只说“我离开以后”。
- 记录板上已经写着“此门一次处置”；守备没有把它改成“安全”，也没有把门后手的旧伤添成伤者数字。
- 阿芙想让自己的名字继续留在门边，守备提醒她的签名只替自己；她说：“那我站着就行。”这句话没有变成正式见证，只让她继续用肩顶门。
- 赛恩蹲在礼灯旁，发现油面只剩灯芯以下一小圈；他没有向家族索取新的灯油，而是在个人账上补写“最后一段仍由本人承担”。
- 章内钩子：巷口有人把第63章的水桶往灰线内挪，说“线里先给”；阿芙第一次听见别人用她的门决定谁能喝水。

### 场景二：水桶把线变成队列

- 现实事件：一只公共水桶被放在东十四巷外，居民以灰线为界排出两列；线内的人先接水，线外的人必须等到桶再回来。
- 没有人宣布这条顺序，但每个人都能指出昨夜牌上的“线外”；有人把第63章的口号抄成一句更短的话：“外面等。”
- 露米记录说话者、桶的位置和实际发生的推挤；有人要求她把“谁先碰桶”写成“谁属于线内”，她没有同意，却也来不及阻止水桶被拖走。
- 阿芙问能不能把一桶水放到门后。守备说门只能开一条手臂宽，桶进不去；如果打开得更大，新木闩会滑，门后人数仍未确认。
- 赛恩把礼灯往门边挪了一点，灯火照出水面和门缝，却不能使水桶获得通行资格；人群把“灯照见了”喊成“里面有资格”。
- 一只手从门缝伸出，想接水，又在碰到灰线前收回；阿芙没有替那只手报姓名，守备也没有把它写成新增伤者。
- 章内钩子：水桶被人踢倒，水从灰线外流过，线没有消失，排队的人却一起后退。

### 场景三：下渠区的第四个人

- 现实事件：下渠区门外来了一名穿湿外衣的人。她没有明显伤口，只说自己想在裂玻璃灯旁站一会儿，直到身上的水干。
- 她每隔一会儿回头看坡道，像在等一个没有准时出现的人；她先说自己不需要水，只想把衣服拧干。
- 她看见照护线里的三个人，问伊莉亚：“我不喝他们的水，也不占他们的木片，为什么不能进去？”
- 负责下渠区的守备指向木板上的签名；上面只有三名已接触身体。守备说：“你不在这三个人里。”说完自己也觉得这句话难听，却没有更好的位置给她。
- 伊莉亚想让她进来，随后看见门缝和三名伤者的位置；第四个人一旦坐进线内，托恩的腿、阿瑟胸口的木片和“旧牌旁的人”之间就没有足够的转身空间。
- 她没有抽走第三个人身侧的裂木板，只把来者挪到门边石角的背风处，自己用身体挡了三次风；她没有写姓名或伤势，只记下“线外暂时遮风，未纳入本班三名身体照护”。没有新的照护资源因此出现。
- 来者问：“那我算什么？”伊莉亚没有立即回答。她的手停在签名旁，没有再添第四个名字。
- 章内钩子：来者把湿外衣拧出的水滴在灰线外，水慢慢流向三名伤者，却在门槛的石凸处停住。

### 场景四：一桶水进不去

- 现实事件：场景二那只公共水桶旁，一个熟悉下渠区路的水夫接过剩下的半桶水送到门边，想从裂开的门缝倒进去；守备没有让他把桶跨过门槛。
- 水夫说：“我不是守备车，我只过一只桶。”守备回答：“我知道。”他仍没有让开。
- 伊莉亚看见托恩的嘴唇发干，也看见第三个人的手从旧牌上松开；她要求水夫把桶沿着地面推近，不要跨过线。
- 桶底碰到门槛，泥水先进入，清水在灰线外洇开；半桶水只剩一小滩，三名伤者仍需要分开喝。
- 线外来者伸手去捧那一滩水，伊莉亚没有叫她滚开，先让她喝了一口；托恩因此多等了一个呼吸，她才让水夫把剩下的水分成三次，分别交给托恩、阿瑟和“旧牌旁的人”。
- 这次照护没有增加水，也没有让门获得通行权；准确的三人记录只帮助他们按顺序分到更少的水。
- 伊莉亚把“水桶未通过门，半桶耗散，三名身体各得一次”写进木片。她没有把线外来者写成偷水者，也没有把她算进三人。
- 章内钩子：阿尔德的徒步传令从东十四巷赶来，带回同一句话：“守备要撤。”

### 场景五：封石再次收紧

- 现实事件：阿尔德在调度处同时收到三份短报：东十四巷没有替班守备；下渠区照护线外出现一个需要遮风的人；中段封石的守备火绳在没有人触碰时向石缝方向收紧。封石旁没有守备，只有上一班留下的绳和石灰。
- 记录员把三份压成“线外新增一处”，阿尔德让他拆开；任却先把“下渠区未纳入照护”删短成“线外等待”，以为下一班更容易看懂。
- 露米看见一个孩子伸手去追被踢倒的水桶，先停下来记“线外等待”是谁写的，没有及时把孩子拉开；水桶滚过孩子的脚，任这才把“未纳入照护”补回原牌旁。
- 记录员说，如果再派一个人过去，火绳才有人能重新绕紧；他不说里面有人，也不说里面没有人。
- 东十四巷守备的返回时间已经到了。阿尔德知道他一离开，门仍会在，但没有人再为“一门一次处置”承担现场复核。
- 东十四巷守备问：“先续哪一处？”阿尔德想问“哪一处更像人”，最后没有问。他把东十四巷和封石写在两块牌上，看见两面都没有足够的手。
- 他命令东十四巷守备回中段封石，继续加固；下渠区守备保持照护线，不得离开；东十四巷进入“本次处置已用，待下一次复核”。
- 阿尔德对东十四巷守备说：“我会让下一班接你。”守备点了点头，没有问下一班是谁。
- 这个命令没有把东十四巷判成无人，也没有让封石获得答案；它只把一个站在门边的人移到一块不肯解释的石头前。
- 章内钩子：阿尔德在“待下一次复核”旁边停笔，发现下一次没有具体时刻，也没有具体人名。

### 场景六：守备离开，线没有马上消失

- 现实事件：东十四巷守备将编号、门件状态和未确认手的记录交给任，最后一次按住新木闩；门在无风时合住，风起时仍发出细响。
- 阿芙问：“你走了以后，这条线还算吗？”守备说：“牌上还在。”
- “那你为什么走？”
- 守备回答不出。他把断门闩靠回墙边，确认它不能再被当作完整门挡，随后沿坡道回封石。
- 灰线没有被擦掉；巷口的居民却把守备离开当成线已退，立刻把水桶向外挪。
- 赛恩没有盖家族印记，也没有站到巷口替所有人挡住人群；他只把礼灯抱近门边，灯油已经不足以照到整条巷。
- 阿芙把自己的手伸出门缝去接水，水沿着她的旧伤流进袖口；门闩向外滑了一下，她只好先收手顶门，门后的人仍不愿开门。
- 她想喊“他们在里面”，又停住，只说：“别推。”
- 露米记录“守备离开 / 灰线留存 / 水桶外移”三件分开的事；有人抢过她的笔，说这些都可以写成“线外不收”。
- 章内钩子：抢笔的人把“线外不收”写在灰线旁，字比正式牌更大。

### 场景七：阿尔德把人送向封石

- 现实事件：阿尔德和返回的守备来到中段封石。东十四巷的门声已经不能沿旧渠传来，阿尔德只能通过任带回的牌知道那扇门还在。
- 守备把火绳重新绕过护石。绳结再次收紧，没有开口，也没有人能说明石面为什么动。
- 守备问：“东十四巷会不会把我叫回去？”阿尔德说：“会。”
- “那我回不回？”
- 阿尔德没有立即答。他想起东十四巷门后一只没有姓名的手。
- 他让守备留在封石，不让他把第三声写成求救或敌袭；同时在调度板上给东十四巷保留“手、声音、人数未确认”，不把退线写成无人。
- 这个选择让封石暂时更稳，却让东十四巷没有人在场承担下一次看见。
- 章内钩子：守备火绳在他手下轻轻动了一下，守备没有说话。

### 场景八：线外来者没有被写进去

- 现实事件：下渠区的线外来者坐在门边石角后，湿外衣已经不再滴水；她仍没有进线，第三个人身侧的裂木板没有被抽走，三名伤者仍各自保留照护位置。
- 她问伊莉亚能否把“未纳入本班三名身体照护”改成“等待照护”。伊莉亚知道后者更像一扇门，可能让下一班把她排进顺序；但她没有权限凭空给出那个顺序。
- 伊莉亚没有替她写姓名，只指了指门边一块没有积水的灰地：“你要写，就写在那里。”任手里的空白木片仍留在调度处，没有被带入下渠区。
- 来者用手指在灰地上写了一个名字，又用湿手把它抹掉。她说：“现在不想给。”
- 伊莉亚把那行字抹掉，没有追问。她让来者继续坐在石角，自己站在三名伤者和门槛之间。
- 这不是照护签名，也不是拒绝一个人；它只形成一段没人愿意承诺太久的距离。
- 传令员从东十四巷回来，带回“线外不收”的大字旁注；伊莉亚看见以后没有要求露米删掉，只说：“别把它贴到这里。”
- 章内钩子：来者在灰线外按住地面，门内的第三个人也在同一时刻按住旧牌；两处动作没有被写成同一来源。

### 场景九：礼灯耗尽

- 现实事件：东十四巷礼灯的火芯烧到最后，灯光从门边退到灯盏内部；赛恩把灯架抱稳，不能用家族印记换取新的油。
- 阿芙问门后的人是否愿意在灯熄灭前让手再伸出来；门后没有回答，只有肩膀继续顶住门。
- 巷口的人要求赛恩把灯提到水桶旁，说至少可以照见谁先取水；赛恩没有把灯移走。
- “这灯是我的。”他说。
- 他把灯架放回原处，没有给任何人解释；油面降到灯芯底部时，火焰缩成一粒很小的光。
- 阿芙没有开门。守备已经离开，正式牌仍写着门、手和未确认人数，灰线却被水冲成断续的浅痕。
- 火焰熄灭时，巷口没有立刻发出声音；有人把“线外不收”往灰痕上又描了一遍。
- 章内钩子：黑暗里，门后一只手碰到门缝，却没有伸出来。

### 场景十：退线

- 现实事件：阿尔德在调度板上收回东十四巷的一次处置牌，把状态分成三行：本次处置已用、门后手与声音仍在、下一次复核未定。
- 任想写“退线”，停了一下。他问阿尔德：“退的是线，还是人？”
- 阿尔德没有回答。任把笔停在“本次处置已用”旁边，没有替那只手补一个去处。
- 露米把东十四巷的“线外不收”旁注与正式牌分开，记录它已经被居民写在灰痕旁，却没有把它从现场抹掉。
- 下渠区的照护线仍在；线外来者仍未纳入三名身体照护，伊莉亚的签名范围仍未扩大；第三个人身侧的裂木板没有被抽走。
- 封石外，守备火绳仍绷着，来源未确认牌没有增加资源。
- 阿尔德没有把东十四巷重新画成线，也没有把封石写成安全；任把一直带在手里的那块空白木片放进下一班栏。
- 章末画面：东十四巷的礼灯已经熄灭，灰线被水冲成几段，门后一只手仍没有姓名；下渠区三名伤者仍在照护线内，第四个人坐在门边石角后没有被纳入签名；封石前火绳绷紧，空白木片等待下一次复核。

## 人物推进

| 人物 | 开场状态 | 本章选择 | 章末变化 |
|---|---|---|---|
| 伊莉亚 | 已签下下渠区三名身体，知道签名有范围 | 不把线外来者自动纳入三人；用身体和门边石角为她挡风，记录“未纳入本班照护”，没有用名字制造资源 | 她在拒绝和伸手之间摇摆；一个活人仍留在线外，她也不确定自己会不会在下一次改口 |
| 阿尔德 | 知道东十四巷与封石都需要人，知道两处事实都是真的 | 将东十四巷唯一守备撤向封石；他对守备说会再派人，却没有人可派 | 守备记住了这句没有兑现的话；阿尔德没有为命令找到更干净的说法 |
| 任 | 试图给“退线”找到准确词 | 先把“未纳入照护”删短成“线外等待”，看见居民把短词抄成“线外不收” | 他的准确性第一次以错误的简化帮助了排除；他只能把原词补回，不能追回被踢倒的水桶 |
| 露米 | 看见旁注已开始影响水桶和队列 | 为了记录口号停了一息，没有及时拉开追水桶的孩子；之后仍把口号留下 | 她知道自己没有删掉恶意，却也没有及时保护一个具体的人 |
| 赛恩 | 私人礼灯油尽，家族印记仍可换取另一路径 | 不盖印、不移灯，把最后的光留在门边并承担灯油耗尽 | 灯熄灭，个人见证暂时失去光，却没有把居民交给家族归属 |
| 阿芙 | 门后身体未确认，自己仍是唯一明确自证者 | 伸手接水导致旧伤进水、门闩外滑，先收手保门，不替门后人报姓 | 她失去了一口水，也让自己成为门最后的支撑；正式处置线的守备已经不在 |
| 零 | 在封线外保持不可登记 | 不靠近线外来者，不对第三声作反应证明 | 它没有帮助解释任何一处，沉默继续被人群当成可疑空白 |

## 章末必须留下的事实

1. “一门一次处置”确认为一次现场动作，不是持续保护；第63章东十四巷的处置已用，下一次复核时间和人员未定。
2. 东十四巷的门仍可能由新木闩短时顶住，断门闩已靠墙且不能作为完整门挡；门后仍有手和声音，姓名、人数、伤势未确认；正式优先级退去不等于无人。
3. 赛恩的同一盏私人礼灯因油耗在本章末熄灭；家族印记仍未盖下，居民归属未转入家族。
4. 下渠区托恩、阿瑟和“旧牌旁的人”仍是伊莉亚签名覆盖的三名身体；裂玻璃灯仍是照护灯，通行线仍关闭。
5. 下渠区出现一个可见的线外来者；伊莉亚为其有限挡风并记录未纳入照护，没有写姓名、归属、伤情或把她计入三名身体。
6. 没有新增灯、药粉、担架、布、固定木片或短绳；既有裂木板继续留在第三个人身侧，不能恢复为完整门挡。
7. 阿尔德把东十四巷守备撤向封石；封石得到加固，东十四巷失去现场守备，阿尔德没有因此确认第三声。
8. “线外不收”成为居民旁注和行为，不成为城防正式规则；水桶、队列和门口站位因此产生排除后果。
9. 第三声只造成守备火绳的再次受力；来源、性质、是否为人声仍未确认，零不成为方向证明。
10. “退线”进入正式牌面，准确描述为优先级与本次处置退去，不写成身体、声音或事实一起消失。

## 第二卷第六十五章接口

- 东十四巷正式优先级已退，门后一只手仍未确认；下一章可以写门内是否再次主动开口、居民是否把“线外不收”变成更强的街面动作，但不能让赛恩礼灯无代价复燃。
- 下渠区三名身体仍在照护线内，线外来者未纳入签名；伊莉亚的边界已明确，下一章可以逼她决定是否承担一项新的、有限的个人承诺，但不能让签名恢复通行线。
- 封石前留下加固后的守备火绳和空白木片；第三声可以继续改变封石受力、引发误传或迫使城防讨论是否撤封，但不能直接揭露本体。
- “本次处置已用 / 下一次复核未定”使第64章把时间也纳入阈值；下一章可以让等待本身成为政治资源，而不是继续增加分类名称。

## Canon 检查清单

- [ ] “一次处置”写成一次动作，不写成持续保护。
- [ ] 退线是行政优先级退去，不是线条、身体或声音自动消失。
- [ ] 东十四巷门件、手、声音、礼灯和人物归属与第63章连续。
- [ ] 礼灯油耗到尽，不新增灯油、正式护灯或家族印记。
- [ ] 下渠区三名身体、裂玻璃照护灯、通行线关闭和既有裂木板留在第三人身侧的状态连续。
- [ ] 线外来者是可见的人，但不自动成为第三声、伤者或签名范围内的人。
- [ ] 伊莉亚不靠签名制造资源，阿尔德不靠准确记录制造守备。
- [ ] 水桶、队列、“线外不收”保持街面行为，不升格为正式制度。
- [ ] 阿尔德撤走东十四巷守备的后果可见，不把他写成纯粹正确或纯粹错误。
- [ ] 第三声与零保持未知，不以受力、停顿或同场证明身份。
- [ ] 正文将通过灯油、湿衣、门缝、水桶、木板、火绳和离开的脚步呈现“退线”。

## 五问自检

1. 这一章首先发生在人身上的，是伊莉亚不把一个活人写进三人范围、阿尔德把守备从门边撤走、赛恩看着自己的灯熄灭。
2. 伊莉亚拒绝扩大签名，阿尔德撤走守备，赛恩拒绝移灯或盖印；每个选择都会让另一个人等待。
3. 不让人物在章末说出“我终于理解边界”；让他们只做出更窄、更疼的动作。
4. 不提前支付第三声身份、伊莉亚最终成长或阿尔德政治立场的终局；本章只让“退线”成为一个可继承的状态。
5. 删除所有制度词后，门后一只手、一个湿衣人、半桶水、熄灭的礼灯和守备离开的脚步仍构成冲突。
