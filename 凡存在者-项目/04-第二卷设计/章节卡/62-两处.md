# 第二卷第六十二章《两处》场景卡

## 状态

- 状态：场景卡与两轮独立审校已完成，定稿候选。
- 承接：第二卷第六十一章《第一声》正文与正文审校。
- 篇章：ARC 06《阈值战争》第二章。
- 本章功能：把第61章的两处求救从现场压力推进为城防制度与公共语言的冲突；让“待听见”第一次被行政规则合并、改写和重新分配；让阿尔德、任、露米、赛恩与伊莉亚各自承担同一分类的不同后果。
- 本章主概念：相邻的声音不等于同一处的人；共享一条传声通道，不等于共享一条命。
- 本章情绪：天将亮未亮的疲惫、被合并的愤怒、想要一个清楚数字的恐惧，以及在没有足够灯光时仍必须给出名字的迟疑。

## 一句话梗概

第61章的两处求救在清晨前同时抵达调度板：下渠区仍有三名伤者，东十四巷则有人敲着失去门闩的门请求护灯。城防旧规把共用一条旧渠传声道、在一声钟内传来的求救合并为“同段事件”，因此只能给出一块救援牌、一个伤者数字和一次路线窗口；东十四巷的正式牌仍写“求救待听见”，但不完整的伤者栏被口头压成“无伤者确认”，下渠区则被口头误读成“已处理三人”，实际牌面仍是“已接触三人”。任的记录显示这明明是两个地点，阿芙却被要求证明门后确实有人，伊莉亚则在下渠区听见新的呼吸声，手边的布和固定木片也已经不能再分。阿尔德派出一支只带一盏检验灯的短巡队沿旧渠中段确认，两处声音确实通过同一条石腔传播，却来自两段不能互相救援的墙。回来的不是答案，而是一句写在石板背面的现场记录：“同源声道，异处人群。”这句话不能增加灯，却阻止调度处继续把两处写成一处。章末，东十四巷的敲门声与下渠区的喘息之后，又从旧渠更深处传来第三种回声，迫使阿尔德为它另开一块没有归属的牌。

## 本章不能做的事

- 不能把“同段事件”写成世界本体或真正的安全边界；它只是城防为了压缩调度牌面而制定的合并规则。
- 不能让共享传声道证明两处求救来自同一批人；巡查只能确认声音相通，不能确认人相同、伤势相同或危险来源相同。
- 不能让阿尔德凭一次巡查就解决东十四巷与下渠区的路线冲突；他只能把错误变得更可见，不能凭记录凭空增加护灯、守备和担架。
- 不能让东十四巷立刻遭到全面袭击；门闩损坏、护灯不足、风和等待已经构成真实后果，外部压力仍未被命名。
- 不能让下渠区三名伤者全部痊愈或全部死亡；阿瑟仍未亲口确认姓名，第三名伤者仍暂记为“旧牌旁的人”，托恩仍惦记女儿米娅。
- 不能给伊莉亚新增药粉；她只有第61章剩下的水、布和固定木片，且这些物资已经被分过，任何新处理都要让旧照护位置承受减少。
- 不能让任的表格自动恢复路线、灯光或担架；他的记录可以分开两个地点，却不能替它们获得资源。
- 不能让露米用一句“他们不是同一处”消除公共语言；她要看到合并规则有时确实便于调度，错误则落在人身上。
- 不能让赛恩用家族名义直接把东十四巷变成优先保护区；家族可以提供见证、礼灯或外部请求，但每一种帮助都带有归属、债务或延迟。
- 不能让露米、赛恩或阿芙的记录后果停在纸上；露米的改写必须让阿芙的自称进入公共牌面，赛恩必须用自己的名字承担礼灯的油料与归还责任，阿芙的擦伤必须被记录但不得被夸大成门后人数。
- 不能让零成为第三种回声的方向证明；它可以在旧渠阴影中出现或退开，但不替人群判断声音来自哪里。
- 不能把本章写成全面战争宣言；战争继续表现为灯、门、记录、路线和“谁被算作一处”的具体后果。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 核心规则

### 1. “同段事件”是行政合并，不是人的合并

- 城防旧规规定：若两份求救在一声钟内抵达、经过同一条传声石腔，且无法立即给出独立伤者姓名，或无法指出一个可复核的具体门、门洞或墙孔编号，则先挂在同一块“同段事件”牌下。
- 城区名不算门牌。下渠区和东十四巷是调度范围，不是可以让守备直接找到人的具体开口；下渠区的旧渠墙第七道石缝与东十四巷阿芙门上的断闩孔，必须经过巡查后才成为可复核的地点描述。
- 合并后只保留一条救援路线、一项护灯需求和一个暂时伤者数字；另一处的声音仍可以被抄在附栏，却不会自动获得独立的车、灯或担架。
- 这条规则原本用于防止同一场坍塌被多人重复报案、避免调度处凭回声制造两支车队；它有实际效率，也会把真正分开的两处人群压成一个事件。
- 同段牌只说明“声音和路线可能相连”，不说明人相同、危险相同、伤势相同或责任相同。
- 合并可以被后续证据拆开，但拆开本身需要一名见证人、一处可辨认的地点或一次巡查；这些条件恰恰需要被合并的地点自己付出时间和风险。
- 见证人的名字会附着在对应地点的照护责任上：伊莉亚若为下渠区签下“三名身体状态分别记录”，她就不能在没有替代者的情况下被调去东十四巷；拆分地点因此会制造新的责任边界，而不是只增加一栏。

### 2. 共享传声道不等于共享救援路线

- 旧渠传声道可以把声音带过墙、弯道和塌石，却不能让担架沿声音通过；声腔的连续性只保证“听见可能相通”，不保证路、灯和门相通。
- 第61章下渠区与东十四巷都能听见旧渠回声，但两处护灯、门闩、坡道和临时照护位置彼此独立。
- 巡查队只能确认三个字段：声音是否能在中段重复听见、石腔是否连续、两侧是否存在可供人通过的实体开口；不能据此确认墙外压力或伤者数量。
- 若巡查只带一盏检验灯，灯本身不满足救援车和担架的“两盏稳定”条件；它只能让巡查者看见一小段，不构成救援路线。

### 3. “无伤者确认”不是“没有人受伤”

- 东十四巷正式牌面仍写“求救待听见”，因为声音已经被接到但尚未形成完整处置；“无伤者确认”只允许出现在不完整的伤者栏或口头公告里，表示尚未有伤者字段，不是正式的否定结论。
- 阿芙可以亲口说“门后有人”，但她不能凭一句话让整条巷获得完整护灯；她需要让一个人、一个门闩或一处可重复的身体后果进入记录。
- 任可以把“有人眩晕、门闩断裂、护灯不足、风从门缝进入”分开记录，但记录不能把眩晕自动升级为重伤，也不能把门闩断裂写成敌情。
- 露米会看到公共公告倾向于把空栏读成无事；她不能用反向猜测把空栏填成伤亡。
- 阿芙门闩造成的擦伤可以进入“现场后果”栏，但不自动计入救援伤者数字；她可以拒绝让自己的血被拿来替门后所有人作证。

### 4. 三种灯不能互相冒充

- 第61章从东十四巷调走的护灯仍留在下渠区，是那里目前唯一仍稳定、且真正属于城防护灯系统的灯；下渠区原有三盏中的原本稳定灯已被灯架受力压坏，原本抖动灯已彻底熄灭，章初已经熄灭的第三盏保持熄灭，短时路线没有重新开放。
- 调度处在旧器材库找到一盏玻璃裂过的备用灯；它只能作为固定照护灯或巡查灯，不能挂上护灯架，不计入“两盏稳定”，也不能让救援车或担架通行。
- 阿尔德最终把裂玻璃灯送到下渠区照见现有三名伤者的照护位置；这不是新路线，也不构成第三次担架转运。
- 赛恩家族的礼灯留在东十四巷门边，作为私人见证灯；它能照见阿芙的门闩和一张请求，但未经城防接入，不能替代护灯、灯油或守备。
- 阿尔德不能把三种灯拆成等价资源；护灯的稳定性、裂玻璃灯的用途和礼灯的归属必须在记录中分开。

### 5. 本章不发生第三次担架转运

- 第61章的第二副担架已经是最后一副可用担架；第62章巡查队不带担架，东十四巷小队只修门闩、听取姓名和记录眩晕。
- 托恩的腿继续由原有夹板固定，不能拆作新材料；阿瑟胸口旁的一块固定木片继续保留，另一块已经断裂；第三名伤者没有布，只保留浅呼吸和旧木牌触感。
- 本章的“下一次担架请求”只进入记录，不在现场兑现；伊莉亚必须在没有转运的情况下维持三名伤者的不同状态。

## 读者此时应该误判什么

- 两处声音经同一条石腔传来，所以它们必定是同一场袭击的两个侧面。
- 城防把两处合并，是因为书记员懒惰或恶意；读者后来会看到合并规则确实曾避免重复调度，但这不能抵消本章的伤害。
- 阿芙只要拿到家族礼灯，东十四巷就能安全；礼灯会让门后的人被看见，却不会让破门闩、护灯和守备凭空恢复。
- 任把地点分成两栏，就已经替两边完成了公平；实际可供重新调度的新增共用资源仍只有一盏裂玻璃灯，正式护灯与私人礼灯各有归属，不能混入这笔账。
- 阿尔德把灯送往下渠区，是在宣判东十四巷不值得救；他的选择也可能来自现有伤者已经在照护位置内，但这不能免除东十四巷的后果。
- 第三种回声会证明墙外有某种已确认的魔物；本章只留下更深处有人或某种物体造成重复回声的可能。

## 场景设计

### 场景一：两张牌被钉在一起

- 现实事件：第二次换班时，下渠区传来托恩请求水和固定木片的声音，东十四巷同时传来阿芙敲门并喊“门后有人”；两份声音都经过旧渠传声筒进入调度处。托恩得到的只是记录，没有新的水和固定木片送进下渠区。
- 书记员把两张木片叠在一起，准备写“同段事件 / 三人”；东十四巷的请求被压在下方，只露出“待听见”三个字。
- 阿尔德问：“东十四巷几个人？”书记员回答“没有确认伤者”；又问下渠区“几个人？”书记员回答“已经接触三人”。两个回答看似不同，正好把一处变成数字、另一处变成空栏。
- 阿芙通过传声筒说出门闩断裂、有人头晕和门缝进风；书记员要求她先说姓名。她说自己叫阿芙，却拒绝替门后所有人报名字。
- 阿尔德没有立刻拆牌，只让人把两处地点写在同一张纸的两侧；这是一个暂时动作，不是新规。
- 章内钩子：书记员在合并牌下写下“同段”，笔尖却穿透木片，把东十四巷的“待听见”划成一条细裂痕。

### 场景二：一条声腔，两处墙

- 现实事件：阿尔德命令传令在下渠区和东十四巷各敲三下，观察回声是否经过同一条石腔返回；两边的敲击分别被听见，但间隔和方向无法让人凭耳朵判定同一处。
- 书记员引用旧规：“同钟、同腔、同段。”他提醒阿尔德，拆开两张牌就意味着调度处承认自己曾把一份事件漏成两份，下一次审查会追问谁签字。
- 阿尔德不把规条说成错误，只问：“它什么时候不够？”书记员回答：“有人被压在另一边的时候。”
- 这一句不是主题总结，而是书记员自己的经验；他曾经见过重复报案，也见过合并后少掉的人。
- 阿尔德让书记员把“同段”旁边的两个地点写全，不允许只留下一个段号。
- 章内钩子：调度板上出现两个地点词，却只有一块可移动的救援牌。

### 场景三：下渠区的持续照护

- 现实事件：伊莉亚在半开的屋门内检查三名伤者。阿瑟的呼吸比上一章稳定一些，但她仍没有说出姓名；第三名伤者的手指从旧木牌上移开，随后又无意识地抓回去；托恩问门外有没有人回东十四巷。
- 伊莉亚手边没有可拆用的固定木片：一块木片仍压在阿瑟胸口旁，另一块已经断裂；托恩的腿由原有夹板固定，不能拆下来给别人。布的一半仍压在托恩腿上，另一半在阿瑟胸口和横木之间，第三名伤者没有布。她不能把这些位置重新平均。
- 她没有把三个人写成一个“三人”数字，而是在旧木板上分开写下托恩、阿瑟和“旧牌旁的人”的身体位置与呼吸状态；阿瑟的姓名栏仍留空。她在木板底部签下自己的名字，作为下渠区三名身体状态的照护见证。
- 她把托恩的铜勺放在他胸口，告诉他米娅的名字已经记在纸边；这不是承诺女儿会来，也不是把女儿加入伤者数字。
- 新的敲击从屋外墙根传来，守备人说是东十四巷的回声；伊莉亚听见其中混着更近的喘息，却不能确认是伤者还是风穿过裂口。
- 她让守备人把耳朵贴墙，不让任何人凭“听见三次”再增加一个伤者数字；签名一落，她就知道自己若没有替代者，不能再被调去东十四巷。
- 章内钩子：门外传令喊“东十四巷有人要求把阿芙写进伤者栏”，伊莉亚手里的笔停在“阿瑟”一行旁。

### 场景四：空栏也会产生方向

- 现实事件：灰门附近的战时公告把调度板上的两处压缩成一句：“下渠区三人已接触，东十四巷求救待听见，伤者栏未开，暂不单独开路。”传令和路人却把最后一段简称成“无伤者确认”。
- 露米看见有人根据公告让出一条路给运灯车，另一名东十四巷居民却被拦在路边，因为“无伤者确认”听起来像“没有需要的人”。
- 她没有冲上去喊两处不同，也没有替门后的人填写伤情；她先问阿芙是否愿意让自己的名字和断门闩一同被记录。阿芙同意名字，不同意把门后所有人写成“她的责任”。
- 露米把两项事实分开：阿芙自称；门闩断裂；门后人数未确认。她知道这份分开记录可能来不及改变灯，却不再用一句完整话替人群包住空白。
- 任在旁边听见“无伤者确认”被人说成“无人”，没有及时纠正；他正在整理更早的时间，错过了露米看过来的那一眼。
- 公告旁原本要出现“东十四巷无伤者确认”；露米用阿芙同意的自称和断门闩记录压住那行字，要求书记员改成“东十四巷：求救待听见，伤者栏未开”。她在纸边留下自己的见证名，署名不代表她替门后人群作证。
- 公告换纸后，路边一名居民指着阿芙问“她的血是不是就算东十四巷有人”，书记员只好另开“现场后果：阿芙，门闩擦伤”一栏，并在伤者数字旁写“不计入门后人数”。阿芙听见后没有道谢，只问露米：“你记的是我，还是你需要的一个人？”

### 场景五：家族礼灯的价钱

- 现实事件：赛恩在家族外侧会客廊收到一盏旧礼灯和一份东十四巷请求。家族执事要求他用家族印记把请求写成“家族护持区”，这样它可以跳过“无伤者确认”的普通等候，但会让东十四巷居民对家族承担礼仪债务。
- 赛恩问如果不盖印记，礼灯能否只作为照明送去；执事回答，礼灯可以照亮门，却不能以无名义进入城防路线，若没有印记，守备可能把它当私人灯具扣留。
- 赛恩没有取得理念胜利。他在请求纸上写下“东十四巷有人等待，阿芙本人自愿留下姓名，门后人数未确认”，拒绝把整条巷归入家族，也没有把礼灯当成无代价的公共资源。
- 调度处的守备要把无家族印记的礼灯退回，赛恩改用自己的名字签下灯油、损坏和归还责任；这不是家族护持，反而把一笔个人礼仪债挂到他身上。门后居民听见后说“不欠你的家”，赛恩仍让灯送去，接受它被拒绝或被扣下的后果。
- 章内钩子：执事问“如果只能照一处呢？”赛恩没有立即回答，因为这个问题已经从礼仪转成了阿尔德手里的灯。

### 场景六：巡查队只带一盏检验灯

- 现实事件：阿尔德从旧器材库找到一盏玻璃有裂纹的备用灯，先派两名守备和一名记录员沿旧渠中段巡查；他们不带担架，不带药粉，也不把这盏灯挂进护灯架，只带检验灯、绳和三块空木片。
- 巡查队在中段依次听见下渠区、东十四巷和石腔深处的回声；他们用敲击回应，发现下渠区与东十四巷的声音可以沿同一条石腔传播，但两处之间没有可供担架通过的开口。
- 一名守备人提议把两处写成“一处墙后”，记录员拒绝，因为他看见两段墙根的水痕方向不同，且东十四巷门闩的碎木没有出现在下渠区。
- 巡查队没有确认墙外是什么，也没有确认第三种回声是不是人声；深处回声在他们点灯时消失，熄灯后又出现。它与前两处不同：前两处都在敲击后返回，深处这一声先于任何敲击落下，没有可供耳朵对照的返回间隔。
- 一块旧石板上有两条被水磨开的白线，它们在中段相邻却没有相交；记录员把“同源声道，异处人群”写在木片背面，并补上“下渠旧渠第七道石缝 / 东十四巷阿芙门断闩孔”。
- 章内钩子：备用灯的裂纹扩大，巡查队必须在回程和继续看清深处之间选择；阿尔德在调度处听见他们只说“能回去”，没有说“看清了”。

### 场景七：同段牌先派错了人

- 现实事件：裂玻璃灯仍在巡查队手里、尚未交回调度处时，书记员按“同段事件 / 三人”先派唯一一支可立即移动的点灯小队去下渠区；小队只带空灯架和挂钩，准备等灯回来后把它挂上护灯架。东十四巷的修闩请求被压在附栏，阿芙仍独自用肩顶门。
- 露米的纸条和巡查队带回的石板记录同时抵达。书记员不能再把东十四巷写成“无伤者确认”，却已经让点灯小队走错了方向；阿芙的手被断闩边缘划开，血滴在她自己的自称旁边。
- 书记员想把这滴血添进合并牌的“三人”数字，阿芙拒绝：“我的手是我的，门后的人不是我的伤。”任把它改进“现场后果：阿芙，门闩擦伤”，并写上“不计入伤者数字”；这次纠正没有追回已经走错的点灯小队。
- 任把时间、具体开口和两处不同水痕并在一起，阻止书记员把“下渠区旧渠第七道石缝”改成泛称“墙后”；纸面仍不能增加灯，却让错误调度留下可追溯的人名和地点。
- 巡查队带着裂灯回到坡道口后，阿尔德命令点灯小队不准把它挂上护灯架，改为把它带进下渠区作照护灯；他用铜扣上的血痕在同段牌中间压出一道折线，写下“资源仍一份”，没有把折线宣布为新制度。
- 阿尔德把两块牌正式分列，却在东十四巷副牌下写入“独立地点已确认 / 本班不重派完整救援路线”；这是误派后的制度后果，不是新的安全判断。修闩、听取姓名的小队仍可去，但不得被称作救援路线。
- 他批准守备带着赛恩的礼灯和新木闩去东十四巷，但那支小队只能修闩、听取姓名和记录眩晕，不得把礼灯当作路线灯。
- 章内钩子：两处牌被分开，错误调度却已经发生；阿芙听见自己的擦伤被写入现场后果栏，反而问露米：“你记住我，是为了让我留下，还是为了让他们不必再来？”

### 场景八：不是每一盏灯都能挂上去

- 现实事件：调度处确认裂玻璃灯只能照亮一段短墙，且不能挂入护灯架。下渠区需要它照见三名伤者的持续照护；东十四巷需要礼灯照着断门闩、修闩小队和门后人的清点，但两处都不会因此恢复完整防御。
- 阿芙通过传声筒问：“你们已经知道我们不是下渠区的人了吗？”阿尔德回答：“知道。”她又问：“那灯呢？”阿尔德没有把知道说成能给灯。
- 赛恩的礼灯抵达，执事要求他最后一次确认是否盖家族印记；赛恩拒绝把东十四巷收进家族名下，只让礼灯作为一盏私人见证灯送到门边。守备按他的个人签名登记灯油与归还责任，礼灯因此留下，但赛恩的个人礼仪债也在东十四巷门边成立。
- 阿尔德把裂灯送往下渠区，理由不是下渠区更重要，而是那里已有三名正在照护中的身体；他在板边留下东十四巷的独立具体开口和“门后人数未确认”。
- 他命令记录员把裂灯写成“照护灯”，不准写成“备用护灯”；这条用词会让下一班人少走一次错误的路线，却不能给东十四巷增加守备。
- 赛恩的礼灯抵达东十四巷门边，阿芙用断闩和自己的血迹证明那里有具体的人在维持门；她没有打开门让人群被重新编号。
- 阿芙听见自己的擦伤被写成现场后果而不是伤者数字，拒绝让修闩小队借她的名字替门后所有人签收；修闩小队只能把门暂时顶住，不能以她的记录请求完整护灯。
- 章内钩子：下渠区裂灯亮起，东十四巷门边礼灯也亮起；两盏灯都没有让任何路线恢复，旧渠深处却传来第三种回声。

### 场景九：第三种回声

- 现实事件：伊莉亚在裂灯下听见下渠区墙后的回声，阿芙在东十四巷门边也听见同样的低响；两处声音不是同时抵达，第三声却在任何一方敲击之前先落下，随后才让两块地点牌上的灯影同时颤了一下。
- 传令想把它写成“同段再次增加一人”；任阻止他直接增加数字，只记录时间、地点和“回声重复，来源未确认”。
- 阿尔德看着两块已被折开的牌，第一次需要在“拆分有用”和“拆分仍然不够”之间停留；他没有把第三声归给零、魔物或敌军。
- 第三声从两块地点牌之间的旧石板后传来，恰好让“同段”规则重新有了合并借口；阿尔德命令巡查队封住中段石板，不得把第三声归给下渠区或东十四巷，也不得继续沿声道深入。
- 封石不是静止处理。石灰和铁钉压入石缝后，旧渠传声道被切成两段：阿芙下一句喊声只到半途便断，调度处再也听不见她是否还在顶门；下渠区也失去向东十四巷回传的声音。两处牌被分开了，却在本班剩余时间里失去互相复核的耳朵。
- 这个命令的代价是两处暂时失去对中段回声的继续核查；修闩小队必须在没有确认第三声的情况下留在东十四巷门边，点灯小队不能把裂灯改成路线灯，下一次换班前所有新的确认都必须由人走路带回。
- 阿尔德让记录员另立一块“第三声 / 来源未确认”牌。这块牌不计入伤者数字、不归入两处地点，也不触发新的灯、车或守备；它只把封住的石板和未确认的声音留在调度处。
- 伊莉亚问门里门外的人：“你们也听见了吗？”托恩说听见，阿瑟没有回答，旧牌旁的人抬了一下手；这三个反应不能组成同一份证词。她的签名已经把下渠区锁在她的照护责任上，她不能借这次回声离开去确认另一处。
- 东十四巷门边，阿芙把断门闩靠在礼灯旁，没有把门打开；门后有人说出一个尚未被记录的姓氏，声音被风截断。
- 章末画面：调度板上有两块分开的地点牌和一块“第三声 / 来源未确认”牌；东十四巷副牌下写着“本班不重派完整救援路线”，裂灯被标成“照护灯”，赛恩以个人名字留下礼灯债务，中段石板封死后旧渠两侧各自失去声音。第三块牌没有获得资源，却使第三声不能被悄悄塞回前两处，也让两处在下一班以前无法再互相证明。

## 章末必须留下的事实

1. 城防存在“同段事件”旧规：同一声钟内、经过同一传声石腔且缺少独立身体或具体门、门洞、墙孔证据的求救，先合并为一块牌；这是行政压缩，不是真相。
2. 第61章下渠区与东十四巷确实共享旧渠传声道，但两处之间没有可供担架通过的实体路线；声音相通不等于救援路线相通。
3. 任和巡查记录共同形成“同源声道，异处人群”的现场描述；同段牌被折开一条缝，但错误调度已经发生，资源仍只有一份完整路线窗口。
4. 阿尔德把唯一裂玻璃备用灯明确标为“照护灯”并送往下渠区；东十四巷得到赛恩送来的私人礼灯和一支修闩、听取姓名的小队，但不获得完整护灯通行条件。
5. 露米的记录阻止公告把东十四巷的正式“求救待听见”改写成“无人”；阿芙的自称、断门闩和门后人数未确认分别进入记录，但没有自动生成伤者数字。
6. 赛恩拒绝用家族印记把东十四巷变成家族护持区；礼灯成为见证物，不等同城防护灯，不覆盖居民的归属边界。
7. 伊莉亚仍没有药粉；阿瑟未亲口确认姓名，第三名伤者仍暂记为“旧牌旁的人”，托恩与米娅的关系记录继续保留；伊莉亚签下三名身体状态的照护见证，因而不能离开下渠区。
8. 下渠区、东十四巷之外出现第三种回声；阿尔德封住中段石板，并另立“第三声 / 来源未确认”牌，但不计伤者、不触发资源，来源、性质、是否属于人声均未确认，零不成为方向证明。

## 第二卷第六十三章接口

- 两处地点已经被记录分开，但完整资源仍无法同时覆盖；“第三声 / 来源未确认”牌与被封住的中段石板同时存在，第63章可从东十四巷修闩小队抵达、下渠区照护灯再次受力或第三回声的封口争执进入。
- “同源声道，异处人群”尚未成为正式制度，只是阿尔德、任和巡查记录共同留下的现场措辞；下一处可能引用它，也可能将它改写成更危险的合并规则。
- 阿芙的名字进入公共记录但不代表整条巷；赛恩的礼灯带来见证与债务风险，不能被写成无代价救援。
- 伊莉亚的三名伤者仍需要持续照护；第63章可以增加数量压力，但不能提前完成他们的身份确认、治愈或死亡。
- 第三回声不应立刻揭露为魔物；它可以先改变城内的调度和人群行为，再逐步逼近外部压力的本体问题。

## Canon 检查清单

- [x] “同段事件”明确为行政合并；城区名不等于可复核的具体门牌、门洞或墙孔。
- [x] 共享传声道与实体救援路线分开，巡查不确认墙外本体。
- [x] 东十四巷“无伤者确认”保持为空栏，不变成无人或已确认伤亡。
- [x] 下渠区仍只有第61章留下的唯一稳定护灯；裂玻璃灯只作为照护灯，东十四巷礼灯不替代两盏稳定护灯。
- [x] 阿尔德承认资源不能双覆盖，不获得公平或正确答案。
