# 第二卷第七十二章《分水》场景卡

## 状态

- 状态：场景卡已完成独立 Canon / 文学最终窄回归，定稿候选；正文待生产。
- 承接：第二卷第七十一章《空位》正文与正文审校。
- 篇章：ARC 06《阈值战争》第十二章，也是第二卷收束章。
- 情绪中心：一层薄水被街面误读分配；费恩进一步把递牌的身体代价带入分水；露米因为过早替人判断留下新的关系损失；伊莉亚在不增加第四个照护位的前提下，允许一只手停在线外；阿尔德在街面误读中第一次作出让一层水向下渠区去的非正式方向选择，并承担上坡的反弹。
- 本章功能：把第71章“阿尔德接了但不来”从队列语言推进到既有公共水桶的分水动作，证明准确的正式字段仍不足以修复有限资源、时间、勇气和人的身体；让第二卷结束在一次不洁净的救援选择与尚未归类的第三声上。
- 本章主概念：一层水可以被准确分成两份，却不能让两边都不渴；一个人可以被写在正确的位置上，却仍没有一只手在场。
- 本章情绪：分配前的短暂安静、两边同时伸手的恐慌、选择已经说出后才开始的后悔，以及水流结束以后才出现的第三种声音。

## 一句话梗概

下一班水钟响时，第71章那名无名申请人的缠布手腕先在门槛边松了一下。她抬头看见同一只公共水桶正被水夫拖出石脚，桶里的薄水贴着桶底往上坡晃；她没有等排位员叫她，先伸手抓住桶耳。人群随后才把墙上的“回执已收”与街面口头的“阿尔德接了，但人不来”读成“下渠已经有人接过，不需要再等一个接水的人”。露米过早说“别拿，你的手不能”，申请人拒绝让她代答；申请人的腕骨下垂，水先漏掉一部分。费恩没有把传闻副牌递出去，而是先挡住上坡拉扯，再用自己的手托住桶耳，承担上一章递牌之后继续扩大的身体代价。上坡传令员把人群的问题带到下渠，阿尔德在不移开缺口脚位的情况下只说“送下去”；水夫负责实际转向，上坡失去这一层既有水，并把缺水与阿尔德的名字连在一起。伊莉亚让申请人和费恩的手停在线外，不把任何人纳入第四个照护位；托恩、阿瑟和旧牌旁的人各得到一点湿意，却没有完整恢复。任只记录水量、站位、请求和损失。水桶回到石脚、桶底干下去之后，留下一个无法成句、无人能指出来源的第三声。

- 不能把“阿尔德接了，但人不来”升格为正式板面字段、正式分水法、城市法令或阿尔德已经承担完整政治责任；它只能作为街面压缩语改变这一次水桶的方向。
- 不能修改“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定”；正式板面不因分水结果新增时刻、到场、受领完成或派遣。
- 不能复制第71章报告牌；同一块牌仍在原板，牌背旧字、牌边水泡炭痕和正式行保持不变。本章不再让牌离板。
- 不能让第71章普通申请人获得姓名、正式候位、复看时刻或新的医疗判断；她可以回到板前，也可以在水桶事件后离开，但记录不能替她决定去处。

## 核心规则与本章新增边界

### 1. 正式字段与分水动作分开

- 正式板面仍然只说“阿尔德受领／仅现场报告／时刻未定”；它没有给分水员一条正式“下渠不需水”的命令。
- 分水员与人群把“阿尔德接了，但人不来”压成一次现实判断：既然“有人接过”却没有人在桶边接水，这层水可以留给上坡。
- 这次判断必须由水桶耳、轮子、站位和人的手产生，而不是由旁白宣告街面错误。

### 2. 一层薄水只能有一个主要方向

- 水夫可以把同一只桶往上坡旧路线拖，也可以沿既有坡道把它往下渠送；不能同时满足两边。
- 桶内的薄水不是新资源，水量必须在桶身倾斜、桶沿溅出、碗或手接取时减少；正文要让读者看见损失，而不是只说“不够”。
- 上坡若失去这层水，失去的是已经等待的人和一次既有分水机会；不要凭空新增死亡名单或确定伤亡数字。

### 3. 申请人的手是行动，不是照护身份

- 普通申请人可以因为看见下渠区被放弃而抓住桶耳；她的旧布手腕会在用力时松开，造成可见的水损失。
- 她的姓名仍不写入正式字段；她可以拒绝称名，也可以只说“下面有人”，不能被任或书记员替她选择。
- 她的手可以停在线外托住桶沿，但不等于进入伊莉亚的三名身体、不等于获得治疗、不等于成为新的候位对象。

### 4. 费恩用身体承担，而不是用副牌代位

- 费恩可以把传闻副牌拿出来，但分水员不会把它当正式凭证；最重要的动作是他最后选择用缠旧布的手接桶耳。
- 他的手会再次疼或渗出旧布里的潮意，但不得新增明确伤口；他可以因此错过下一次普通复看机会或被上坡人叫成“灰七代位”，但不能完成责任成长。
- 他没有替阿尔德签字，也没有把副牌交给水夫；“帮助”与“代位”在街面上可以同时存在，正式字段不跟着变。

### 5. 伊莉亚的第四只手边界

- 下渠区需要一只额外的手：有人必须托住桶沿，否则薄水会直接倒进灰里；但这只手不能成为第四个被她照护的身体。
- 伊莉亚可以说“手留在线外”，让申请人或费恩托住桶，但她不能把对方的手臂拉入三名身体之间。
- 如果托桶的人松手，伊莉亚必须在“保水”与“保住既有身体”之间做一个瞬时选择；无论选择哪一边，都应留下具体损失。

### 6. 阿尔德的分水命令

- 上坡传令员只带来一句由街面误读产生的口头问法：“既然阿尔德接了，这层水是不是不必下坡？”这不是正式权限，也不是正式字段的解释。
- 阿尔德不离开缺口，不上板争辩；他必须在下渠三名身体、上坡等待者和自己名字的传播之间选一个方向。
- 本章阿尔德选择让水下去；这是一次非正式方向选择，水夫负责执行，正式板面和“阿尔德受领”不变；上坡不能只说几句就放弃，而要留下失去这一层水的具体反弹。
- 建议保留一句极短的命令：“送下去。”后面不加完整伦理解释；传令员带回命令时，街面会把它扩成“阿尔德把水给了下渠”。

## 读者此时应该误判什么

- 误以为“阿尔德受领”意味着下渠有人负责接水；实际正式字段没有到场、时刻或资源承诺。
- 误以为只要有一只手抓住桶耳，水就能稳定抵达；实际反复失力的缠布手腕、坏轮和两边同时拉扯会让水先损失。
- 误以为费恩拿出副牌就能成为合法代位；实际副牌只能改变人群看他的方式，不能改变正式记录。
- 误以为露米说得更准确就能保护申请人；实际过早替她决定可能让申请人失去自己的行动。
- 误以为任把“水已分”写清楚就能让上下坡接受同一种事实；实际两边会把同一层水的去向记成不同的损失。
- 误以为伊莉亚允许一只手在线外就等于她已经学会照护边界；实际她仍会在水与身体之间做出让自己不舒服的选择。
- 误以为第三声是前面线索的答案；实际它只在两种分水叫法结束后出现，证明还有一种不能被现有说法接纳的事实。

## 场景设计

### 场景一：手先抓住桶耳

- 现实事件：开场不先读墙字。无名申请人的缠布手腕在门槛边失力，她看见水夫把第65—66章以来同一只公共水桶拖出石脚，先伸手抓住桶耳。
- 她不是来领取下渠区的水，也不是为了取得代位；她只是看见桶里的薄水正被拖向另一边。旧布在腕骨上松开，桶身先偏了一下。
- 露米脱口而出：“别拿，你的手不能。”她伸出手又收回，没有真正碰到申请人；申请人问：“你看过吗？”她拒绝让露米替她回答。
- 费恩从普通复看队外侧赶来，普通复看牌仍夹在另一只手里；他先侧身挡住上坡伸来的手，用肩膀把那一下拉扯挡开，低声叫水夫先别拽，再看向申请人和桶耳之间的空隙。
- 申请人的手腕再次下垂时，费恩才用自己的手托住桶耳；他没有抽出传闻副牌，也没有把自己说成代位。
- 水夫喊“松手，桶要倒”，申请人说“下面有人”；她的手腕再次下垂，一股薄水沿桶沿漏进石缝。
- 章内后果：水损失先发生在人的手上；露米留下关系代价，申请人留下湿透的旧布，费恩的手背旧布被水浸冷；墙面、正式行和任的记录尚未成为解释中心。

### 场景二：误读变成方向

- 现实事件：上坡人这时才指向墙面“回执已收”和“阿尔德接了，但人不来”，说“下面有人接过了，那这一桶送给谁”。水夫没有把这句话当正式规矩，却开始顺着它把桶往上坡转。
- 书记员在门洞里读正式行：“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定。”人群只抓住“阿尔德受领”；正式行没有增加“分水”或“到场”。
- 费恩仍托着桶耳；有人从后面喊“灰七代位”，他没有把副牌交出去，也没有承认自己是代位。申请人说：“我不是代谁。”
- 同一场拉扯中，传令员从下渠区带来街面误读形成的问题：“既然阿尔德接了，这层水是不是不必下坡？”这不是正式权限，水夫才负责实际移动。
- 阿尔德不离开缺口，只问：“这一桶？”传令员说：“这一桶。”上坡还会失去什么没有被说成死亡，只被说成这一次分水没有了。
- 阿尔德说：“送下去。”传令员问：“要不要另记你的名字？”阿尔德说：“正式行不动，别另记新字段。”这次选择沿坡传开后，街面仍把它说成“阿尔德把水给了下渠”。
- 章内后果：水夫把桶转向下渠；上坡的人抓住桶身或墙沿，失水的愤怒与阿尔德名字同时扩散；报告牌没有离板，正式字段没有变化。

### 场景三：线外仍不是照护位

- 现实事件：坏木轮在灰线外卡住。申请人的手留在灰线外托桶，费恩的手压住另一侧；两只手都没有进入三名身体之间。
- 伊莉亚只说：“手留在线外。”她没有叫申请人的名字，也没有把她的手臂拉进来。她的手、膝、肩分别承受托恩夹板、阿瑟固定木片和旧牌旁人的裂木板。
- 托恩的夹板向外滑，阿瑟胸口固定木片往上顶。伊莉亚先保住既有身体，桶沿随之向下偏。
- 申请人的缠布手腕再次失力；费恩先松开桶耳，去托住在线外露出的夹板木端，不碰三名身体，也没有跨进照护线；水又洒出一小股。
- 申请人没有新伤，只把旧布咬在牙间重新绕紧：“我还能按住。”伊莉亚回答：“按住桶，不要进来。”这是一条临时边界，不是成熟结论。
- 章内后果：三名身体各只得到一点湿意，不形成完整水量；申请人和费恩都付出身体不适，水损失无法追回，第四个照护位仍未建立。

### 场景四：记录被第三声打断

- 现实事件：水夫把桶拖回石脚，桶底更轻；任只在旁页上记一次：水由上坡转下渠、桶内水量减少、三名身体各得一点湿意、上坡一次分水未得、申请人旧布浸湿、费恩旧布浸冷、申请请求仍未完成。
- 任不把上坡失水写成阿尔德杀人，不把下渠得到一点湿意写成救援完成，不把申请人的手写成正式照护对象；旁页始终在他手中。
- 露米想在申请人之后补上“她自愿”，笔尖停住；申请人没有给出完整姓名，也没有授权她替自己解释。两人的关系代价停在那里，不以道歉结算。
- 费恩把传闻副牌压回衣襟，普通复看牌仍为“暂缓”；没有人感谢他，申请人也没有向他道谢。
- 上坡人沿墙抹“回执已收”，另一人说“阿尔德把水拿走”；同一层水的去向出现两种说法，正式板面五字段仍不变。
- 就在任要写下“水尽”时，空桶旁响了一声。任的笔尖停住，没有把它写成词；水夫、申请人、费恩和伊莉亚都听见了，却没有人能指出它来自哪里。
- 声音只有半个音节，又不像任何人的喊话。它没有再回来。
- 章末画面：桶底的一点湿意被石头吸走；申请人的线外手慢慢松开；三名身体仍在呼吸；墙上一行字被风吹白；那半个音节没有再回来。

## 章末必须留下的事实

1. 正式板面仍是“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定”；“阿尔德接了，但人不来”没有进入正式字段。
2. 同一只公共水桶仍沿既有路线移动，桶内薄水减少；没有新增水桶、水源、灯、药、守备或候位资源。
3. 第71章普通申请人仍不留名，复看未发生；她的旧布浸湿、手腕再次失力，但没有新增伤势或正式照护身份。
4. 费恩的普通复看牌仍“暂缓”，灰七临时在场记录仍“期限未定”，传闻副牌仍“灰七代位／未确认”，三项与旧布不合并。
5. 费恩用手而非副牌参与分水；申请人和费恩的手都曾在线外，伊莉亚没有新增第四个照护位。
6. 阿尔德作出一次非正式的薄水方向选择，选择结果同时给下渠和上坡留下损失；他的名字扩散为街面责任，但正式责任字段没有升级。
7. 任记录了水量、站位、请求、损失和照护边界；记录准确，却没有恢复水、时间、姓名或复看。
8. 第三声在水尽之后再次出现；本章不说明其来源、身份、意图或与零、封石、浅弧的因果。

## 第二卷后续接口

- 第二卷以“分水”结束：分类已经从入册、候位和街面称呼进入稀缺资源的实际方向，但没有被宣布为终极制度。
- 上坡对阿尔德的失水记忆可以进入下一卷的政治追责、住房或守备分配；不要把一层水自动写成城市全面战争的唯一原因。
- 普通申请人的姓名、复看时机与去处继续未知；她可能再次出现，也可能只留下旧布、湿痕和一个没有被制度捕捉的行动。
- 费恩的“灰七代位”街面说法可以继续伤害他的身份，但不应让他下一章立刻承认、否认或完成责任成长。
- 露米对“保护”与“替人决定”的混淆继续存在；不要用一次道歉结清。
- 伊莉亚允许线外的手，却没有学会承认所有帮助；第四个正式照护位仍未解决。
- 任可能开始怀疑准确记录是否也会参与资源分配，但不要让他提前获得终局认识论成熟度。
- 第三声可以成为第三卷入口，但不能在下一章立即揭示答案。
