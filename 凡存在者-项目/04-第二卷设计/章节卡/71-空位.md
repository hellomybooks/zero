# 第二卷第七十一章《空位》场景卡

## 状态

- 状态：独立 Canon / 文学窄回归通过；正文已完成审校，定稿候选。
- 承接：第二卷第七十章《回执》正文与正文审校。
- 篇章：ARC 06《阈值战争》第十一章。
- 情绪中心：阿尔德的名字被读成一个“不来的人”；露米试图提前干预却只说出半句；费恩为了不让一块既有报告牌被踩坏，短暂拿走了不属于自己的位置，并因此错过自己的普通复看时机。
- 本章功能：让第70章的“回执已收”进入第65—66章已经存在的候位板和下渠区报告牌，不改变正式板面，却让一名普通申请人误把别人的报告牌当成自己的复看机会，具体失去一班时间。
- 本章主概念：板上被拿走的不是一个真正的空位；但一个人仍然可以因为相信它空了，而失去自己原本的位置。
- 本章情绪：一个人等了两班钟，只想让人看一眼自己缠布的手，却在错误的牌面前选择继续等；费恩发现自己伸手帮忙的动作，已经让他错过了自己的叫号。

## 一句话梗概

下一班钟后，墙上的“回执已收”沿街面传到调度板前。正式板面仍写着“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定”，但人群把它压成“阿尔德接了，但人不来”。第65—66章同一块下渠区报告牌仍挂在候位二旁，牌边有被水泡淡的“二”字炭痕；有人把这块既有报告牌从板前取下，说“二号空了”。费恩（普通复看牌暂缓、灰七牌下临时在场期限未定、传闻抄录副牌“灰七代位／未确认”，手背旧布另算身体状态）先伸手接住将要落地的报告牌，随后把它递给一个已经等了两班钟的普通复看申请人。申请人真正想复看的是自己的缠布手腕——她靠这只手替铺面端热汤，近来端到半路就会松腕——却拿着“下渠区／二”去排位窗口；露米尝试提前说明牌面不对应她的手，却没有给出她可以回去的路。任分开记录她的请求、牌的来源和正式行没有变化。费恩在递牌时错过自己的普通复看叫号，申请人则错过自己的原有队列位置；阿尔德收到针对报告牌退回的上坡询问后，选择留在缺口，没能亲自把自己的名字从街面读法里取回来。报告牌最终回到板上，正式候位二仍无时刻，申请人的手仍没有被复看；空出的不是候位，而是两个人都失去的一班时间。

## 本章不能做的事

- 不能把“回执已收”改成正式板面的“阿尔德受领完成”、正式候位完成、派遣完成或阿尔德政治责任的终局确认；正式板面必须保留“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定”。
- 不能把“阿尔德接了，但人不来”写成全城统一制度；它只能作为板前和街面的压缩说法，推动同一块既有报告牌被错误取下与递转。
- 不能新增候位牌、临时牌、空钉、木钩、守备、灯、药、担架、车、候位时刻或第四个照护位；正文只使用第65—66章同一块下渠区报告牌、其旁边的“二”字炭痕、既有调度板和既有普通复看队。
- 不能把下渠区报告牌同时留在原处又被申请人带走；物件链必须是“板前既有报告牌被取下 → 费恩接住 → 递给申请人 → 排位窗口退回 → 回到同一板面”。
- 不能把费恩的普通复看牌、灰七牌下临时在场记录、传闻抄录副牌和手背旧布合并；前三者各自保持既有状态，旧布只描述身体，不是记录。
- 不能把普通申请人写成第58—60章的母亲、孩子或费恩；她是新出场的无名普通复看申请人，具体愿望是复看缠布手腕，姓名与正式对象可不确认。
- 不能让申请人获得下渠区照护、阿尔德受领、正式候位二、复看时刻或新的医疗资源；她只能拿错报告牌并失去自己的普通复看时机。
- 不能让伊莉亚再次做“腾出第四个位置—既有身体失稳”的动作；她只在下渠区承受“有人说已经接了”的远处压力，三名身体的照护边界不重演第67章。
- 不能让露米用一句正确的话追回申请人的叫号；她可以尝试提前说明，但说明不完整，申请人的原有位置仍被下一人占去。
- 不能让任再次用字段分解解决事件；他只能把申请人的具体愿望与报告牌来源分开记录，不能制造一个新的时间。
- 不能确认提空碗男人的母亲、男孩、女人、线外来者、第三声、浅弧、封石、零或东十四巷的未决状态。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 核心规则与本章新增边界

### 1. 街面读法与正式行分开

- 正式行保留“阿尔德受领／仅现场报告／时刻未定”；“受领”是已有字段，不等于阿尔德承诺亲自到场，也不等于下渠区获得下一班。
- “阿尔德接了，但人不来”来自墙面“回执已收”、空白回执人位置和阿尔德留守的混合读法；它只能在板前推动动作，不能写回正式板面。
- 阿尔德实际仍在下渠区；他在场，却不能让街面立刻停止把他当成缺席的人。

### 2. 同一块报告牌不能分身

- 第65—66章的下渠区报告牌是同一块物件，牌边“二”只是临时炭痕，不是独立候位牌。
- 本章物件链必须可追：板前既有报告牌被取下 → 费恩接住 → 递给普通申请人 → 排位窗口退回 → 回到同一板面。
- 报告牌在手里时不代表持有人获得报告、候位、受领或复看；它只能暂时让一块旧牌面被人看见。

### 3. 一班时间可以被错误位置消耗

- 普通申请人有具体请求：复看缠布手腕是否影响握力；她原本在普通复看队末尾等待，拿错报告牌后离开自己的队列。
- 费恩在接住并递出报告牌时错过自己的普通复看叫号；他的正式普通复看状态仍是“暂缓”，但这一班时间不会回到他手里。
- 申请人把报告牌带到排位窗口，排位员退回牌时，她原来的普通复看位置已经被下一人占去；这不是正式编号重写，而是一个具体时段已经过去。

### 4. 准确记录保留请求，却不能恢复时刻

- 任可以写：申请人请求复看缠布手腕；报告牌来源为下渠区既有牌、街面递转；正式候位二未改；申请人离开普通队列；复看未发生。
- 申请人可以拒绝留下姓名；任不把拒绝姓名写成拒绝事实，也不凭身体、牌面或阿尔德名字替她补出对象。
- 露米可以提前说明“这不是你的复看牌”，但如果她没有告诉申请人可以回到哪里，准确说明仍然会让人失去路径。

### 5. 阿尔德面临真正的二选一

- 上坡传令员可以带来一句询问：要不要阿尔德亲自到调度板前说明“受领不等于到场”。
- 阿尔德若离开脚位，伊莉亚和三名身体将失去他现在压住的缺口边；若不离开，他无法当面纠正街面读法，只能眼看“阿尔德接了，但人不来”继续扩大。普通申请人的叫号已经因错牌、递转和排位延误而错过，不再归因于他的这一选择。
- 本章阿尔德选择留守，但让传令员带回一句“正式行未改”；这不是成功纠正，也不是接受街面责任，而是放弃当面取回自己名字的一次机会。

## 读者此时应该误判什么

- 误以为“阿尔德受领”与“阿尔德亲自接人”相同；实际正式行仍有“仅现场报告”，现场没有新资源。
- 误以为报告牌边的“二”是一个可以转让的候位号；实际它只是同一块既有报告牌旁的临时炭痕。
- 误以为费恩把牌递给申请人是帮助且没有代价；实际他错过自己的一班普通复看。
- 误以为申请人拿到旧牌便获得新的复看机会；实际她失去自己的普通队列位置，报告牌也不能兑现时间。
- 误以为露米提前开口就能完成纠正；实际她的说明不够，申请人的路径仍然断掉。
- 误以为任把字段分开便能把错过的时刻写回来；实际纸面比事件慢一步。

## 场景设计

### 场景一：板前读成不来

- 现实事件：下一班钟后，传令员把墙上的“回执已收”带到调度板前；他没有带新副页，只带来人群已经说顺的一句：“阿尔德接了，但人不来。”
- 书记员先读正式板面：东十四巷候位一、下渠区候位二、封石不入候位；下渠区一行完整写着“阿尔德受领／仅现场报告／时刻未定”。
- 任问：“谁把受领读成到场？”
- 书记员没有回答，指向墙外被水泡淡的炭字。
- 人群说：“二号有人接了，就该空出来。”
- 书记员没有改正式行，只伸手去取同一块下渠区报告牌。
- 露米想说“先别拿”，但看到牌边水痕和伸来的手，先问申请人：“你等的是什么？”
- 申请人说：“看手。”
- 露米说：“这块不是看手的牌。”
- 她没有接着说她应该回哪里。
- 章内钩子：报告牌从板前脱下，牌边的“二”字炭痕在多只手之间变成一个可被占用的说法。

### 场景二：同一块牌离开板面

- 现实事件：报告牌从书记员手里滑落，费恩先伸手接住，避免牌角摔裂；牌仍是第65—66章那一块，不生成新牌。
- 费恩的普通复看牌夹在另一只手里；灰七临时在场记录仍留在既有暂缓架，传闻抄录副牌压在衣襟内。
- 普通申请人说：“他们说二号空了。”
- 费恩看着牌边的炭痕：“它写的是下渠区。”
- “下渠区有人接了。”
- “不是我的。”
- 申请人看了一眼自己的旧布手腕：“我只想让人看一眼，握不住东西了。”
- 费恩短暂把报告牌贴到自己胸前；他想知道一块“有人接过”的牌能不能比“暂缓”快一点。
- 普通复看队里有人喊：“费恩，下一次。”
- 他没有听见，或没有回头。
- 申请人伸手：“给我。”
- 费恩把同一块报告牌递给她。
- 章内后果：牌离开板面，费恩错过自己的叫号；他没有把自己的三项记录交出去，却已经用自己的时间替别人递了一块不属于她的纸面。

### 场景三：她的请求不是下渠区

- 现实事件：申请人把报告牌抱在胸前，向普通排位窗口走；她没有下坡，只想让窗口的人告诉她牌上的“二”能不能换一个手腕复看。
- 排位员问：“姓名？”
- 她把手收回旧布里：“先看手。”
- “先写姓名。”
- “写了就能看？”
- 排位员没有回答。
- 她把报告牌放到窗口：“这个呢？”
- 排位员认出“下渠区”，说：“这不是你的。”
- 她说：“费恩给我的。”
- 费恩从后面赶到，普通复看叫号已经结束。
- 他没有说“我帮她”，也没有说“我只是捡到”。
- 申请人问他：“你不是说它空了吗？”
- 费恩说：“我说它不是我的。”
- “那你给我干什么？”
- 费恩没有马上回答。
- 露米把第70章旁页压在窗口边，想补一句，最后只说：“你要复看的是手。”
- 申请人看她：“我知道。”
- 后果：申请人的具体请求被看见了，却没有获得排位；费恩的普通叫号已过，报告牌仍没有替他们生成一次复看。

### 场景四：两边都没有回去

- 现实事件：排位员把报告牌从窗口推出，牌上的水痕蹭到木沿；他说：“把它送回下渠区的板。”
- 申请人没有接：“我从那里拿的吗？”
- 费恩伸手要接，普通复看队已经换了下一人。
- 他的普通牌仍是“暂缓”，但叫号不再回到他身上。
- 书记员说：“牌回板，人在原队。”
- 申请人问：“我的手呢？”
- “手跟你。”
- “那我去哪里？”
- 排位员指向普通队末尾。
- 那里已经站了下一名申请人。
- 申请人的旧布手腕被人群挤到门框上，她没有被划伤，只是旧布松开了一角。
- 露米伸手替她把布按住，又停下；这是申请人的手，不是她能替对方重新包好的东西。
- 她说：“你可以回去排。”
- 申请人说：“我刚才就在排。”
- 这句话让露米没有再说下去。
- 章内后果：申请人没有得到复看，也不能回到原来的位置；她只是从一个没有时间的板面，回到一个已经有人占据的队尾。

### 场景五：阿尔德收到询问

- 现实事件：同一传令链把排位窗口关于“报告牌退回”的问话带到下渠区：“要不要由阿尔德亲自上板说明，这块牌退回后仍不代表有人到场？”
- 阿尔德看着自己的脚。
- 伊莉亚的手、膝、肩仍压住三名身体；阿瑟固定木片边缘刚刚又滑了一下。
- 传令员说：“你上去，只要说一次。”
- 阿尔德问：“谁替我站这里？”
- 传令员没有回答。
- “那你把话带回去。”
- “带什么？”
- 阿尔德说：“正式行不改。报告牌回原板。候位二时刻未定。”
- 这句话没有把普通申请人的复看时机带回来。
- 传令员问：“那你接不接？”
- 阿尔德说：“我接报告。”
- “不是她的。”
- “不是。”
- 阿尔德没有离开脚位。
- 后果：他保住了三名身体当前的站位，却放弃了亲自到板前纠正自己的名字；“不来”继续有传播空间。

### 场景六：分别写下请求与损失

- 现实事件：任在下渠区旁页和调度处回话纸之间写下几行，不把报告牌变成新的候位凭证。
- 记录：普通申请，请求复看缠布手腕；报告牌为下渠区既有牌，牌边“二”是既有临时炭痕；牌经费恩递转；正式候位二未改；普通复看叫号已过；复看未发生。
- 申请人不愿留下姓名。
- 任问：“姓名不写，可以吗？”
- 她说：“你们写了我也不会被看。”
- 任没有反驳。
- 他写：本人不留名；手腕旧布松开；请求未完成。
- 露米看见“请求未完成”，没有把它改成“拒绝复看”。
- 费恩把排位窗口退回的报告牌递回书记员；书记员接过同一块牌。
- 申请人没有跟着牌下坡，也没有回到普通队首。
- 章内后果：事实被分开保存，申请人的时间却没有被保存；她的请求有记录，但没有对应的手、灯或时刻。

### 场景七：牌回到原板

- 现实事件：书记员把同一块下渠区报告牌挂回原来的位置；牌边“二”字比之前更淡，板面正式行没有改动。传令员后来只把排位窗口关于退牌的口头问话带回下渠区。
- 书记员读出：“下渠区，候位二，阿尔德受领，仅现场报告，时刻未定。”
- 他没有读“回执已收”。
- 墙外有人说：“阿尔德接了，但不来。”
- 费恩站在普通复看队外侧，手背旧布被申请人松开的布角勾住了一线。
- 他把布角解开，没有追上申请人。
- 任把费恩错过叫号写进旁页，没有写成普通牌顺序已经正式后移。
- 露米看见申请人回到人群后面，想叫她的手腕，却没有姓名可叫。
- 申请人没有看他们。
- 后果：正式牌回到原处，普通申请人的原队列却没有回到原处。板上的水痕在夜里干了，费恩与申请人各自错过的那一班没有回来。

### 场景八：空出来的一班

- 现实事件：夜色压到调度处，普通申请人离开普通队尾，手腕旧布重新绕了一圈，但没有新的布料；她没有获得姓名、复看时刻或受领人。
- 费恩手中的普通复看牌仍是“暂缓”；灰七临时在场记录仍挂在既有暂缓架，状态为“期限未定”；传闻抄录副牌仍写“灰七代位／未确认”。三项没有合并。
- 任的旁页上有：牌已归板；普通申请人请求未完成；费恩叫号已过；正式候位二未改。
- 露米没有把自己的迟疑添进申请人的记录；她已经提前说过半句，却没有给出能回去的路。
- 阿尔德的脚仍压在缺口边；伊莉亚的手、膝、肩仍在三名身体上；没有第四个人进入照护线。
- 章末画面：同一块下渠区报告牌回到板上，水泡淡的“二”贴着“阿尔德受领／仅现场报告／时刻未定”；普通申请人的手腕在队尾重新被旧布缠住；费恩站在错过的叫号旁；墙外的“不来”比板上的小字更容易被听见。
