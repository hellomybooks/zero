## 一句话梗概

任跟随抱着断裂同行牌的普通妇人办理，发现她与一户持有完整家族陪同牌的人请求相同，却被无签灰条挡在门外；赛恩可以用自己的姓氏为妇人的孩子增加一条家族责任分支，却不能用印记替她通行，孩子暂时获准出来，母亲却被留在“无同行”队列；露米证明两张灰条只是格式相同而非纸张同源，零拒绝被纳入家族分支，伊莉亚则面对孩子是否应先于身份进入救治台的选择，任终于看见“借路”不是公平，而是把责任转交给愿意承担的人。

## 本章不能做的事

- 不能让“无签处理”被宣布为正式法律或被幕后人物统一操纵；本章只写不同窗口如何主动套用路径。
- 不能让家族姓氏恢复赛恩的印记借用权、会客廊自由出入权或研究权限；姓氏只能触发一次责任分支，且责任落在赛恩本人和家族记录上。
- 不能让赛恩用家族身份替零同意进入任何登记栏；零的边界必须先于家族救援路径。
- 不能把普通妇人的孩子写成新的世界谜题或魔物；孩子只是一个被同行牌与身份规则阻隔的具体人。
- 不能让任用“我亲眼看见”替妇人证明他没有亲眼见到的母子关系；他可以记录条件，不能把同情变成证词。
- 不能让露米把两张同样格式的灰条认定为同一来源；她只能证明格式、折痕、栏位布局或短尾压痕的相似与差异，来源继续分离。
- 不能让伊莉亚用一次救治解决身份、药物和母子分流；她要在儿童身体需要与记录责任之间作出有限选择。
- 不能提前进入第49章完整的“谁是怪物”判断；身体排除可以加重，但仍通过门、队列、看牌和人群低语发生。
- 不能提前揭示 Copy、Observed、Original、旧页、空册、门内刻痕或世界本体；“借路”只证明制度路径可以跨案套用。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

- 任：持有三条被重新编号的短号记录，正追查“无签处理”如何作用于普通申请；他知道路径可以复制，却还没有看见身份分支如何改变结果。
- 赛恩：普通牌被削去一角，旁证份额已用尽，家族外侧会客廊仍不为他自由打开；他仍知道如何让家族责任窗听见自己的姓。
- 零：继续停在屋檐、墙根和门影之间；人群已把“没有见证”当成避让它的理由，零拒绝被写入任何家族或中央分支。

- 伊莉亚：承担“已发药，见证未确认”的药耗追问，普通药仍有限；临时救治台今天只能保留一个不看身份的急救位置。
- 普通妇人：抱着断裂同行牌，孩子在另一道门内；她有孩子的名字和自己的记忆，却没有一名愿意为母子同行签字的人。

## 核心规则

### 1. 无签路径可以分出责任分支

- 当申请缺少愿意签名的人、又需要经过两个以上办事处时，窗口可以套用“无签处理”：先补来源，再定顺序，最后安排下一处。
- 如果后来出现一名具备资格的责任人，灰条不会被擦掉；窗口会在它旁边加一条责任分支，写明“由谁承担后续说明”，原有的无签等待仍保留在底层。
- 家族责任窗能从赛恩普通牌背已经存在的“家族相关，待核”和家族责任簿中识别他的承担资格；这不是旁证签名，不消耗已经用掉的普通旁证份额，也不打开会客廊或印记权限。家族姓氏只能让窗内的人听见一次责任请求。
- 家族姓氏或家族记录可以让责任窗先开一条路，但不能证明申请内容真实，也不能替申请人获得所有普通资源。
- 责任分支的代价是签名者必须出席后续追问；若分支中的人再次失联，原有的无签路径会重新回到主队列，并把“责任未结”写入下一张牌。

### 2. 同一请求因身份不同进入不同门

- 同行核对台只看牌是否完整、是否有陪同字段和是否有可追问的责任人；它不判断母子之间的真实亲属关系。
- 完整家族陪同牌可以直接进入家族责任窗；断裂普通牌只能进入无签队，除非出现合格旁证或责任分支。
- 家族责任窗只负责“谁承担说明”，不负责“谁一定正确”；进入家族分支的人可能更快见到门内的人，却会被写入家族责任、配额与后续问询。
- 任的完整记录不能替妇人补上陪同字段；赛恩的姓氏不能替妇人获得家族印记。

### 3. 借路不等于借到资源

- 一条路径被借用后，借路者只获得该路径允许的下一步；原申请中的药量、床位、通行权和正式身份不会随路径复制。
- 门内孩子可以被允许暂时出来，但母亲仍可能停在“无同行”或“责任待结”队列；家庭被拆开是路径生效的一部分。
- 临时救治台可以按身体危险先处理孩子，不必先确认母子的同行字段；它只有一个不先问身份的急救位置。值班医者必须留下“无同行急救”记录，急救位置被占用后，下一名普通伤员只能回到普通等待；后续身份核对仍会另行发生。

### 4. 不同格式不证明同一来源

- 露米只能比较两张灰条的栏位布局、折痕方向、中央号位置和短尾压痕；这些可以证明普通妇人的新条沿用了同一格式，却不能证明它来自昨夜汇总册、同一支笔或同一名抄录者。
- 她可以另写一张“关联索引”，把三个短号暂时列在一起而不钉合两张灰条；这样能让责任分支先找到三条记录，却会把她自己的名字写进“关联说明人”栏，后续任何短号不一致都要先追问她。
- 格式可以继承，来源必须另记；一张纸上的空白责任栏不能替另一张纸承担责任。

## 场景推进

### 场景一：相同的请求，不同的门

- 现实事件：普通妇人抱着断裂同行牌到同行核对台，要求把门内的孩子带出来；同一时间，一户穿着深色礼服的家族人带着完整陪同牌来到相邻窗口，也要求接回一名被暂留的孩子。
- 具体对照：两边都说“孩子在里面”“我要把他带回去”；家族牌直接被送往家族责任窗，断裂牌被夹上“无签处理”，先补来源、再定顺序。
- 任的行动：任要求窗口至少把两人的请求写成同一类，登记员说请求相似不等于办理条件相同；他只能在妇人的牌旁添“本人陈述：孩子在门内”，不能替她补同行字段。
- 妇人的选择：她拒绝把孩子写成“失踪者”，因为那会让门内的人重新寻找；她坚持写“被暂留的孩子”，承担窗口要求她说明最后一次见面的时间与地点。
- 赛恩的羞耻：他看见相邻家族牌只经过两次问话便得到内侧门牌，自己却站在外侧；他知道只要说出姓氏，责任窗会听见，却不愿把妇人的孩子变成家族案件。
- 章内钩子：家族窗口的值班人听见赛恩的姓，从帘后问：“你要替谁承担？”赛恩没有立刻回答。

### 场景二：赛恩借出姓氏

- 现实事件：门内传来孩子的哭声，声音短而急；妇人的断牌被重新压进无签队，窗口说下一次叫号还没有确定。赛恩没有走进家族责任窗，只站在外侧传声口前；他普通牌背的“家族相关，待核”被窗内旧簿认出，责任窗因此愿意听他说明。
- 赛恩的选择：他报出自己的姓，却明确说自己没有家族印记，也不代表妇人承认家族归属；他只要求建立一次“临时责任分支”，让孩子先被带到门边核对母亲的声音。这一请求不消耗他已经用尽的普通旁证份额，也没有让门为他重新打开。
- 家族反应：长辈从帘后出现，要求他写明“家族知情、赛恩承担外部说明”；这不是印记借用，也不是家族担保真相，而是一笔会进入家族责任簿的外部义务。
- 任的冲突：任认为赛恩终于使用了自己一直拥有的捷径；赛恩回答，他借出的是会让自己被追问的姓，不是让门为自己打开的印记。两人的嫉妒第一次同时刺向对方的优势与代价。
- 具体结果：家族责任窗在妇人灰条旁加上一条分支：由赛恩说明陪同经过，母子可先到门内侧声辨台；原有“无签处理”不被删除，妇人的身份仍写着“责任待结”。责任窗只开一扇内侧小门，没有为赛恩恢复会客廊通行。
- 章内钩子：长辈把一枚新的责任牌从传声口递给赛恩，牌面没有家族印记，只有他的姓和一个未完成的空栏；姓氏写在“责任人”栏，不写在孩子的身份栏。

### 场景三：孩子出来，母亲留下

- 现实事件：门内小吏把孩子带到声辨台。孩子先喊母亲的称呼，妇人从门外回应；两人的声音被写在同一张临时纸上，却没有被写成同行确认。
- 规则后果：责任分支只允许孩子先出门，不允许妇人直接跟出；妇人仍需完成断牌来源、最后见面地点和无同行说明，母子被门槛和两张牌分在两侧。
- 赛恩的选择：他可以签下“母子同行已确认”，让妇人也进入，却没有亲眼确认他们一路同行；他拒绝签这一行，只签“孩子与门外妇人的声音相互回应”。
- 任的反应：任想替妇人补写“她是孩子的母亲”，被赛恩拦住；任说自己听见孩子喊她，赛恩说听见回应不等于能替两个人完成身份栏。
- 妇人的代价：孩子被交到她手里前，必须先在门外短暂登记为“责任分支下暂出”；责任牌的“责任人”栏多出赛恩的姓，孩子身份栏仍留着自己的名字。妇人当场说：“不要把他的名字写到你家下面。”她接受孩子先出来，却要求在旁边添上“暂不改变姓名与归属”。
- 关系推进：任第一次明白赛恩的姓可以救出一个孩子，却也会把孩子暂时放进家族责任的影子里；赛恩第一次承认，自己不确定这是不是帮助。
- 章内钩子：孩子抓住妇人的衣角，问“为什么我出来了，你还要等？”没有人能用一行字回答。

### 场景四：露米给三条短号留一条窄线

- 现实事件：露米把中央留存的原案灰条记录和普通妇人的新灰条放在两块不同的木板上，不把纸张钉在一起。
- 可见差异：两张灰条都有“采纳人、退回人、下一步”三栏，折痕方向相同，中央号位置相近，短尾压痕却不完全相同；这些只能说明后来办事人沿用了格式，不能说明两张纸来自同一张原纸。
- 露米的判断：她只在新条旁写“格式相近，纸源未定”，又取一条窄纸，列出妇人断牌上的无签号、赛恩责任分支的分号和孩子暂出牌的短号，注明“暂作关联，不合并来源”。这三个短号属于同一桩新申请的三种办理记录，不是此前那名肩缠灰布的伤员留下的三个短号。她没有把两张灰条钉在一起，却给新申请的三条记录留下一条可追问的窄线。
- 现场压力：中央搬牌人说，只要她在“关联说明人”栏签名，责任分支就能马上找到三个短号；若她不签，三个短号会继续各走各的队伍，孩子的责任牌不能在这一轮完成核对。
- 露米的选择：她签下“关联说明人”，但在旁边加上“本人不确认纸源、不确认词义”；这次她不是拒绝建立联系，而是建立一条带有明确边界的联系。
- 具体代价：声辨已经完成，责任分支分号与孩子暂出牌短号暂时相邻，孩子的记录没有退回无签队；但从此任何一个短号与另外两个不符，窗口都会先叫露米说明。她失去保持旁观的资格，保护来源差异换来自己的名字成为新责任入口。
- 章内钩子：两张灰条被风吹起，折痕几乎同时张开；旁观者以为它们是同一张纸的两面，露米却把那条窄索压在两者之间，不让纸面相碰。

### 场景五：伊莉亚让急救位置先于姓名

- 现实事件：孩子抱回母亲后开始发抖，额头滚烫；临时救治台只保留一个不先问同行字段的急救位置，普通药又因为前一办理时段的药耗追问暂缓。台面上没有第二个同样的空位。
- 值班要求：伊莉亚必须在“责任分支下暂出”与“无同行急救”之间选一个记录入口；前者可以把孩子留在责任牌旁等待家族转交，后者可以立刻占用唯一急救位置，却会让下一名普通伤员退回普通等待。
- 伊莉亚的选择：她不把孩子的身体交给赛恩的责任牌，也不调用新的药物；她在药牌上写“无同行急救，身体危险先于来源核对”，把孩子抱进唯一的急救位置，用冷水、干布和短时看护先压住发热。
- 现实代价：急救位置被孩子占用后，一名在旁边突然软倒的普通伤员只能被抬回普通等待；伊莉亚的名字进入“急救位置使用”追问，妇人则必须在孩子接受处理期间补写最后见面地点，不能因为孩子暂时退热而自动获得同行资格。
- 任的边界：任想把母亲的叙述和孩子的声音并列成一份完整记录，伊莉亚要求他分开写“亲耳听见”“妇人自述”和“孩子身体反应”；完整记录不能替急救位置的取舍消失。
- 赛恩的边界：长辈要求他把急救位置记入家族责任分支，赛恩拒绝把伊莉亚的看护写成家族恩惠，只承认“我承担孩子暂出后的说明”；急救没有消耗家族药物，也没有恢复他的通行权。
- 章内钩子：孩子退热后睡着，药牌上同时出现“无同行急救”和“责任分支暂出”两行；两行并列，却没有一行能替另一行收尾。救治位置已经空出来，普通伤员的等待却没有回到原处。

### 场景六：借路的账

- 现实事件：家族责任窗要求赛恩在离开前完成三项说明：孩子从哪道门出来、谁把他交给妇人、妇人的断牌为何仍未补全；每一项都对应一个不同的空栏。
- 赛恩的选择：他可以把责任推给任、露米或伊莉亚，声称他们也在场；他选择只写自己亲眼见到的门内交接和自己没有亲眼确认的部分，拒绝把同行写成事实。
- 长辈的后果：家族没有收回他的普通牌，却在家族责任簿上写下“外部责任未结”；赛恩下一次想申请旧档案旁听，必须先完成这份说明，研究冻结没有恢复也没有被新的即时冻结替代。
- 任的发现：他看见同一条“无签处理”在家族牌、普通断牌和儿童急救牌旁产生三种不同结果；路径本身没有偏爱，能借到哪一段取决于谁能承担哪一类责任。
- 任与赛恩的冲突：任说“你还是可以用姓氏让门改变”；赛恩说“你还是可以用完整的话让人知道门错了”；两人都知道对方拥有自己没有的工具，却第一次看见那工具也会把人绑住。
- 零的边界：门卫询问零是否也属于赛恩的家族责任分支，赛恩拒绝替零回答；任也没有把零写入妇人的灰条。零从门影里移开，留下自己的空白，不借赛恩的路。
- 章末事实：孩子暂时到门廊外侧，妇人仍留在责任待结白线内；妇人的断牌仍在“责任待结”，孩子的药牌仍在“无同行急救”；赛恩的姓名进入责任簿，家族路径帮助了一个孩子，却没有让所有人平等通行。
- 章末钩子：任把两张格式相似的灰条分开放在薄木两侧，想到“借来的路”最终总会问一句：谁替你走完剩下那一段？门内没有回答，只有责任牌上的空栏继续等待。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 追查无签模板如何作用于普通申请 | 看见同一路径因身份与责任分支产生不同结果；与赛恩正面争执，却仍拒绝把同情写成未经亲见的证词 |
| 赛恩 | 只有普通牌，无法自由进入家族外侧 | 借出姓氏建立一次责任分支，孩子暂时获准出来；自己被写入家族责任簿，权限没有恢复 |
| 零 | 面对“没有见证”的身体排除 | 拒绝进入赛恩的责任分支，保留不被代答的空白；门影成为它主动选择的边界 |
| 露米 | 比较原案与普通申请的灰条格式 | 建立不合并纸张的短号关联索引，签为“关联说明人”；声辨后关联记录补入交接栏，她成为后续不一致的追问入口 |
| 伊莉亚 | 承担药耗追问，普通药有限 | 占用唯一无身份急救位置，建立“无同行急救”记录；另一名普通伤员退回等待，问责转向急救位置使用 |
| 普通妇人与孩子 | 被断裂同行牌和无签处理分开 | 孩子暂时出来，母亲仍在责任待结；家庭获得短暂团聚，却没有获得共同资格 |

## 读者此时应该误判什么

- 只要使用家族姓氏，任何无签申请都能被完整转入家族保护。
- 赛恩借出姓氏等于恢复了家族印记或获得自由出入权。
- 孩子能被带出，母亲就会自动获得同行资格。
- 任只要把母亲与孩子的叙述写在同一张纸上，就能替他们完成身份核对。
- 两张灰条折痕相同，说明它们来自同一张纸、同一个人或同一处秘密。
- 伊莉亚先救孩子，意味着她做出了没有后果的正确选择。
- 零进入赛恩的责任分支会获得保护，也会因此同意被家族解释。

## 章末必须留下的事实

1. 同一项“把门内孩子带出来”的请求，完整家族陪同牌进入家族责任窗，断裂普通牌进入无签队；相似请求不等于相同办理条件。
2. 赛恩在门外传声口说出姓氏，凭“家族相关，待核”记录触发一次责任分支，使孩子可以先到门内侧声辨台；这不是旁证签名，不恢复印记或会客廊权限，责任进入家族责任簿。
3. 孩子暂时出来，母亲仍留在“责任待结”；母子短暂团聚不等于同行资格被确认。
4. 露米证明新旧灰条只是格式继承，纸源和抄写者未定；她另写短号关联索引并签为关联说明人，没有钉合两张纸。声辨完成后，关联记录补入三处交接栏，暂出记录不退回无签队，后续不一致会追问她。
5. 伊莉亚以“无同行急救，身体危险先于来源核对”占用唯一无身份急救位置，不调用新药；另一名普通伤员退回等待，她承担急救位置使用追问，母亲仍需补写来源条件。
6. 任拒绝把同情或听见的回应写成未经亲见的同行证词；他看见自己与赛恩分别拥有“完整话语”和“家族姓氏”的不同捷径。
7. 零拒绝进入赛恩的责任分支，不被家族、任或妇人的申请替写；门影是它主动保留的边界。
8. “借路”证明办理路径可以跨案套用，但身份、责任、资源和后果不会公平复制；不提前揭示技术或世界本体真相。

## 第45章接口

- 任追查“责任分支”是否会让无签模板变成新的阶级门槛，开始调查家族责任窗与普通证词窗的不同记录。
- 赛恩必须完成外部责任说明，家族要求他把任、露米和伊莉亚的在场写入可追问范围；他要决定保护同行者还是保护家族的责任边界。
- 零面对门卫把“没有被家族接纳”当成危险理由，身体排除会进一步靠近“异常”语言，但尚未进入完整魔物判断。
- 露米继续保存格式与来源的分离，却因建立短号关联成为“关联说明人”，开始怀疑“证明不同”是否也会成为另一种让人等待的力量。
- 伊莉亚在既有药耗问责与新的急救位置追问下继续面对“先救谁”的日常选择，为第61章战争线积累更深的名字与麻木压力。

## Canon 检查清单

- [ ] 无签路径不升级为正式法令，只在责任人出现时分出旁支，原有等待仍保留。
- [ ] 赛恩不恢复印记、会客廊自由出入或研究权限；姓氏只带来一次责任分支与后续问询。
- [ ] 普通妇人与孩子不被写成世界谜题；母子暂时团聚不等于同行资格确认。
- [ ] 任不能替妇人补写未经亲见的亲属或同行事实。
- [ ] 露米区分格式继承与纸源相同，以不合并纸张的短号关联索引连接三条记录，承担“关联说明人”追问。
- [ ] 伊莉亚先救孩子但留下无同行急救和急救位置使用追问，不调用新药，有限位置继续造成他人等待。
- [ ] 零不进入家族责任分支，行政与家族语言不等于零同意。
- [ ] 正文以门、牌、队列、姓氏、责任窗、药牌和人物选择承载阈值，不出现技术 API 或说明书式解释。
