# 第二卷第四十七章《无误》场景卡

## 状态

- 状态：通过 / 定稿候选，可进入正文生产。
- 承接：第二卷第46章《定本》正文与正文审校。
- 篇章：ARC 04《回到王都》。
- 本章功能：让任与赛恩进入一个真实、有效、可重复的“无差庭”，使赛恩亲眼看见精确结构如何减少误差、消除偏差，却必须把活物、随机动作和不完美记忆挡在外面；让任的胜利不是说服赛恩，而是让赛恩自己看见“没有错”也可能意味着“没有人能活在里面”。
- 本章主概念：无误 / 完美几何——一个被固定参照支撑的空间能够让物体保持一致，却会把生命的变化当作需要排除的扰动；精确不是邪恶，代价在于它要求世界先变得不像世界。
- 潜在技术隐喻：理想几何、零误差、形状约束、全局一致与动态对象排除；正文只写一座庭院、静止的水线、无法落脚的鸟、被修直的物件和一张歪画。
- 本章情绪：秩序的诱惑、被排除的生命、任第一次不急着证明自己正确、赛恩第一次面对精确结构的伦理代价，以及儿童画带来的私人裂缝。

## 一句话梗概

赛恩接受无名校典使者的邀请，凭一次性参照室申请进入一座被称作“无差庭”的封闭庭院，任作为不触碰器具的见证人留在外圈。庭院能让水沿绝对笔直的沟槽流动、让破裂的石桥恢复成无缝几何，任何物体都不会偏离规定位置；但鸟无法在里面落脚，园丁的手不能伸入，活人的脚步一旦改变节距就会被推出边界。赛恩承认它“做得没有错”，却在父亲留下的儿童画被庭院改成一张更漂亮、更规整的图时夺回原画，第一次意识到一个完美答案可以把它要回答的人也一并抹去。

## 本章不能做的事

- 不能让无差庭只是幻觉、梦境或一句哲学比喻；它必须修复真实的石桥、稳定真实的水线、改变真实的人和物的通行结果。
- 不能让无差庭一出现就杀人或毁城；它的危险首先表现为排除、静止、无法落脚、无法照料和记忆被修直，诱惑必须先真实有效。
- 不能让任靠一句“它没有生命”说服赛恩；任只能把一个活物或真实人的动作带到庭院边缘，让后果自行发生。
- 不能让赛恩突然厌恶精确、规则和结构；他必须承认无差庭确实解决了旧门、石桥和水线的问题，动摇来自代价而不是能力失效。
- 不能让儿童画成为遗迹证据、世界本体线索或父亲的完整辩护；它只是一张不完美、不可替代的私人记忆。
- 不能让无差庭提前变成第七卷的完美城市、完整教会据点或世界终极答案；本章只展示一个可扩展的局部模型和一张无名邀请牌。
- 不能让赛恩正式加入教会或宣称自己已经找到真值；他只决定继续看下去，并把儿童画从庭院的校正动作中抢回来。
- 不能让任取得内层自由阅览权；他的见证位置、不能触碰和不能带走材料的限制必须持续有效。
- 不能让零进入无差庭或被庭院判定成功；它在外圈保持主动空白，不由任、赛恩或使者代答。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码。

## 核心规则

### 1. 无差庭先固定参照，再排除变化

- 庭院四角各有一块白石，白石之间拉着肉眼几乎看不见的细线；细线规定水槽、石桥、门框和人的行走节距。
- 进入庭院前，所有可移动物件必须放入外圈的木格；木格会记录物件的形状，庭内只允许按照记录后的形状存在。
- 物件若发生偏斜，白线会把它推回原位；裂石、弯轮、断裂的水槽都能恢复一致，前提是它们先被当作静止物件处理。
- 活物不能被放入木格。进行工作或验证时，活人可以沿事先记录的固定步架进入庭内，但呼吸、步幅、体温和回头都会改变参照；一旦动作偏离固定步架，庭院会先把脚步推回原位，无法继续贴合时才把人推出白线之外。

### 2. “没有误差”会改变资源和身体

- 无差庭可以把北侧回水渠的水线压回直槽，让药运门附近的水不再漫过药材堆；修缮署因此愿意继续投入资源。
- 庭院内的水流没有浪花，落叶会在触及白线前被推到外圈，石桥上的每一块砖都保持同样间距；这确实比普通修缮稳定。
- 需要在庭内工作的园丁、搬运工和医者不能被记录成静止物件，只能沿已经记录的固定步架进入；他们不能一边保持活人的自由动作，一边要求庭院承诺零偏差。凡是需要临时改变路线的工作，都必须退到庭外交给固定器具完成。
- 被推出庭院不等于被宣布为错误，但被推出的人无法在庭内取水、修桥、捡起掉落物或照料另一名活物；“不属于此处”本身会产生现实代价。

### 3. 观察也有边界

- 任只能站在庭外观察圈，记录“谁在什么位置被推出、哪一条水线被拉直、哪个物件被改形”；他不能触碰白石、拉线、静水槽或被校正的物件。
- 见证记录只证明现场动作，不证明无差庭本身正确；任若写下“庭院有效”，必须另负责任，因而只记录亲眼看见的结果。
- 赛恩可以进入庭院，但不能把任、零或其他人写成自己的同行物；他的邀请牌只允许一次参观和一次不超过一项的物件试验。

### 4. 庭院对私人记忆也只认形状

- 无差庭可以把一张纸摊平、拉正、压入规定的四角，却不能知道一条歪线为何被画下。任何物件一旦接受“承认试验”，庭院都会生成一个符合参照的副本；申请人若再要求“修正”，只会让副本更规整，不会保留原画的偏差理由，原纸本身不被改写。
- 校典使者把这种结果称为“更清楚的版本”，但不强迫申请人带走；原画若被取回，庭院只留下改写后的副本。
- 赛恩必须亲眼看见：一张更漂亮、更准确的画，可以同时是一张不再属于他的画。

## 场景推进

### 场景一：白石门只开一次

- 现实事件：赛恩和任来到定本厅后方的白石门。无名校典使者收回邀请牌的一角，只留下本次参观的白痕；单案协验牌已经失效，赛恩不能凭姓氏再打开前一扇门。
- 申请与受理：赛恩先出示邀请牌，校典使者在白石门旁的窄簿上写下“参观一次、范围仅限无差庭、任为外圈见证、零不登记”，再用无名印记受理申请。使者明确说明，这不是家族权限、公共通行权或教会成员资格；申请只在本次参观结束前有效。
- 使者的条件：受理后，赛恩可以进入一次，任可以站在外圈作为不触碰见证人；任若越过观察圈，整次参观立即停止。零不在名单上，也不进入名单。
- 任的选择：他要求把“我只记录看见的事”写在见证纸上，不写“无差庭正确”；使者接受，且把见证纸放在庭外，不让任带入核心区域。
- 赛恩的动作：他先把儿童画从衣内取出，确认纸没有受潮，又把它压回责任牌后。他没有把画当作实验材料。
- 场外交接：任把外来者区送来的两张窄条压在见证纸下：露米的关联说明仍等三号短号核对，伊莉亚的“急救位置使用”仍在药耗追问栏里；两张纸不进入无差庭，只证明庭外的人仍在承担自己的后果。
- 章内钩子：白石门开启，门后没有风；庭外的雨水落下时会溅开，庭内的水线却静得像一根透明的硬线。

### 场景二：会自己回到原位的桥

- 现实事件：无差庭中央有一座低矮石桥，桥面少了一块石板。修缮署把一块边缘不齐的备用石放入木格，白线从四角压下，石板缓慢地被推成桥面需要的形状。
- 视觉现象：石板的缺口消失，桥面每块砖之间的距离一致；水从桥下流过时没有撞击声，连一片落叶也在白线外被整齐推成一排。
- 赛恩的反应：他走到桥边，看到那块石板不再留下任何无法解释的弯角；他承认这是有效的，比临时修补更稳定，也比人争论哪条线才是原线更快。
- 任的记录：任在庭外写下“石板进入木格后改变形状，桥面恢复通行”；他不写“石板被修好”，因为那会把改变后的形和原来的石板混在一起。
- 现实结果：一名修缮工从庭外试走桥面，鞋底不再被松动石块绊住；北侧旧药运门的回水渠开始保持直流，药材堆旁的积水退下去。
- 章内钩子：校典使者说：“你们看，这里没有谁需要猜另一块石头想成什么。”

### 场景三：鸟没有落脚的地方

- 现实事件：一只被雨打湿的小鸟从庭外飞入，落向桥栏。它的爪子刚碰到白线，身体便被一股看不见的力推回外圈；它再次飞入，又被推回。
- 反复动作：小鸟在桥上方盘旋，水面没有因为翅膀扇动而起皱；它试图落在石板、栏杆和庭角的树枝上，每次都被相同的力量送回原处。
- 任的选择：任走到观察圈边缘，把手伸向小鸟可能落下的位置，但没有越过白线；他看见自己也被无差庭的边界挡住，不能替小鸟完成一次停留。
- 校典使者的解释：使者说庭院没有伤害小鸟，只是小鸟的重量和动作不在已经记录的形状里；如果要让它落下，就必须先把它做成不再变化的形。
- 赛恩的反应：赛恩说“它只是想停一下。”使者回答：“那就让它在庭外停。”庭外泥水淹到鸟的腹部，庭内却没有一滴水越过白线。
- 关系推进：任没有看赛恩，只说：“这里没有错。它只是没有地方给活的东西留下。”赛恩第一次没有立刻反驳。
- 章内钩子：小鸟终于飞向庭外的歪树，树枝向下弯了一下；那一下弯曲在无差庭的白线里没有留下任何记录。

### 场景四：人的脚步被改成同一个脚步

- 现实事件：修缮署派来一名老园丁测试庭内的水槽。园丁先在庭外木牌上留下自己的姓名和固定步架，得到一次进入许可；他需要跨过石桥，伸手拨开一片卡在槽口的叶子。进入后，他的脚步被白线一次次推回固定间距。
- 身体后果：园丁想快一点，左脚便被推回；他想停下，右脚又被迫跟上。每一步都没有摔倒，却没有一步真正属于他。
- 园丁的选择：他抬手去捡叶子，手腕在白线前停住，像被看不见的门挡住；他只能退回外圈，让一根固定夹把叶子夹走。
- 校典使者的说法：庭院不允许活人的动作改变水线，否则下一次水流就会偏。园丁的工作可以被器具代替，因此他不必进入。
- 任的反应：任在见证纸上写下“园丁进入后不能改变步幅，不能拾取落叶”；他没有写“庭院伤害了园丁”，因为园丁没有受伤，也没有写“庭院保护了园丁”，因为园丁被剥夺了完成工作的方式。
- 赛恩的反应：赛恩看着那名园丁退到外圈，问：“如果他的手比夹子更快呢？”
- 使者回答：“快慢会产生偏差。”
- 赛恩问：“如果他知道哪片叶子必须先取呢？”
- 使者说：“知识不改变形状。”
- 章内钩子：园丁在庭外把手掌放在水渠边，水线从他掌下经过，却没有沾湿他的指缝。

### 场景五：任让赛恩看见无误的代价

- 现实事件：庭外有一名抱着空药篮的年轻医者，想进入庭内取回一只被白线推走的药瓶。先前的搬运工把药瓶放到水槽边时，白线从瓶底和瓶口同时压过，书记员在木格边记下瓶子的朝向；随后药瓶才被推到庭角。瓶子没有损坏，瓶口也没有打开，却已经成为一个被记录的静止物件。
- 医者的请求：她说药瓶属于一名正在等药的病人，药瓶离开她的手后已经不再记得原来的位置；她要求进入庭内取回。
- 规则后果：使者拒绝。药瓶已经被记录为静止物件，医者的身体不能进入同一条白线；如果把药瓶带出，必须重新登记形状，药物分发会再延后一轮。
- 任的选择：任没有越过观察圈，而是请医者说出病人的名字和药瓶的颜色，自己把这些话写进见证纸的附注；他没有替医者进入庭内，也没有把同情写成“无差庭错误”。
- 赛恩的选择：赛恩可以用单案邀请要求使者放行医者，但邀请只允许一项物件试验，不能改写活物规则。他看着药瓶和医者之间隔着一条细白线，没有立刻开口。
- 医者的行动：她退后一步，从自己的篮子里取出另一只备用瓶，要求修缮署把新的瓶子记成旧瓶的替代。她救了取药的下一步，却失去原来的药瓶位置，病人必须再等一名记录员确认。
- 赛恩的冲击：无差庭没有让药瓶消失，也没有让医者受伤；它只是把一个需要立刻取药的人变成了庭外等待者。所有动作都合乎它的规则，结果却不是谁愿意承受的结果。
- 任的低声话语：任对赛恩说：“我没有办法证明它错。”
- 赛恩回答：“所以你想让我说它错？”
- 任说：“不。我想让你自己看见，它根本没有问这个人要什么。”
- 章内钩子：赛恩的手按在衣内的儿童画上，纸面被他按出一条新的折痕。

### 场景六：一张画被修得更准确

- 现实事件：使者注意到赛恩一直护着衣内的纸，问他是否愿意做唯一一次物件试验。赛恩没有说画是什么，只把它递过去，要求“不要改动原纸，只看它能不能被庭院承认”。
- 试验限制：使者把原画放在外圈木格里，不让赛恩亲手将它压入；纸张四角被拉平，庭院把赛恩的请求记为一次“承认试验”，先读取原画外形，再生成一份可入庭的形。生成副本不等于改写原纸。
- 画面变化：歪房子的墙线被拉直，门宽与墙面变成一致比例，太阳被推回一个规整的圆；人物的几根线被分成相同长度，纸角的折痕被压平。
- 赛恩的反应：他先看见一张比原画更清楚、更匀称的纸，随后才意识到那已经不是自己小时候画的房子。父亲保存的不是这张更好的画。
- 使者的判断：使者说：“它现在更容易被保存、复制和放入主档案。原来的偏差没有必要继续存在。”
- 任没有说话：他知道任何一句“这就是你一直追求的东西”都会把赛恩的痛苦替他归类。见证纸上的炭笔停在半空，没有落下。
- 赛恩的行动：他从白线外沿冲向木格，第一次触碰无差庭的木格；白线在他手背前亮起，邀请牌的白痕裂开一道细口，庭院无法同时接受他的身体和被校正的纸。
- 现实代价：赛恩的手背被白线擦出一条细红痕，原画从木格里滑出；校正后的副本留在庭内，原纸落到庭外泥水边。
- 赛恩的选择：他没有去看副本，先捡起原纸，用袖口挡住泥水，再把画压回胸前。
- 章内钩子：使者说：“副本更准确。”赛恩回答：“我不要它准确。”

### 场景七：无误没有被击败

- 现实事件：赛恩离开无差庭时，庭内的水线仍然笔直，石桥仍然稳固，药运门回水渠仍然没有漫出；庭院没有因为赛恩取回儿童画而崩塌。
- 赛恩的承认：他对任说：“它做得没有错。”这不是替庭院辩护，而是拒绝用一个人的痛苦抹掉它确实解决的问题。
- 任的回应：任说：“我也没说它错。”他把见证纸折好，保留园丁无法拾叶、医者无法取药、鸟无法落脚和儿童画被改写的四件事。
- 赛恩的裂缝：他问：“如果一个地方只接受不会改变的东西，它还能叫地方吗？”任没有回答，因为这个问题必须由赛恩自己继续问。
- 零的边界：零仍在白石门外。无差庭的白线向门外延伸时，在它的暗边前失去完整形状；使者没有把这记成庭院失败，赛恩也没有把它记成零的能力证明。
- 退出规则：参照室收回邀请牌，赛恩不能把任何白石、线片或庭内副本带走；他只能带走自己原本拥有的儿童画和写下的责任记录。
- 章末事实：赛恩没有放弃精确、规则或结构，却拒绝让无差庭把儿童画改成“更准确”的版本；任没有说服他，赛恩自己看见了没有生命的秩序。
- 章末钩子：回到外廊后，赛恩把儿童画放在一张极平的石桌上。纸自己向一侧卷起，太阳偏回纸角；他的手抬起，又停在半空。

## 角色与关系变化

| 角色 | 本章开始 | 本章结束 |
|---|---|---|
| 任 | 试图用条件差异证明定本不是唯一答案 | 看到无差庭有效却排除生命，放弃用口头说服赛恩，改为保留不替他解释的见证 |
| 赛恩 | 带着无名邀请牌，相信更深参照室可能提供可靠答案 | 仍喜欢精确、规则和结构，但亲眼看见无误秩序没有生命；夺回儿童画，第一次拒绝“更准确”的替代品 |
| 零 | 保持不进入任何答案结构的边界 | 白线在其暗边前失去完整形状，却没有被庭院、赛恩或任登记为异常结果 |
| 露米 | 在外来者区处理既有责任 | 不进入无差庭；她的缺席提醒读者，完美秩序的代价仍由具体的人在庭外承担 |
| 伊莉亚 | 在外来者区处理急救位置追问 | 不进入无差庭；药物与照护线没有因参照室的演示暂停 |

## 读者此时应该误判什么

- 无差庭既然能修复石桥、稳定水线，就一定值得推广到所有人身上。
- 鸟被推出去只是因为它不够稳定，而不是因为庭院没有为生命留下位置。
- 任只要记录四个被排除的案例，就已经说服了赛恩。
- 赛恩抢回儿童画只是情绪化反抗，意味着他开始否定精确与规则。
- 校正后的画更清楚、更容易保存，因此比原画更接近“真正的画”。
- 零使白线失去形状，意味着无差庭已经识别出零的真实本体。

## 章末必须留下的事实

1. 无差庭是真实有效的局部结构：它修复石桥、稳定水线、减少药运门附近的积水，确实解决公共问题。
2. 庭院以白石、细线、木格和固定步幅排除活物变化；鸟无法落脚，园丁不能自由拾叶，医者不能取回已被记录的药瓶，排除本身造成等待和照护代价。
3. 任只在庭外观察和记录，不触碰白石、静水槽、参照线或校正物件；他不替赛恩宣布无差庭错误。
4. 赛恩承认无差庭“做得没有错”，但拒绝让它把父亲保存的儿童画改成更准确的副本；原画由赛恩抢回，庭内只留下校正副本。
5. 赛恩仍喜欢精确、规则和结构，却第一次亲眼看见没有误差的秩序可以没有生命；这不是彻底转变，也不是加入教会。
6. 零不进入无差庭；白线在其暗边前失去完整形状，但没有形成对零的正式判断。
7. 第48章需要承接赛恩把儿童画放在平桌上、看见它再次向一侧卷起后没有立刻压平的动作；他的改变应表现为允许一件东西暂时歪着，而不是变成混沌艺术家。

## 第48章接口

- 赛恩回到自己的临时桌面，仍会整理牌、纸和笔，仍然相信结构有用；但儿童画在桌面上卷起时，他第一次允许它保持不齐。
- 任不宣布自己击败赛恩，也不替赛恩解释“没有生命”的结论；两人的关系从辩论转向共同见证后的沉默。
- 无名邀请牌的来源继续不明；它只证明有更深的参照室和可扩展的秩序，不揭示组织、教会或世界本体。
- 零继续不进入赛恩的答案结构；白线失形只留下现场现象，不升级为身份判断。
