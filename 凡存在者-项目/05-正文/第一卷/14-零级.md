# 第十四章　零级

任的手还悬在石盘上方。

指尖离石面不到一寸。

石盘边缘那道白色刻线已经暗了下去，像从未出现过。可测试场里的每个人都看见过它，没人能把刚才那一瞬间从自己的眼睛里擦掉。

负责测试的长老抬起手。

“先完成其他人。”

记录员看向任。

“他呢？”

“他等。”

长老的声音不高，却让测试场重新有了顺序。

任把手收回来，退到白石线外。

他的木牌挂在胸前，背面有一道代表共同看护责任的浅刻痕。别人只需要等待读数，任还要等待装置决定刚才那道白线算不算读数。

第一个新生走进安全圈。

他看起来比任小一些，手腕上缠着一根红绳。记录员让他把手放在石盘中央，固定光照落在他的指节上，金属环缓慢转动。

石盘内圈亮起一格。

又一格。

随后是更多。

刻度停在二十三。

记录员用炭笔在木牌上写下数字，旁边有人松了口气。那个新生回到队伍里，红绳的主人似乎变得更挺直了一点。

第二个人得到五十七。

他走出安全线时，立刻回头看了一眼石盘，像在确认那个数字还在不在。身旁的同伴拍了拍他的肩膀，两个人小声交换了什么。

第三个人得到一百零八。

这次没有人拍肩。

队伍里响起一阵短促的吸气声。

一百零八这个数字在他们之间传开，像一块被投入水中的石子。有人抬头看石盘，有人下意识往那名新生身边让开半步。

数字没有说话。

人却已经替它说了许多话。

记录员把薄木牌一一交还给新生。有人低头抚摸自己的刻度，有人把牌面转向同伴。测试场里没有谁宣布高低，可每个人都知道自己应该站在哪一边。

任看着他们。

这些输出和前一晚的火线很不一样。

火线会被风吹弯，会被湿泥截断，会因为一个错误的判断烧上屋檐。数字却干净得多。它们从石盘里出来，落在木牌上，然后进入人的眼睛。

下一名新生走进安全圈。

他穿着一件没有学院灰色短袍的深色外衣，衣领扣得很整齐。没有人陪着他，也没有人替他把木牌拿在手里。他站在固定光照下时，金属环先亮了一下。

不是一格。

也不是两格。

那一圈光沿着金属环向上攀升，越过了前面学生触碰过的刻度。站在三侧的教师同时抬起头，记录员的笔停在半空。

金属环还在亮。

它没有失控，也没有发出警报，只是继续把光推向更高的位置。石盘的内圈几乎被白光填满，最外面那一道刻度却始终没有完全闭合。

长老的手指在桌面上轻轻敲了一下。

读数停下。

记录员低头写字，写得比刚才慢了许多。

那名新生走出安全线。

没有人笑。

也没有人向他道贺。

他把自己的木牌接过来，向记录员点头，然后回到队伍里。他的动作很礼貌，甚至有些克制，仿佛刚才那一圈异常高的光并不属于他，只是石盘暂时借他的手亮了一下。

任看见木牌上的数字，却没能看清全部。

它太高，已经超出了其他木牌能提供的比较范围。

那个陌生的新生抬眼看了一下任。

他的目光没有停留太久。

任却第一次意识到，自己可能也会成为别人测试中的一个结果。

不是因为白界。

不是因为那道残骸上的标记。

只是因为他站在这里，胸前挂着一块写有无源和共同看护责任的木牌。

“任。”

记录员叫他。

队伍的声音低了下去。

任走进白石安全圈。

三名教师同时改变站位。

他们的动作让任想起练习场里那次水盘事故。一个人看石盘，一个人看金属环，一个人看他的手。

没有人看他的脸。

固定光照落在他的指节上。

任把手放到石盘中央。

石面是凉的。

那道白色刻线没有回来。

没有失色。

没有嗡鸣。

只有石盘内部一圈冷光向内收束，像一口很浅的井，正在等待一滴水落下。

任忽然想起自己在地球上调试程序时的感觉。

当所有输入都已经检查过，所有路径都没有报错，程序却在某个最不该停下的地方停下。

那时他会先怀疑自己漏看了某个条件。

可这里没有日志，没有堆栈，也没有能被他翻开的源文件。

石盘安静了一会儿。

记录槽里传来一声轻响。

一枚薄金属片从槽口落下，撞在石盘下方的浅槽里。

它很小，只有指甲盖那么大。

金属片翻了半圈，正面朝上。

上面刻着一个清晰的数字。

`0`

测试场安静了一瞬。

随后有人笑了。

不是一个人。

笑声从队伍后面先起，像有人终于等到了一个可以确定的答案；接着它沿着人群传开。有人低声说“零级”，有人重复了一遍“零”，有人朝外院侧廊的方向看了一眼。

那一眼落到了零身上。

零站在阴影里，没有靠近测试场。

任的胸口像被什么东西从里面轻轻拧了一下。

“零级。”记录员确认。

他用夹子夹起那枚薄金属片，放进公开记录匣，又在任的木牌正面刻下两个字。

零级。

刻刀划过木面，粉末从字缝里落下。

任看着那两个字。

他不知道学院的零级意味着什么。是最低的起点？是没有任何视术？是某种只有名字、没有内容的空位置？

可在旁边那些人的眼里，答案已经完成了。

他们不需要知道零级如何测出来。

只要看见它被写在木牌上，就知道任应该站在队伍的哪一边。

“你的东西也叫零？”一个声音从后面问。

任转过头。

一个脸上还带着笑的新生朝侧廊扬了扬下巴。

“我是说那个。”

零没有看他。

任的手指放在身侧。

他可以把零叫过来。

可以让它站到自己身边，用两条轮廓证明它和木牌上的两个字不是同一件事。

可那样一来，别人就会把它们写进同一个故事。

任想起门槛前的固定光，想起零退入阴影时没有回头。

“它不是我的东西。”任说。

笑声停了一下。

“那它叫什么？”

“零。”

“这不还是一样？”

“不一样。”

任说完才意识到，自己没有任何证据。

数字已经落进了槽里。

名字却还站在阴影里。

记录员把任的木牌递回来。

无源。

共同看护责任。

零级。

三道浅痕挤在同一块木头上，彼此没有连接，却都在任身上留下了位置。

测试长老仍然没有笑。

她看着那枚薄金属片被收入公开记录匣，确认封盖扣好，才抬起眼。

“继续。”

下一名新生走进安全圈。

任走出白石线。

他没有回到普通新生队伍里。

共同看护责任让他站在靠近外院侧廊的位置，零就在那片阴影里。两者相隔不到十步，却没有任何人把这段距离当成关系。

有人从他身边经过时，故意绕开了半步。

有人朝他胸前的木牌看了一眼，又很快移开。

有人笑了一声，像确认自己刚才没有笑错。

任盯着那枚刚刚落入记录匣的金属片。

0 是一个稳定的结果。

稳定到不需要任何人知道他从哪里来，也不需要知道他在村门外看见过什么。

它干净、明确、容易归档。

正因为如此，任感到一种说不出的不安。

他站在侧廊的阴影里，看着零的轮廓一点点贴近墙根。

“你还好吗？”他问。

零没有回答。

它只是把自己的边缘压进了石墙与地面之间那条更暗的缝里。

像是连看别人笑，都嫌太亮。

测试继续进行。

记录员将下一个木牌推到石盘旁边。

长老低头检查刻度，固定光照从石盘移到金属环。

然后，刚才还安静的记录槽里又响了一声。

任抬起头。

一切发生得很慢。

不是白界的嗡鸣。

不是村庄遭袭时那种看不见的重量。

金属环开始转动。

它先对准石盘中心，随后又向左偏了半寸。环上的光沿着内侧亮起，试图把自己合拢起来。

合到一半。

停住。

记录员手里的炭笔落下。

笔尖碰到纸，却没有留下完整的黑线。它像被纸面拒绝，落下一点粉末，又弹起。记录员重新落笔，结果还是一样。

固定光照照着任的手。

任看见自己的皮肤。

看见石盘。

看见金属环。

颜色没有退去。

白界没有回来。

可装置内部的某种顺序正在断开。

任本能地想寻找它的边缘。

如果金属环是对象，哪里是它的边界？

如果光是输出，为什么它不能照亮记录？

如果刚才的 0 已经落下，为什么现在的装置像是无法继续沿着同一条路走？

他想问。

他想让记录员停下，重新摆正石盘，检查金属环的接缝。

可那不是水盘事故。

没有一个盘脚松了。

没有参照旗被风吹动。

没有火线越过白石。

这一次，失去形状的是输出本身。

“停。”测试长老说。

笑声在这一声里彻底消失。

记录员抬起头。

“是装置坏了吗？”

长老没有回答。

她走到石盘前，低头看着停在半闭状态的金属环。她用手背靠近固定光，没有碰到任何术具。

金属环没有继续动。

记录槽里的炭笔又落下一次。

纸上只出现一截断掉的笔画。

石盘中央忽然浮出一行字。

不是刻度。

不是数字。

字母一笔一画亮起，光比刚才的 0 更冷。

`Undefined`

任盯着那一行字。

他认识它。

正因为认识，才更加无法接受。

人群里有人向后退。

“那是什么？”

“是不是坏了？”

“刚才不是零吗？”

没有人笑。

他们的恐惧比笑声安静得多。

任听见自己的心跳。

0 还在公开记录匣里。

它没有被擦掉。

装置没有把它改成别的数字。

Undefined 出现在它之后。

不是更小。

也不是更大。

像是同一块地面上，忽然出现了一条不能沿着原路继续走的缝。

“长老。”一名教师低声说。

测试长老的表情第一次改变。

不是惊恐。

更像是她在石盘上看见了某种本不该出现在公开测试里的旧字。

她抬手。

“所有人离开安全线。”

没人立刻动。

“现在。”

教师开始驱赶新生。队伍向后退，鞋底擦过石地，木牌彼此碰撞。刚才还在笑的人低着头，不再看任。

任站在安全线内。

“刚才不是 0 吗？”他问。

长老看着他。

“先记住顺序。”

“这是什么意思？”

“先出去。”

任没有动。

长老的视线落在他胸前的木牌上。

“零级先成立。”她说。

她没有说零级是对的，也没有说它是错的。

记录员从临时公开记录匣里取出那枚薄金属片，用夹子把它转入任木牌背面的窄槽。金属片轻轻一响，像一颗小小的牙齿咬进木头。

然后长老从桌下取出一块新的纸板。

纸板比任的木牌大，边缘包着深色皮革。她把纸板放在石盘旁，亲自写下刚才浮出的字。

`Undefined`

她没有把纸板交给任。

也没有让记录员把它挂到任的胸前。

封蜡在火上融开，落在纸板下方，形成一小滴暗红色的圆。

长老把印章压下去。

“后面的东西，不在今天的公开记录里。”

这不是解释。

是一道被合上的门。

任看着那道门。

羞耻还没有消失。

刚才所有人的笑声仍然像细小的砂子，卡在他的耳朵里。可羞耻下面又有另一种东西正在发热。

他想知道为什么。

为什么是 0 之后。

为什么不是先出现 Undefined。

为什么装置能给出一个稳定的数字，却不能把后面的状态放进同一条记录里。

他想证明装置错了。

也想知道装置究竟看见了什么。

“复验什么时候？”任问。

长老把封蜡纸板压在掌下。

“会通知你。”

回答仍然没有解释。

测试暂停。

新生被教师带离测试场。有人经过任身边时，目光落在他胸前的木牌上；有人低声读出“零级”；还有人只是低头走过去，仿佛只要不看，自己就不会被卷进那块封蜡纸板。

那名读数异常高的学生走在队伍最后。

经过任身边时，他停了一下。

他看向长老掌下的封蜡纸板。

只看了一眼。

那一眼没有笑意，也没有怜悯，更不像是在等待任出丑。

他抬起眼，向任礼貌地点了点头，然后离开。

任站在原地。

如果那是轻蔑，他反而容易理解。

可那不是。

那更像一次真正的观察。

任第一次觉得，自己不只是被归档成一个笑话，也可能已经成为别人想要比较的对象。

这让他比笑声更不舒服。

边境视术师站在测试场外，没有走进安全线。他看了一眼任的公开木牌，又看了一眼长老手下那块封蜡未干的纸板。

“不要把装置的输出当成你的全部。”他说。

任看着他。

“你们是不是早就知道会这样？”

“不知道。”

“那你为什么这么说？”

“因为我见过太多人把自己交给一块牌子。”

视术师转身离开。

任走向外院侧廊。

零在那里。

它没有靠近测试场，也没有看那些离开的新生。固定光照把墙面切成明暗两块，零正蹲在一条更暗的墙根旁。

墙根有一道水痕。

水痕从石缝里流出来，在某处被另一块石头挡住，转向了更深的阴影。

零看了很久。

任走到它旁边。

“他们叫我零级。”他说。

零没有抬头。

“我得到的是一个 0。”

仍然没有回答。

任望向测试场。

“然后它变成了 Undefined。”

零把那片贴在墙根的阴影往更深处挪了一点。

它没有安慰任，也没有解释那两个词之间有什么关系。

任忽然觉得这很好。

如果零现在说出一个答案，他也许会立刻把答案当成新的边界。

“你不是我的零。”任说。

零终于抬头看他。

那道目光里没有赞同，也没有否定。

它只是看了一眼，然后又转回墙根的水痕。

任没有再追问。

测试长老从记录厅的门缝里看向外院。

她的表情已经恢复平静。

只有压在封蜡纸板上的那只手没有移开。

任低头看自己的木牌。

公开面上，三个字已经刻好。

零级。

背面那枚薄金属片被木槽卡住，只露出一个清晰的圆形刻痕。

远处，封蜡还没有完全冷却。

那块不属于公开记录的纸板上，只有一个词。

`Undefined`
