# 第八章　映入者

任向灯火走了一步。

零没有跟上来。

它停在树影里，轮廓被夜色切成一段一段，像一件还没有决定是否要被看见的东西。

任回头看它。

峡谷深处传来沉闷的撞击。

声音沿着岩壁传过来，先在远处变小，再在脚下重新震响。

魔物还没有找到他们。

但它正在找到新的路。

“走。”任说。

零仍然不动。

任没有再催。

他往前走了几步，等到灯火照亮肩膀上的血，才发现零已经沿着更暗的一侧跟了上来。

它没有进入光里。

只是在光的边缘保持着距离。

峡谷出口外是一段向下的缓坡。

坡底立着一排木栅。

木栅不高，横杆却密得不像用来挡人的。

每根木桩上都刻着三道不相等的短痕，短痕中填着暗红色的粉末。夜风吹过时，粉末没有飞散，只在灯影里露出一线很细的颜色。

任看不懂那些刻痕。

他先看见了灯。

栅门两侧各挂着一盏黄灯，灯罩上开着窄缝，把光切成一条一条的亮带。

一名巡夜人站在栅门旁，手里握着一根长柄钩杆。

他没有立刻靠近任。

先看任身后。

再看峡谷方向。

峡谷里又传来一次撞击。

巡夜人的手指收紧了钩杆。

“停在那里。”

任停下。

他听懂了。

不是猜出来的。

也不是像听见零说话那样，先从声音里判断情绪，再拼出意思。

那句话本身就在他脑子里变成了可以理解的声音。

任看着巡夜人。

巡夜人也看着他。

“水。”任说。

他的嗓子干得发疼，声音几乎裂开。

“还有布。”

巡夜人愣了一下。

他向后喊了几句。

任没有听出那几句和自己刚才说的话有什么关系，只看见一个年轻女人从栅门后跑出来，手里抱着一只陶壶和一卷灰白色的布。

她没有走近。

把陶壶放在栅门外的石块上，又把布卷压在壶旁边。

然后立刻退回灯影里面。

任盯着那只陶壶。

他短暂地松了一口气。

村里的人听得懂他说话。

至少他们听得懂“水”和“布”。

这个世界没有先要求他证明自己是谁，才允许他活下去。

下一刻，巡夜人把外侧那盏黄灯的遮片拉下了一半。

光线从坡面上收回。

任这才发现，村里的灯不是同时熄灭的。

先是最外侧的灯罩合拢。

然后是栅门上的灯。

最后，居民区深处的一盏灯向内缩成一点暖色。

像一条看不见的线正在从外向内收紧。

巡夜人对年轻女人说：“外灯先关。”

“里面的人还没——”

“先关。”

他的声音不大，却压过了女人后半句。

任回头看向峡谷。

夜色里什么也没有。

只有灰尘在出口上方缓慢地飘。

他们担心魔物跟着他过来。

任走到陶壶旁，蹲下去。

他先闻了闻。

水没有异味。

然后他看了巡夜人一眼，才把壶举起来。

第一口水进入喉咙时，他差点咳出来。

身体太久没有得到足够的水，连吞咽都变成一种需要重新学习的动作。

他没有一次喝完，只把水含在嘴里，等干裂的喉咙适应之后才慢慢咽下。

肩膀上的伤口随着手臂抬起重新发疼。

他把陶壶放下，扯开灰白布卷。

布不干净，却比衣服内侧的破布厚。

任刚把旧绷带拆开，血腥味立刻散到冷风里。

年轻女人下意识向后退了一步。

“他要在外面包。”巡夜人说。

这句话任听懂了。

也听懂了其中没有询问的意味。

他低头给自己重新缠布。

零停在坡上的树影里。

它一直没有靠近陶壶。

任抬头看它。

“过来喝水。”

零没有动。

巡夜人握紧了钩杆。

“它喝什么？”

“水。”

“它是什么？”

任看着零。

这个问题他已经被问过很多次。

他自己也没有答案。

“它跟我一起。”任说。

巡夜人没有把钩杆放下。

木栅后方传来一阵脚步。

几个人停在灯影里，没有走出居民区的边缘。

他们先看任，再看任身后的黑暗。

零在这时向前移动了一点。

它的轮廓刚好进入外侧黄灯被窄缝切开的亮带。

灯光没有照出它的身体。

只照出一段不稳定的黑色边沿。

那段边沿没有和地面形成正常的影子。

光落在它身后，影子却断在半途，像某个应该存在的东西被人从中间擦掉了。

木栅后立刻传来一声吸气。

有人把孩子往屋檐下拉。

“别靠近。”一个女人说。

她的手臂护在孩子头顶，眼睛却没有离开零。

“它没有影子。”

“灯影对不上。”巡夜人说。

他的声音里没有愤怒，只有一种守栅时才会有的紧张。

“我看不清它是不是还在原地。”

“它就在那儿。”任说。

“你怎么知道？”

任没有回答。

他知道零在那里，是因为那段黑色轮廓仍然贴在光的边缘。

可如果灯光无法照出完整的身体，谁能证明下一刻它还在原来的位置？

巡夜人的职责不是相信。

是确认。

而零偏偏是一个无法被灯光确认的东西。

峡谷深处再次传来撞击。

这一次更近。

栅门上的三道刻痕同时泛起暗红色的光，又在下一瞬熄灭。

任看见了。

那不是白界里的线。

不是 Edge。

也不是他熟悉的任何东西。

木栅后的几个人却像看见了某种再普通不过的警告。

他们向后退了一步。

“人可以进。”巡夜人说。

他盯着零。

“那个东西不准进村。”

任的手指停在肩膀的布带上。

“它不会伤人。”

“你怎么知道？”

“它已经跟了我很久。”

“所以你还没死？”

巡夜人看向零。

“这不能证明它不会伤别人。”

一个站在门后的男人说：“它要是没有影子，怎么知道它还在不在？”

“它刚才已经退了。”有人回答。

“退了不代表走了。”

“别吵。”赫恩说。

声音不高。

却让门后的几个人同时安静下来。

任这才注意到，老人站在栅门内侧的暗处。

他身上的衣服很旧，肩膀披着一件颜色深得看不出原本是什么的外衣。头发被风吹得乱，手里没有武器，只有一盏用铜片包住边缘的小灯。

赫恩先看任的脸。

再看任身后的空路。

最后看向零。

他的目光在零的轮廓上停得太久。

不是害怕。

更像是在判断自己究竟看见了什么。

峡谷里的声音又响了一次。

赫恩抬头听了听。

然后看回任。

“映入者？”

这个词从他口中出来时，语气不像是在询问名字。

更像是他先看见了某种不该出现在这里的东西，随后才发现自己把它说了出来。

任没有听过这个词。

但他听懂了。

“什么是映入者？”任问。

赫恩的脸色立刻变了。

那变化很短，像灯火在风里抖了一下。

“没什么。”他说。

他把灯往任肩膀上的伤口旁移了移。

“你只是受伤了。”

“你刚才说的是——”

“我说你只是受伤了。”

赫恩看向巡夜人。

“给他水，给他布。”

“已经给了。”

“那就别让他站在栅门正中。”

巡夜人先看了赫恩一眼，才挪开一步。

不是让任进村。

只是让开木栅前那块最亮的地方。

任明白了。

他们愿意让他活着，却不愿意让他成为灯下所有人的问题。

零又向后退了一步。

它的轮廓从黄灯亮带里离开，重新融进树影。

女人护着孩子的手没有放下。

“它要扑了。”她说。

零停住。

它没有扑。

只是那段轮廓在树影里变得更薄。

任看见它在看自己。

不是看村民。

不是看灯。

而是在等任决定下一步往哪边走。

任看向木栅门。

门后有水，有火，有人能包扎伤口。

门外有零、冷风、峡谷里还没有死去的魔物，以及一条随时可能被重新堵上的路。

他只要往前一步，就能进入灯影里面。

巡夜人已经侧开身。

没人再拦他。

任迈出半步。

零的轮廓在树影里向后缩了一寸。

任停下来。

他收回脚。

“它跟我一起。”他说。

巡夜人抬眼。

“那你也别进。”

任的肩膀开始发麻。

伤口重新渗出的血沿着布带往下浸。

他看着那扇并不算高的木栅门。

他没有力气和一群陌生人讲零是什么。

也没有证据证明零不会伤人。

更没有资格要求别人接受一种连他自己都解释不清的存在。

可他不想把零留在这片黑暗里。

不是因为他已经相信零。

而是因为他知道被单独留下是什么感觉。

任慢慢放下手。

“那就都不进。”

这句话说完，他转身面向峡谷。

零的轮廓没有移动。

木栅后的女人小声说了句什么。

巡夜人皱起眉。

赫恩却看着任。

他看了任一会儿，忽然对门后的男人说：

“把外栅旁的工具棚打开。”

“那不是给人的。”

“今天开始可以给受伤的人。”

“那个东西呢？”

赫恩看向树影。

“留在灯影外。”

“要是它靠近住屋——”

“我会看着。”

“你看得见它吗？”

赫恩没有立即回答。

“我看得见它有没有越过灯影。”

这句话说得很轻，任没有确定自己是否听清。

赫恩对巡夜人说：

“把刚才那壶水和剩下的粗布留下。不要叫治疗师。”

巡夜人看向任的伤口。

“他需要——”

“我知道他需要什么。”赫恩说，“但今晚村里没有位置给他。”

这句话比“不准进村”更直接。

任把刚才那只陶壶和剩下的粗布带进工具棚。

没有食物。

没有热汤。

没有人邀请他进入居民区。

工具棚在外栅旁，门板只有一半，里面堆着旧木柄、断裂的车轮和晒硬的绳索。棚顶漏风，地上铺着一层没有完全干透的稻草。

任走进工具棚一步。

零留在灯影之外。

它退到更远的树影里。工具棚门口的风穿过残缺的木板，隔开了两人的低语；它只能看见赫恩和任的嘴在动，听不清他们说什么。

两者之间隔着一段不长的黑暗。

却比峡谷更像一道边界。

任坐在旧木箱上，重新包扎肩膀。

粗布磨过伤口时，他的手指控制不住地发抖。

零站在灯影边缘，没有看村内的人。

它只看任。

“你要进去吗？”零问。

任把布带绕过肩膀。

“不是进去。”

“那是什么？”

“先活下来。”

零沉默了一会儿。

它没有说“好”。

也没有说“那你进去”。

只是把自己的轮廓再往树影里挪了一点。

村里的灯继续向内收拢。

最外侧的黄灯彻底熄灭。

门柱上的灯罩合上，只留下窄缝里一线很细的光。

居民区深处仍有人走动。

任听见碗碰到桌面的声音，孩子压低的哭声，还有一个女人在问巡夜人外面的东西走了没有。

巡夜人回答：“还在。”

“那为什么不赶走？”

“因为峡谷里的那个更麻烦。”

任抬起头。

他第一次意识到，赫恩不是因为相信他才暂时收留他们。

只是因为零留在村外，比魔物直接撞进村里更容易控制。

这种帮助仍然是帮助。

但它带着价格。

夜深以后，人群散开。

赫恩站在工具棚门口，手里的铜边小灯没有照向零，只照亮任坐着的半边脸。

“你的名字。”他说。

“任。”

赫恩把这个音节在嘴里过了一遍。

“从哪里来？”

“林子里。”

“之前呢？”

任看着他。

电脑、办公室、城市的玻璃窗、凌晨还亮着的楼层，一连串不可能被解释的东西从脑子里掠过。

“我醒来就在林子里。”他说。

赫恩没有追问。

他只是把灯抬高了一点。

任的袖口因为包扎被挽到手肘上方，内侧手腕暴露在灯下。

赫恩伸手握住他的手腕。

动作不重，却让任立刻绷紧了身体。

“别动。”赫恩说。

他用拇指擦过任腕内侧一小块皮肤。

那里什么也没有。

没有伤口。

没有疤。

也没有任能理解的痕迹。

赫恩的手指停住了。

他看了任一眼。

那一眼里第一次出现了真正的警惕。

任想把手抽回来。

“怎么了？”

赫恩松开他。

“别让城里的人知道你没有源痕。”

任低头看向自己的手腕。

“源痕是什么？”

赫恩站在工具棚门口，背后的灯光被窄缝切成几段。

“每个出生在这里的人，都该有。”

他没有再说。

远处的峡谷里传来魔物的声音。

村里的灯一盏接一盏熄灭。

任看着自己的手腕。

那里什么也没有。

零在灯影外抬起头。

任第一次觉得，村外的黑暗和村内的灯光，正在同时把他们留在各自的范围里。
