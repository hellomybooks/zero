# 项目验证工具

`validate_project.py` 是项目结构与来源边界的机械检查，不判断文学质量，也不替代 Canon、连续性或奇幻感审校。

在项目根目录运行：

```bash
python3 tools/validate_project.py
```

它会检查：

- `01-原始资料/` 中已归档的 v1—v7 原始资料、共享页面 HTML、完整转录、原始对话核对回复和 v1—v4 恢复状态记录的 SHA-256 是否变化。
- Canon、结构化设定、第一卷维护入口等必需文件是否存在。
- `02-Canon/` 是否只有一个正式 Canon 入口。
- 原始资料、Canon、结构化设定、第一卷设计、正文和审校六个层级是否都有入口 README，且项目导航仍将第一卷标为当前生产目标。
- 仓库根目录的 README、AGENTS、STATUS、CANON orientation 和 CORE-SEED 冷启动入口是否存在且保留关键导航标记。
- 第一卷、第二卷、第三卷章节卡与正文编号是否连续且文件名对应。
- 三卷每一章是否至少有一份章级审校记录；第一卷第1—2章的历史通用命名也按章节号计入覆盖。
- Markdown 相对链接是否指向存在的文件。
- 第一卷外部审核包是否存在，是否保留首次阅读隔离规则、无剧透简介、第1—36章正文直达链接，以及观察 / 推测 / 评价、阅读行为、影响范围和严重度理由等反馈字段。
- 第一卷高风险正式术语的时序、禁止项和身份泄漏。

原始资料区的源页面尾随空格属于保真内容；本工具不对它执行格式化写回。
