# 项目验证工具

`validate_project.py` 是项目结构与来源边界的机械检查，不判断文学质量，也不替代 Canon、连续性或奇幻感审校。

在项目根目录运行：

```bash
python3 tools/validate_project.py
```

它会检查：

- v1—v7 原始资料和共享页面 HTML 的 SHA-256 是否变化。
- Canon、结构化设定、第一卷维护入口等必需文件是否存在。
- 第一卷、第二卷、第三卷章节卡与正文编号是否连续。
- Markdown 相对链接是否指向存在的文件。
- 第一卷高风险正式术语的时序、禁止项和身份泄漏。

原始资料区的源页面尾随空格属于保真内容；本工具不对它执行格式化写回。
