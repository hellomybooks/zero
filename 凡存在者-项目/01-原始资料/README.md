# 01｜原始资料层

这里保存从共享会话、原始页面和人工核对中得到的来源材料。来源层只读保留，不因正文写作需要而静默改写，也不会自动升级为 Canon。

## 当前入口

- [共享会话逐版本原文索引](./共享会话原文/README.md)
- [共享会话完整转录](./共享会话-完整转录.md)
- [原始对话核对回复](./原始对话核对回复.md)
- [v1—v4 资料恢复状态](./缺失与恢复状态/v1-v4-资料状态.md)

## 使用规则

1. 需要确认来源时，先查本层文件和原始页面 HTML 快照。
2. v1—v7 按版本职责读取，不能以最新版本静默覆盖旧版本。
3. 来源材料与当前设定发生差异时，进入 [Canon 权威层级](../02-Canon/权威层级.md) 和 Canon Change 流程。
4. 原始文件的 SHA-256 由 `tools/validate_project.py` 持续校验。
