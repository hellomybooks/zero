## 本卷生产边界

- “流动大陆”必须先以道路、地面、聚落和地图实际错位的事件出现，不能先用概念解释。
- 诺克先作为一个极其好用的同行者进入：他能提前发现运动、计算路线、预测短程变化，但不直接替别人作决定。
- 诺克的预测不是未来视，也不是全知；它依赖观察时长、相对运动和稳定参照，面对人的临时选择、被遮挡的变化和新信息会失效。
- 任可以喜欢诺克的说话方式和能力，但不能立刻看出“建议”背后的责任逃避。
- 本卷不能把“缺失区域”立即解释成零、第三声、界兽故乡或古代阴谋；证据必须先以地图、道路、归属和人的选择出现。
- 第二卷结束时的分水损失、阿尔德名字传播、无名申请人、第四照护位未建立和第三声未知边界必须继续存在，但不能每章重复回顾。
