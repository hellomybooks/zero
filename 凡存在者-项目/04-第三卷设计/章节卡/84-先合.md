# 第三卷第八十四章《先合》场景卡

## 状态

- 状态：已完成独立 Canon / 文学最终窄回归，标记为定稿候选。
- 承接：第三卷第八十三章《半沟》场景卡与正文；第83章已标记为定稿候选。
- 篇章：第三卷 ARC 07《流动大陆》第十二章，ARC07 收束章。
- 情绪主轴：诺克 / 任；露米与零在章末自然进入下一阶段的情绪视角。
- 情绪方向：任第一次看见诺克的局部判断被普通人主动转成共同安排。他这次没有擅自把诺克的话补成命令，却也没有及时阻止别人把“先接上”当成“今晚就按这边走”。诺克仍不完成承担责任的成长，只把判断范围留在地面；露米与零因具体生活方向暂时走向另一边。
- 本章功能：不新增视觉概念，收束诺克加入后“轻松 → 佩服 → 不适”的第一段关系；把运动判断从个人有用推进到公共使用，让“建议”第一次由一群普通行人主动转成共同安排；为第85章《地图之外》留下没有铺石、没有路签、却带有生活方向和痕迹的低草路径，不正式进入 Missing Region。
- 主概念：一段地面先与另一段接合，不等于另一段断裂；“先接上”可以帮助人安排今晚的行走，却不自动决定谁应该走、谁应该等待或哪条路更有价值。
- 技术翻译层：继续使用诺克已有的 optical flow / 相对运动观察边界；不新增 CV API，不在正文解释技术。技术只通过两条都真实存在的生活路径、几次短暂接合和人们对半句判断的使用进入故事。

## 一句话梗概

第83章清沟后的同日下午，主角团在最后一段铺石外遇到几名各自赶路的普通行人：一边是沿浅色石缘返回铺石内侧的路，另一边是穿过低草、朝向外侧一扇普通木门的路。两条路都没有消失，也都有人使用，只是地面移动时白石边会先与内侧硬地接上。诺克说“白石这边先靠”，又补“草路没有断”；一个行人明知他没有决定权，却把这句话转成“今晚按白石边回”的共同安排。任准确复述，却没有补上“这不等于所有人都走白石边”。一名外侧行人仍走自己的方向，露米跟上几步，零看了一眼后自行跟去；任抬手又放下，留下继续看白石边接合。两条生活路径暂时分开，诺克仍只看见地面，不替任何人解释归属，铺石之外仍是普通地面。

## 本章不能做的事

- 不能把本章写成“诺克说某条路—任复述成命令—物件受损”的重复结构；第75、80、81章已经承担过判断进入行动后的具体损失。本章的后果是公共安排和人物站位改变，不新增水罐、布料、奶桶或路签损失。
- 不能让诺克判断哪条路正确、哪户更重要、谁应该等待或谁必须跟随；他只描述白石边与内侧硬地的先后接合，以及草路当前没有断。
- 不能把普通人主动采用诺克的判断写成被魔法控制或单纯误听；他们知道诺克只说了先后，仍在时间、家和同行压力下把事实变成今晚的安排。
- 不能让任完成“数据给你信息，但做决定的人还是你”的成熟总结；他只准确复述半句，却没有及时补足范围，动机可以是想看看共同安排是否真的减少混乱。
- 不能重复第74、76章的追队或街区错过、第78章的门缝窗口、第80章的路签收回；本章没有公共路标、收路人、窄车、门缝或追赶队伍。
- 不能把白石边与低草路写成一真一假、一个安全一个危险；两条都是普通人的生活路径，区别只是今晚的接合先后和各自目的地。
- 不能把露米跟随外侧行人、零跟随露米写成“这里才是自己的地方”“零不想回去”或 ARC08 的归属答案；他们只沿着具体的低草路径走几步，不抵达木门、不进入住处。
- 不能安排告别、争吵、责备、团队解散或诺克正式离队；本章只让队伍短暂分成两个可见的行走方向，未来仍可以重新相遇。
- 不能让低草路径、远处普通木门、铺石内侧或白石线成为 Missing Region、第三声、零身份、诺克哥哥、古代文明或流动大陆本体的直接证据。
- 不能新增 CV-16 warpPerspective 或任何透视重建、视角校正、区域裁切概念；第84章只收束已经建立的运动观察边界。
- 不能新增第四照护位、补给、住所、路线册权限、正式同行身份或新的长期配角关系。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、template matching、特征、模板匹配、算法、系统、代码、霍夫、直线检测、字段或模型等作者侧技术词。

## 核心规则与本章新增边界

### 1. 两条路径都存在

- 白石边路径沿着几段旧浅石和内侧硬地走；低草路径沿着住户之间的踩实土面走。两条路径都有人走过，都有脚印、草倒和普通生活痕迹。
- 白石边会先与内侧硬地靠拢，但这不表示低草路断裂、消失或错误；它只说明当前这一次地面运动中，哪一侧先形成较连续的脚下平面。
- 低草路径可能在白石边接合后继续向外侧偏开；外侧行人仍可沿它继续，不能因为没有铺石就被写成不存在。
- 诺克需要观察同一块浅石边、内侧旧墙脚和低草边缘至少两次连续位移，才能说出先后；他不从静止相似外观判断哪条是“真正的路”。

### 2. 诺克只说先后，不说安排

- 诺克说：“白石这边先靠。”这是对接合顺序的描述，不是“所有人今晚走白石边”。
- 他随后补：“草路没有断。”这句话防止把另一条生活路径写成被排除的空白，但不告诉住户该如何分配同行。
- 当有人问“那今晚按哪边走”，诺克可以看着两条路不回答；如果必须开口，只说“你们各自回”。这不完成道德判断，也不替人安排同行。
- 诺克不能判断谁的家更近、谁的工具更急、谁的承诺更重要，也不能预测一群人是否愿意暂时分开。
- 他不应把“建议”变成“命令”，但他知道人们会把局部事实拿去做安排；他的沉默和有限说明本身也会成为现场的一部分。

### 3. 普通人主动把事实变成共同安排

- 一个内侧行人说：“那今晚就按白石边回。”他说的不是诺克的原话，而是自己的安排；他知道草路没有断，却不愿为所有人等待下一次接合。
- 任可以补：“他只说白石边先接。”但不能立即接上“所以你们都走这边”；他的准确复述仍然可能给这项安排增加可信度。
- 外侧行人说：“我不走白石边。”她没有争辩哪条路是真的，只把自己的方向说出来。
- 人们根据家、工具、天色和同行关系自行分流：想回内侧的人走白石边，外侧行人走低草，另外的人各自决定是否同行。
- 没有人宣布谁被赶走，也没有人把低草路命名为被裁掉的区域；这是一次有生活原因的分路，不是制度分类。

### 4. 接合会暂时分开人，但不决定关系

- 白石边与内侧硬地先接上，任、诺克、赛恩、伊莉亚和部分行人可以通过；低草路向外侧偏开，露米、零和外侧行人仍在视野内，但中间多出一段普通硬土，不能立刻横跨。
- 这是暂时的物理分隔，不是危险封锁、传送、结界或空间异常；下一次地面变化可能让两边重新靠近，也可能让他们走远。
- 任短暂抬手，想叫露米和零回来观察白石边；他看见外侧行人已经走向低草，于是放下手。这个动作不是成熟的放手，也不是对伙伴的抛弃，只是他再次选择继续看。
- 露米跟上外侧行人几步，是为了确认低草确实能让人行走，不是为了证明外侧更真实；零看了一眼后自行迈步，不等待任的许可。

## 场景设计

### 场景一：两条都有人走的路

- 现实入口：先写主角团走过一片宽阔的普通硬地。诺克抬手指向一条干燥的浅色带：“走这边。”他们少绕过一段被湿草遮住的软地，没人摔倒，也没有物件损坏；任甚至先笑了一下，像终于有人替他们把路上的小麻烦提前拿走。随后才出现外侧行人提着空篮在低草路口停住、内侧行人站在浅色铺石边回头看天色。主角团先让出中间位置，不把普通人变成等待诺克开口的观众。
- 生活冲突：内侧行人要在天暗前回去取遗下的工具，外侧行人要沿低草方向办完自己的事；他们原本想暂时一起走，却发现两条路径的接合时间不一样，不能把所有人的目的地压成一条路。
- 现场对白：内侧行人说“白石以前能接回去”；外侧行人说“草路一直有人踩”；两人都没有说错。
- 露米的动作：她把任往铺石边让半步，自己站到低草和白石之间，不替双方排序。
- 零的动作：零看了一会儿两条路径上被压平的草茎，又低头看自己的鞋尖；不捡石，不排线。
- 世界推进：流动地面改变的不是抽象地图，而是几个人今晚能否继续并肩走；公共路线之外的生活路径先以人的目的出现。

### 场景二：诺克只看见先后

- 连续观察：诺克蹲在白石边外侧，看同一块浅石、内侧旧墙脚和低草边缘连续靠近两次；他没有拿出路线图指向任何方向。
- 诺克说：“白石这边先靠。”
- 外侧行人问：“草路呢？”
- 诺克看向低草：“没有断。”
- 内侧行人问：“那今晚按哪边？”
- 诺克看着两条路，没有回答。他没有说“建议全走白石边”，也没有说谁应当等。
- 任听见这句话，立刻想在旁页写下“先后 / 目的地分开”；他停住笔，因为露米已经把纸角压住。
- 露米说：“先让他们自己说。”她没有替任总结，也没有把诺克的边界翻译成伦理判断。

### 场景三：半句变成今晚的安排

- 内侧行人听完后说：“那今晚就按白石边回。”他说的是自己的安排，声音却足够让另外几个人听见。
- 他没有说草路不能走；他只是觉得不值得为一条尚未接上的地面继续等。
- 任准确复述：“他只说白石边先接。”他没有加“你们都跟上”。
- 但内侧行人点了点头：“我知道。”然后对自己的同行者说：“我们走。”
- 这不是单纯误听。普通人知道事实的范围，仍主动把它缩成一个今晚可执行的秩序，因为时间、家和同行意愿都不够。
- 外侧行人提起空篮：“我往外边走。”她没有等待任或诺克批准，也没有要求别人证明低草路会一直存在。
- 诺克没有纠正内侧行人的安排，也没有替外侧行人辩护；他只是继续看白石边的接缝。
- 任看见这一幕，第一次发现自己的准确复述即使没有错误，也可能帮助一个安排获得公共重量。

### 场景四：露米和零走几步

- 外侧行人走出几步，低草里有一段被雨压倒的草根横在脚前；她蹲下把草根拨开，露米跟过去扶住空篮底。
- 露米说：“这边能走。”这句话只说明她对脚下的判断，不说明低草路的价值，也不替零定义方向。
- 任短暂抬手，想叫露米回来继续看白石边什么时候接上；他的手停在半空，最后放下。
- 赛恩问：“不等她们？”不是责备，只是确认队伍是否还算在一起。
- 任说：“她知道自己去哪。”说完自己也觉得这句话太快，便不再解释。
- 零看了一眼白石边，又看外侧行人脚下的草根。他没有等任喊，也没有被露米牵住；他自己迈进低草，保持与露米几步距离。
- 伊莉亚想问露米是否需要扶篮，露米摇头，她便收回手；没有新增照护位。
- 露米回头看任一次，没有挥手，也没有告别；她只是确认任仍站在白石边，然后继续走。

### 场景五：白石边先合

- 地面变化：白石边与内侧旧墙脚靠拢，接缝变窄并形成一段能让人连续踩过的浅平面；低草路向外侧偏开，但草根和土面没有消失。
- 内侧行人带着同行者通过。他回头喊：“这边接上了。”这句话只报告自己的位置，却在现场再次强化了白石边的共同安排。
- 任跟着诺克踏过接缝，没有碰任何路标或石块；他看见低草一侧的露米、零和外侧行人仍在视野里。
- 诺克被一名同行者问：“下一次还接吗？”
- 诺克看着接缝：“会动。”
- 对方等了一会儿：“那会不会接？”
- 诺克把视线移向低草，把扁石在掌心换了一个方向，没有回答。过了一会儿，他说：“再走的时候再看。”这不是终局的“我不知道”，只是把判断留在尚未发生的下一次。
- 任听见这句话，想问“那我们等不等”，没有问；他把笔按在旁页上，没有写下新的规则。
- 两边暂时分开：中间是一段普通硬土，跨过去需要绕行，不是无法返回的深渊或空间裂口。

### 场景六：谁都没有被解释

- 低草一侧：外侧行人带露米和零绕过压草，走到一段能看见远处半开普通木门的低草边就停下；她没有邀请他们留下，也没有向门内发声，更没有与门后的人相遇。
- 白石一侧：任、诺克、赛恩、伊莉亚和内侧行人停在旧墙脚旁，等接缝再次变窄后继续向内侧走。
- 赛恩看着两条线在视野里分开，说：“两边都在。”这句可以说，但不能变成作者主题总结；它只回应眼前的地面。
- 任把“白石先靠 / 草路未断 / 人各自回家”写在旁页，写到“谁决定”时停住。他没有把空白改名为缺字段。
- 诺克没有追向低草，也没有要求主角团等他；他只是把扁石换到左手，继续走内侧。
- 露米没有回头叫任；零回头看了一眼铺石边的浅色石背，随后跟上她。两人停在距木门仍有一段普通硬地的位置。

### 场景七：先合之后

- 章末画面：铺石内侧的白石边在任身后重新错开，低草与远处半开的普通木门在露米与零前方显出一小段；两边都属于同一片普通地面，却暂时不能从同一个站位看全。门前没有人、声音或异常脚印，露米与零没有靠近。
- 任打开旁页，画出两条线，在分开处留下一段空白。他没有写“错误路线”“正确路线”或“被裁掉的人”。
- 诺克问：“你不跟她们？”任没有回答；他看了一眼低草，又看向白石边，继续走。
- 这不是决裂，不是归属答案，也不是世界边界揭示；只是一次共同路线暂时无法维持时，几个人各自朝生活目的地走。
- 章末事实：地面会先合后分，普通人的路径与公共安排不总是一件事；诺克仍只负责看见局部，任仍没有完成责任判断，露米与零在没有进入或相遇的前提下抵达第85章的现实入口。

## 人物推进

| 人物 | 开场状态 | 本章选择 | 章末变化 |
|---|---|---|---|
| 任 | 仍期待局部事实能减少所有人的混乱 | 准确复述“白石边先接”，没有擅自补成命令；却没有及时说出这不等于所有人都走白石边，并选择继续观察 | 第一次看见准确复述也会给公共安排增加重量；不适增加，但尚未完成责任判断 |
| 诺克 | 以“建议”保护自己，不主动承担最后选择 | 只描述先后和草路未断；面对下一次是否接合，把判断留给下一次观察 | 他的能力进入普通人的共同安排，却仍没有把安排认领为自己的决定；与任的关系更具体地不舒服 |
| 露米 | 不愿任把普通人和零折成一条说明 | 跟随外侧行人走几步，扶篮、拨草，在远处普通木门前停下，不替低草路命名 | ARC08 前第一次主动让具体站位带着她走，不等于她已解决定义他人的冲动 |
| 零 | 对路径、影子和细小移动保持兴趣 | 自己选择跟进低草，不等待任喊，也不解释选择 | 与露米形成未说明的同行动作；没有获得“同类”“归属”或来源答案 |
| 赛恩 | 能看出两条地面的接合差异，习惯把事实说得清楚 | 只问队伍是否还一起，不替任何一侧裁判；跟随内侧路线 | 看到精确描述无法保持所有人同路，但不提前接受误差哲学 |
| 伊莉亚 | 维持既有三名照护对象 | 询问露米是否需要扶持，得到拒绝后停手 | 照护边界通过一次询问和一次退回继续成立 |
| 外侧行人 | 需要沿低草完成自己的普通事情，不愿被公共路径替代方向 | 明知白石边先接，仍选择低草路，并带着空篮走出视野范围 | 她没有被写成被排除者或谜团，只是一个方向不同的普通人 |
| 内侧行人 | 需要在天暗前回去取工具，不愿无限等待 | 主动把“白石边先接”转成今晚的同行安排 | 他的安排有效地减少等待，却也让共同路线不再覆盖所有人；没有被判定为坏人 |

## 读者此时应该误判什么

- 误以为诺克说白石边先靠，就等于白石边是正确路线；实际低草路也真实存在并被人使用。
- 误以为任没有加错话就已经完成责任边界；实际他准确复述后仍默许一句局部事实承担了公共安排的重量。
- 误以为露米跟低草是因为她认定那里更接近零的归属；实际她只是跟着外侧行人走几步，并处理眼前的草根与空篮。
- 误以为零跟随露米证明他已选择归属；实际只知道他自行迈步，没有解释原因。
- 误以为两条路线暂时分开就是团队解散或进入 Missing Region；实际两边仍在普通地面和彼此可见范围内。

## 章末必须留下的事实

1. 两条都有人使用的生活路径可以在流动地面上先后接合；先接合不等于另一条断裂或错误。
2. 诺克可以准确说出接合顺序与草路未断，却不能决定谁回哪里、谁应等待、哪条路径价值更高。
3. 普通人明知诺克没有决定权，仍会在天色、家和同行压力下主动把局部事实转成今晚的共同安排。
4. 任准确复述但没有及时补足范围；他开始看见自己的转述也会赋予安排重量，但没有完成成熟的责任判断。
5. 露米跟随外侧行人走几步，零自行跟进低草；任、诺克、赛恩和伊莉亚暂时走白石内侧。分路是物理和生活目的造成的暂时状态，不是告别或解散。
6. 低草路径朝向远处一扇没有铺石、没有路签的普通木门；门前没有人、声音、异常脚印或进入动作，这只是下一阶段的现实入口，不是 Missing Region 的解释。
7. 第三声、Missing Region、零身份、诺克哥哥、古代文明、流动大陆本体与 CV-16 保持未知。

## 第二卷后续接口与第三卷伏笔

- 任的旁页继续保留“谁先伸手”与“谁决定”的空白；他暂时没有把空白改写成字段，也没有完成“信息不等于决定”的终局理解。
- 诺克的运动观察从道路、轻物、街区、旧沟推进到“先后关系被普通人用于公共安排”；不新增技术概念，不把能力升级为全知。
- ARC07 的情绪从任对诺克的佩服转为具体不适：任开始看见诺克的建议会被别人依赖，却还不能要求他承担选择，也不能把问题一次说成责任伦理。
- 露米与零沿低草路径走出几步，在没有进入、相遇或获得资格的前提下接入第85章；真正的归属诱惑、被理解感与“也许这里更适合我”留给后续生长。
- 第85章不得从本章直接跳到世界解释；先写普通木门、低草和生活痕迹如何成为视线问题，再逐层建立地图之外的含义。

## 五问自检

1. 本章首先发生在人身上的是否是几名普通行人的家、工具、天色和同行选择，而不是运动观察？——是。
2. 有没有角色做了以后可能后悔的事？——任看见安排形成却没有及时补足范围；内侧行人把局部事实转成共同路线；任最后继续观察而没有追上低草一侧。
3. 有没有一句“正确的话”其实不应该由当前角色说出来？——没有人说“建议就是责任转移”或“低草路代表被排除者”；他们只谈回家、天色、先后和谁跟哪边。
4. 这一章有没有把未来非常重要的东西提前支付？——没有揭示 Missing Region、第三声、零身份或诺克终局选择；分路只是暂时，低草和远处木门只是普通视线入口。
5. 如果删掉所有技术隐喻，几名行人的目的地、两条路的先后接合、任的默许、露米与零的跟随是否仍然成立？——成立。
