# 第三卷第七十三章《不落脚》场景卡

## 状态

- 状态：已完成独立 Canon / 文学窄回归；定稿候选，正文待生产。
- 承接：第二卷第七十二章《分水》正文与正文审校；第二卷正文闭环已经完成。
- 篇章：第三卷 ARC 07《流动大陆》第一章。
- 情绪主角：任 / 诺克。
- 情绪方向：轻松 → 佩服；不适只留下很小的种子，不在本章完成。
- 本章功能：让团队在离开阈值之城后遇到一段真实移动的地面；让诺克以“建议”而非命令救下一段路线；让任第一次觉得有人终于能把混乱提前说清楚；让读者同时看见预测的有效范围和责任的空洞。
- 本章主概念：道路不是因为地图画错才离开位置；地面本身可以移动。一个人可以准确预测下一步，却仍不能替同行者决定要不要走。

## 一句话梗概

离开阈值之城后的第三天，任一行人在一块旧地图标明的石桥前遇到整段地面缓慢横移：桥柱、草坡和驿路正在以不同速度错开，留给他们的不是“正确道路”，而是几次会迅速关闭的落脚机会。一个站在桥头的陌生人诺克先指出石块、尘土和人群的共同运动，连续给出短程建议，带他们避开即将断开的路面；任第一次因为有人能把变化说在发生之前而兴奋。最后，一名赶车人拒绝诺克的路线，诺克没有追上去替他作决定，只说“那是他的选择”，任也没有立刻追问这句话的代价。众人抵达流动大陆的边缘营地，旧地图上的石柱在他们身后慢慢离开原位；诺克提出同行，只说他们的路线暂时相交。

## 本章不能做的事

- 不能把流动大陆写成传说中的概念介绍；必须先让地面、桥柱、道路和人的站位产生可见错位。
- 不能让诺克拥有全知未来、读取思想、解释地面为何移动或预测一个人一定会怎么选的能力。
- 不能让诺克一出场就成为正式队友、导师或权威；本章只建立一次路线上的合作和同行提议。
- 不能让任立刻识破诺克是在用“建议”回避承担；任应先真心佩服这种能力。
- 不能把危险写成大型战斗、城市毁灭或终极敌人；本章的危险是地面移动、道路关闭、车辆和人群在错误位置上的后果。
- 不能用“地图错误”解释全部问题；旧地图在绘制时可以准确，失效来自地面与标志后来移动。
- 不能让任何人因一次正确路线获得永久安全、正式身份、报酬或新的资源承诺。
- 不能揭示 Missing Region 是零的故乡、被裁掉者的聚居地、古代阴谋或第三声来源；本章只让一个区域在地图上出现不稳定的当前位置。
- 不能把第二卷的无名申请人、阿尔德、分水或第三声重新完整复述一遍；只允许通过人物携带的疲惫、纸张空白、谈话停顿或一句短消息留下余波。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、系统、算法或代码等作者侧技术词。

## 核心规则与本章新增边界

### 1. 流动大陆先是身体经验

- 地面不是突然升起或沉没，而是不同地块以不同速度、不同方向缓慢移动；桥柱、路面、草坡和尘土因此出现相对错位。
- 人站在地面上时，身体会先感觉到脚下的微小拖动，随后才看见石缝、尘线和道路位置变化。
- 移动不等于危险本身；真正的危险来自人在旧位置上做出没有更新的动作，例如继续踏上已经离开的桥面。
- 旧地图在绘制时可以准确；它记录的是某个时刻的相对位置，不是永远固定的地面真相。

### 2. 诺克的运动感知限制

- 诺克必须先观察至少两个连续变化，才能判断一块地面、石头、尘土或人群的相对方向；没有变化的目标只能作为暂时参照，不能被他确认稳定。
- 他能判断短时间内的趋势和可能路径，不能说明运动的原因、终点或本体。
- 观察被尘雾、拥挤、遮挡、同时反向运动或人为改变路线干扰时，诺克会降低把握，却不会因此停止说“建议”。
- 对人，他最多判断身体已经开始朝哪个方向移动；不能预测一个人临时改变主意，也不能替人选择。
- 他的建议必须通过石块、脚印、尘线、桥面和人的动作验证，不由旁白宣布正确。

### 3. 本章的路线选择

- 石桥不是“左边正确、右边错误”的固定谜题；桥面和草坡在移动，安全窗口只持续很短时间。
- 诺克可以连续提出“先等”“踩黑石”“不要追车轮”等短建议，但每一次都会把选择留给同行者。
- 任可以询问概率或依据；诺克可以回答趋势，却不能用数字把责任转走。
- 最后一名赶车人拒绝诺克建议并选择另一条刚刚看似稳定的路；诺克不追、不强拉，只承认那是对方的选择。该选择不造成确定死亡，不用悲剧立刻证明诺克正确。

### 4. 同行边界

- 诺克可以提出暂时同行，因为他的路线和队伍路线在流动大陆边缘相交；他不获得正式职务、领队权、资源份额或队伍成员资格。
- 任可以主动邀请他在下一段路同行；诺克回答“建议”，或说“路线目前相交”，不说自己已经加入。
- 本章不揭示诺克哥哥、旧伤、概率创伤或暗恋对象；只允许从他避开“我决定”的措辞和不追赶赶车人的动作中留下性格影子。

## 场景设计

### 场景一：石桥没有在地图上

- 现实事件：队伍按旧地图找到白色测地柱，却发现石桥不在柱旁。任先怀疑地图被改过；零把一枚扁石放在地面，扁石没有立即滚动，却在众人说话时偏移半指；伊莉亚让所有人先离开缝边，不把这句话说成命令。开场的松弛动作在这里被脚下的轻微拖动打断。
- 他们听见桥下没有水声，只有石头相互摩擦的低响。草坡上的露珠朝同一方向移动，桥柱和草坡却不是同一方向。
- 诺克从桥头外侧说：“别站在白柱旁。”他说得像建议，不解释自己是谁；任注意到他没有看地图，而是在看尘土和石缝。
- 章内后果：旧地图没有被宣布为错误，队伍第一次意识到“位置”会过期；任对诺克产生好奇，露米先对一个不报姓名却指挥脚步的陌生人不耐烦。

### 场景二：建议先于危险

- 现实事件：一辆属于过路车夫的小货车从草坡上下来，车轮压过的地面把一条窄缝扩大；诺克先说“往后”，车夫没有听，轮子在缝边打滑。诺克没有冲上去接管车辆，只把一枚扁石踢到可踩的黑石旁，告诉车夫“下一步踩那里”。
- 车辆信息：车上只有两只空木箱和一名随车老人；老人扶着车厢边，车轮打滑时被车身带倒。车夫执意追赶旧地图上的直线，是因为要赶到旧驿路交还空箱，不是为了追随队伍或寻找新资源。
- 任观察诺克的视线：他不盯一个目标，而是在看连续移动的尘土、车轮、人的脚和桥面相互改变的位置。诺克说“建议停一下”，而不是“停下”。
- 赛恩把绳子递给车夫，伊莉亚扶住一名差点被车身带倒的老人但不把老人写入正式照护；零站在一块正在移动的石板上，突然跳回队伍，不解释原因。
- 车夫最后脱险，却骂诺克说话像不肯负责。诺克只回答：“我没有说你必须听。”任第一次觉得这句话很诚实，也第一次没有觉得它刺耳。
- 绳子连续性：车夫脱险后，赛恩收回自己递出的既有短绳；场景四临时营地压帐篷使用的就是这根绳子，不新增第二根或新的补给。
- 章内后果：诺克的能力通过真实动作证明有效；他的“建议”同时保留了帮助与撤退责任的两面。

### 场景三：三十息的路

- 现实事件：桥面与草坡短暂重合，队伍必须在一个狭窄窗口内通过。诺克按地面相对运动给出顺序：先让伊莉亚和老人过，再让赛恩牵绳，最后任与露米；零不按顺序，自己选择另一块正在移动的石板。
- 任追问“为什么不是先走最快的人”，诺克只说“快的人会让桥面更早失去重量”，并指出车轮和人群会改变脚下的压力；他不给出完整理论。
- 露米不喜欢被排在任之后，故意说“那我偏要先走”，诺克看了她一眼，只说“可以，但我建议不要”。她停了半息，仍然先迈一步，桥面没有立刻出事，却让任不得不伸手拉她回来。
- 这不是诺克预测错误；他预测的是桥面趋势，不是露米临时的赌气。露米没有受伤，但任因拉她而错过原定落脚点，必须自己选择下一块石头。
- 章内后果：任第一次在诺克的建议之外行动，仍然安全；诺克的能力没有被削弱，但“建议”与“决定”之间出现第一条可感知的缝。

### 场景四：不落脚

- 现实事件：队伍抵达流动大陆外缘的临时营地。营地没有固定桩，只用队伍已有的短绳压住帐篷；没有新增补给或资源承诺。诺克看见一处看似平稳的白石正在缓慢离开地面，提醒“今晚不要把营地钉死”。
- 同一名车夫不接受建议，执意沿旧地图上的直线追赶已经偏移的石柱；诺克没有追上去，也没有叫守备拦人，只把路线图折回原来的折痕。
- 任问：“你知道他会走错？”诺克回答：“我知道那条路现在在动。”任再问“那为什么不拦”，诺克没有替这句话解释，只看着车夫的车轮离开白柱，过了一会儿才说：“他自己选的。”这让任第一次感到一点不舒服，但不立即反驳。
- 车夫回头问他叫什么。诺克只报出自己的名字：“诺克。”车夫没有再问，他也没有补充来处。

## 读者此时应该误判什么

- 误以为诺克能看见未来；实际他只能从连续运动估计短程趋势。
- 误以为旧地图被某个机构故意篡改；实际地图在绘制时可能准确，地面后来移动。
- 误以为诺克加入队伍就会成为稳定的领队；实际他只提出路线相交的暂时同行。
- 误以为任立刻识破诺克的责任逃避；实际任先享受终于有人能把变化提前说清楚。
- 误以为露米提前迈步证明诺克预测错误；实际他预测的是地面运动，不是人的临时选择。
- 误以为移动大陆的“缺失区域”已经指向某个终极真相；实际本章只证明位置和地图会失去同步。

## 章末必须留下的事实

1. 流动大陆边缘的地面、桥柱、草坡和道路存在不同速度或方向的相对移动；这不是一次幻觉或地图抄错。
2. 第70章以来的第二卷资源损失仍在背景中，但本章不新增灯、药、车辆、守备或正式补给。
3. 诺克首次正式进入主角团的行动范围；他没有正式职衔、身份认证或队伍职位。
4. 诺克能根据连续运动给出短程建议，不能解释地面本体、预测人的选择或保证未来安全。
5. 任先佩服诺克，随后因“建议不是命令”产生一点未完成的不适；不要让任在本章说出完整批判。
6. 露米因赌气提前迈步，任把她拉回；她没有新增伤势，但两人的关系留下一个未处理的停顿。
7. 旧地图上的白色测地柱在章末离开原位；地图没有被证明从一开始就是错误。
8. 诺克与队伍暂时同行，路线相交不等于加入；第三卷的“流动大陆”从具体地面事件开始，而不是从概念答案开始。
