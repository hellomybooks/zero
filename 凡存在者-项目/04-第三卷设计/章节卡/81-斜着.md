# 第三卷第八十一章《斜着》场景卡

## 状态

- 状态：场景卡与正文均已完成独立 Canon / 文学最终窄回归；定稿候选。
- 承接：第三卷第八十章《收图》正文与正文审校；第80章已标记为定稿候选。
- 篇章：第三卷 ARC 07《流动大陆》第九章。
- 情绪主角：任 / 诺克；露米与零开始出现不依赖任解释的共同停留与注视。
- 情绪方向：任继续期待诺克把变化翻译成下一步 → 诺克只给出一个局部物理判断 → 任把一只脚翻成一个动作并造成小损失，之后没有立刻把停顿转换成新字段，却仍然不甘心地想要完整步骤。
- 本章功能：把第79章的“墙段相对转动”推进为“同一件物体的两端以不同速度移动”；让 affine transform 的故事层表现为持续的斜切与形变，而不是新的危险窗口；让任的错误模型从“字段还不够”暂时转向“地图还没补全”，但不让他完成对地图和排除的终局认识；给露米与零留下第85章前第一处共同停留与注视。
- 主概念：一件物体可以保持局部连接，却不再保持原来的整体形状；几段地面关系相同，不代表它们共同承载同一个用途。
- 技术翻译层：深化 CV-15 affine transform 的平移 / 转动边界，落到剪切式形变；正文只写木架、湿布、木钉、染水、草坡和铺石末端，不新增视觉 API，不命名算法。

## 一句话梗概

第80章次日，主角团在外缘遇到一名染布匠和来取货的买主：一匹刚染好的长布挂在横跨两片石台的木架上，木架由三段木料和松动的木钉拼成，没有被谁推倒，却因两端地面的移动速度不同而逐渐错位。诺克只判断“外脚会先离地”；任下意识把这句话变成“先解外钩”，买主因此扯松一枚木钉，染布匠只得沿原有接缝剪开布面，保住木架和一段能暂时补屋棚的布，却让一笔整幅交货变成半段货款。没有人判断错地面，也没有人得到完整结果。零捡回一只滚到边缘的木梭，染布匠直接让他把木梭放到布外；他留下没人要的窄布条，露米没有替他解释，也没有把它拿走。风把另一截染线吹过最后一段铺石，落到一片没有铺砖却仍然连续的浅色地面上；铺石到此为止，地面没有到此为止，远处只留一扇半开的木门。

## 本章不能做的事

- 不能把木架倾斜写成突然坍塌、倒计时关卡或“还有几息”的安全窗口；形变必须持续、可观察、逐步增加。
- 不能把诺克的判断写成哪一卷布更有价值、谁应该赔钱、谁应该先拿货或谁应该承担订单损失；他只描述外脚将先离地。
- 不能让任的喊话变成公共裁决或专业许可；他可以把“外脚会先离地”误喊成“先解外钩”，但不能因此获得决定剪布、交货或赔付的权力，染布匠必须由自己的劳动经验完成剪布选择。
- 不能把窄布条写成路标、追踪物、身份凭据、零的来源线索或地图方向；它只是零从工作现场拿走的一件废料。
- 不能重复第73—80章的路签、白带、窄台抢行、门缝争夺、公共取水、灶房排烟、回绳修复或路册登记骨架。
- 不能把染布匠的选择判定成唯一正确答案；保住木架、按时交出整幅长布、让买主暂时补上屋棚和收回全部货款之间必须留下真实损失。
- 不能让主角团获得食物、工具、住所、身份、路册权限、固定路线或染布匠的长期带路资格；他们只是经过并短暂被卷入木架旁的劳动现场。
- 不能新增第四照护位。伊莉亚可以询问被木梭或剪刀擦到的人能否自己处理，但不能接收新的长期照护者。
- 不能让露米用一句主题判断解释零为什么拿布条；她只通过不替他说明、不强行收回或一句生活化提醒完成动作。
- 不能在第81章正式进入 Missing Region，不得揭示第三声、零的真实身份、诺克哥哥、古代文明或流动大陆本体。
- 正文不得出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、template matching、特征、模板匹配、算法、系统或代码等作者侧技术词。

## 核心规则与本章新增边界

### 1. 节点先错，外脚后离

- 木架不是一根刚性整木，而是三段木料用留有空隙的木钉拼成；四个支脚仍分别接触地面，节点可以先吸收一小段变化。
- 地面移动时，靠外侧的石台相对移动更快，三段木料在松钉处发生错动，四角逐渐不再对齐；这是一种结构本身的剪切，不是整架先作为刚体转过去。
- 木架在一段时间内仍能承重，但四个支脚、木钉和布面承受的力已不再相同；节点继续错动后，外脚才离地，不是被某个人推倒，也不是突然从稳定变成坍塌。
- 湿布的重量会把斜向下的一侧压得更低；染水沿布面向侧边流，先在布纹里形成斜色，再从边缘滴落。
- 外侧布边用一小段染线绕过铁钩，钩柄压在外侧木料的松钉节点旁；铁钩不是新的支脚，扯动它会把湿布的拉力突然集中到松钉上。
- 形变可以让一个局部仍然稳定，同时让整体用途失效：木架的一端还站着，不代表整匹布可以继续作为一件完整交货物。

### 2. 诺克只能说出一只脚

- 诺克至少看到同一根外侧木脚、同一枚木钉和布边的连续变化，才指出“外脚会先离地”；他不需要重复测量，也不把判断说成“建议先救架”。
- “外脚会先离地”只描述先发生的物理变化，不说明剪哪一段布、谁先拿货、谁赔定金或谁应当留下修架。
- 诺克不能从木架形变推出染布匠的订单优先级，也不能从买主的着急推出谁更有资格使用完整布料。
- 他不需要在本章预测木架最后是否完全倒下；现场的人会在判断之后自行改变物件和承诺。

### 3. 剪开是人的选择，不是正确答案

- 任听见“外脚会先离地”后，可能问“那先松哪边”；染布匠拒绝把这个问题交给诺克或任。
- 她看见长布的原有接缝、染水的流向和外脚的受力，沿一条原本就存在的接缝剪开布面，把一匹布分成一段较完整的临时补棚布和一段沾灰、带湿色的待重晾布。
- 剪布保住木架，却改变了唯一一笔整幅订单的数量和价值；她没有同时保住整幅交货、木架、买主当日的完整修棚和已收定金。
- 买主可以拿走较完整的一段，先盖住屋顶的小洞，再把原定金折成半段货款；染布匠保留工具和架子，却失去剩余货款，另一段布还要重晾。双方都知道发生了什么，仍然无法同时得到想要的结果。

### 4. 工作现场不等于公共路线

- 木架、木梭、染线和窄布只属于染布匠的工作现场，不升级为路线、地图标记、共同财产或隐藏坐标。
- 染布匠可以让零把木梭放到布外，随后对窄布条说“不要就还我，要就拿走”；这只是对一个现场动作的直接回应，不是承认零属于她的工坊，也不是确认零的身份。
- 露米不替零解释他为什么留下布条；她可以在零伸手或迈步过快时说“慢一点”，但不把布条从他手里拿走。
- 章末的浅色连续地面不是 Missing Region 证明，只是现有铺石终止而自然地面继续，远处只保留一扇半开的普通木门，不叠加人影、声音、脚印或多重生活信号。

## 场景设计

### 场景一：长布还没有干

- 现实入口：主角团离开外廊旧灯柱，沿最后一段铺石走向低草坡；一匹蓝灰色湿布横在两片石台之间，先出现的是买主伸手去摸布边、染布匠拍开他的手，而不是诺克解释地面。
- 生活冲突：买主今天要拿完整长布去修主街屋棚，屋顶有一处洞等着这匹布；他已付定金，染布匠却知道湿布现在拆下会先毁掉颜色和架子。两个人争的不是谁更值得，而是整幅交货是否还能按原约定发生。
- 木架细节：四根支脚分别压在不同石面，木钉上有旧蜡和染色；靠外的木脚比内侧低一点，外侧布边的染线绕过铁钩、钩柄压着松钉，布边的水沿斜向流。
- 人物对白：买主说“我付的是一整匹”；染布匠回得很短：“我知道。”她没有马上解释谁更重要，只用袖口去压住布边。
- 世界推进：木架没有倒，布面却先失去原来的平整；地面运动开始通过一件普通工作物的受力传给人，而不是通过路签或公共标记。

### 场景二：木架慢慢斜下去

- 现实动作：买主试图把内侧支脚往回踢，染布匠用肩压住一根横杆；木钉连续发出不同的响声，湿布上的染水从中心向一侧流。
- 诺克观察：诺克不走近木架，只盯住外侧同一根木脚、同一枚木钉和布边。变化连续到足够明显后，他说：“外脚会先离地。”
- 任的反应：任立刻问：“那先松哪边？”他不是为了替买主争整匹布，而是本能地期待诺克把一个物理判断延伸成完整步骤。
- 诺克的边界：诺克没有回答“先松哪边”，只收回视线。他没有说剪布、保架、交货或赔钱。
- 赛恩的动作：赛恩伸手想扶木架，染布匠喝住：“别扶那根，钉会拔。”他收回手，改把滑向石边的松木钉拨到不会被踩到的位置；他知道结构，却没有把知识变成替她决定。
- 任的动作：任没有等染布匠问，朝买主喊：“先解外边的钩！”买主伸手扯住外钩，染布匠已经喝出“别解”，一枚松钉还是从孔里跳出，布边先撕开一小口。诺克没有说错那只脚，任却把一只脚翻成了一个动作。
- 任的选择：他想再替自己解释，染布匠已经抓住剪刀；任看着她的手，没有立刻把这件事写成新的字段。

### 场景三：剪刀沿旧缝走

- 现实操作：外脚抬起一寸，木架并未倒；染布匠摸到长布上原来为拼接留下的窄缝，从刚才撕开的缺口接着剪开。剪刀不是法器，没有把布“正确分成两件”，只是让撕裂发生在她选择的位置。
- 买主反应：买主抓住较完整的一段，仍说自己付的是整匹；染布匠说：“先盖你的洞。”买主把已付定金折成半段货款，抱走那一段，剩余货款不再支付。
- 现实后果：买主暂时盖住屋顶的小洞，却仍缺一段长布；染布匠保住木架和剪刀，失去整幅订单的剩余货款，另一段布要重晾。刚才被买主扯出的初裂口让可用段少了一掌，任的喊话进入了这笔小损失，但没人把它说成谁的单独过错。
- 任的阶段性错误：任想把“布完整、布可用、布已交、钱已付”分成四行；蓝水先晕开纸角，染布匠用剪刀柄把纸推回他膝上，只说“记你的”，任收回纸张，没有新增字段。
- 伊莉亚的边界：买主的手背被剪刀柄擦出一道浅红，伊莉亚先问“能自己压住吗”；买主说“能”，她把手收回，不新增照护位，也不把两人的经济争执接成医护问题。
- 露米的动作：她把染布匠脚边的剩余布卷移开一点，让人能站稳；没有替买主或染布匠说谁更有理。

### 场景四：木梭和窄布条

- 现实动作：木架一端终于离地，剩余布面向外侧滑。木梭和一小截染线掉到石台边，零钻进布影下把木梭捡回。
- 染布匠的回应：她没有问零是什么，只说：“木梭放到布外面，别让它再滚。”零把木梭放在她伸手够得到的位置。
- 窄布条：被剪下的窄布条缠在零手腕附近；露米抬手想替他取下，看到零自己把线解开，便停住。染布匠说：“不要就还我，要就拿走。”
- 零的选择：零留下窄布条，不解释用途，也不把它绑到路边、桩孔、灯柱或任何人的身上。他只是把刚才拿过的东西握在手里。
- 人物推进：露米没有把“拿走”翻译成归属，也没有把“留下”翻译成拒绝；她只在零看向外侧地面时说：“慢一点。”
- 世界推进：一个工作现场的废料成为零与露米共同面对的物件，但没有被升级为身份线索或新能力。

### 场景五：铺石到头以后

- 现实画面：染布匠把脱出的松钉收进围裙，架子靠内侧的两只支脚暂时站住；买主抱着半段布沿主街回去。她留下湿色较重的窄段和断开的染线，准备重晾。双方没有道谢，也没有和解。
- 任的纸：任重新打开旁页，写下“架斜、外脚先离、布分、订单未全”，写到“谁承担”时停住。他没有把诺克的判断记成完整方案，也没有删掉第80章的四行记录。
- 诺克的动作：诺克收回扁石，没有告诉任哪条路能把他们带回主街。他看着外侧草坡，只看见铺石停在边上，没看见地面在眼前断掉。
- 露米与零：零把窄布条折在掌心，没有跟着那截被风吹走的染线向外走；露米没有把他拉回，只在他迈步靠近边缘时说“慢一点”。
- 普通生活痕迹：那截染线落在最后一段铺石外，旁边只有一扇半开的普通木门；不能出现完整陌生生物、神秘声音、脚印或世界解释。
- 章末画面：主角团站在最后一段铺石内侧，染布匠的半架晾布在身后，零与露米都看着那扇半开的木门；地面本身没有在铺石尽头停下。

| 诺克 | 继续面对别人把局部判断期待成完整答案 | 只说出外脚先离地，不替任何人决定布、架、订单或赔付的优先级 | 任的不适开始指向他的“只说到这里”，但任尚未把它说成责任问题 |
| 露米 | 不愿让任把普通人和零折成说明 | 移开布卷、停住替零取线的手、只提醒“慢一点” | 她没有把零手里的窄布条解释成方向，也没有在他没有真正走出时强行拉回 |
| 零 | 对可移动小物保持兴趣，不被路签定义 | 捡回木梭并留下窄布条，折在掌心，没有跟随被风吹走的染线 | 与露米共享一个未解释的注视动作；没有获得“同类”证明或新能力 |
| 赛恩 | 仍擅长看结构，但对任代替判断保持警惕 | 想扶架却被阻止，随后只移开木梭，不用精确性接管现场 | 再次看到结构知识不能自动变成正确顺序；对任的沉默多于劝告 |
| 伊莉亚 | 维持既有三名照护对象 | 先问买主能否自行处理浅伤，得到肯定后停手 | 照护边界通过一次询问和一次退回继续成立 |
| 染布匠 | 想按约定交出一整幅长布，但材料与地面不允许 | 沿旧缝剪布，保住木架与半段交货，主动接受剩余货款损失 | 没有被作者判定为正确；她带着剩余湿布回到自己的工作里 |
| 买主 | 需要整匹布修屋棚，已支付部分定金 | 拿走较完整的一段并拒绝按整匹付清 | 损失未被抹平，回主街后仍要决定如何修屋棚 |

## 读者此时应该误判什么

- 误以为只要诺克说出外脚先离地，就能推出应该先保木架还是先保布；实际上判断只到一只脚。
- 误以为剪刀沿旧缝剪开是唯一正确解；实际上它只是染布匠承担一组损失的选择。
- 误以为窄布条会成为新的路标或追踪物；实际上它只是零留下的一件工作废料。
- 误以为最后一段铺石之外的连续地面就是 Missing Region 入口；实际目前只知道地面继续，并有微弱生活痕迹。
- 误以为任停笔代表他已经想通；实际上他只是被自己的喊话和染布匠的动作打断，仍然想把损失拆成栏位。

## 章末必须留下的事实

1. 流动地面可以让同一件物体两端发生不同位移；局部连接仍在，整体形状和用途却会改变。
2. 湿布重量、木钉受力和染水流向都能成为地面形变的现实证据，不需要突然坍塌或敌人介入。
3. 诺克能判断外脚先离地，但不能判断剪布位置、订单价值、赔偿责任或人的优先顺序。
4. 染布匠沿原有接缝剪开长布，保住暂时站住的木架和半段交货；买主将定金折为半段货款并承担屋棚仍缺一段的后果，染布匠失去剩余货款。
5. 任确实把诺克的局部判断喊成了一个错误动作，并没有因此获得裁决权；他也没有在本章完成对地图、责任或排除的成熟认识。
6. 零被普通手艺人直接交代过一个动作，并自行留下窄布条；露米没有替他解释，也没有强行收回。
7. 旧聚落的铺石在章末结束，但其外仍有连续地面和普通生活痕迹；这不是 Missing Region、第三声或零的来源证明。
8. 主角团没有获得食物、工具、住所、身份、路册权限、固定路线或新照护位；第80章的外路、收签和姐弟未和解事实继续有效。

## 第二卷后续接口与第三卷伏笔

- 任的旁页从第80章的公共路签状态继续写到“架斜、外脚先离、布分、订单未全”；他暂时没有增加字段，但“未登记等于未补全”的倾向开始成形。
- 诺克的运动观察从道路和公共路签推进到同一物体两端的不同位移；本章强化 CV-15 affine transform 的剪切边界，不新增 API。
- 露米与零第一次在普通人的工作现场形成共同的停留与注视：她不替零定义，他也没有等待任解释；这为 ARC08 的情绪中心转移留下行为接口。
- 第82—84章可以继续让主角团沿普通劳动路径、外侧居住痕迹和旧地图末端前进，但每章必须先有人的生活用途，再有地图边界；不得将这些路径直接命名为 Missing Region。
- 第85章《地图之外》可从“铺石结束而地面继续”的事实起步，将视线与情绪逐渐交给露米 / 零；第81章不预支类似存在的正式相遇。
- 第三声、Missing Region、零、诺克哥哥、古代文明和流动大陆本体保持未知。

## 五问自检

1. 本章首先发生在人身上的是否是染布匠、买主、一笔订单和一匹湿布，而不是 affine transform 的定义？——是。
2. 有没有角色做了以后可能后悔的事？——染布匠沿旧缝剪开布，买主只拿走半段并放弃剩余货款，任把“外脚”喊成“外钩”并让初裂口扩大。
3. 有没有一句正确的话不应该由当前角色说出来？——没有人说“记录制造排除”或“噪声不是错误”；他们只谈木架、布、钱、手和要不要继续走。
4. 这一章有没有把未来非常重要的东西提前支付？——没有正式进入 Missing Region，没有解释零的来源、第三声或古代文明；只留下铺石尽头之外的生活痕迹。
5. 如果删掉所有技术隐喻，染布、订单、木架形变、窄布条和铺石外的一扇半开木门是否仍然成立？——成立。
