# 第三卷第八十九章《挪开》场景卡

## 章节定位

- 篇章：ARC 08《地图之外》
- 时间：第88章同一晚，暮色之后，不强行跳到第二天。
- 地点：同一处小院、半开的木门、旧墙脚和门外低草；门槛与外侧硬地仍不连续。
- 情绪主轴：任 / 伊莉亚，露米 / 零作为门内的回声与牵制。
- 功能：改变 ARC08 的压力形态。前几章里“站在门外等待”仍然可被当作暂时策略；本章让烟、冷、湿地和院内生活的实际需要证明：继续站着本身也会伤害人。
- 题目含义：既是一个具体的挪位动作，也可能成为某个人不愿承认的关系动作；正文不得替它提前下结论。

## 本章只锁定的事实

1. 第88章的四个人仍在门外；旁页上的“外四”已经写下，但纸边返潮，粗麻袋布条沾泥，两根根茎已经被分食，院内的布和硬木仍未完成。
2. 夜风改变方向，火烟开始朝门缝和旧墙脚回卷。烟不构成敌袭、预兆或新魔法，只是这处火与门外站位在当下的物理后果。
3. 院内生活者必须提出一个具体要求：门外的人需要挪开、降低站位、把湿物移走，或允许门暂时收窄。要求应当保护火、锅或布，不是宣告“外来者不配”。
4. 门外至少有一个人必须在“继续靠近门”与“让人 / 让自己离开门边”之间做选择。这个选择要改变下一章的站位或关系，不要求完成情绪理解。
5. 本章至少保留一件场景卡没有预设、但正文人物自己长出来的普通生活细节。它可以没有主题职责，也可以让人物尴尬、发笑、嫌弃、犯蠢或暂时走神。写完后记录它，但不能在本卡中预先规定它是什么。

## Canon 与连续性边界

- 不触碰第36章，不回写第一卷，不把第一卷的 protected reviewed baseline 变成第三卷的解释材料。
- 不解释送篮女人为什么没有回来；她可以继续缺席，也可以在远处经过但不进入本章视线。不能把她的缺席绑定到 Missing Region、第三声、界兽历史或新敌人。
- 不解释 Missing Region、第三声、Zero 身份、Alpha、界兽来源、古代文明、诺克哥哥或任身份。
- 不让门内外恢复人物连续通行。可以有烟、声音、光、粗布、根茎或其他普通小物件造成的有限互动，但不产生稳定传送或新空间能力。
- 不让零劈开硬木，不让露米的视觉判断直接产生第二块布，不让诺克从当前烟流或地面判断推出远期未来。
- 不让任在本章完成“我不知道”“我尊重所有选择”或“等待没有意义”；不让伊莉亚完成“不必救所有人”；不让露米完成标签与身份的终局区分；不让零完成不再需要被留下的终局成长。
- 正文不出现 API、OpenCV、Mask、Edge、Contour、Bounding、Alpha、Foreground、Background、Mat、View、Threshold、Classification、模板、算法、系统、模型、字段、代码等作者侧技术词。

## 场景压力

### 场景一：烟先找到门

- 火边的水终于开始冒小泡，界兽把锅盖抬起一条缝；同一阵风把烟压向门缝，烟在门内外之间形成短暂的灰线。
- 门外的人先咳嗽或揉眼睛；不要把反应写成整齐的“大家都意识到问题”，让每个人的身体反应和脾气不同。
- 院内的布、硬木、锅和门的位置受到烟影响。界兽提出具体要求，但理由只停留在眼前的火、烟、布和站位。
- 露米可能听见门外的人说话，也可能先注意到烟落在布上；她可以对物理变化做出准确判断，但不能替门内或门外决定谁该动。

### 场景二：站在门口开始有代价

- 伊莉亚要处理任的手、纸或呼吸，也要考虑门内火边的实际需要；她不能同时让所有人留在原位。
- 任把“挪开”听成让出门、放弃机会或承认他们不属于这里的可能性，但他不应立刻把这种感受说成完整判断。
- 赛恩可以检查旧墙脚哪边更少烟、哪块地当前还能站，却不能把烟流固定成路线，也不能把门槛修好。
- 诺克只能描述当前烟往哪边压、哪一块地被风吹干或哪一处站位更糟。它的建议要有用，但不能替任或伊莉亚选择。
- 门内界兽的要求可以让外侧人不舒服。它不需要道歉，也不需要成为反派；“自己的火不能被挡住”与“门外的人不想离开”可以同时成立。

### 场景三：关系选择，不是谜底选择

- 至少一个人采取会改变关系的行动：挪到旧墙另一侧、带走任的旁页、让某人独留门边、把门稍微收窄、或把有限物件交给不在自己这一侧的人。
- 选择必须带来即时具体代价：看不见门缝、丢失一点火光、让某个人误解、使纸受潮、让某个照护对象离开手边，或使门内生活者不再愿意继续回应。
- 不能把选择写成正确答案。挪开可能保护身体，却让人更远；留下可能保留视线，却让别人承担烟和冷。
- 任和伊莉亚之间至少有一次不对称：一方以为自己在照顾，另一方感到自己被安排；不要用解释童年或完整伦理判断立即修复。
- 露米 / 零的门内互动应当保留小而具体的摩擦，不要把门外的选择翻译成他们已经理解了归属主题。

### 场景四：保留一件没有用途的生命

- 场景卡不指定这个细节。正文写作时，允许某个角色做一个与主线无关的动作、说一件蠢话、嫌弃食物、发笑、打喷嚏、发痒、走神或误会一件小事。
- 这个细节不能被结尾解释成“所以他们仍然是人”，也不能承载伏笔；它只因为人物当时就是这样而留下。
- 独立生成审校必须记录该细节，并回答：如果删掉它，情节几乎不受影响，但人物是否会因此变薄？如果是，保留。

### 场景五：章末不是恢复

- 章末应当留下一个新的站位或关系事实：有人已经离开门边、有人拒绝离开、有人把旁页交给别人、有人第一次不再回应门内的声音，或其他由正文自然长出的等价变化。
- 不要求门移动，不要求女人回来，不要求火变大，不要求第三声出现。
- 章末的变化必须让“继续等”在第90章不能原封不动地重复；但不要把下一章的路线、冲突和答案写死。

|---|---|---|---|
| 任 | 门内的视线、旁页上的人数、露米是否仍在火边 | 继续靠近门会使别人承受烟与冷；他不能把自己的等待单独定义为必要 | 不完成放手，不完成“分析不等于拥有”，不把同伴的离开解释成正确或错误 |

| 露米 | 火边的布、门外声音、自己被需要的位置 | 界兽的生活需要可能与门外人的需要冲突；她的判断不能同时满足两边 | 不完成“标签不是身份”，不把继续做事等同于留下 |
| 零 | 硬木、火边位置、露米的注意力 | 它可能因为烟、笑声或某个小物件被迫停止当前动作；它的反应可以难看 | 不完成归属，不把临时用途变成自我定义 |
| 赛恩 | 找到一块可站的地、让结构不再继续坏 | 没有足够材料和时间让他修复全部关系；他可能要接受一个不漂亮的临时站位 | 不完成接受误差，不把临时动作升级为空间能力 |
| 诺克 | 当前烟流、地面和队伍相对位置 | 建议可以指出更安全的地方，却不能替人决定谁留下；它的准确会让责任更明显 | 不完成承担选择，不把局部可见当作未来保证 |

## 第89章开放空白登记

- 场景卡主动不规定：具体是谁先咳、谁说了最蠢的一句话、谁突然笑、谁嫌弃根茎、谁把一个小物件拿错、谁在烟里短暂走神。
- 正文若长出一个不承担主题职责但使人物变厚的细节，将其登记到正文审校的“生成审校”部分；不得为了证明开放而硬塞笑点。
- 场景卡不预写对白，不预写象征物对应关系，不预写最后一句话。

## 后续接口

- 第90章必须承接本章的新站位或关系后果，不能把人物自动放回门外原位置。
- 送篮女人的缺席继续作为普通生活空位存在，除非未来事件以人物行动而非作者解释迫使它重新进入视野。
- 如果有人把旁页、粗麻袋布条、硬木或其他普通物件交给另一侧，后续只记录该次具体互动，不扩展为空间通则。
- 露米或零可能因为门内的生活需要与门外队伍发生一次不完全一致的选择，但不把它写成身份答案。
- 任与伊莉亚的照护冲突可以留下不舒服的沉默；理解不必在本章完成。

## 本卡自检

1. 本章是否先处理烟、冷、咳嗽、站位和人的选择，再产生任何主题意味？——是。
2. 是否有至少一个选择会改变下一章的站位或关系？——必须有，但不预设其正确性和完整对白。
3. 是否避免把“没预设的生命”提前写成测试项目？——只规定保留开放空白，不规定它的内容。
4. 是否没有提前支付送篮女人、Missing Region、露米归属、零身份和任放手？——是。
5. 删除所有技术隐喻后，烟、火、冷、门边和谁该挪开是否仍能构成冲突？——必须成立。
