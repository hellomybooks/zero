# 第二卷第六十二章《两处》场景卡审校

## 审校结论

- 状态：通过 / 定稿候选。
- 审校对象：`04-第二卷设计/章节卡/62-两处.md`。
- 对照对象：第六十一章场景卡、正文与审校、第二卷总控、第二卷生产看板、Canon Change 记录。
- 当前卡片规模：229 行、32,528 字节。
- 审校方式：独立 Canon / 连续性审校、独立文学 / 叙事审校，以及针对跨章资源账的修订后短回归。

## 设计目标核对

- 本章不再重复第61章“护灯分配—担架通过—关闭路线”的高潮，而把冲突推进到两处求救被行政合并后产生的误派、公共语言和记录后果。
- “同段事件”首先是城防为压缩调度牌面而设的旧规，不是世界本体规则；共享旧渠声腔只说明声音可达，不说明人群相同、地点相同或实体救援路线相通。
- “无伤者确认”被限定为不完整伤者栏或口头压缩，不替换东十四巷正式牌面上的“求救待听见 / 伤者栏未开”，避免把空栏提前写成无人。
- 三种灯被严格拆开：第61章留下的唯一稳定正式护灯、旧器材库裂玻璃照护灯、赛恩家族私人礼灯各有用途、归属和限制，不互相冒充。
- 本章明确不发生第三次担架转运；伊莉亚的水、布、便携木片、托恩旧夹板和三名伤者状态沿用第61章账目。
- 第三种回声只生成“第三声 / 来源未确认”牌，不计伤者、不归入两处、不触发资源，也不被确认成魔物、敌军、零或其他既定对象。

## 首轮独立审校发现与修订

### Canon / 连续性审校

首轮发现并修订以下风险：

1. 合并规则如果只写“同一声道”会过宽，已增加“一声钟内”“缺少独立身体或具体门、门洞、墙孔证据”等合并条件，并在巡查中补出下渠旧渠第七道石缝与东十四巷阿芙门断闩孔。
2. 东十四巷“无伤者确认”容易被读成正式否定，已把它限定为不完整伤者栏或口头公告；正式牌面始终保留“求救待听见 / 伤者栏未开”。
3. 共享声道容易被误读为可供担架通行的路线，已在规则、巡查和章末接口中分开声音连接与实体救援路线。
4. 裂玻璃灯、赛恩礼灯与第61章护灯可能混成三盏可互换资源，已固定裂玻璃灯只能作照护灯、礼灯只能作私人见证灯，且第61章下渠区的唯一稳定正式护灯仍留在那里。
5. 木片和布的跨章状态容易出现凭空补充，已锁定托恩旧木夹板仍在腿下；伊莉亚两块便携木片一块断裂、一块留在阿瑟处；布分留在托恩与阿瑟处，第三名伤者无布；本章不补新水、新药、新木料，也不进行第三次担架转运。

### 文学 / 叙事审校

独立回归重点检查：

- 主要高潮从“灯是否够”转为“同段牌先派错了人”，让制度的便利性与伤害同时发生。
- 露米的改写保护东十四巷不被写成无人，却把阿芙的自称暴露到公共牌面；记录有效但不等于关系修复。
- 赛恩的礼灯只能提供见证，不能解决护灯和守备；阿尔德仍必须在知道两处不同的情况下承认资源只能给一处完整路线。
- 第三声不是为下章提前发放的答案，而是让“拆分已经发生，但拆分仍不够”成为章末压力。
- 任、伊莉亚、阿尔德、露米、赛恩与阿芙分别承担记录、照护、调度、公告、关系与自称的代价，概念通过门、灯、声腔、木闩、喘息和错误派遣呈现。

## 修订后回归要点

- 第61章四盏正式城防灯账与第62章三种灯用途已分开；裂玻璃照护灯不计入“两盏稳定”，礼灯不接入城防系统。
- “资源仍一份”是阿尔德当场记录，不被提前升级为新制度或公平分配方案。
- 第三声的牌面不获得车、灯、担架或守备；中段石板封住后，两处都暂时失去继续核查的可能。
- Canon 检查清单覆盖合并条件、形式字段、资源边界、人物后果和未确认的第三声；正文生产仍需保持不出现作者侧技术术语。

## 第二轮独立回归与新增修订

- Canon 回归确认下渠区“已处理三人”只是不完整口头压缩，正式牌面仍为“已接触三人”；东十四巷写作“只剩一盏可用且稳定的护灯”，新增共用资源明确为裂玻璃灯，未吞并正式护灯或私人礼灯。
- 文学回归要求本章的不可逆后果区别于第61章的护灯分配，已把制度转折落为：伊莉亚签下照护见证后被责任锁在下渠区；误派后东十四巷副牌写入“独立地点已确认 / 本班不重派完整救援路线”；阿芙擦伤进入现场后果栏但不计入伤者数字；赛恩用个人名字承担礼灯债务。
- 第三声不再只是下章钩子：它在任何敲击前先落下，封石后切断旧渠两侧的声音，使两处在下一班前失去互相复核的耳朵，新的确认必须由人走路带回；其来源仍未确认。
- 第二轮独立 Canon 回归：通过；第二轮独立文学回归：通过。无新增必须修复项。
