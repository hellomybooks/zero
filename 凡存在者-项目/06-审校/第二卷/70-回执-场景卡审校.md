# 第二卷第七十章《回执》场景卡审校记录

## 审校结论

- 结论：通过，标记为定稿候选。
- 审校对象：[第70章《回执》场景卡](../../04-第二卷设计/章节卡/70-回执.md)。
- 对照对象：第69章《移脚》场景卡、正文与正文审校；第65—66章公共水桶与水夫物件链；第二卷 Canon Change。

- 下一步：依据已通过场景卡生产第70章正文。

## 本章承担的连续性任务

第70章不再重复第69章的“要求阿尔德签字—拒绝写已封—现场旁注”动作，而是把第69章的纸面状态推进到一个新的现实后果：上坡回话被抄成“回执已收；现场未封；本班后续不派”，这条窄回执被带到水桶边后，沿用第65、66章的同一名水夫把既有公共水桶从下渠旧绕路拖回。

“回执已收”因此先改变一只桶的方向，再改变一个人的取水位置，最后被抄到下渠区墙上。它仍不是救援、封闭、责任人或正式水规。

提空碗男人带着第69章裂开的半只碗来到公共水桶边。他本人到场，但母亲不在；水桶边只给到场的一人一次倾水，破碗漏掉大半，男人只能用手接住短暂湿意。露米准确记录事实，却不能把漏掉的水追回。

## 第一轮审校发现与回修

### 文学 / 结构问题

1. **前两场复演第69章。** 初稿再次让传令员要求阿尔德签名、阿尔德写同一旁注。回修后，窄条先由上坡抄入旁注并带回；“回执人”栏保持空白，阿尔德不再重新写同一句话，而是在水桶路线改变时选择不离开脚位追水。
2. **回执后果过于解释化。** 初稿只写人群把“回执已收”抄到墙上。回修增加了可见事件：同一名水夫正要按旧绕路向下渠送既有剩水，听见回执后把桶拖回石脚；下坡一侧的人收回空容器，另一个人占据空出的石边。回执的影响先作用于物件和站位，再进入墙面语言。
3. **人物首先承担的代价不够早。** 回修后提空碗男人追着被拖回的水桶上坡；他的请求从第一处新事件进入，破碗漏水和无法带走湿意成为本章个人损失。
4. **人物行动职能趋同。** 回修后阿尔德只作留守选择，任负责对象和来源记录，露米跟随水桶和旁页观察词语如何变化，男人负责取水与身体损失；没有让所有人都用“准确区分”发表主题判断。

### Canon / 物件链问题

1. **窄回执的新字段边界不清。** 回修明确：“回执人”只确认收到窄条，不等于受领人、责任人或派遣承诺；“现场备注”只是下渠现场旁注，不更新原副页、主册或水簿。
2. **水夫身份可能被误读成新增人员。** 回修将所有场景中的水夫锁定为第65、66章拖同一只公共水桶的既有水夫，不新增水夫队伍。
3. **窄条往返来源出现断点。** 回修锁定同一条窄条的物理顺序：上坡抄出 → 传令员带到下渠 → 露米与提空碗男人沿旧坡带到调度处水桶边 → 记录员确认后交还传令员 → 传令员沿旧坡带回下渠；正文生产不得复制出第二条窄回执。
4. **现场备注来源容易混淆。** 回修明确区分：第69章原副页上的现场备注由阿尔德书写；第70章窄条上的旁注由上坡抄入。二者都可被任记录，但不是同一处新写。
5. **水桶路线与水量锁定。** 公共水桶沿用第66章以来同一只，水仍是既有泼失后的剩余；坏木轮、石脚、旧绕路和本章洒出的一点水不重置，不新增第二只桶或新水。

## 最终 Canon 窄回归

结果：通过。

- P1：无。
- P2：无。
- P3：无。

最终确认：

- “回执已收”不等于现场封闭、救援、资源、责任人或派遣；它只是纸沿既有传令链返回。
- “回执人”栏保持空白；现场旁注不扩大阿尔德正式“仅现场报告”范围。
- 同一名既有水夫、同一只公共水桶、既有剩余水量和坏木轮连续；路线被人群口头借回执改变，但“未到，不计”没有进入正式水簿、主册或城市法令。
- 提空碗男人本人到场，母亲仍只有亲属转述；一次倾水不能使母亲获得到场、候位、伤者或死者身份。
- 半只碗沿用第69章裂损状态，漏水造成具体损失，不产生新容器或新资源。
- 阿尔德仍留在缺口，伊莉亚仍维持三名身体；男孩、女人、线外来者、第三声、浅弧、封石、零和东十四巷未知边界保持不变。

## 最终文学窄回归

结果：通过。

- “回执已收”通过水桶路线取消、取水位置挪动和墙面抄写形成事件推进，不再只是角色解释。
- 章首由男人追着被拖回的桶启动人物代价；破碗、漏水和干掉的湿痕保留私人损失。
- 任、露米、阿尔德和提空碗男人的功能与语言区分：任记录来源，露米跟随物件与口头词，阿尔德留守，男人实际取水并承担漏水。
- 没有提前支付母亲生死、阿尔德政治崩塌、伊莉亚麻木、男孩命运或第三声答案。
- 删除技术隐喻后，窄回执、公共水桶、破碗、缺席亲属、三名身体和有限水量仍构成完整冲突。

## 五问自检

1. 本章首先发生在人身上的，是一个男人看着原本可能下坡的水桶被拖回，并追上去为缺席母亲取水；不是一条回执被准确抄写。
2. 阿尔德不离开脚位追桶，露米没有替男人夺水，男人把一次有限倾水留给母亲的请求；每个选择都留下了损失。
3. 本阶段没有让角色总结“回执不等于真实”之类的终局判断；纸条、空白栏、桶的方向、漏水和墙字承担主题。
4. 没有提前支付母亲生死、阿尔德政治崩塌、伊莉亚麻木、男孩命运或第三声本体。
5. 删除技术隐喻后，回执、水桶、破碗、缺席亲属、三名身体和有限水量仍能支撑整章。

## 生产提示

正文必须把同一条窄回执的传递写清楚，尤其保留上坡→下渠→调度处→下渠的物件路线；不要把“回执人”或“现场备注”写成新的受领制度。水桶路线的改变必须发生在水夫手上，不能用作者总结替代；水桶边的“未到，不计”必须作为口头词落到一次取水损失，不得进入正式水簿。阿尔德不重复第69章的签字争辩，他的本章选择是留在三名身体前，放弃当面追水路线。
