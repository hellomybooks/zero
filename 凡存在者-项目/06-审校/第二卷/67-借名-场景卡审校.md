# 第二卷第六十七章《借名》场景卡审校记录

- 结论：通过，标记为定稿候选。
- 审校对象：[04-第二卷设计/章节卡/67-借名.md](../../04-第二卷设计/章节卡/67-借名.md)

## 一、审校基线

本章承接第66章：正式主册仍记录东十四巷候位一 / 受领待定、下渠区候位二 / 阿尔德仅现场报告、封石不入候位 / 来源未确认。第66章正文只有一张街面抄联；本章新增的第二张纸是街面照着原抄联另抄出的非正式副本，不是新的正式文书。

本章必须完成的叙事任务：

1. 让一个具体的人主动借用错误范围的名字，而不是再次由旁人替她误读。
2. 让借名进入实际动作：线外来者靠近、抹开一掌宽临时照护线、造成灯灭和后续缺口。
3. 让伊莉亚在三名照护身体与线外来者之间留下不能靠解释消除的选择后果。
4. 让阿尔德在追回副本与留守下渠区之间选择留守，并把“未追”写入副页而不扩大正式受领。
5. 让封石产生新的物理证据，但不把它解释成第三声、名字回应或零的行为。

## 二、第一轮 Canon 审校与回修

### 必须修正项

1. **抄联数量与残角来源。**

   初稿曾把第66章的一张抄联写成两张既成纸，并让开场副本已经缺角。已回修为：第66章只有一张原抄联；第67章街面另抄出一张完整的非正式副本；原抄联折成细条流向东十四巷，副本在下渠区冲突中被脚从折痕处踩裂，线外来者带走写有“阿尔德 / 受领”的窄角，之后残角被风带到封石。

2. **线外来者的伤势与正式字段。**

   已明确她被人群肩膀撞倒、膝盖磕到石边；膝伤是身体事实，但不自动进入三名伤者栏、照护签名、受领、候位、归属或通行资格。露米只记录“持残角离开照护线，方向上坡，未确认”。

3. **临时照护线的后果。**

   已新增并锁定：线外来者用带泥的手抹开一掌宽灰线；伊莉亚没有恢复缺口，缺口会进入第68章，可能改变风、人群和照护动作的进入条件。本章没有灰料、备用灯、守备或时间补回它。

4. **阿尔德的选择边界。**

   已锁定阿尔德只接下一份现场报告；残角被风带向封石时，他说“不追”，留在下渠区。“阿尔德未追残角”只进入副页，不改变正式“仅现场报告”范围。

5. **新增工具的来源。**

   “旧木钩”已明确为封石处原本用于拨开护石边碎物的工具；没有新增灯、灯油、药粉、守备、担架、车辆、水或路线。

## 三、第一轮文学 / 结构审校与回修

### 必须修正项

1. **避免第65—66章的第三次纸面循环。**

   初稿主要重复“误读 → 拒绝扩大 → 任记录 → 现实无法追回”。已把中心转为线外来者主动拿纸、越过一只脚、亲手抹线、跌伤后带走副本残角；照护线的缺口成为新结构，而不只是“记录无效”的再说明。

2. **把不可逆后果落到关系与现场。**

   灯灭不再只是黑暗意象：伊莉亚不扶起线外来者，也不恢复缺口；线外来者带着错误纸离开；阿尔德留下“未追”；赛恩放手让原抄联继续流通。第68章接口因此同时获得未恢复的线、未追回的纸和未确认的去向。

3. **压低主题完成句。**

   已将阿尔德的“先让他们活着”删去，保留“不追”和停顿；赛恩的“纸不是印”改为“别把印拿来”。正文仍可保留“我现在不能”“那我现在算哪一份”，但不能在其后补作者式总结。

4. **封石浅弧与人物选择的接口。**

   残角之所以到达封石，是因为阿尔德选择不追；守备尝试用既有旧木钩从外侧拨纸时，火绳先收紧、牌件滑动、石灰留下浅弧。先后关系保留为证据，不宣布因果，也不让浅弧立即要求人物给出答案。

## 四、最终窄回归

### Canon 回归

- 结果：通过。
- P1：无。
- P2：无。
- 核验：原抄联 / 非正式副本数量和来源、残角撕裂链、照护线缺口、阿尔德“仅现场报告”与“未追”、既有灯具与守备、旧木钩、封石牌件、第三声和零的边界均闭合。
- P3：正文需把副本从“完整到场”写到“踩裂后带走窄角”，不能倒叙成开场已经缺角；灯灭后必须让未恢复的线缺口进入动作，不只存在于说明。

### 文学 / 结构回归

- 结果：通过。
- P1：无。
- P2：无。
- 核验：抹开照护线是本章新增事件，造成灯灭、跌伤、缺口、离开和阿尔德留守；赛恩从拒绝盖印推进到放手让纸流通；封石只留下物理证据，没有提前支付谜底或未来情绪。
- P3：场景一至三的“抄联不等于资格”解释应在正文中压缩；赛恩的邻居压力要具体；“完整副本 → 踩裂 → 受领窄角 → 被风带走”的纸张动作要保持同一物理链。

## 五、五问自检

1. 本章首先发生在人身上的，是线外来者主动借名、抹开一段线并带着残角离开，而不是主册增加了一个新字段。
2. 伊莉亚不扶起她、不恢复缺口；阿尔德不追纸；赛恩不抢回原抄联；线外来者带走错误证据。每个选择都有后续代价。
3. 没有人在本章完成“我终于明白”；主题由一只脚、被抹开的线、灯灭和未追记录承载。
4. 没有提前支付伊莉亚最终麻木、阿尔德关闭防御安排、第三声本体、零的身份或战争终局。
5. 删除所有技术隐喻后，一张副本、一段照护线、一盏熄灭的灯、一个带纸离开的人和封石浅弧仍构成完整冲突。
