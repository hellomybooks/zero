# 第二卷第六十五章《候位》场景卡审校记录

## 状态

- 状态：场景卡已完成两轮独立 Canon / 文学审校、回修与最终窄范围回归，定稿候选。
- 场景卡：[65-候位.md](../../04-第二卷设计/章节卡/65-候位.md)
- 对照材料：第63章《线外》场景卡与正文、第64章《退线》场景卡与正文及审校；第二卷总控；Canon Change 记录；创作原则与阶段评价。
- 最终规模：279 行、32,946 字节。

## 审校范围

1. 候位是否作为有限复核时间的临时行政顺序出现，而不是魔法、保护、处置线或通行资格。
2. 新守备、第三声牌、既有报告牌、空白木片、公共水桶、私人礼灯、门件和下渠区照护物资的跨章连续性。
3. 东十四巷、下渠区、封石三处的人员、记录、时间和路线是否保持分开。
4. 伊莉亚、阿尔德、任、露米、赛恩、阿芙与线外来者是否通过选择承担实际后果，而不是由主题替他们完成成长。
5. 第三声与零是否保持未知；场景卡是否给第66章留下证据接口而没有提前支付本体答案。

## 第一轮 Canon 审校发现与回修

- 新守备的派遣顺序曾出现重复：前文已经写到东十四巷复核完成，后文又写阿尔德才决定让新守备先去东十四巷。已将派遣固定在场景一，场景四写现场复核，场景七写唯一一次返回调度处；后文改为新守备暂留调度处，不重复索取报告。
- 封石原先容易被读成保留候位空栏。已明确封石只保留“无候位 / 来源未确认”，风掀开的只是旧换班板上被划掉的空白，不是新的候位栏。
- 候位数字与牌件身份曾有歧义。已明确“候位一”“候位二”只是东十四巷、下渠区既有报告牌边的临时标记；任持有的空白木片仍是另一件既有物件，没有新增候位牌或木板。
- 公共水桶已明确沿用第64章同一只，水量仍是泼失后的剩余量；候位造成挪桶、倾斜和水浸报告牌，但没有新增水、药、布、固定木片、担架、灯或车辆。
- 伊莉亚的个人转告补全了徒步传令员返回链，并明确“未进入正式候位”；线外来者可先离开，转告失败不由世界自动补答案。
- 第63章正文的第三声牌交接补为“任把牌递还给阿尔德”，随后由阿尔德重新贴回护石并用火绳压住；第65章开场牌物归属闭合。

## 第一轮文学审校发现与回修

- 删除“政治资源”“等待就是政治”等作者侧定性，改用数字被挪动、水桶被两边拉住、报告牌被水浸和传话被误抄呈现主题。
- 让人物保留语言失败：露米脱口说出“谁先来谁拿”，阿芙先说“我知道他们是谁”后收回，赛恩先说“这不是家族的门”造成误读，伊莉亚把“可能没有空位”摆给传令员却仍想接住结果。
- 避免把伊莉亚写成已经完成边界成长；她只把个人转告停在“最后一次看见”，仍想继续伸手。
- 保留阿尔德决定的合理性与伤害性：他选择短路线和可返回的报告，不把这一先后解释成价值排序；下渠区的三名身体仍因此等待。
- 给“还在”留下新的后果：口头转告未进入正式候位，却被旁人误抄成“候位二有人”，线外来者因此成为最容易在传递中丢失的人。
- 将候位冲突落到身体事件：孩子穿过拉桶的人群、报告牌浸水、抢牌者手掌被划破；记录准确不能撤销已经发生的推搡和损失。

## 最终窄范围 Canon / 文学回归

两名独立子智能体分别复核后均返回“通过”。最终确认：

- 换班后只有一名新守备；东十四巷、下渠区和封石没有同时获得新的人手。
- 第104行是唯一派遣点，第163行是唯一返回点；第167、206、210行只处理返回后的调度与板面，不重复带回报告。
- 候位一只完成一次东十四巷门边复核；“别开”、手、姓名、人数和伤势仍分开记录，身体未确认。
- 下渠区候位二没有自动时刻；三名身体、线外来者、照护线、通行线和个人转告保持分开。
- 赛恩的礼灯仍熄灭，家族印记未盖；阿芙只为自己作证；没有新的归属、正式护灯或资源进入东十四巷。
- 第三声不进入候位体系，来源、性质和是否为人声仍未确认；零不提供排序、方向或身份判断。
- 正文侧作者技术词仍位于“禁用约束”中，不进入未来正文表层。

## 五问自检

1. 本章首先发生在人身上的，是阿尔德把唯一一名新守备交给一扇不肯开的门，伊莉亚只承担一句转告，赛恩拒绝让未知者被家族名字先行接收。
2. 阿尔德延长下渠区等待，伊莉亚留下可能失败的承诺，阿芙让失言先被听见，露米把自己的口头规则也记下来；这些选择都留下未来可能反噬的后果。
3. 没有人完成“我终于明白”；人物通过停顿、改口、暂留和不盖印记行动，正确的话没有被提前交给他们。
4. 没有提前支付候位制度终局、伊莉亚最终麻木、阿尔德最终政治立场或第三声本体；只让时间第一次变成可被人群争夺的先后。
5. 删除所有技术隐喻后，一名守备、两处等待、一扇拒绝打开的门、一句被携带的话和一张被水浸透的报告牌仍构成完整冲突。
