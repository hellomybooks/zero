# 第二卷第六十四章《退线》场景卡审校记录

## 状态

- 状态：场景卡已完成两轮独立审校、回修与最终窄范围 Canon 回归，定稿候选。
- 场景卡：[64-退线.md](../../04-第二卷设计/章节卡/64-退线.md)
- 对照材料：第63章《线外》场景卡、正文与 Canon Change 记录；第二卷总控；创作原则与阶段评价。
- 最终规模：258 行、28,229 字节。

## 审校范围

1. 两名守备、第三声牌、空白木片、公共水桶、私人礼灯、裂木板和守备火绳的跨章物资与责任连续性。
2. “一次处置不自动续线 / 退线”是否是行政与资源结果，而不是魔法或安全本体。
3. 伊莉亚、阿尔德、任、露米、赛恩、阿芙和线外来者是否拥有具体选择、失败和后果。
4. 第三声与零是否保持未知，是否提前支付后续世界观答案。
5. 场景卡是否能支持正文通过水、湿衣、门缝、灯油、火绳、队列和等待呈现冲突，而不是逐项解释规则。

## 第一轮 Canon 审校发现与回修

- 初稿曾让“封石旁负责的守备”与东十四巷守备、下渠区守备并列出现，形成第三名即时守备；已改为封石无人驻守，只有上一班留下的火绳和石灰，东十四巷守备随后被撤往封石。
- 第63章结尾第三声牌已经贴在护石旁；已在第64章开场明确写出上一班离开封石时把牌取回调度处交给任，火绳留在封石。
- 线外来者原先提到“他们的药”，易被读成新增药物；已改为“不喝他们的水，也不占他们的木片”。
- 既有裂木板已经在第63章成为第三名伤者身侧的支撑；已删除把它抽去给线外来者挡风的写法，改用门边石角与伊莉亚身体挡风，裂木板继续留在第三人身侧。
- 空白木片统一为任从开场一直持有的同一块，线外来者在门边灰地上写字并抹去，末尾由任把木片放入下一班栏。
- 下渠区半桶水明确沿用场景二公共水桶旁的水源，未新增隐性水源或新灯。

## 第一轮文学审校发现与回修

- 将章节的关键动作前置并减少解释依赖：守备准备离开、阿芙接水导致门闩外滑、赛恩灯油见底、半桶水过不了门槛先成为场景事实；“退线”在守备离开和居民挪动水桶之后才命名。
- 给人物增加失败版本：任先把“未纳入照护”删短成“线外等待”；露米为记录口号迟了一息，没有及时拉开追水桶的孩子；阿芙为了接水让旧伤进水、门闩外滑；阿尔德对守备说会有下一班接替，却没有可派的人。
- 让伊莉亚在拒绝与伸手之间摇摆：她没有把线外来者纳入三人签名，却先让她喝了一口水，使托恩多等一个呼吸；她用身体和门边石角挡风，不以签名制造资源。
- 让线外来者拥有非谜底化的生活惯性：她回头等待迟到的人，先说不需要水，随后因寒冷伸手；她写下名字又用湿手抹掉，拒绝在此刻交出名字。
- 让赛恩只做灯的动作，不替他解释“灯也是排除”；他拒绝把礼灯移到水桶旁，灯最终因油耗熄灭。
- 削弱第三声提示：本章只保留守备火绳重新受力，不叠加多处回应、石灰来源或拟人化等待。

## 最终窄范围 Canon 回归

- 结论：通过。
- 人员：开场只有东十四巷与下渠区各一名守备；封石无人驻守，东巷守备后被撤往封石，没有第三名即时守备。
- 牌与责任：第三声牌的跨章位置已闭合；空白木片始终由任持有；“本次处置已用”“门后手与声音仍在”“下一次复核未定”分开记录。
- 物资与门件：公共水桶、半桶水、同一盏私人礼灯、新木闩、断门闩、第三人身侧裂木板和既有守备火绳账目闭合；未新增药、灯、担架、布、固定木片或短绳。
- 三种线：一次处置、照护线、通行线和退线均未写成结界；下渠区仍照护线内 / 通行线外，东十四巷正式优先级退去不等于无人。
- 未知边界：第三声只表现为火绳受力，来源、性质和是否为人声未确认；零不提供方向或身份；线外来者未被写成第三声、伤者或正式照护对象。
- 禁用词回归：场景卡中的作者侧技术词只存在于“正文不得出现”的设计约束中，未来正文不应出现。
- `git diff --check`：通过。

## 五问自检

1. 本章首先发生在人身上的，是守备准备离开、阿芙接不到完整的一口水、伊莉亚让一个未签名的人喝一口、赛恩看见灯油见底。
2. 任、露米、阿芙、阿尔德和伊莉亚都做了可能后悔的事；准确记录与实际保护之间留下了可见损失。
3. 没有让人物完成“我终于明白”；伊莉亚只是摇摆，阿尔德只是下令，任只是补回自己的短词。
4. 没有确认第三声、伊莉亚终局成长或阿尔德政治结论；“退线”只成为下一章可以继承的状态。
5. 删除制度词后，门后一只手、湿外衣、半桶水、熄灭的礼灯和离开的脚步仍构成冲突。

## 结论

第64章《退线》场景卡达到定稿候选，下一步按卡生产并审校第64章正文。
