## 正文落实的核心事件

1. 开场先落在人身上：一名普通复看申请人已经等了两班钟，只想确认缠布手腕是否影响端汤握力；她的手腕、旧布、等待和生活愿望先于板面与街面话语出现。
2. “回执已收”沿墙面传播为“阿尔德接了，但人不来”，人群把下渠区报告牌边的淡炭痕“二”读成“二号空了”。正式板面仍完整保留“下渠区／候位二／阿尔德受领／仅现场报告／时刻未定”。
3. 同一块下渠区报告牌完成唯一物件链：板前脱离 → 费恩接住 → 普通申请人持有 → 排位窗口退回 → 费恩递回书记员 → 书记员一次性挂回同一板钉。传令员随后只携带退牌的口头问话，没有携牌下坡，也没有接走任的旁页。
4. 费恩的普通复看牌“暂缓”仍在手中，灰七临时在场记录仍挂在既有暂缓架且期限未定，传闻抄录副牌仍写“灰七代位，未确认”，手背旧布保持为身体状态；四者没有合并。
5. 申请人因拿错牌离开自己的普通复看队，排位窗口退牌时原有时机已失；费恩递牌时错过叫号。她没有进入下渠区照护，没有获得新的灯、药、候位、复看时刻或医疗资源。
6. 任只记录请求、牌的来源、正式候位二未改、普通复看叫号已过、复看未发生和本人不留名；记录没有制造新时刻。露米提前指出牌面不对应手腕，却没有给出可回到的路径；旧布松开时她也没有代申请人重新包好。
7. 申请人叫号已经过去后，阿尔德面对“是否亲自上板说明受领不等于到场”的新问话。他不抬脚，让传令员带回“正式行不改；报告牌回原板；候位二，时刻未定”；他放弃的是当面取回自己名字的机会，不被写成能够挽回申请人时间的人。

## 首轮审校发现与回修

### Canon / 连续性问题

1. 初稿在牌回板后又让传令员携牌下坡，造成第二次物理转移；已删除，传令员现在只携带口头问话，报告牌只由书记员完成一次回板。
2. 初稿把牌背写成只剩旧折角，抹掉第65—66章同一块牌既有的背面旧字；已改为旧字被水泡得发白、没有姓名和确定时刻，旧折角仍在。
3. 初稿把“正式主册”与正式板面混用；正文统一使用正式板面五字段，没有改写主册原始字段。
4. 初稿在正文里直接写入章节编号；已改为“昨夜”“已经在那里很久”等现场语言。
5. 生产回修同步校正结构化记录：场景卡、Canon Change 和本审校记录均统一为“费恩递回书记员—书记员挂回；传令员不携牌下坡”，并统一物理牌面用语为“下渠区”。

### 文学 / 人物问题

1. 初稿阿尔德段落过长，重复了第67—70章的“上坡—看脚—留守”骨架；已压缩为一次针对退牌问话的短现场选择。
2. 初稿提前替读者解释淡炭痕不是新候位牌；已删去校正句，只让“二号空了”由人群说出。
3. 初稿直白解释费恩的自欺、露米没有提供回路和任对请求的主题判断；已改由压牌、停顿、叫号、旧布松开和停笔表现。
4. 初稿有第二次费恩叫号和多次“牌已回板”的状态确认；已收束到一次叫号、一次实际挂回和章末一次视觉回收。
