# 第二卷第四十五章《不必第一》正文审校

## 审校结论

- 状态：通过 / 定稿候选。
- 审校对象：`05-正文/第二卷/45-不必第一.md`。
- 对照对象：第45章场景卡、场景卡审校、第44章《借路》正文与正文审校、第二卷生产看板、人物圣经中“赛恩和父亲”段落、Canon Change。
- 审校方式：独立子智能体初审 + 主审修订 + 独立回归复核 + 本地主审硬扫描。

独立初审提出两项必须落地的问题：侧门召见必须实际留下入门与出门登记，不能只由叙述声称存在；赛恩接受父亲“坐下”的要求后必须出现身体层面的迟疑与落座。主审补入侧门簿的入、出记录，以及赛恩膝盖失衡、扶椅、延迟坐到椅沿的动作；同时收紧零的拒绝边界，删除任替零解释靠近原因的句子。独立回归确认“通过 / 定稿候选”，没有必须修改项。

## Canon 与连续性核对

- 第45章直接承接第44章：赛恩带着普通牌缺角、责任牌和“外部责任未结”回到家族外门。家属召见只打开父亲晚年旧房，不恢复印记借用资格、禁书库、会客廊通行权或研究权限。
- 侧门登记把本章的责任边界落到纸面：入门人、责任人均为赛恩，带入物只有责任牌，同行者为空，召见牌由门内收回；离开时又登记赛恩本人出门和责任确认。任与零没有被登记为父亲私室的同行者。
- 零在门卫询问时由自身暗边退回屋檐并说“不进”。赛恩只说明零不属于本次召见，任和赛恩都没有替零解释拒绝原因；零的边界仍是零主动保留的边界，而非家族制度替它完成的判定。
- 父亲第一次明确说“其实你不用一直第一”。赛恩以“现在你告诉我”“我花了二十年变成你想要的人”“然后你告诉我其实不用”爆发；父亲的迟到道歉没有撤销过去的训练、座次、资源、赞许和失败后的安静，也没有立即完成和解。
- “第一”没有被写成一条正式法令。旧牌册没有“必须第一”的单句命令，却显示首位者长期获得灯室、训练师、主桌和优先资源；当下唯一灯室复验席按旧序写给赛恩，他要求转给候补者，只能记录“首位未接”，候补者和其他人仍须等待下一次分配。首位因此成为正在发生的资源阈值，而不只是父子争执中的抽象词。
- 父亲保存赛恩幼年歪斜儿童画，理由是“因为是你画的”。画没有家族印记和正式编号，保存同时包含私人爱意与长期隐藏的失职；赛恩带走儿童画，却没有因此原谅父亲。它暂时只是带着私人重量的物件，不是遗迹线索、世界谜题或治愈工具。
- 赛恩查不到“第一”最初由谁规定，只找到“沿前例”“按上一席”“依旧序”；家庭阈值由多人重复执行而维持，没有被归因给单一幕后制定者。这为后续寻找可靠答案留下接口，但没有提前提供高层真相。
- 任在侧廊外等待，只听见赛恩转述的“不必第一”，不进入私室，也不替父子关系调解；任与赛恩的关系继续保留公共制度和私人经验之间的不对称。

## 文学性与风格检查

- “不必第一”首先通过侧门、旧牌册、灯室席位、椅子、桌面和一张儿童画成为可触摸的生活事件，技术隐喻没有浮到叙事表面。
- 父亲不是全知解释者。他承认自己看见赛恩被排序，却没有及时阻止；私人爱意没有抵消公共沉默，迟到的道歉因此既真实又无力。
- 赛恩的爆发有连续的现实依据：身体先被要求站直，资源再按首位分配，最后才进入父子语言。把“第一”写成座次、训练、灯室和沉默，避免痛苦只停留在抽象说明。
- 零的拒绝没有被主角或任翻译成动机，保留奇幻感和未决危险；任也没有被安排成替父子戏提供答案的旁观者。
- 结尾保留不对称结果：父亲的道歉留在门内，首位未接仍留在簿子里，赛恩带着未结责任和儿童画离开。家庭内部的私人情感没有改写公共责任记录。

## 本地硬扫描

扫描对象：`05-正文/第二卷/45-不必第一.md`。

- 规模：2,105行、33,211字节。
- 禁用技术/API词、世界本体词和作者侧章节号扫描：正文仅因标题命中“第四十五章”，其余无命中。
- 关键链路扫描均有正文落点：`家属召见`、`外部责任未结`、`侧门簿`、`出门时刻`、`首位未接`、`灯室`、`儿童画`、`不进`、`我花了二十年`、`坐到椅子的最外沿`。
- 空间与责任结果扫描：侧门簿记录同行者为空；任留在侧廊，零拒绝进入；赛恩独自进入并独自出门，儿童画夹在责任牌与召见牌之间带走。
- 因果顺序扫描：先有召见登记与责任牌，再有私室冲突和灯室席位处理，最后完成出门登记；儿童画没有被写成制度凭证，首位未接没有被写成资格恢复。

## 第二卷第四十六章接口

- 赛恩开始寻找一种不依赖家族沉默、旧序和他人迟到解释的可靠答案；这个动机来自私人伤口与公共记录的双重不一致。
- “首位未接”仍留在簿子里，候补者没有被直接接替；下一章可以继续追问“谁有权定义下一步”，但不能把本章的家庭阈值直接解释成终极规则。
- 儿童画作为私人物件继续存在，暂不升级为遗迹证据或世界本体线索。
- 零的“不进”仍没有获得完整动机解释；后续危险可以从群体如何替它命名开始，但不提前完成第49章的怪物判断。
