## 一、审校目标

本章承接第65章《候位》，必须把候位推进为行政受领事件，同时保持以下边界：

1. “受领”只接收下一份报告，不等于救援、资源、到达、照护、处置、归属或时间保证。
2. 主册、任的副页、街面抄联和口语必须有清楚来源，不能把误读写成正式责任。
3. 东十四巷、下渠区、封石、第三声牌、零、守备、灯具、门件、木片和伤势必须承接第65章，不凭空增加资源。
4. 事件要首先发生在人身上：阿尔德签名并接到真实补记，赛恩处理被借走的家族名，伊莉亚承受湿指印误读和自己的失言。
5. 正文保持奇幻现场感，不出现作者侧技术词，不把规则写成 API 或说明书。

## 二、首轮 Canon 审校与回修

### P2：托恩夹板位置

原文“托恩躺在旧夹板旁”可能让人误读为夹板已经离开腿下。已改为“托恩的腿仍在旧夹板上”，与第65章“旧夹板没有移动”闭合。

### P3：术语来源

首轮发现“待填 / 待受领 / 受领待定 / 受领未闭合”来源容易混淆。回修后锁定：

- 主册使用“待受领”。
- 交班副页使用“待填”。
- 任的木片和副页旁注使用“受领待定”；副页不再出现“受领未闭合”。
- 街面口语从“待填 / 待受领”改成“无受领”“没人要”。
- 抄联把主册“待受领”压成“受领待定”，并明确这是抄写造成的改写。

### P3：封石转场

原文从封石记录直接切到阿尔德看火绳，位置略有跳跃。已加入“阿尔德把副页夹在臂下，跟着文书走到封石记录旁”，并明确：主册上的封石记录行与封石处的实体第三声牌不是同一物件；前者可以进入文书，后者仍由火绳压在护石旁。

## 三、首轮文学审校与回修

### P2：避免第65章行政复演

首轮指出本章原稿重复经过“调度板—东十四巷—赛恩 / 阿芙—下渠区—伊莉亚 / 线外来者—露米误读—封石—街面传播”的路径。回修没有删除必要地点，而是改变每段的动作功能：

- 东十四巷前段是阿芙与赛恩第一次面对受领栏；后段改为处理抄联擅自写下的“家族代领”。
- 下渠区前段是伊莉亚拒绝把个人转告并入主册；后段改为湿指印被当成签名，以及她看见阿瑟恶化后仍不扩大照护。
- 全章唯一真正的行政转折是阿尔德签名后立即收到下渠区牌背补记；后续街面冲突围绕这份已被接收的报告展开。
- 开场不再重复第65章的抢水事故，水桶只作为名字争夺的旁观物和既有物资背景。

### P2：压缩概念问答

已删除或压缩多轮“文书提问—角色定义—文书补充定义”对白，改用以下动作承载规则：

- 阿尔德先落笔，再接到阿瑟状态越过旧线的牌背，随后被追问“什么时候来”。
- 任把被主册压住的副页抽出，露米把纸写穿，显示准确记录无法控制传播。
- 赛恩实际刮掉“家族”两字，却无法让街面撤回“家族代领”。
- 伊莉亚的湿指印先造成误读，之后才出现“我已经有三个了”的语言失误。
- 封石段保留少量制度问答，但由火绳收紧、石灰掉落和阿尔德停顿完成现场证明。

### 已保留的人物代价

- 阿尔德只能说“我接这张”，无法回答何时到达。
- 伊莉亚的失言伤到线外来者，她没有用解释立即洗掉后果。
- 赛恩先过快说“我知道”，最终只能说“别替我写家”。
- 露米留下旁页上的小孔，不替世界裁决“没人要”是否是真相。
- 任的副页保留差别，却被主册重量压出折痕。
