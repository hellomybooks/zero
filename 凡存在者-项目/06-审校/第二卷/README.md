## 审校重点

- Threshold 是否先成为制度事件、人物冲突或具体危险。
- 分类是否产生资源、羞耻、暴力或关系后果。
- 任的分析是否被写成有用但有限的工具。
- 零的定界态是否被行政制度误读，而不是被作品提前解释完整。
- 赛恩、露米、伊莉亚与阿尔德的选择是否保留各自代价。
