## 场景卡初稿

- 初稿规模：230 行，27,324 字节。
- 初始功能：将第85章门内生活推进到第一晚的火、湿布、干柴、门外寒冷与临时劳动；让“借火”成为有限资源事件，而不是空间能力或当地制度。
- 人物主轴：露米接受分辨湿布与干柴的劳动请求；零尝试送炭；任想等待露米和零回来却没有足够参照和位置；伊莉亚、诺克、赛恩各自只能处理一小段现实。

## 首轮独立审校

### Canon / 连续性

- P1：0
- P2：5
- P3：4

必须回修的边界：

1. 炭运输若再次触发新的地面移动，会复演第85章门内外错位；必须完全建立在第85章既有断续地面、风、容器和零的急躁上，不新增 `MAP-OUT-03`。
2. 缺口陶碗必须明确是第85章被推到露米面前、但仍属于院内的同一只碗；“缺口”只能指碗沿破损，不能临时变成漏水裂缝。
3. 火源范围不能扩展为当地通用借火规则；只登记为本院本晚的一块炭，不产生第二处稳定火源。
4. 第85章墙边木板、墙脚散石要与零的窄布条、两枚扁石和第83章小圆石区分，不能静默新增路标或空间固定物。
5. “我不知道”等台词只能是被现实逼出的失败版本，不得写成任完成终局认识；不得让零或露米完成归属选择。

### 文学 / 人物

- P1：0
- P2：2
- P3：执行提醒

必须回修的边界：

1. 初稿的“炭到门槛前失败”与第85章节拍过近，需要让炭短暂送到任手里、暖手后在门外湿地熄灭；这样资源发生了有限传递，但没有形成第二处火。
2. 初稿的“火在”“我不留下 / 我也没问”过于整齐，容易提前支付主题；改为火边劳动、木柴和明早动作，让人物用生活事务回避真正问题。

## 回修记录

- 将炭的结果改为：缺口碗沿浅硬土滑到外侧，任短暂接住并被暖到手，炭放入湿草与碎柴后熄成灰；不写成抽象的“火无法传递”。
- 明确人不能沿浅硬土连续通过，但物件可以在这一次具体条件下短暂滑行；第86章不再发生新的地面移动。
- 明确缺口碗是第85章同一只院内普通碗，缺口限定为碗沿破损；露米没有获得所有权。
- 将火源收窄为本院本晚一块炭，删除可扩展为当地制度的“一小截干柴”借火选项。
- 将木片锁定为第85章墙边既有木板，将赛恩使用的物件锁定为墙脚普通散石，不调用零的两枚扁石，不制造新路标。
- 删除“火在”与“我不留下 / 我也没问”，保留露米的明早翻布、零的硬木和任的有限等待。
- 将候选 ID 收窄为 `ARC08-FIRE-86-01`、`ARC08-HOUSE-86-01`、`ARC08-LUMI-86-01`、`ARC08-ZERO-86-01`、`ARC08-86-01`；它们仍只在正文通过后考虑登记，角色项不自动扩展为世界通则。

## 最终独立窄回归

### Canon / 连续性

- P1：0
- P2：0
- P3：1（正文执行提醒，不阻断）
- 结论：通过。

最终确认：

- 浅硬土与第85章末状态连续，本章没有新的地面移动，也没有新的声音方向规律；物件短暂滑行不等于人物可以沿同一路径通过。
- 缺口碗来源、破损属性和归属明确；零的窄布条、两枚扁石、第83章小圆石、路线图、旁页和第85章墙边木板均未发生越界转移。
- 火源限定为本院本晚的一块炭；炭短暂暖到任的手，却没有在门外形成第二处火，没有新增火焰、空间或身份能力。
- Missing Region、第三声、零身份、Alpha、界兽来源、古代文明、诺克哥哥和任身份均未解释。

### 文学 / 人物

- P1：0
- P2：0
- P3：执行提醒
- 结论：通过。

最终确认：

- 露米的“明早翻布”、零的“明早木头很硬”、任的“等火灭之前”都是不完整的防御动作，不是主题结论。

- 删除技术隐喻后，借火、过夜、等待、劳动和不愿承认的害怕仍然成立。
