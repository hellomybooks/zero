## 回修内容

- 将两笔订单改为一笔屋棚修缮整幅订单：买主已付定金，半段布只能暂时盖住小洞，定金折成半段货款，剩余货款不付，另一段布重晾。
- 将木架锁定为三段木料与留有空隙的木钉组成；地面两端不同位移先造成节点剪切，外脚随后离地。
- 明确外侧布边的染线绕过铁钩，钩柄压在外侧木料的松钉节点旁；任把“外脚会先离地”喊成“先解外钩”，买主扯钩使拉力集中，松钉脱出，布边初裂。
- 保留诺克物理判断正确，但不让他回答剪布、交货或赔付；染布匠依劳动经验沿旧缝剪布。
- 零保留窄布条但不跟随被风吹走的染线；露米与零只共同停留、注视半开的普通木门，不把布条绑定到外侧方向。
- 将卡片中所有“共同外向动作”旧表述改为“共同停留与注视”；统一“半段货款”“重晾”“染线”等物件与账目称谓。

### Canon / 连续性

- P2：0

最终确认：

- 第80章次日白天成立，旧灯柱火已熄，黑签仍在布袋中。
- 第79章的局部关系保持 / 朝向与功能分离，被第81章进一步落到多段木料节点剪切；没有把形变写成刚体瞬移或新魔法。
- 物理链为：节点错动 → 外脚后离 → 染线绕钩 → 拉力集中到松钉 → 松钉脱出 → 布边初裂。
- 任确实把局部判断喊成错误动作并造成小损失，但没有因此获得裁决权；诺克不承担订单价值判断。
- 单笔订单账目闭合：定金折为半段货款，买主暂时补洞但仍缺一段，染布匠失去剩余货款，另一段重晾。
- 半开的普通木门是唯一远处生活痕迹；没有人物、声音、脚印、异常回应或 Missing Region 入口解释。
- 主角团没有获得食物、工具、住所、身份、路册权限、固定路线或新照护位。

Canon P3：

1. 正文中应保持“松钉脱出后木架只是暂时站住”，不能下一章无痕恢复。
2. 正文中应保持“半段”指同一幅布被分成两段，不写成宽度减半的技术规格。
