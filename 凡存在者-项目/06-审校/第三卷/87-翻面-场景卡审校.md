## 场景卡初稿

- 初稿规模：275 行，约27KB。
- 初始功能：把第86章的“明早”推进到晨间翻布、回篮、劈柴和门外寻找物资；用一块半干布让门内、门外和回篮女人面对同一项有限资源。
- 人物主轴：露米被要求把布翻面，却不能从干湿判断优先级；零劈不动硬木后改搬湿柴；任第一次看到等待会改变门外人数；伊莉亚与赛恩离开寻找普通布和食物。

## 首轮独立审校

### Canon / 连续性审校

- P1：0
- P2：3
- P3：2

问题：

1. 诺克在章末说“他们会沿硬地回来”，超出场景卡规定的局部判断边界。
2. “同一只空篮”把第85章已带走的旧状态与本章篮中新增粮食混在一起。
3. 摘要中的“下一块布”可能被读成静默新增物件，需要明确为手里的湿布。

连续性核对通过：

- 第85章同一只篮子可以随提篮女人回返；新出现的一小袋粮食由她带入，不是院内生成。
- 第86章院内已有多块晾布，半干布、另一块湿布、木板、缺口陶碗、旧火钳、零的物件和墙脚散石均有连续来源。
- 门内外人物仍不能连续通过；伊莉亚与赛恩沿可见硬地离开，没有进入新聚落、恢复通路或引入新路线。
- 半干布、粮食受潮和临时寻找布 / 食物仍是普通生活资源，没有扩展为制度、正式债务或新能力。
- 第三声、Missing Region、零身份、Alpha、界兽社会、古代文明和任身份均未揭示。

### 文学 / 人物审校

- P1：0
- P2：2
- P3：3

问题：

1. 任的“抬起手—没有喊”复演第86章，需要让本章压力由门外少掉两个人和转身看离开的脚步承担。
2. 场景六“里面有 / 已有人拿 / 下午会还 / 那是下午”的对白过于整齐，像人物共同替作者总结资源不足。

人物核对：

- 露米通过分辨干湿、帮助折布和继续翻湿布推进，未把劳动误说成归属。
- 零的“那是我坏了？”是粗糙的失控；木头失败后分湿柴不是成熟成长，只是一次无人夸奖的转向。
- 任仍有不甘和自欺，没有完成放手；伊莉亚和赛恩离开找物资不是照护终止；诺克只描述当前地面。
- 回篮女人已有篮耳、草籽、湿粮和“下午还”等生活动作，不是纯粹制造资源冲突的功能人物。

## 回修记录

- 将“昨晚提空篮 / 同一只空篮”统一为“昨晚送篮的女人 / 同一只篮子”，明确篮子已离开并在本章带粮返回。
- 将“下一块布”统一为“手里的湿布”，并补明第86章院内本来就有多块晾布，避免静默新增物件的误读。
- 将诺克的返程判断改为“我只看见他们往那边走”；并将前一句改为“这段硬地没有变”，避免同一句机械复述。
- 删除第86章式的“抬手—没有喊”收束，改为任听见“这面还湿”后转身看向离开的硬地，旁页上的人数记录被露气晕开。
- 将场景六对白压回不完整的人话：“里面有 / 我看见了 / 她下午还 / 我现在就要”，保留当下需求与未来承诺的摩擦，不让人物共同解释主题。
- 给提篮女人增加掸掉裙摆草籽的普通动作，使她在资源冲突之外拥有自己的生活节奏。

## 五问自检

1. 本章首先发生在人身上的是否是晨间翻布、取篮、擦冷手、找吃的和劈木失败，而不是资源规则解释？——是。
2. 有没有角色做了以后可能后悔的事？——露米继续替女人折布，零急着劈硬木，任没有阻止伊莉亚和赛恩离开。
3. 有没有一句正确的话不应该由当前角色说出来？——没有人说“准确描述不能创造资源”或“等待会改变队伍”；人物只谈布、篮、木头、冷和下午。
4. 是否提前支付未来重要情绪？——没有确认露米留下、零归属、任放手、界兽制度或下午一定归还；只留下劳动、欠布和人数变化。
5. 删除技术隐喻后冲突是否仍成立？——成立。有人要保住粮，有人要擦冷手，有人想证明自己能劈木头，有人不愿承认等待让同伴走远。
