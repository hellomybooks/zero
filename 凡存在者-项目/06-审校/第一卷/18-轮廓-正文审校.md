# 第18章《轮廓》正文审校

## 审校对象

- 文件：`05-正文/第一卷/18-轮廓.md`
- 依据：已通过的第18章场景卡、场景卡审校、Canon v1.0、第一卷总控、伏笔矩阵、技术概念与魔法翻译表
- 当前状态：通过最终双审，定稿候选

## 审校重点

- 是否先呈现真实活体目标、反光、灰粉、白线、固定钉、错误闭合和危险，再出现 `Contour`。
- 折尾兽是否只作为作者侧称谓；课堂人物是否只称目标或槽中活物。
- 细灰粉、短铜线、三枚白色固定钉与第15章普通金属固定钉的器材连续性。
- 任是否只比较相邻观察中的少数局部边缘变化，不预测目标下一步，不提前引入光流或追踪能力。
- 任、赛恩、露米的能力分工是否成立：任判断归属，赛恩稳定平面，露米排除反光层。
- 第一次闭合是否有临界危险、奇幻震撼、短时限制和未接尾端代价。
- `Contour` 是否只是事后私人翻译，不成为咒语或 API 教程。
- 章末是否集中在“未接上的尾端是否仍属于同一目标”，并不提前进入 Bounding Region、Mask、Inside / Outside、Ground Truth。

## 第一轮独立审查记录

### Canon / 连续性与技术边界

第一轮审校无必须修复项。审校确认正文只使用“目标”“槽中活物”“那只活物”，没有提前公开作者侧称谓“折尾兽”；第15章普通金属固定钉与课堂三枚白色固定钉已区分；第17章的一晚许可结束后，正文明确进入第二天下午，零没有进入课堂。

正文中的器材统一为浅黑石槽、浅水、细灰粉、短铜线和三枚白色固定钉。赛恩只负责固定钉与平面，露米只指出反光延迟和颜色层差异，任只比较相邻观察中的少数边缘局部变化，并明确不预测目标下一步。`Contour` 在错误闭合、危险、成功闭合和代价之后才出现，仅作为任的私人标签；正文未提前出现 Bounding Region、Mask、Inside / Outside、Ground Truth、光流、追踪、Canny、OpenCV 或 API 等概念。

### 文学 / 奇幻感

第一轮审校无必须修复项。三次失败分别表现为反光误合、尾部误分和按目标当前位置画线导致固定钉反弹；任的判断从失败总结、露米的层次提示、局部边缘筛选逐步推进到第一次闭合，没有突然获得答案。闭合瞬间通过白线临界接合、水面静止、未触及的水纹继续、声音变化、活物收紧和手腕反震呈现奇幻震撼。

审校建议已采纳：教师补明“从多条边缘中找出属于同一目标的连续外沿”；补出白线反震与普通金属固定钉硌伤的区别；统一为“石槽边”；赛恩明确记录“尾端未接”；压缩章末重复，让主悬念集中在未接尾端是否仍属于刚才的活物。

## 最终针对性复核

- 连续外沿任务自然，且由三次失败逐步具体化。
- 普通金属固定钉造成物理硌伤，白线反震造成术力伤害，两者区分清楚。
- `Contour` 保持事后私人翻译，不是咒语，也没有 API 教程感。
- 章末的石槽、浅水、细灰粉称谓统一，未接尾端的归属悬念集中，余味成立。

## 最终结论

- Canon / 连续性：通过。
- 文学 / 奇幻感：通过。
- 状态：正文通过最终双审，定稿候选。
