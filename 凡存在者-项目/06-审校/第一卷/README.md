第1—2章保留历史审校文件命名；第3—36章分别使用“场景卡审校”和“正文审校”两份记录。命名差异属于资料沿革，不代表审校等级差异。

任何第一卷修订必须同时说明：

1. 触发修订的正文事实或 Canon 冲突。
2. 是否改变人物、规则、伏笔或读者误判。
3. 是否需要登记 Canon Change。
4. 修改后是否重新通过 Canon 与文学双审。
