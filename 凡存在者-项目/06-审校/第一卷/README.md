# 第一卷审校区

这里保存第一卷《白色边缘》的场景卡审校、正文审校、收束审计和可持续生产记录。

## 当前状态

- 第1—36章的场景卡、正文和对应审校记录已完成。
- 第一卷收束审计已通过；正文状态统一为“定稿候选”，不是不可修改的终稿。
- 当前生产目标是维护第一卷的可持续生产基线：任何重写、补写或跨卷引用，都必须先经过本目录的连续性核验。
- 后续卷的已提交正文属于项目快照，不改变本目录作为第一卷基线的职责。

单章审校文件保留当时的生产过程记录；其中“下一生产目标”“可进入正文生产”等句子描述的是记录生成时的节点，不等于当前项目仍停在该节点。当前状态以本 README、《第一卷-收束审计》《第一卷-可持续生产基线》和《第一卷-状态账回归》为准。

章节卡末尾的验收清单使用以下语义：`[x]` 表示截至当前审计版本已由章节卡、对应正文和审校记录核验通过；若后续发生正文、接口或 Canon 变更，须重新置为 `[ ]` 并回归审校。它不代表永久 Canon，也不代表不可修改终稿。

## 单章记录规则

第1—2章保留历史审校文件命名；第3—36章分别使用“场景卡审校”和“正文审校”两份记录。命名差异属于资料沿革，不代表审校等级差异。

任何第一卷修订必须同时说明：

1. 触发修订的正文事实或 Canon 冲突。
2. 是否改变人物、规则、伏笔或读者误判。
3. 是否需要登记 Canon Change。
4. 修改后是否重新通过 Canon 与文学双审。
