# 第 5 章《第一道边》—正文审校记录

## 状态

- 正文：已写入。
- 审校：独立复核完成，定稿候选。
- 依据：Canon 唯一真源、第 5 章场景卡、第 1—4 章正文、审校协议。

## 待检查项目

- 小屋袭击是否产生新的空间后果。
- 峡谷入口、出口、侧支道和光照位置是否清楚。
- Edge 是否只作为局部、短暂、失败率高的观察现象出现。
- 光照是否被误写成魔物弱点。
- 任的观察是否有明确代价，零是否越界成为提示器。
- 是否提前出现完整白界、Canny、OpenCV 或稳定魔眼。
- 章末 Edge 是否是命名而非咒语或 API 调用。

## 独立复核结果（2026-08-15）

### Canon / 连续性审计

- 未发现 Canny、OpenCV、Sobel、魔眼、完整白界或全世界失去颜色的提前泄露。
- `Edge` 只在章末出现，表现为任给局部白线贴上的临时名字，不是咒语或攻击术。
- 光线没有伤害、束缚或驱逐魔物；正文明确写出它只是改变某个条件下的可观测结果。
- 湿岩反光、角度变化、灰尘噪声和运动时机均已写入；肩伤在实验中重新裂开。
- 已修复触碰连续性：任不再抓住零，也没有被零拖动；改为任跟随零的可见轮廓移动。
- 已补足代价因果：任因停留观察而错过主路出口，坠石封住出口，随后被迫进入侧支道。
- 手机仍只有屏幕冷光；零没有解释机制，也没有泄露 Alpha、Copy、Observed、Mat 等后期概念。

### 小说编辑 / 奇幻感审读

- 小屋坍塌把避难所变成陷阱，危险升级明确。
- 峡谷入口、主路、出口、湿岩观察位和侧支道均可执行；侧支道出口与零重新汇合。
- 任从逃跑转向主动观察的心理铰链成立，但观察导致受伤和失去出口，没有形成外挂式胜利。
- 本章实验与第 2 章的泥浆 / 灰尘 / 落叶试探不同，核心是光暗交界与视角条件。
- 零的对白保持局部、迟到和偏题，没有成为机制提示器。
- 已将章末定义收窄为“暂时只能把它看成”，保留后续推翻空间。

## 审校结论

**通过，定稿候选。**
