# 第22章《哪里是火》正文审校

## 审校对象

- 正文：`05-正文/第一卷/22-哪里是火.md`
- 场景卡：`04-第一卷设计/章节卡/22-哪里是火.md`
- 对照：第21章《火兽》正文、CANON 唯一真源 v1.0、Canon Change、伏笔矩阵
- 当前状态：最终 Canon / 连续性与文学 / 奇幻感双审通过，定稿候选

## 第一轮独立审校

### Canon / 连续性与技术边界

通过。正文承接第21章未熄灭的火兽、封住的观众侧油槽、另一段连续媒介、浅水盘、湿布和教师持续干预；Contour 闭合失败、范围判断失败和“哪里是火”的问题转换均已落地。透明范围只存在于任的白界中，不是实体、结界、安全区或火兽本体，火焰、热浪和烟仍可越过范围。

### 文学 / 奇幻感

首轮不通过，发现一项即时承接问题：第21章末教师木片已经敲击，第22章初稿又写木片停在半空，章末还重复敲击，形成同一动作被倒回和重复触发。

## 修订记录

- 第22章开头改为承接第21章“木片敲过石面的回声还没有散尽”，浅水盘、湿布、油槽和封术均写成持续状态，不重新授予观察许可。
- 删除中段再次敲击的动作，改为“那一下敲击的回声在火声里渐渐变薄”；章末改为教师继续压住白石边缘，沿线推进的封术又亮一截。
- 清除作者侧章节编号，正文不写 API 名称，不把透明范围写成说明书或现代技术笑话。

## 最终双审

- Canon / 连续性：通过。第21章即时承接、教师干预、白界被动回返、范围可越界和第23章尚未收缩均一致。
- 文学 / 奇幻感：通过。火势与热感先形成真实危险，Contour 失败和热痕误判推动“哪里是火”；透明范围保留神秘性与不可靠性，结尾留下“范围里有许多不是火的东西”的探索钩子。
- 技术边界：通过。`CV-04 / boundingRect` 只作为故事现象出现；未提前引入 Mask、ROI、minAreaRect、Hough、Ground Truth、Inside / Outside，也未让赛恩、露米、教师或对手看见任的透明范围。

## 结论

正文通过最终双审，标记为定稿候选。下一生产目标为第23章《一平方米》场景卡；正文不得反向悄悄修改本章 Canon。
