# 第一卷 Canon—正文反证审计

## 审计目的

这是一份针对高风险正式伏笔的“最严格读法”审计，不以“可以解释”为通过条件，而是逐项比较：

1. Canon / 章节卡究竟要求什么。
2. 正文实际让读者看见了什么。
3. 两者是否可能被读成不同的世界规则或人物完成态。

本审计由 GitHub Issue #1（2026-08-18 阶段审阅）触发，首次范围为第一卷第36章的水面倒影和任的“我不知道”。

## 反证规则

- 如果正文最自然的读法越过了 Canon 的限制，即使可以用作者侧解释补回，也记为问题。
- 如果一个句子让长期人物完成态看起来已经完成，即使后文仍可反转，也记为提前支付风险。
- 修复优先回到既有 Canon，不用新设定覆盖旧冲突。
- 本记录保留原审校“通过”的历史结论；修订结果写入末尾，不静默改写历史判断。

## 修订后的严格复读

### CH36-RX-01

正文现在让赛恩和任都先于水中影子动作，水面停顿后才跟随；任放下时，倒影再次延迟。异常仍然具体、可感知且不能被普通水波完全解释，但不再天然意味着倒影拥有人物尚未做出的未来动作。

这保留了：

- 水面不是现实的即时镜像。
- 任和零的观察条件不完全相同。
- 现象仍可能指向更深层的观察关系。

同时删除了：

- 第一卷直接展示未来动作。
- 过早打开时间层或预测层的解释路径。

### CH36-RX-02

“你又说不知道了”只指出任再次使用这句话，不替他宣布已经学会接受未知。任仍然在心里形成漂亮而危险的模型，仍然试图继续解释世界；他在这一刻做对的只是没有把零交给墙上的解释。

## 未触发修改的 Issue #1 观察项

### Boundary Form 的情绪 / 视觉兑现

第35章已经提供三条白线、三处现实锚点、零主动答应站入交点、白边沿三线形成、每处受力传到零、裂纹蔓延、三种后果第一次归于同一有限区域，以及为救伤员主动拆界。它的爆发不是体型升级，而是零在不依靠墙、灯或任的手时维持边界，并承担了选择的代价。

结论：当前叙事功能已经成立；保留“出版级锁定前再做音量审阅”的 P2 观察，不为追求更大画面而立即重写。

### 精确拆分不是万能解法

这是全书长期约束，不由第36章局部重写解决。第一卷已有“线不能挡住力量”“救人优先拆界”等失败条件；后续外部阅读若指出“拆分后问题总能局部解决”，再按章节和具体后果登记。

### 人物语言失败

“不是 A，是 B”“我不知道”等节奏继续保留，但需要在后续外部阅读中分别观察任、零、赛恩、露米、伊莉亚和诺克的语言失控方式。当前没有足够证据进行全卷统一降精度改写。
