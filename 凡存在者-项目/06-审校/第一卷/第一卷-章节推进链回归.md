# 第一卷《白色边缘》章节推进链回归

## 回归状态

- 日期：2026-08-17
- 范围：第1—36章章节卡、每章后续接口、第一卷总控、第一卷收束审计及对应单章审校记录
- 目的：检查每章是否同时完成至少一项人物/关系推进、一项世界或社会推进，并把真实的未决问题传递给下一章
- 方法：先读章节卡的承接、核心功能、场景推进、章末钩子和后续接口，再与已有正文审校结论交叉；本轮不是逐句润色，也不把技术术语数量当作章节推进

## 三、三条连续事件带

### 1. 第1—12章：追杀 → 共同求生 → 社会危机

这十二章不是把同一个“不可见魔物”重复展示十二次。推进顺序是：

`后果可见` → `痕迹会误导` → `非人存在可交谈` → `关系暂时成立` → `局部边缘出现` → `白界过载` → `人类灯火` → `社会排斥` → `身份缺失` → `魔法制度` → `群体异常` → `共同防守`。

每次技术现象升级，都改变任与零的现实处境：逃生、饮水、进村、登记、被利用、救人。第12章不是能力展示的终点，而是把“任能看见什么”转换成“谁愿意依据他的判断行动”。

### 2. 第13—24章：学院比较 → 局部胜利 → 历史不安

第13—14章完成制度转场，第15—20章建立任、赛恩、露米三种观察方法的关系，第21—23章把三人的差异放进同一场火兽战，第24章再把个人胜利接回古代文明。

第21—23章是有意的单一事件带，不应拆成三个独立的“新技能展示”：

`Edge 不稳定` → `先问哪里属于火` → `范围收窄到现实媒介`。

三章的新增不是术语数量，而是责任从任的视野转移到多人、方石、油槽、湿布和教师的现场协作。若外部读者指出战斗拖沓，优先检查每章的人物站位和现实媒介是否清楚，不直接删掉问题收窄链。

### 3. 第25—36章：修复 → 失效 → 对象归属 → 公共边界

第25—26章先把历史悬疑落回身体和生活；第27—29章让同一未知袭击分别击穿识别、复验和价值感；第30—35章再逐步把“没有轮廓”推进为背景、对象、区域、身体和公共战场的不同尺度。

第27—29章的差异必须保持：

| 章节 | 失败的层次 | 人的后果 |
|---|---|---|
| 27 | 看见环境却锁不住袭击者 | 任和零撤离，伊莉亚处理伤口 |
| 28 | 看见方法却无法复验结果 | 任被“目标未确认”击中，知识优势失效 |
| 29 | 能改变媒介却不能证明伤害目标 | 零把失败理解为“自己没用”，任无意造成关系伤害 |

第30—35章也不是六次哲学解释：每一步都伴随搬运事故、记录字段、零的受伤、固定带、共同选择、锚点损失和救人。技术概念删掉之后，人物的恐惧、控制、拒绝和责任仍然成立。

## 四、未发现断档，但登记三项 P3 观察

1. **第1—2章的追杀重复风险。** 章节功能已有明确差异：第1章建立不可见跟随者，第2章证明痕迹会误导且敌人会适应；如果外部阅读认为开篇节奏重复，只做局部压缩或场景节奏调整，不改变“第二章白线前兆”的接口。
2. **第5—7章的 Edge / 白界连续风险。** 第5章让观察导致任错过出口，第6章让白界造成过载和误判，第7章让名字无法替代能力并把自然危险转成社会选择；功能已递进，但后续不能只重复“看见边缘”的视觉震撼。
3. **第21—23章的战斗疲劳风险。** 这是同一场战斗的连续收窄，结构上成立；需要外部读者验证每章的空间变化、人物分工和失败代价是否都能被感知。若不清楚，优先修正文中的空间锚点，不增加 API 说明。
4. **第25—28章的修复 / 失效连续风险。** 第25—26章分别把修复放到零的身体和学院日常，第27—28章分别处理“眼前却无边缘”和“重复观察也不可复验”；人物后果已经不同，但后续不得再次只用复验失败制造同一冲击。
5. **第27—35章的概念密度风险。** 这是第一卷真正的认识论推进区，且人物后果存在；但“失效—没用—背景—不是一个东西—边界—零的边界—定界”连续出现，未来润色必须保护日常动作、沉默、疲惫和错误语言，避免读者只记住概念名词。

## 五、阶段性答案保护

以下章末信息目前都只承担“把读者带到下一层”的功能，不得被当作已经支付的答案：

- **第4章“你刚刚才来？”** 是零的双义问句；后续若解释得过于直接，会抹掉它作为关系和语言歧义的伏笔价值。
- **第9章 `SOURCE ERROR`** 是任看到的社会/表示异常，不是万能系统提示，不能直接替他解释穿越本质。
- **第12章“凡存在者，总得留下点边”** 是任在战场中做出的临时判断，不是世界终极法则；后续不得反复让人物替作品背诵主题。
- **第24章“像函数调用”** 只是任的私人联想，古代符号没有被读懂、运行或证明来自现代技术。
- **第36章英文警告、`...Mat...View...` 与倒影慢一拍** 信息密度最高，但它们只证明还有更深层结构，不能让第二卷立刻给出原图、观察者或计算规则答案。

## 七、独立只读监督复核

本次另由子智能体对第1—36章章节卡、正文审校和第一卷总控进行独立只读检查，未修改任何文件。它与主审结论一致：

- 三个十二章篇章的推进链均闭合，所有章末至少传递了人物/关系、规则或社会压力中的一项。
- 未发现只有技术展示、没有新人物后果的连续章节；第18—23章和第30—34章的概念递进都由问题、家庭压力、协作、记录、受伤或责任承接。
- 最需要继续观察的是第5—7章的 Edge / 白界连续段、第25—28章的修复 / 失效连续段，以及第12、24、36章的高层联想密度。
- 未发现章末提前揭示 Zero / Alpha、任的穿越本质、无界存在本体、世界原图或“谁定义计算规则”等终局答案。
