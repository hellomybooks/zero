# 第22章《哪里是火》场景卡审校

## 审校对象

- 文件：`04-第一卷设计/章节卡/22-哪里是火.md`
- 来源：`36章导演卡-v7.md` 第22—23章段落
- 依据：CANON 唯一真源 v1.0、世界观与视术规则、技术概念与魔法翻译表、技术概念总登记表、伏笔矩阵、Canon Change、第18—21章场景卡与正文审校记录
- 当前状态：最终双审通过，场景卡可作为正文生产依据

## 审校重点

- 是否自然承接第21章未熄灭的火兽、封住一侧油槽、另一段连续媒介仍燃烧的战斗状态。
- “哪里是火”是否由危险现场逼出，而非 API 说明或作者直接讲解；任是否真正改变问题而不是突然升级。
- 第18章已有 Contour 经验是否先失败；透明包围区是否是更粗的空间范围，不是重新发现 Contour，也不是结界安全区。
- Bounding Region 是否首次以真实魔法现象出现，且只限制可能范围，不证明框内只有火兽、不证明对象本体、不自动熄火。
- 四个外侧位置、包围区过大、包含空白/烟/热影响和任的肩伤代价是否具体可执行；第23章“一平方米”收缩是否被保留。
- 对手是否仍然控火而不脸谱化；赛恩只记录几何；露米只提供颜色/热的局部差异；零不入场。
- 是否提前引入 Mask、ROI、minAreaRect、Hough、Ground Truth、Inside / Outside 或世界本体解释。

## 第一轮独立审查记录

### Canon / 连续性与技术边界

第一轮审校不通过，需修订。必须修复：透明包围区被写成物理墙/结界；四个位置到四条边的媒介和观测者不清；“全场看见透明框”违反第21章已确立的白界视角；“教师封术先被触发”有自动防护倾向；第23章的收缩被提前到第22章末。第21章的油槽、浅水盘、湿布、教师封术和另一段连续媒介仍燃烧的承接本身成立。

### 文学 / 奇幻感

第一轮文学审校认为问题转换和包围区素材成立，但戏剧链不够完整。当前只有 Contour 闭合失败，需增加一次“把持续发热石面当成安全外侧后仍被侧面火势逼退”的范围判断失败；“哪里是火”要先成为即时求生选择；包围区应先作为烟、水面、热感和火势异常出现，再被任理解为四边；框内危险要造成呼吸/站立/视野等具体后果；赛恩不能在任发现前画四点；章末不能真正开始收缩。

## 修订记录

- 将包围区改为任白界中的观察结果，不是实体、结界、物理墙或自动封术；火焰、热浪和烟仍可越过范围，实际隔离仍由教师、湿布和浅水盘完成。
- 明确四个极值位置来自火种、油槽、灰烬、蒸汽、白石和残余白界的先后记录；不在同一时刻稳定出现，不新增锚点或媒介。
- 将其他人的所见收窄：任看见淡白四边；赛恩只在任的站位与油槽亮带、灰烬停留处、蒸汽边、白石发红尽头等既有场地后果形成对应后画四边形；露米只看见颜色与热的局部差异；观众只看见火势、蒸汽和任的动作。
- 增加第二次范围判断失败：任把持续发红石面当成暂时安全外侧，火兽另一侧沿油槽绕过，热浪从背后逼退，他不得不依靠湿布和教师封术脱离。
- 将“哪里是火”改为任在白石线旁、脚下再次发红时的求生选择；对白被火声与灼痛打断后才补完。
- 将透明包围区显形改为：火势白痕先失去去路、烟向内折、水面倾斜、迟到热感先后出现，最后才在任白界中淡白连接；不写成火焰撞墙或框外扩散被自动压回。
- 将包围区内部危险具体化为任脚下灼热、烟遮出口、白界消耗；明确范围先颤动且不实际收缩，随后白界退薄但残白未消失，真正收缩留给第23章。
- 修正连续性：第22章不重新授予“再观察一次”的许可，只承接第21章已经发生的许可和教师持续的安全干预；任只能在自己的判断中尝试接合白痕，白界不响应主动召回、稳定或延长。

## 最终针对性复核

- 复核重点：包围区是否始终是观察结果而非物理阻挡；教师封术是否主动；第21章安全媒介状态是否连续；任白界与他人所见是否分离；Contour 失败、第二次范围失败、问题转换和过大范围是否形成完整戏剧链；第23章收缩是否未提前发生。

## 第二轮独立复核记录

- Canon / 连续性与技术边界：通过。范围始终只存在于任的白界观察中；教师只根据现实火焰、热浪和油槽危险行动；第21章的既有许可没有被重置；白界回返条件与“不可主动召回、稳定或延长”一致。
- 文学 / 奇幻感：通过。零散异象先于四边意识，Contour 失败与第二次范围误判形成连续危险；“哪里是火”由求生压力逼出；章末完整呈现“范围先颤动且未缩小，随后白界退薄但残白未消失”，第23章收缩未提前。
- 技术边界：通过。`Bounding Region` 只表现为可能范围，包含空白、烟、热影响和非火区域；不成为结界、安全区、对象本体、自动封术，也未提前引入 Mask、ROI、minAreaRect、Hough、Ground Truth 或世界本体解释。

## 最终结论

- Canon / 连续性：通过
- 文学 / 奇幻感：通过
- 技术边界：通过
- 状态：最终双审通过，场景卡可写正文，定稿候选
