# 第一卷外部阅读反馈入口

这里接收作者邀请的外部读者、编辑或审核者对第一卷《白色边缘》的阅读反馈。

第一次阅读请先看[第一卷外部审核包](./第一卷-外部审核包.md)，它把正文阅读顺序、首次阅读禁区、分段阅读和反馈边界集中在一起。

## 阅读顺序

第一次阅读与作者侧复核必须分开。

### 首次阅读

1. 先读[第一卷外部审核包](./第一卷-外部审核包.md)。
2. 只读[第一卷正文](../../../05-正文/第一卷/README.md)和其中第1—36章正文，按编号连续阅读。
3. 复制[反馈模板](./模板.md)，记录第一次阅读时的事实、猜测、情绪和阅读行为。

首次阅读不需要打开维护队列、第一卷总控、章节卡、审校记录、Canon、结构化设定或第二、三卷。

### 作者侧复核

首次阅读完成后，如需核对规则、人物功能或伏笔，再按以下顺序阅读：

1. [第一卷当前维护队列](../第一卷-当前维护队列.md)。
2. 对应章节卡和正文审校记录。
3. [第一卷总控](../../../04-第一卷设计/第一卷总控.md)。
4. 必要时才打开 Canon 和结构化设定。

不要先阅读远期 Canon 反转再判断读者是否“猜对”。本作有意保留漂亮但错误的第一层解释；读者的误判本身是有效反馈。

## 信息分层

- `05-正文/第一卷/`：本次外部阅读的唯一作品对象。
- `06-审校/第一卷/外部阅读反馈/`：审核说明和反馈填写工具。
- `04-第一卷设计/`、`06-审校/第一卷/` 其他文件：作者侧生产资料，不是首次阅读材料。
- `02-Canon/`、`03-结构化设定/`：作者侧设定和远期边界，不是正文事实索引。
- 第二卷、第三卷：后续项目快照，不属于本轮第一卷阅读范围。

如果你在首次阅读中打开过作者侧资料，请在反馈模板中如实记录；这不会使反馈失效，但主审会把它标记为“受作者侧资料影响”。

## 提交方式

- 复制[反馈模板](./模板.md)，按日期和审核者代号另存，例如 `2026-08-20-reader-A.md`。
- 反馈文件只写入本目录，不直接修改 Canon、章节卡或正文。
- 每条重要意见尽量注明卷、章、场景或可搜索的短语；不要只写“感觉不对”。
- 可以记录“不确定”“暂时喜欢但说不清原因”或“我可能误读了”。这类信息不需要被强行归纳成结论。
- 不要在反馈中写入私人联系方式、未授权的个人信息或项目外秘密。

## 处理流程

1. 主审收到反馈后，先判断它属于文字、章节功能、人物、奇幻感、技术隐喻、连续性还是 Canon 风险。
2. 反馈中的读者事实与主审的解释分开保存；读者误会不自动等于正文错误。
3. 若需要修改，先在第一卷当前维护队列登记触发原因，再决定局部修订或 Canon Change。
4. 修改后重新检查受影响章节卡、正文、审校、伏笔矩阵和必要的验证器。
5. 在反馈文件末尾记录处理状态：`待分类`、`保留为读者反应`、`局部修订`、`登记 Canon Change` 或 `暂不处理`。

## 审核者最有价值的反馈

- 你在哪一章第一次真正想继续读？为什么？
- 你把看不见的东西、零、界视或白界理解成了什么？这个理解在哪一处改变？
- 哪一处规则让你相信世界确实有魔法，哪一处像作者在解释技术？
- 哪个角色的动作或沉默比台词更清楚，哪个角色像在替作者说话？
- 哪个地方的情绪、信息或答案来得太早？
- 如果删除所有技术词，人物和冲突是否仍然成立？
