# 第一卷《白色边缘》外部审核包

## 这份文件给谁

给第一次接触项目、没有编程背景、准备以普通读者或编辑身份阅读第一卷的人。

你不需要先理解 OpenCV、Canon、章节卡或全部世界观。第一轮阅读的价值，正是记录你在不知道作者答案时实际看见了什么、误解了什么、在哪些地方想继续读或停下来。

## 无剧透简介

<!-- synopsis:start -->
现代软件工程师任在陌生的魔法异世界醒来，随即遭到一种无法看清的存在追杀。他只能从脚印、灰尘、光线和受损的物件中猜测危险；在逃亡中，他遇到一个不被当地分类接纳的存在零，并逐渐接触一个有真实规则、媒介和代价的魔法社会。

## 推荐阅读顺序

首次阅读只读第1—36章正文。

1. 先读本文件，了解反馈方式。
2. 打开[第一卷正文区](../../../05-正文/第一卷/README.md)，按编号从第1章读到第36章；也可以直接进入[第一卷正文目录](../../../05-正文/第一卷/)。

本审核包随所在 Git 提交版本生效。若从 GitHub 下载项目，请记录分支名称、提交短哈希或下载日期，避免把后续快照与本次反馈混在一起。

## 第一轮最有价值的记录

请优先回答具体问题，不必写长篇理论：

- 你在哪一章第一次真正想继续读？是什么动作、危险或关系让你继续？
- 你把“看不见的东西”、零、任的异常和白界分别理解成了什么？你的理解在哪一处改变？
- 哪一处最像真实的魔法世界，而不是技术演示？
- 哪个角色的动作、沉默或错误让你相信他/她真实存在？
- 哪一句话像角色自己说的？哪一句像作者借角色说的？
- 哪一处让你停顿、困惑或失去兴趣？当时你以为发生了什么？
- 如果删掉所有技术词，人物和冲突是否仍然成立？

“我不知道”“我暂时不想知道”“我喜欢这个误解”都是有效反馈，不需要替作者补答案。

这些不是要求你必须同意的结论，只是当前已经登记的 P3 观察区：

- 第5—7章：Edge / 白界连续出现，需观察视觉能力是否持续带来人物或社会代价。
- 第21—23章：同一场火兽战连续收窄，需观察空间、分工和失败代价是否清楚。

- 第4、9、12、24、36章：双义问句、`SOURCE ERROR`、边界格言、古代结构和遗迹残痕都必须保持阶段性，不应被当成已经公布的终局答案。

请先写自己的反应，再阅读这些观察项；不要让作者侧标签替代你的阅读经验。

## 如何标记问题

每条问题尽量包含：

1. 章节和场景，或可搜索的短语。
2. 你当时看到的事实。
3. 你产生的理解、情绪或停顿。
4. 这是否妨碍继续阅读。
5. 可选建议；不需要替作者设计修复方案。

严重度定义：

- `P1`：可能造成 Canon、情节或人物根性事故，或让后续无法成立。
- `P2`：明显妨碍理解、情绪投入或阅读推进，但可以局部修复。
- `P3`：节奏、语言、偏好、猜测或值得讨论的观察，不要求立即改稿。

“我不喜欢某个角色”通常不是 P1/P2；如果你能指出“因为哪一动作、哪一句话或哪一后果”，它就是有价值的角色反馈。

- 复制[反馈模板](./模板.md)，不要直接改正文、章节卡、Canon 或审校记录。
- 反馈文件只放在本目录，并使用日期和审核者代号命名。
- 不写入私人联系方式、未授权个人信息或项目外秘密。
- 主审会把读者事实与作者解释分开保存；读者误解不自动等于正文错误。
- 只有在反馈被分类并满足[当前维护队列](../第一卷-当前维护队列.md)的触发条件后，才会决定局部修订、Canon Change 或保留为读者反应。
- 修订后的提交和推送只是可见快照，不代表第一卷终稿或 Canon 锁定。
