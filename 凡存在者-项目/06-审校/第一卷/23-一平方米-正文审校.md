# 第23章《一平方米》正文审校

## 审校对象

- 正文：`05-正文/第一卷/23-一平方米.md`
- 场景卡：`04-第一卷设计/章节卡/23-一平方米.md`
- 对照：第22章《哪里是火》正文、CANON 唯一真源 v1.0、Canon Change、伏笔矩阵
- 当前状态：最终 Canon / 连续性与文学 / 奇幻感双审通过，定稿候选

## 第一轮独立审校

Canon / 连续性与技术边界通过。正文承接浅水盘已经推近白石线且水已漫出、湿布和油槽状态；残余白界只是短暂加深，不是重新开启。错误收窄明确为任误判烟下方/旁侧油膜，火焰沿现实媒介从范围外侧出现；最终方石大小来自教师、助手、湿布、浅水盘和火术学生共同处理外侧媒介，范围仍包含石面、烟和不确定热。

文学 / 奇幻感首轮通过，无必须修复项；建议压缩重复的“范围不是对象”说明、弱化“淡白边被划开”的物理感，并补足湿布动作交接。

## 修订记录

- 将一处规则解释压缩为“范围像被水汽打皱、始终不肯替他作答的薄纸”，让火势与行动承担更多说明。
- 将“淡白的边被它划开”改为“淡白的边在他眼前剧烈抖散”，避免透明范围产生物理墙感。
- 补出教师示意助手、助手抬起湿布再停住、后续重新压槽的动作衔接。

## 最终双审

- Canon / 连续性：通过。第22章媒介状态、白界被动性、范围可越界性、错误收窄和现实协作链均一致。
- 文学 / 奇幻感：通过。失败—判断—协作—收窄—安静—掌声形成完整节奏；任没有获得无代价全知能力，火术学生、教师、露米、赛恩均保留主体性。
- 技术边界：通过。`Bounding Region` 只以观察现象存在；“一平方米”是任对方石尺度的私人翻译，不是精确测量或对象本体；正文没有 API 教程、现代梗或禁用技术概念。

## 结论

正文通过最终双审，标记为定稿候选。下一生产目标为第24章《凡存在者，必有其界》场景卡；正文不得反向悄悄修改本章 Canon。
