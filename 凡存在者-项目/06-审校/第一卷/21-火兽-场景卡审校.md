# 第21章《火兽》场景卡审校

## 审校对象

- 文件：`04-第一卷设计/章节卡/21-火兽.md`
- 来源：`36章导演卡-v7.md` 第21—23章段落
- 依据：CANON 唯一真源 v1.0、第一卷总控、技术概念与魔法翻译表、技术概念总登记表、人物圣经、关系架构、伏笔矩阵、第18—20章场景卡与正文审校记录
- 当前状态：通过最终双审，可进入正文生产

## 审校重点

- 是否忠实落地导演卡的公开对抗课、强敌、巨大火兽和 Edge 不稳定，同时不把第18章已有的 Contour 经验误写成可稳定迁移，也不提前释放第22章 Bounding Region。
- 火兽是否首先作为真实、危险、动态的魔法现象出现，而不是 OpenCV 概念的说明案例。
- 任的能力边界是否通过两次具体误判、过载和身体/场地后果落地；是否仍保留主动判断而不是无意义挨打。
- 公开对抗规则、白石安全线、浅水盘、湿布、越界判定和火源媒介是否与既有学院魔法规则冲突。
- 对手是否强大但不脸谱化；赛恩、露米、零是否保持各自边界，不替任解决战斗。
- 第20章的赛恩精度压力、任的观察者位置与本章战斗是否连续；章末能否自然承接第22章“哪里是火”。
- 是否提前引入 Mask、ROI、Hough、Ground Truth、API 教程感或世界本体解释。

## 第一轮独立审查记录

### Canon / 连续性与技术边界

第一轮审校不通过，需修订。主要问题：场景卡把 Edge 写成可主动启动，与任只能在高压、收缩照明和残余边界叠加时短暂触发的既有规则冲突；新增“火砖”“安全水门”等媒介/设施超出已授权范围；第18章已经出现 Contour，不能写成该能力尚未释放；“赛恩看见白线”越过近距离第三人称与他人不可见任白界的限制；新增 `FIRE-01`、`REN-07` 未登记。

第一轮通过项：公开对抗课、强敌、巨大火兽、Edge 失稳、两次具体后果、与第20章翌日时间线、露米的有限提醒、零不入场、战斗未结束均成立。

### 文学 / 奇幻感

第一轮审校认为核心结构成立，但文学现场暂不完全通过。必须修复：让热压/观众后退等真实火势后果先于白痕分析；把两次误判明确区分为“热浪/烟边被当作外沿”和“只在瞬间成立的局部亮边漏掉侧面火势”；让对手以控制火势、避开身体而非作者说明体现强大；让赛恩只看见任的动作和站位，露米的提醒有限且可能被火声切断；收紧章末，不提前说出区域限定答案；解释安全介入只隔离一侧油槽，为什么火兽仍未熄灭。

第二轮 Canon / 连续性 / 技术边界内容通过：Edge 仍不可主动重现；场地媒介已收缩到既有 Canon；第18章 Contour 已出现但不能稳定迁移；赛恩只看见任的动作；零仍在外院侧廊非照明侧；第20章至第21章连续；无新增未授权技术能力。

第二轮文学 / 奇幻感确认热压先于白痕、对手战术、教师封术逻辑和章末留白均成立，但要求局部收紧第二次误判与观战压力因果，已完成修订。

最终独立复核通过。Canon / 连续性确认 `FIRE-01` 已在场景卡、伏笔矩阵与 Canon Change 登记；Edge 不可主动稳定重现；第18章已有 Contour 经验只在本章迁移失败；场地只使用既有媒介；赛恩不可见任的白界；零仍在外院侧廊非照明侧。

最终文学 / 奇幻感复核通过。第一次火势后果先于白痕；两次误判分别为热浪/烟边误认与局部亮边误当整体外沿；观众喊话改变任从准备退场到请求继续；对手以控火行动体现强大；教师只封住观众侧一段油槽，火兽腹下连续媒介仍燃烧；章末未提前说出第22章完整问题。

## 修订记录

- 将“任启动/再次启动边缘感知”改为“任试图依靠已有边缘经验”；白界如回返，改为由高压、收缩照明、残余白石边界和呼吸极限叠加触发，任不能主动控制。
- 将场地收缩为已有学院公开练习场、白石安全线、油槽/火种/连续媒介、浅水盘、湿布和教师/助手主动封术，删除火砖、安全水门及自动喷雾设定。
- 将第18章 Contour 的关系改为“已有经验无法稳定迁移到动态火兽”；本章不释放 Bounding Region，不否定 Contour 已经出现。
- 将赛恩的反应改为观察任反复改变站位、抓住栏杆又被挡回；他看不见任的白界。
- 将对手的战术改为维持火兽主体在油槽附近、以外焰逼退、在任受伤后收回最尖火舌，体现控制力而非恶意。
- 章末改为任停止追逐变化最快的白痕，注视持续发热却没有稳定白边的石面；不在本章提出“占据区域”的完整替代模型。
- 删除未登记的 `REN-07`，改为推进已登记的 `REN-06`；`FIRE-01` 已登记中央伏笔矩阵和 Canon Change。
- 第二轮后修订：任原本准备接受中止，听见“界视者只会看”后才请求最后一次观察；第二次误判明确为把真实却只覆盖一小段的局部亮边误当成整体外沿，侧面火舌从未覆盖的空隙伸出；删除“证明自己是在控制火势”等作者解释；将“收缩的灯火”改为“照明范围正在缩小”。

## 最终针对性复核

- 复核完成：Edge 触发条件、场地媒介、Contour 迁移失败、赛恩视角、零的位置、FIRE-01 登记和第22章问题突变空间均通过。审校记录统一为“第21章不稳定迁移第18章已有的 Contour；第22章释放 Bounding Region”。

## 最终结论

- Canon / 连续性：通过
- 文学 / 奇幻感：通过
- 状态：场景卡通过最终双审，可进入正文生产
