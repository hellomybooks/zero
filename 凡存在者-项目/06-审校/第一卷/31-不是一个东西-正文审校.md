# 第三十一章《不是一个东西》正文审校

## 状态

- 正文：`05-正文/第一卷/31-不是一个东西.md`
- 场景卡：`04-第一卷设计/章节卡/31-不是一个东西.md`
- 结果：通过 / 定稿候选
- 审核方式：逐项 Canon、连续性、文学性、奇幻感与正文禁用项复核

## Canon 与连续性

- 通过：承接第30章“环境变化”“同环境变化”，清晨墙脚与旧石板分别出现相反方向的灰尘变化，并推进为“归属未定”。
- 通过：本章危险不是再次搬运石板；石板保持在原位，墙脚木栏与石板立架的支架同时受力，形成两个搬运者分别面临险情的行动选择。
- 通过：任先保护两名搬运者，再讨论一个或两个；赛恩、露米和伊莉亚各自保持受力、证据和治疗边界。
- 通过：赛恩坚持“存在应有几何结构”，任提出“那如果只是我们看不出来”；双方没有被轻易说服。
- 通过：学院新增“归属未定”，不确认一个、两个或多个目标；任没有重新开启白界，也没有发现未知存在的数量、形状、来源或弱点。
- 通过：零听见命名问题后提出“如果没人能确认它是什么，就可以随便给它取名吗”，关系余波与 `Z-08` 连续；任以“我不知道”回应，没有立即和解。
- 通过：正文未出现 API、OpenCV、Edge、Contour、Bounding、Foreground、Background、FAIL-01、VOID-01、Alpha、代码、计算机、观察层或作者侧章节引用。

## 文学与奇幻感

- 开场以旧石板、墙脚灰尘和学院清理工作承接上一章，迅速进入“两处同时变化”的新谜题。
- 观察问题具体落在灰尘方向、木楔、支架、灯影和两名搬运者的撤离选择上，没有变成脱离现场的哲学讲义。
- “一个”“两个”“归属未定”反复出现，但每次承担不同功能：现场判断、行动决策、学院记录和关系试探。
- 任与赛恩的理念争论通过三块石片、木尺和真实受力展开；露米保持证据边界，避免给出答案。
- 零的命名问题延续被替换恐惧，任的迟钝通过停顿和未出口的解释表现；章末保留第32章“谁画边界”的接口。

## 最终检查

- 场景卡必备事件均已落地：同时受力、理念争论、先行动后命名、学院保守记录、零的关系问题和“同一个东西”章末认知。
- 正文保持近距离第三人称；零的情绪通过轮廓、退后、停顿和不回头表现，没有进入零的内心。
- 技术概念只转化为魔法现象、危险、记录规则和人物判断，没有成为 API 教程。

最终结论：通过，标记为定稿候选。下一生产目标：准备并审定第32章《边界是谁画的》场景卡。
