# 第一卷《白色边缘》现象—术语—限制矩阵

## 回归目的

这份矩阵把第一卷的技术隐喻检查拆成可复查的四个问题：读者先看见了什么现象，任在何时才产生术语联想，能力在哪里失败，以及故事为此付出了什么代价。术语是任的翻译语言，不是当地人的 API 咒语。

## 第一卷已落地概念

| 概念 / 登记 | 故事先行的现象与章节 | 术语进入方式 | 失败条件与代价 | 正文边界结论 |
|---|---|---|---|---|
| Edge / CV-02 | 第5—7章：追杀、白线短暂显现、墙石与人的外沿可见，完整魔物仍不可见 | 任在第5章后开始给边缘命名；`Canny` 在第6章末只是私人联想，第7章被零误听成人名 | 噪声、伤势、呼吸和观察条件会让白界过载或消退；误判会使任和同伴失去时机 | 现象先于词；术语不能重开白界或直接显形 |
| Contour / CV-03 | 第18章：活性目标、反光和背景暗线混杂，任只把同向连续的边缘收拢成不规则闭环 | 任在闭合经验之后浮出 `Contour` 标签，不调用函数 | 反光会成空环，尾部会被误分，转向会使闭合滞后；成功只维持十余息 | 闭合是对“是否同一目标”的暂时判断，不是对象本体 |
| Bounding Region / CV-04 | 第22—23章：动态火兽、烟、热和油槽先被透明范围包围，再逐段收窄到接近一块方石 | 任事后可能在木记板边写下 `Bounding Region`；“一平方米”是私人近似 | 范围会包含非火区域，框外火势会越界，框内仍有危险；肩伤、呼吸和多人协作承担代价 | 范围改变问题规模，不等于识别、结界或安全 |
| Closing / CV-09 | 第25—26章：清除裂口残屑、让仍相邻的两侧靠拢、用替代材料加固，修好后仍留下接缝 | 伊莉亚通过短咒、压力、固定带、针线和药泥完成；正文不说 `Closing` | 缺失材料、错误对齐、对象不稳定和承重限制不能被咒语绕过；修复会改变通行路线 | 技术概念服务于伊莉亚的修复伦理，不是万能治疗 |
| 失去边缘 / CV-02 失效段 | 第27—29章：白界能显示环境外沿，却在袭击者处留下空洞；攻击改变木板、绳线和灯火，却没有可复验命中 | 任先把失败当作“目标无边”，后来被迫承认“观察没有稳定回声”；正文不出现高层术语 | 对象与背景无法分开，重复观察得不到同一结构；零的力量因此被误判为“没用” | 失败本身是事件和关系代价，不是技术演示的错误提示 |
| Foreground / Background | 第30—31章：灰尘、灯影、墙、石板和遮布的变化保持同一环境纹理，观察者无法稳定指出独立目标 | 概念只保留在结构化设定；正文使用“前面的东西”“后面的关系”等自然语言 | 变化可见却不能说明归属；任开始怀疑是自己先切出了对象和背景 | 主题通过观察错误发生，不由角色讲成结论 |
| ROI / 有限区域 | 第31—32章：任不再试图同时解释全场，先把问题压到一小块、可比较的石灰与石片区域 | 只作为结构化翻译方向；正文写区域、石灰、绳、灯影和两侧差异 | 选错区域会排除真实危险；区域集中压力并制造新的错误 | 有限观察是注意力与权力边界，不是安全视窗 |
| Mask / 人工定界 | 第32—35章：先画区域使内外产生差异，再由零选择短界的一侧，最后多人以锚点共同承担边界 | `Mask` 只存在于章节卡和结构化登记；正文写石灰、绳、石片、线、里面和外面 | 人工划分第一次加重零的断裂；线会受击、区域需拆除，保护不能替对方决定 | 定义先于检测，但定义带有排除、伤害和责任 |
| Inside / Outside | 第35章：三处锚点、多道开放白线和多人分工让不可识别压力拥有可受击的“里面” | 作为章名和任的翻译概念出现；不是 API 触发 | 受击会留下裂纹，边界必须允许拒绝、拆除和先救人；零主动承担交界处风险 | 人物选择与共同承担先于几何术语 |
| Mat / View | 第36章：遗迹回应站位、火光、水面和触碰；残碑残留 `...Mat...View...`，倒影慢一拍 | 只保留残缺文字和任的错误模型；不能补全、运行或解释 | 文字残缺、观察条件改变、倒影与现实不一致；任的模型立刻失效 | 只打开 Representation 谜团，不回答世界本体或谁定义规则 |

| HoughLines / HoughCircles | 未在第一卷正式落地 | 保留给后续几何事件；不得用遗迹或火兽回填为已掌握能力 |

| Alpha / Channel / Layer / OpenCV | 作为长线翻译和本体边界登记，未在第一卷正文承担施法或解释 | 禁止写成零的完整身份、当地咒语或世界源码 |

## 回归结论

- 已落地概念均有“现象 → 任的局部联想 → 限制 / 代价”的证据链。
- 术语密度最高的第24章“函数调用”仍只属于任的私人联想，继续作为 P3 观察项，不在无外部反馈时改稿。
- 本矩阵不新增 Canon，不改变正文；后续修改任一支柱章、正式术语时必须重跑本矩阵与技术隐喻边界回归。
