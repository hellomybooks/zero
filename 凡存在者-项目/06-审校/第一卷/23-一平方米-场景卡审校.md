# 第23章《一平方米》场景卡审校

## 审校对象

- 文件：`04-第一卷设计/章节卡/23-一平方米.md`
- 来源：`36章导演卡-v7.md` 第23章段落
- 依据：CANON 唯一真源 v1.0、技术概念登记表、伏笔矩阵、Canon Change、第21—22章场景卡与正文审校记录
- 当前状态：最终双审通过，场景卡可作为正文生产依据

## 审校重点

- 是否直接承接第22章过大的透明范围、火兽未熄和教师/对手/媒介状态，不重置战斗。
- 收窄是否通过现实后果和可验证位置发生，而不是任意志拖动透明边或透明范围物理捕获火兽。
- 是否至少有一次错误收窄与现实危险，保留任的能力代价和不完整识别。
- “一平方米”是否是标准方石大小的粗略私人翻译，不变成精密测量或 API 讲解。
- 最终越级胜利是否依赖教师封断外侧媒介、对手收回核心火势和同伴有限信息，而不是单人无敌。
- 全学院安静、掌声爆发和赛恩慢半拍鼓掌是否推动关系与世界观，而非只做爽点特效。

## 第一轮独立审查记录

第一轮不通过，提出以下必须修复项：

- 错误收窄必须明确为任误把烟下方/旁侧仍在供火的油膜或热区排除，火焰沿现实媒介从边外出现，不能像由范围删除产生。
- 最终代价必须保留一块看似冷却、实际仍可能有热的石面，不能把不确定性提前消除。
- 第22章残余白界只能短暂加深或闪烁，不得写成第23章重新开启能力。
- 第22章末浅水盘已经推近白石线且水已漫出，不能在本章重置到原位。
- 透明范围应写成现实媒介处理后的观察结果，不得写成任直接删改、物理捕获火兽。
- “全学院先安静后爆发”需给出看台、拱廊和相邻课场高窗的在场依据；赛恩应写成进一步意识到记录不能完全先于任，而非第一次产生该认识。
- `BBOX-01` 的章节归属需明确：第22章首次形成过大的范围，第23章首次收窄到接近方石大小。

## 修订记录

- 将第22章末浅水盘状态改为已推近白石线、水已漫出半边；教师、湿布、油槽和对手均按持续状态承接。
- 将“白界再次回返”改为残余白界在高压叠加下短暂加深，明确不是新开启、不能召回或延长。
- 将收窄的因果改为：任指出现实位置，教师/助手/对手处理现实媒介，任随后在残余白界中观察到范围变窄；透明范围不阻挡火焰。
- 补出错误收窄、油膜从边外重新供火、肩伤/呼吸代价，以及最终保留仍可能有热的石面。
- 弱化“标准方石”的预设用途，改为本章现场出现的边缘规整方石；“一平方米”保留为任对其尺度的私人近似。
- 补足公开练习场周围看台、拱廊和相邻课场高窗的师生在场；赛恩的关系推进改为“进一步感到精确记录无法完全先于现场判断”。

## 最终双审记录

- Canon / 连续性：通过。第22章透明范围的首次形成与第23章首次收窄已分开；浅水盘、残余白界、油槽和教师封术状态连续；没有重新授予观察许可。
- 文学 / 奇幻感：通过。错误收窄、现实危险、多人有限协作、方石尺度、全场安静与掌声爆发形成完整爽点链；任没有变成无代价全知者，赛恩慢半拍保留关系余震。
- 技术边界：通过。Bounding Region 仍是观察结果，不是结界、笼、对象本体或自动封火；未提前引入 `minAreaRect`、Mask、ROI、Hough、Ground Truth、Inside / Outside 或世界本体解释。

## 最终结论

Canon / 连续性与文学 / 奇幻感最终双审通过，场景卡标记为定稿候选，可进入第23章正文写作。
