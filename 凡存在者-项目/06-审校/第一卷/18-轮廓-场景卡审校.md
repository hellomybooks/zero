# 第18章《轮廓》场景卡审校

- 文件：`04-第一卷设计/章节卡/18-轮廓.md`
- 前置依据：第15—17章场景卡、正文与审校记录、第一卷总控、Canon v1.0、人物圣经、伏笔矩阵、技术概念与魔法翻译表
- 当前状态：通过最终双审，可进入正文生产

## 第一轮独立审查记录

### Canon / 连续性

第一轮 Canon 复核发现五项必须收紧的问题：课堂目标在“复杂魔物 / 活性映兽 / 折尾兽”之间未锁定；第17章“一晚许可”不能延续到次日课堂；课堂固定钉与第15章赛恩交给任的普通金属固定钉需要区分；材料和固定钉的动作职责不统一；局部运动判断需要限制在相邻观察，不能提前长成追踪或预测能力。另发现“折尾兽”尚未与第21—23章预留的火兽明确区分。

主智能体已完成修订：第18章固定为次日下午；零不进入课堂；折尾兽登记为独立的真实活体课堂练习兽，不等于后续火兽，课堂人物只称“目标”或“槽中活物”；课堂材料统一为细灰粉、短铜线和三枚白色固定钉；固定钉只稳定石槽平面与安全边界，白线不得触碰；赛恩负责调整固定钉，任负责边缘归属；任只比较相邻两次观察中的少数局部边缘变化，不预测下一步。

最终 Canon 复核通过：未提前把 `Contour` 写成咒语；未在故事现象中引入 Bounding Region、Mask、Inside / Outside、Ground Truth、光流或追踪；第15章普通金属固定钉与本章课堂器材已分层；第17章许可时间连续；`CONTOUR-01`、`REN-06` 改为“本章落地”。

### 文学 / 奇幻感

第一轮文学复核认为核心事件成立，但要求加强第一次闭合的临界危险，并集中章末悬念。主智能体已补入：最后一小段白线悬空，任等待活体目标的少数边缘再次朝同一方向挪动，白线才贴回亮痕；闭合后被白线选中的边缘产生暂时牵制，水面与水纹出现不同状态，随后尾端触碰未被接上的灰粉。

章末已删去“起点是否可靠”“回得来的线是否唯一”等并列问题，只保留“未被白线接上的尾端是否仍属于刚才的目标”这一主悬念。固定钉、白线、反光、灰粉和热光反弹均有可执行的现场动作；`Contour` 继续作为任在危险和成功之后写下的私人旧世界标签，不承担施法功能。

## 最终双审结论

- Canon / 连续性：通过，可进入正文生产。
- 文学 / 奇幻感：通过，可进入正文生产。

## 正文执行硬约束

1. 折尾兽只作为作者侧固定称谓；任和课堂人物第一次只称目标或槽中活物。
2. 白线由细灰粉显现，由短铜线牵引；三枚白色固定钉只稳定平面与安全边界，白线不得碰钉。
3. 任只比较眼前相邻观察中的少数局部变化，不预测目标下一步，不出现光流、追踪、速度或完整运动场。
4. 先写空环、尾部误分、固定钉反弹和活体危险，再写任的闭合；`Contour` 只能在事后作为私人标签出现。
5. 白线只牵制被选中的边缘结构；不能把闭合写成完整结界、识别身份或证明目标本体。
6. 章末只保留未接尾端的归属悬念，不提前进入 Bounding Region。
