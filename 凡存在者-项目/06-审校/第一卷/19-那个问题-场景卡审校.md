# 第19章《那个问题》场景卡审校

## 审校对象

- 文件：`04-第一卷设计/章节卡/19-那个问题.md`
- 前置依据：第18章场景卡、正文与审校记录、第一卷总控、36章导演卡 v7、Canon v1.0、伏笔矩阵、技术概念与魔法翻译表

## 审校重点

- “边缘定义物体”是否先作为学院操作规则，而不是世界终极真理。
- 两枚黑石的课堂实验是否具体、可视化，并保持“当前不可区分”而非偷换为同一物、复制品或幻影。
- 任的问题是否从第18章尾端未接自然推出，且没有通过旧世界术语直接回答。
- 教师是否只受课堂方法边界限制，不突然解释世界本体。
- 赛恩是否保持求知兴奋，不提前进入嫉妒；露米和零的能力、出场边界是否连续。
- 是否不提前引入 Bounding Region、Mask、Inside / Outside、Ground Truth 或其他后续概念。
- 章末是否把问题留给读者，并自然转入第20章《一分》。

## 第一轮独立审查记录

### Canon / 连续性与技术边界

第一轮审校发现三项必须修复：时间文字曾把“第18章后的第二天下午”与“前一日的闭合痕迹”混用；遮光后单纯“交换位置”会让学生直接推知原对象位置；白线标记状态不清，容易被理解为附着在黑石上。另要求明确两枚黑石是两个真实、独立登记对象，未解决的只是打乱后无法判断对应身份，而不是它们是否真实存在。

主智能体已修订：统一为第18章后的次日下午、上一堂课留下的闭合痕迹；白线在遮光前熄灭，只在木板上留下记号；教师把两个铜框移开、打乱次序并随机放回，学生只知道位置改变，不知道对应关系；两枚黑石锁定为真实、独立登记对象。最终 Canon 复核确认：课堂不可区分结论是条件性的，未提前引入 Bounding Region、Mask、Inside / Outside、Ground Truth 或其他后续概念。

### 文学 / 奇幻感

第一轮审校认为双石方向成立，但要求让“边缘定义物体”先产生具体制度效果，澄清双石闭合的先后逻辑，给白线同时变细明确的到期原因，把一行/两行记录争议写成实际术式危险，并锁定赛恩翻书地点。

主智能体已修订：闭合记号可转印到搬运木牌并允许铜框通过固定光门；遮光后重新观察两枚黑石，白线不随对象移动；白线同时变细是短时术式到期与铜框受热，不是世界回答任；记录员把两行压成一行时白痕分叉，险些烧穿木板；赛恩固定在外院图书室几何阅览桌翻书。

## 最终双审结论

- Canon / 连续性：通过，可进入正文生产。
- 文学 / 奇幻感：通过，可进入正文生产。

## 正文执行硬约束

1. 两枚黑石是两个真实、独立登记对象；问题只针对打乱后当前观察无法判断对应身份。
2. 白线先短时闭合，随后熄灭并只在木板留下记号；没有任何白线跟随黑石移动。
3. 遮光板后必须是移开、打乱、随机放回，不得写成学生知道的简单互换。
4. “边缘定义物体”是学院的操作规条；搬运木牌、固定光门和记录板失稳要先于抽象讨论出现。
5. 任只提出问题，不获得新能力；教师不解释世界本体；赛恩保持求知兴奋，露米不替任回答，零不入课堂。
6. 不提前引入 Bounding Region、Mask、Inside / Outside、Ground Truth 或现代说明。
