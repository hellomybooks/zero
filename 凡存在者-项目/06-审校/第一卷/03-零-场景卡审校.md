# 第 3 章《零》场景卡—审校记录

## 审校对象

- 文件：`04-第一卷设计/章节卡/03-零.md`
- 类型：结构化场景设计，不是小说正文
- 审校日期：2026-08-15
- 审校方式：两名只读子智能体分别进行 Canon 连续性审计与小说编辑 / 奇幻感审读

## Canon / 连续性审计

### 已确认

- 零的首次出场严格遵守 v7：偷食物，不救任，不驱逐不可见追杀者。
- 没有提前泄露 Alpha、Copy、Observed、Mat 或世界本体真相。
- 手机光源已限定为第 1 章确认存在的“手机屏幕冷光”。
- 食物道具固定为一直放在裤袋内层的被压扁能量棒，不再保留二选一。
- 三处伤势来源已固定：肩部旧伤、背部擦伤、石缝造成的手指伤。
- 零对追杀者的判断只能依据灰尘和碎石等局部迹象，不具备系统提示式全局识别。
- 已补充碎石空地通往废弃猎人小屋的空间过渡。

### 保留的限制

- 零的名字只通过简短对话确定，不解释来源。
- “没有正常影子”“光线异常”“轮廓平移”只作为现象，不给出灵魂、投影、复制或数据结构解释。
- 结构化卡片可以记录后期术语作为作者侧禁区，但这些术语不得直接进入第 3 章正文。

## 小说编辑 / 奇幻审读

### 已确认

- “那是我的 / 现在不是了”能在第 2 章高潮后制造荒谬感，同时保留危险背景。
- 零有独立即时目的：它原本就在寻找可食之物，不是围绕任生成的引导角色。
- 任跟随零是生存判断，不是信任或情感依赖。
- 场景卡要求对白由动作推动，避免把零写成设定问答窗口。
- 手机、银白植物、石缝灰尘、伤势和食物都成为可写的行动媒介。

### 正文执行警告

- 食物戏中必须让石缝和不可见追杀者的压力仍在场，不能突然变成安全喜剧。
- 零可以嘴贱，但不能只负责吐槽；它必须保持自己的边界和行动方向。
- 不要逐项总结零的全部视觉异常，以免像技术概念展示清单。
- 第 3 章最终钩子必须仍然落在“你味道不对 / 不知道”，推动第 4 章而不解释任的异常。

## 结论

**通过，场景卡可进入正文生产。**

本记录只审定结构化设计，不代表第 3 章正文已经通过；正文写入后仍需建立独立正文审校文件。
