# 第26章《修好》正文审校

## 审校对象

- 正文：`05-正文/第一卷/26-修好.md`
- 场景卡：`04-第一卷设计/章节卡/26-修好.md`
- 对照：第25章《伊莉亚》正文与审校、Canon 唯一真源、人物圣经、伏笔矩阵、36章导演卡-v7
- 当前版本：正文初稿；共 677 行，约 1.68 万字节

## Canon / 连续性复核

通过。

- 开头承接第25章翌日：零的新断口由伊莉亚“接住”后仍留暗线和动作限制；第12章旧缺口没有消失；任的肩伤仍在。
- 任尝试召回白界，只得到短促、不完整的白光残留，不能定位零的伤口；没有提前进入第27—28章的无边敌人与全面失效。
- 第25章留下的同一只裂陶碗贯穿本章，药泥、细金属线和缺失小块均保留；理论上最多承受少量温热水，但本章明确只装冷水。
- 伊莉亚对陶碗、药箱扣环、训练标杆、术靶、木盆、遮光布和木盒的处理均依赖现实材料、清理、对齐、固定、替代材料或承重/冷热限制，没有凭空补回缺失部分。
- 遮光布修复后改变固定灯下的阴影路线；零明确说出“你修好的是布，不是这里”，自行选择更窄的暗边路线，没有被写成服从者。
- 零明确拒绝继续调整固定带：“我还没坏。”伊莉亚退开，但转而整理无人要求的药架，`E-01` 从可靠照护推进到无声依赖与边界摩擦。
- 章末只保留无法判断来源的沉闷响动，没有宣布后续袭击；第27—29章与第33章接口均保留。

## 文学 / 奇幻感复核

通过。

- 章节以清晨复查进入，随后由陶碗、药箱、训练器具、木盆和遮光布逐步扩大“修复”的社会范围；每次修补都带来新的使用限制或关系变化，没有写成能力清单。
- 伊莉亚先通过真实有效的处理赢得信任，再由未经请求地拿走木盆、重排阴影路线和反复检查接缝显出温柔控制；她没有被提前写成反派。
- 任的作用保持为观察者：他能看见“能用”和“恢复原状”的差别，却不能替零治疗或替伊莉亚下结论。
- 零保留玩笑、拒绝、路线选择和对“有用”的敏感，不因受伤或受助失去主体性。
- 赛恩只在训练器具的支点与承重上提供有限结构判断，不抢走伊莉亚与零的关系中心。
- 章末的平静来自物品暂时恢复使用，而不是危险被解决；水面、接缝、暗边和沉响共同留下不安。

## 技术隐喻与语言边界

通过。

- 未发现 `Morphology`、`Erode`、`Dilate`、`Opening`、`Closing`、`Mask`、`Foreground`、`Background`、`Inside / Outside`、`Alpha`、`Mat / View`、`Observer / Observed`、`Ground Truth` 等禁用概念。
- 未发现作者侧章节编号或现代互联网梗；“修好”仍是世界内部人物对暂时可用状态的日常说法。

## 最终针对性复核

- 重新核对第25章同一只裂陶碗：正文没有改称裂杯，少量温热水的理论承受范围与本章只装冷水的安全决定均保留。
- 重新核对零的旧缺口、新断口和任的白界局部不回应：正文没有把“接住”升级为治愈，也没有把局部失败升级为全面失效。
- 重新核对遮光布、暗边改路、零的拒绝和章末沉响：动作均有现实后果，未提前宣布下一章事件。
- 通过项目级禁用词与作者侧章节编号扫描；仅保留正文标题中的章节名。
