# 《凡存在者，必有其界》

*All Things Have an Edge*

一部长篇思辨奇幻小说，计划 **7 卷 / 252 章 / 21 个主要篇章**。核心问题不是“世界是不是一段代码”，而是：我们总要通过观察、描述、分类、地图、记忆与模型来行动，但这些表示从来不等于存在本身。
