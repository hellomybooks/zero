# All Things Have an Edge

**《凡存在者，必有其界》 / All Things Have an Edge** is a long-form speculative fantasy project built around one central idea:

> A representation is useful, but it is not the thing itself.

The current primary manuscript follows Ren, Zero, Lumi, Sain, Elia, and Nox across a world where perception, classification, mapping, repair, prediction, copying, and shared truth can all become forms of power.

## What is authoritative?

The current Canon file is authoritative for locked setting decisions. Historical chats, old Story Bible versions, outlines, prose, and review notes are supporting evidence or working material and must not silently overwrite Canon.

If there is a conflict, read:

1. `STATUS.md`
2. the authoritative Canon
3. the relevant current volume material
4. continuity / review records only when needed

Do **not** start by reading the entire historical archive.
